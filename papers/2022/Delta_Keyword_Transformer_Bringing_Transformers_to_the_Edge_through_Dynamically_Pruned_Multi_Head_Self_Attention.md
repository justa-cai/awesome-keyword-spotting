# Delta Keyword Transformer: Bringing Transformers to the Edge through Dynamically Pruned Multi-Head Self-Attention

- **作者/机构**: Zuzana Jelcicova (丹麦技术大学; Demant A/S), Marian Verhelst (MICAS, 鲁汶大学, 比利时)
- **发表日期**: 2022年3月 (tinyML Research Symposium 2022)
- **链接**: https://arxiv.org/abs/2204.03479
- **关键词**: Transformers, delta computations, pruning, compression, keyword spotting, edge devices, multi-head self-attention

## 问题陈述

### 问题背景和领域痛点
Transformer架构通过多头自注意力（Multi-Head Self-Attention, MHSA）机制在关键词识别任务中展现了卓越的性能（如KWT系列模型在GSC-12上达到98.4%的准确率）。MHSA能够建模输入序列中任意两个token之间的关系，从而捕获全局的声学依赖——这对于区分在局部特征上相似但全局时间结构不同的关键词（如"yes"和"yet"）至关重要。

然而，MHSA的计算复杂度随序列长度呈二次增长：对于长度为$N$、特征维度为$d$的序列，标准MHSA需要$O(N^2 \cdot d)$的乘加操作和$O(N^2)$的存储空间。在KWS中，典型的输入长度$N=40$（40个时间帧），$d=64$，单层MHSA需要约$40^2 \times 64 = 102,400$次乘加操作。叠加12层Transformer后，MHSA层的计算量占整个推理的60-80%，成为在资源受限的边缘设备上部署Transformer的主要瓶颈。

### 现有方法的具体不足
- **需要重新训练的剪枝方法**：结构化剪枝（如移除整个注意力头、层剪枝）或非结构化剪枝（如权重幅度剪枝）通常需要在剪枝后进行微调或重新训练以恢复性能。这意味着剪枝是一个离线的、耗时的过程，无法在推理时根据输入动态调整——而实际上，不同的输入样本有不同的"计算难度"（如安静环境下的语音比噪声环境下的语音更"规则"，可能有更多冗余计算）。
- **粗粒度剪枝的信息损失**：现有的动态剪枝方法通常以token为单位（跳过整个token的计算，如DynamicViT、SpAtten）或以注意力头为单位（移除整个头的计算，如Head Pruning）。这种粗粒度操作的问题在于"全有或全无"——要么完全保留一个token/头的所有信息，要么完全丢弃。在KWS中，一个时间帧可能包含部分判别性信息和部分噪声，粗粒度剪枝无法"保留有用的部分、丢弃冗余的部分"。
- **需要专用硬件的稀疏计算**：非结构化剪枝产生的不规则稀疏模式（即权重矩阵中随机分布的零值）需要专门的稀疏矩阵运算硬件（如GPU的稀疏张量核心或定制的稀疏加速器）才能获得实际加速。在通用的ARM Cortex-M系列处理器上，稀疏卷积的实现需要引入大量的条件分支（if-else）和间接索引操作，实际加速效果远低于理论值，有时甚至比密集计算更慢（因为条件分支打乱了流水线）。
- **语音信号时间冗余的未被利用**：语音信号的一个基本特性是"短时稳定性"——在约10ms的帧移间隔内，相邻帧的频谱特征高度相似（相关系数通常>0.95）。这种时间冗余意味着相邻帧的MHSA计算中存在大量重复，但现有的剪枝方法未系统性地利用这一特性。

### 该论文要解决的关键挑战
设计一种无需重新训练、细粒度（特征维度级别而非token级别）、且仅需通用硬件支持的MHSA动态压缩方法，利用语音信号的时间稳定性，使预训练的Transformer KWS模型能够高效运行在边缘设备上。

## 方法论

### 整体架构设计和设计动机
Delta Keyword Transformer（Delta-KWT）的核心观察植根于信号处理领域的经典概念——delta特征。在传统的语音识别中，delta cepstrum（一阶差分倒谱）和delta-delta cepstrum（二阶差分倒谱）被广泛用于捕获语音的动态变化。这一概念的隐含假设是：语音信号的"变化"（delta）携带了比"绝对值"更多的判别信息，且相邻帧之间的"不变部分"是冗余的。

Delta-KWT将这一思想应用到Transformer的推理过程中：在MHSA计算中，如果相邻token的特征向量差异很小（即delta很小），那么两者的MHSA计算结果也应该很相似，因此可以跳过变化量小的计算，直接复用前一帧的结果。

### 核心算法的数学原理：Delta阈值剪枝

设Transformer第$l$层的MHSA计算为标准流程：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V$$

其中$Q = XW_Q$、$K = XW_K$、$V = XW_V$，$X$为输入特征矩阵。

**Delta判断过程**：

对于序列中第$t$个token的特征向量$x_t \in \mathbb{R}^d$，计算其与前一个token的特征差异：

$$\delta_t = |x_t - x_{t-1}| \in \mathbb{R}^d$$

这是一个逐元素绝对差操作。对于每个特征维度$j$，进行阈值判断：

$$\text{skip}_t[j] = \begin{cases} 1, & \text{if } \delta_t[j] < \tau \\ 0, & \text{if } \delta_t[j] \geq \tau \end{cases}$$

其中$\tau$是预设的Delta阈值。

**特征传播策略**：

被标记为"冗余"的特征维度（$\text{skip}_t[j] = 1$）直接复用前一个token的计算结果：

$$x_t^{(l)}[j] = \begin{cases} x_t^{(l)}[j], & \text{if } \text{skip}_t[j] = 0 \\ x_{t-1}^{(l)}[j], & \text{if } \text{skip}_t[j] = 1 \end{cases}$$

这一替换在MHSA的所有子步骤中递归应用：

1. **Q/K/V投影**：$Q_t = X_t W_Q$ 中，被跳过的维度直接用$Q_{t-1}$的对应维度替代。这节省了投影矩阵乘法的计算。
2. **注意力分数计算**：$S_t = Q_t K^T / \sqrt{d_k}$ 中，由于$Q_t$的某些维度被替换，$S_t$与$S_{t-1}$的差异减小。
3. **注意力加权求和**：$\text{out}_t = \text{softmax}(S_t) V$ 中，进一步减少计算量。

**Delta管道的累积效应**：由于替换是递归的（第$t$帧的冗余维度复用第$t-1$帧，而第$t-1$帧可能复用第$t-2$帧的结果），在一段连续稳定的时间段内（如元音的稳态部分），只有第一个帧需要完整计算，后续帧的大多数维度可以直接"传递"。

### 无需训练的关键设计

Delta-KWT的关键创新在于它是一个纯推理时的优化，不修改模型的任何权重或架构：
- **无需修改模型**：不改变Transformer的层数、注意力头数、隐藏维度等架构参数
- **无需校准数据集**：不需要代表性的数据来统计权重的重要性分布（如幅度剪枝所需）
- **无需微调或重新训练**：不需要任何训练过程来恢复性能损失
- **即插即用**：可以直接加载任何预训练的Transformer模型（如Hugging Face上的开源KWT模型）并应用Delta剪枝
- **动态可调**：阈值$\tau$在推理时设置，可以根据设备的实时资源状况（电池电量、CPU负载）动态调整——高资源时使用小阈值（高精度），低资源时使用大阈值（高效率）

### 细粒度优势的量化分析

Delta方法的核心优势在于"特征维度级"的细粒度：
- 对于一个典型的KWS输入（40个时间帧，每帧64维特征），每个token中通常有50-80%的特征维度可以被跳过（因为语音信号的时间连续性导致相邻帧的特征向量高度相似）
- 具体而言，对于语音的"稳态段"（如元音的持续部分），相邻帧差异主要来自频谱的随机波动，可跳过比例高达80-90%；对于"过渡段"（如辅音到元音的过渡），可跳过比例降低到30-50%
- 相比token级剪枝（整帧跳过或整帧保留），Delta方法在同一帧内实现了"选择性计算"——稳定的维度被跳过，变化的维度被保留

### 硬件友好的实现

- Delta判断仅需简单的比较操作（$|\delta_t[j]| < \tau$），这些操作在所有通用处理器上都是最高效的指令之一（ARM Cortex-M上仅需1个时钟周期）
- 不需要稀疏矩阵运算硬件——跳过的特征维度被直接替换为前帧的值，输出仍然是密集张量（与稀疏剪枝产生的不规则稀疏矩阵不同）
- 内存访问模式保持规则（连续的帧按顺序处理），有利于缓存利用
- 额外的存储开销极小：仅需保存前一帧的特征向量（$d$个浮点值）和delta判断结果（$d$个布尔值）

### 实验设置
- 在预训练的KWT-1模型上评估（Google Speech Commands数据集，12类分类）
- KWT-1包含12层Transformer编码器，原始准确率98.4%
- 每层Transformer包含MHSA（8头注意力，每头8维）和FFN（前馈网络）

## 主要贡献

1. **无需训练的细粒度MHSA动态剪枝**：首次在特征维度级别提出动态剪枝方法，利用语音信号的时间稳定性实现高效推理。该方法将"delta计算"这一经典信号处理概念与现代Transformer架构巧妙结合——delta cepstrum的物理直觉（语音的判别信息在"变化"而非"绝对值"中）在Transformer的注意力计算中找到了新的应用场景。

2. **即插即用的模型后处理**：方法可直接应用于任何预训练Transformer模型，无需修改模型架构或重新训练。这在工业部署场景中具有极高的实用价值：开发者可以直接使用Hugging Face上的预训练KWT模型，通过调节一个超参数（Delta阈值）在精度和效率之间灵活权衡，部署时间从数小时缩短到零。

3. **极致的操作减少**：在80%操作减少时保持98.4%原始准确率（4.2倍加速），在87-94%操作减少时仅损失1-4%准确率（7.5-16倍加速）。这些数字远超同时期的其他动态剪枝方法。

4. **纯比较操作的硬件友好设计**：整个剪枝决策过程仅需比较操作，在任意通用处理器上均可高效实现。这使得Delta-KWT可以在不增加任何专用硬件的前提下实现Transformer KWS在边缘设备上的部署。

## 实验结果

### 使用的数据集及其规模
- **Google Speech Commands V1-12**：12个命令词类别，约65,000条1秒语音片段。标准训练/验证/测试划分。

### 评估指标的定义和选择理由
- **准确率（%）**：分类准确率，用于评估Delta剪枝对模型精度的影响
- **操作减少比例（%）**：被跳过的乘加操作占总操作的百分比
- **理论加速比**：基于操作减少比例的估计（假设跳过的操作不产生计算开销）

### 与基线方法和SOTA的详细对比

**核心性能数据（在KWT-1上）**：
| 操作减少比例 | 准确率(%) | 理论加速比 | 准确率损失(%) |
|:---:|:---:|:---:|:---:|
| 0% (原始) | 98.4 | 1.0x | 0 |
| 80% | ~98.4 | 4.2x | <0.1 |
| 87% | ~97.5 | 7.5x | ~0.9 |
| 90% | ~96.5 | 10x | ~1.9 |
| 94% | ~95.0 | 16x | ~3.4 |

关键发现：在80%操作减少（4.2倍加速）时，准确率几乎无损（损失<0.1%）。这意味着语音信号中的80%的MHSA计算确实是冗余的——这些冗余源于语音信号的时间连续性，而非模型设计的冗余。

### 消融实验的发现

**阈值敏感度分析**：
Delta阈值$\tau$在$[0.01, 0.1]$范围内，准确率-操作量权衡曲线呈现平滑的递减关系（没有突变点）。这表明方法对阈值选择具有良好的鲁棒性——在实际部署中，开发者不需要精确定位某个"最优"阈值，而可以在一个较大的范围内选择合适的权衡点。

**不同层的剪枝分布**：
- Transformer底层（第1-4层，靠近输入）：被剪枝的比例较高（约85-90%），因为底层特征捕获的是低级声学特征（如频谱能量分布），这些特征在相邻帧之间变化缓慢
- Transformer高层（第9-12层，靠近输出）：被剪枝的比例较低（约70-75%），因为高层语义特征的变化更频繁（反映了关键词的高级语义信息）
- 这一发现与语言学中的"层次化信息处理"一致：低层处理缓慢变化的声学特征，高层处理快速变化的语义特征

**与token级剪枝的对比**：
在相同的操作减少目标（如80%）下，Delta细粒度剪枝比token级剪枝的准确率高3-5个百分点。token级剪枝的80%操作减少意味着需要完全跳过32个token（共40个token中），这导致了严重的信息丢失；而Delta剪枝在每个token中仅跳过80%的特征维度，保留了20%的关键变化信息。

**与静态剪枝（权重幅度剪枝）的对比**：
Delta方法在相同压缩率下准确率更高，因为它保留了"关键变化"（delta大的维度）而非随机保留。静态剪枝可能剪掉了某些权重小但对delta变化敏感的关键连接。

## 局限性与展望

### 方法的技术局限性
- **对时间稳定性的依赖**：Delta剪枝的有效性本质上取决于输入数据中相邻token之间特征差异的大小。对于高度动态的语音信号（如快速语速、爆破音密集的关键词如"stop"、"go"），相邻帧之间的差异可能较大，导致可剪枝的比例降低，加速效果减弱。在极端情况下（如跳变信号），Delta方法可能无法提供显著的加速。
- **阈值的手动调整**：虽然阈值-准确率权衡曲线平滑，但针对特定应用场景（如要求准确率不低于97%）选择最优阈值仍需要人工实验。缺乏自动化的阈值搜索机制（如根据目标准确率约束自动确定阈值）。
- **仅验证于KWT-1**：实验仅在单一的KWT-1模型上进行，该模型是较小的Transformer变体（12层，8头，64维）。对于更大的Transformer模型（如KWT-3的约3M参数、AST-Base的约85M参数），Delta剪枝的有效性可能因模型容量和冗余程度不同而变化。
- **Delta误差的累积**：在递归的特征传播中，每一帧的替换都引入了微小的近似误差。随着序列长度增加，误差可能在层间和帧间累积，导致最终输出的偏差增大。论文未系统分析这种误差累积的长期效应。

### 实验设计的不足
- **加速比基于操作计数而非实测**：论文报告的4.2x-16x加速比是基于乘加操作减少比例的理论估计。实际加速效果受限于：（1）Delta判断操作本身的开销（虽然很小，但在高速推理中不可忽略）；（2）特征替换的内存访问开销（需要读写前一帧的缓存）；（3）条件分支对CPU流水线的影响。未在实际边缘硬件（如ARM Cortex-M4、RISC-V等）上测量端到端的推理延迟。
- **缺乏能效数据**：未报告实际功耗或能量消耗的测量数据。虽然操作减少理论上降低功耗，但比较操作和内存访问的增加可能部分抵消这一收益。
- **噪声条件未评估**：所有实验在干净条件下进行。噪声可能增加相邻帧之间的差异（因为噪声是随机波动的），从而降低可剪枝比例，减弱Delta方法的加速效果。这是一个重要的未验证场景。
- **缺乏与其他动态推理方法的系统对比**：如与动态深度（Dynamic Depth，根据输入选择执行哪些层）、动态宽度（Dynamic Width，根据输入选择执行哪些通道）等方法的对比。

### 未来可能的改进方向
- **自适应阈值机制**：设计基于当前输入特征统计量（如帧间差异的均值和方差）的自适应阈值策略，使剪枝决策更加智能和鲁棒。例如，对于稳态语音段使用较大的阈值（更多剪枝），对于过渡段使用较小的阈值（保留更多信息）。
- **与量化结合**：Delta剪枝与INT8/INT4量化是正交的优化维度。量化减少每次操作的计算开销，Delta减少需要执行的操作数量。两者的联合应用可能带来叠加的压缩效果——初步估算可达50-100倍的综合加速。
- **学习型Delta判断**：用一个小型神经网络（而非简单的阈值比较）来判断哪些特征维度可以跳过，可能更精确地识别真正的冗余计算。
- **扩展到其他序列任务**：Delta计算的思想可应用于语音识别（ASR）、语音翻译等其他使用Transformer处理语音序列的任务。这些任务通常有更长的序列长度（数百帧），Delta方法可能带来更大的加速潜力。
- **对KWS领域的启发**：Delta方法揭示了一个重要洞见——KWS模型在推理时的计算冗余是"有结构的、可预测的"，这种结构源于语音信号的物理特性（时间连续性）。这一洞见可启发更多基于"输入特性"而非"模型结构"的动态推理优化方法。
