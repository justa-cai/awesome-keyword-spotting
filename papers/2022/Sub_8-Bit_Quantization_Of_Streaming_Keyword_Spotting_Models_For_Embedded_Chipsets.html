硬件的量化器不能动？那就把权重养均匀：
流式 KWS 的亚 8 比特全组件量化

Sub-8-bit QAT · Amazon Alexa arXiv 2207.06920 · 生产级 250K 无状态 FFN 26K 小时生产数据 · ARM NEON 实测 全 8 比特仅退化 3.5% · CPU 3.65× · 内存 −75%
一句话：把 Alexa 生产级流式唤醒模型的权重、gain、bias、BatchNorm 四套参数、激活、输入全部压到 8 比特及以下（权重最低到 1 比特），核心思路只有一个——硬件的均匀量化器不能动，就改造数值分布去适配它：tanh 把高斯权重养均匀、C_BN 把 BN 参数搬进窄动态范围、算子重排让 clip 作用在归一化量上。全 8 比特在工作点只付 3.5% 相对退化，ARM NEON 实测 CPU 37.6→10.3 MCPS、内存 912→228KB。
TL;DR
  • 商用 KWS 有三条研究界普遍忽略的隐性约束：亚 8 比特要硬件指令集真支持、必须流式逐帧出后验、不能用可损坏内存——第三条直接决定基线是无状态 FFN（某帧异常下一帧自愈，递归状态会残留污染）。
  • NEON 的 MAC 最小容器是 8 比特：权重压到 4/5 位在通用芯片上不换 CPU 也不换内存，收益只有溢出余量与 OTA 分发体积；直接内存红利要靠专用加速器（投影 4–7×）。
  • 计算图关键：gain 放 MAC 外面——y_q ← α_q(W_q·x_q + b_q)，每层一个标量缩放乘在外面，内积用最稠密的整数指令跑满；逐元素缩放会把 SIMD 打散归零。
  • 精度最大来源是 tanh 权重整形：高斯过 tanh 的概率积分恰好摊平成 U(−1,1)，训练中用目标分布初始化+正则锁住——同一量化器，退化 7.4% vs 12.3%。
  • BN 全四套参数量化靠缩放因子 C_BN：分子分母同除（分母根号内除平方），代数恒等但每个进量化器的数都被压窄——5.3% vs 无缩放 9.0%，杠杆最高的单点技巧。
  • 激活到 8 比特就是墙：权重可继续压到 4/5 比特（静态、可整形），激活分布随输入逐帧漂移只能间接规训——全模型比特下限被激活卡死，不对称。
  • 二值档（1 比特权重）要 2×/6× 参数量换容量，且对学习率极度敏感：恒定 lr 掉 14%，仅把阶段 1 末尾若干次更新的 lr 调小就追平基线（0.4% / −0.4%）。

    • §01问题：常驻端侧的六条约束

    三条显性（体积/内存/功耗）+ 三条隐性（指令集/流式/不可损坏内存）

    生产基线：250K 无状态 FFN

    瓶颈架构 {87,400,87,400,87,400}，全部隐藏层配 BN+ReLU，LFBE 20 维、81 帧滑窗、3 倍时间下采样。唤醒词训练时中心对齐——后验峰位置固定，WMA 平滑+阈值才有稳定对齐前提。这不是学术基线，是 Alexa 的生产形态。

    为什么必须是 FFN 不是 RNN

    「不可损坏内存」红线：递归状态一旦被数值溢出污染会一直残留，唤醒整体失效只能重启；无状态模型某帧异常、下一帧从头开始，天然自愈。前馈结构对整数推理也最友好——全网络就是一串矩阵向量乘，NEON SIMD 满载。

    PTQ 掉点，低位宽有地基

    训练后量化误差无人补偿，小模型上致命。QAT 靠伪量化+STE 直通估计器传梯度（量化函数离散、梯度几乎处处为零）。多数量化工作只处理权重顶多加激活，BN 四套参数留浮点——整数算力优势从最热路径漏光。

    权重分布与量化器错配

    网络权重近似高斯：九成以上挤在零附近窄带，只分到中间少数码字；两侧长尾码字密布却无权重落点——等效于拿大部分精度去表示从不出现的值。改量化器成非均匀会破坏整数 MAC 的均匀格点假设，所以要反过来改分布。

    §02方法：改造分布，适配硬件

    gain 外置的整数 MAC · tanh 概率积分摊平 · 代数恒等缩放
    y_q ← α_q(W_q · x_q + b_q) # 整数域 dense，gain 乘在外面 y_q^φ ← q_z( ReLU(y_q) ) # 激活量化（实测选 clipped ReLU） y_q^φψ← q_z( BN(y_q^φ) ) # BN 量化（带 C_BN 缩放）
    人话：三步恰好对应原网络的计算顺序，整条链路没有任何浮点逐元素运算——这是「全组件量化」的数学含义。gain 若放进 MAC 里（每权重各自缩放），向量化整数乘累加被打散成逐元素乘法，SIMD 吞吐归零。
    W_q ← q_z( tanh(W) ) · 初始化 W ~ N(0, σ_t²) 正则: λ_σ(σ_w − σ_t)² + λ_μ·μ_w²
    人话：若 W 服从合适方差的高斯，tanh(W) 的分布近似 U(−1,1)——高斯过 tanh 这个概率积分恰好把钟形摊平，每个码字承载的权重质量近似相等。只在量化时刻套 tanh 不够（零区陡峭挤压、饱和区复用码字），要训练中就用目标分布初始化+正则把权重「养」成甜点形状。
    x_norm = (x − μ_B)/√σ_B² = (x/C_BN − μ_B/C_BN)/√(σ_B²/C_BN²) x_norm_q ← ( q_z(x/C_BN) − q_z(μ_B/C_BN) ) / √q_z(σ_B²/C_BN²)
    人话：分子分母同除 C_BN（分母在根号内除平方），归一化的数学结果一个字不变——但 μ_B、σ_B² 这类动态范围大且训练中持续漂移的值被压进窄区间，量化分辨率随之提高。这是「把数值搬进量化器甜点区、又不改网络函数」的标准手法，与 tanh 异曲同工。

    激活：clipped ReLU + 算子重排

    ReLU 正半轴无界，线性量化器被迫覆盖大值域导致单位分辨率极差。系统试了 clipped ReLU / sigmoid / tanh / GeLU / SiLU：clipped ReLU 胜出；sigmoid/tanh 反而更差（梯度饱和要更多更新）。同时把 dense→ReLU→BN 交换成 dense→BN→clipped ReLU——clip 作用在归一化后的稳定量上，阈值稳健；块输出有界，恰好对齐 8 比特无符号罐。

    两阶段训练的用意

    阶段 1 只量化权重（tanh 整形效果可单独测量）；阶段 2 对其余组件线性量化+1 epoch（35K 次更新）重估。两层动机：误差归因可追溯——商用发布决策（压到几比特、量化哪些组件）需要每步代价的证据链；权重整形扰动训练动力学，需要全精度组件构成的稳定骨干托底。

    输入量化：第三次同款手法

    LFBE 特征先做全局均值方差归一化，再除 C_input 后线性量化——与 BN 缩放同源：先缩小动态范围，再进量化器。

    验证口径的讲究

    DET 曲线上报告「基线工作点 FRR 处的相对 FDR 退化」：两个错误代价极不对称（误拒伤可用性、误报伤信任与云端成本），固定 FRR 锚点比 FDR 才公平；相对归一化让不同规模模型的数字可直接横比。WMA 平滑参数在 held-out 数据上调，防泄漏。

    图2 · 机制解剖：左是 tanh 整形的分布图景（钟形 → 均匀，训练全程用正则锁住）；右上是 BN 的 C_BN 缩放（代数恒等搬窄动态范围），右下是两个决定成败的排序（算子序 dense→BN→clip、gain 在 MAC 外）。

    读表要点
  • M0→M1 一口气付 3.1%（同时含权重 32→8、参数 32→8、激活 32→16 三重压缩）；激活 16→8 只再 +0.4pp；权重 8→4 到 8.7%——整条曲线没有悬崖，两阶段 QAT+分布整形的直接成果。
  • CPU 的两段收益来源不同：M0→M1 是 32→8/16 比特参数（省 50%）；M1→M2 是 128 位寄存器装 8 个 int8 吞吐翻倍（再省 45%）。M2→M4 的 CPU 纹丝不动——NEON 8 比特地板。
  • 运行时内存 = 模型大小：无状态流式 FFN 没有递归状态没有大缓冲，内存故事干净（912→228KB，−75%）。M3/M4 权重已是 5/4 位内存却不变——同一块地板。
  • 那为什么还要亚 8 位权重？给 16 路累加留溢出余量、允许更低精度累加器、缩小 OTA 分发体积（142/114KB）；真吃内存红利要换加速器——投影 912/128≈7.1×、912/198≈4.6×，即摘要的「4 到 7 倍」。
  • 逐组件阶梯（全 8 比特）：只重量化 3.8% → +bias/gain 4.7% → +输入激活 5.2% → +BN（带缩放）5.3%——每层边际代价 <1pp，「全组件 8 比特」几乎免费；BN 无缩放直接量化 = 9.0%。

    • §04贡献

    五点：从算法到系统级账本
    1

    两阶段全组件亚 8 比特 QAT 算法：阶段 1 tanh 权重分布整形（适配 Strom 等），阶段 2 对 gain、bias、BN 四套、激活、输入做线性量化——覆盖了此前工作普遍留浮点的组件。

    2

    生产规模数据上与全精度工作点打平：全 8 比特仅 3.5% 相对退化、4 比特权重 8.7%；二值权重加扩容模型在学习率调整后 0.4%/−0.4%。

    3

    真实指令集上的系统级收益账本：NEON 实测 CPU 37.6→10.3 MCPS、内存 912→228KB、模型最小 114KB；并讲清「亚 8 比特权重在通用芯片换不到 CPU/内存、换得到溢出余量与分发体积」这个反直觉结论。

    4

    可直接抄的工程配方：BN 动态范围缩放量化（9.0%→5.3%）、激活选型结论（clipped ReLU 胜出）、算子顺序要交换（dense→BN→clip）。

    5

    二值权重的落地投影：M5/M6 在 86.0%/78.3% 内存缩减下保持精度，验证 1 比特权重 KWS 在扩参数量补偿后可用。

    §05局限与判断

    投影不等于实测 · 零外部对比 · FFN 之外未验证
    图4 · 边界与延伸：左技术边界（NEON 无收益、激活 8 位墙、二值靠扩容、超参不公开、仅 FFN），右实验边界（零外部对比、加速器纸面投影、功耗代理指标、无方差）+ 延伸方向。
    可迁移判断

    ↳ 量化器不能动，就动分布：tanh 整形、C_BN 缩放、算子重排全是同族手法——不改网络函数、只改数值分布去适配硬件的均匀格点。遇到「量化掉点」先看分布与量化器错配在哪，而不是急着加比特。

    ↳ 每压一档都要重新核对硬件的最小容器：NEON 的 8 比特 MAC 地板让 4/5 位权重白压——比特数的收益以指令集真实支持为前提，纸面压缩率不等于系统收益。

    ↳ 静态可整形，动态只能间接规训：权重能在训练中被「养」成量化器喜欢的形状，激活的分布随输入逐帧漂移——这解释了两者量化下限的不对称，也提示下一步该做激活侧的分布整形（LSQ 类）。

    ↳ 二值模型的精度挑战可能部分在训练日程而非方法本身：末期大步长让权重符号在临界点反复翻转，仅调小最后若干次更新的学习率就回收 13.6pp——调参的边际收益大到必须先排除再谈方法论。
