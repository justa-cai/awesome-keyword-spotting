换唤醒词，零训练零发版：
81 维嵌入装下开放词表

QbyE-MLPMixer · LG Toronto AI Lab · arXiv 2206.13231 纯 MLP · 免 patch · Hardswish 0.25M 参数 · 20.16M MACs 双全场最小 Hey-Snips + 内部 8 家电词（400 说话人）
智能家电的唤醒词出厂即固定——"Hey LG"之外的词，厂商要重采数据、重训模型、重发版本，链路以周计。QbyE-MLPMixer 让用户用自己的说法注册唤醒词：注册只是几次前向编码，推理退化为一次余弦距离比较，全程零解码零重训。

一分钟版本

  • 任务：开放词表 KWS——用户自定义唤醒词；旧范式换词 = 重采 + 重训 + 发版，本文换词 = 念 3 遍注册，零训练零发版
  • 范式：QbyE（Query-by-Example）——变长音频编码成定长嵌入，同词相近、异词相远；推理只是注册嵌入与查询嵌入的距离比较，无解码 / 无注意力 / 无递归
  • 架构：MLPMixer 音频化三改动——① 免 patch 直接喂 81×81 MFCC（MFCC 已是压缩时频特征，patch 化是视觉的负资产）② 混合轴从 token/通道改为特征/时间（单通道时频输入真正有物理意义的两个轴）③ 时间维平均池化出 81 维嵌入（词位置随机 → 平均天然平移不变）
  • 公式：U = X + W₂σ(W₁·LN(X))（特征维）、Y = (U + W₄σ(W₃·LN(Uᵀ)))ᵀ（时间维）同构交替堆 12 块；块输出形状恒等 → 真超参只有 4 个（h, g, 块数, 激活），ASHA 数百次搜索定隐宽 64
  • 激活：Hardswish 全面优于 GELU/ReLU/SiLU，且分段线性不含指数——硬件更容易实现
  • 推理：1 秒窗 / 100ms 步滑窗（每秒 10 次前向）；注册短 → 对查询做卷积取最小距离（模板滑移对齐）；余弦距离只看方向，对响度漂移免疫
  • 训练：LibriSpeech 1000h 词级切分 + 4–12dB 噪声 + 50% 远场仿真增广；训练词表与评测词零重叠——纯零样本评测
  • 尺寸：0.25M 参数 + 20.16M MACs 双全场最小（参数 = 最小基线的 45%，MACs = 91%）；嵌入 81 维 vs 基线约 1000 维
  • 主结果：Hey-Snips 六场景 FRR@0.3FA/h——条件越苦优势越大（领先次优 2.15 → 8.57 点单调放大）；远场 10dB 的 7.50 几乎只有次优（13.93）的一半
  • 诚实边界：干净近场不是最优（内部集 2.68 vs MobileNetV3 0.62）；优势场景被作者自己清晰限定在噪声与远场

    • §01问题：唤醒词的出厂锁定

    为什么"开放词表"是个真需求，而不是锦上添花

    固定词表的成本结构旧范式

    智能音箱、家电的唤醒词出厂即固定。要换一个词，厂商需要重新采集数据、重新训练模型、重新发版，整条链路以周计。对厂商是成本，对普通用户是完全关闭的选项——你只能用它选好的那个词。

    ASR 转录匹配路线的两硬伤被否路线

    一个直觉方案是跑完整 ASR 再匹配关键词。硬伤一：完整解码与 KWS「常驻低功耗」的定位冲突；硬伤二：关键词落在 ASR 词表外立刻退化——而词表外恰是开放词表的典型用例，路线自相矛盾。

    QbyE 范式：嵌入检索代替判决

    变长音频 → 定长嵌入，训练目标是同词相近、异词相远。推理退化为：查询嵌入 vs n 个注册嵌入的距离比较，距离小于阈值即触发。注册新词 = 念几遍做前向编码，零训练、零发版。

    真正的挑战：分布外 + 资源紧

    注册与查询音频天然落在训练分布之外（训练词表不可能覆盖所有未来词）——模型不能靠记住特定词的判决面过关，必须学出通用的词级音频表征；同时端侧要求低延迟、小内存，编码器必须又小又快。

    图1 · 机制全景：上——任务三路线对比与开放词表三挑战；中——81×81 MFCC 免 patch 输入 + 12 个特征/时间混合块 + 公式(1)(2)(3)；下——滑窗余弦检索与零重叠词表训练协议；底部数字行为全文关键量。

    §02方法：MLPMixer 的音频化改造

    不是拿来就用——三个「去视觉化」决策各有消融背书
    特征混合（公式 1）：U = X + W₂ σ(W₁ · LayerNorm(X))　　W₁ ∈ ℝ^{h×f}, W₂ ∈ ℝ^{f×h}
    时间混合（公式 2）：Y = (U + W₄ σ(W₃ · LayerNorm(Uᵀ)))ᵀ　　W₃ ∈ ℝ^{g×t}, W₄ ∈ ℝ^{t×g}
    时间维平均池化（公式 3）：z = (1/t) Σᵢ O_{:,i}　→　z ∈ ℝ⁸¹
    人话：公式 1 在每一帧内部重组 81 维频谱（这帧像什么音色）；公式 2 在每个频点上重组 81 帧历史（这个频率成分怎么随时间变化）——两个式子完全同构，只换操作的轴。每块都带 LayerNorm + 残差，输出形状恒等于输入，所以可以自由堆叠，真超参只有 4 个（h, g, 块数 n, 激活 σ）。最后公式 3 对时间平均：词在 1 秒窗内位置随机，平均把位置信息抹掉、只留词身份——顺带把嵌入压到 81 维。

    免 patch：直接喂 81×81

    视觉 MLPMixer 要把图像切块成 token。音频这里 1 秒音频（25ms 窗 / 12.5ms 移）恰好产生 81 帧 × 81 维 MFCC 的方阵——MFCC 本身已是压缩后的时频特征，信息量就这么多。强行 9×9 patch 化反而把跨 patch 交互推到深层去补，额外多付 7K 参数 + 500K MACs，六场景消融（Table 4）直接证伪：直接输入相对 with PE 错误率低 40%。

    混合轴：特征 × 时间

    视觉里 token-mixing / channel-mixing 对应图像的两个轴；音频单通道输入没有"通道"概念，本文改成特征维（每一帧的频谱形状）× 时间维（每个频点的历史）——这是时频表示真正有物理意义的两个轴，也是 MFCC 方阵天然的两个维度。

    Hardswish 激活

    原版 MLPMixer 用 GELU。本文六场景消融（Table 5）里 Hardswish 全面最优，且它是分段线性函数、不含指数和 sigmoid——硬件实现指令更少。每秒 10 次滑窗前向会把激活开销放大 10 倍，这个选择在端侧不是小事。

    ASHA 搜出来的极简配置

    异步超参搜索（ASHA）数百次试验后收敛到：12 个混合块、隐宽 64、无 dropout。搜索目标很明确——参数和 MACs 都要比所有基线的单项冠军还小。最终 0.25M 参数 / 20.16M MACs，双全场最小。

    训练LibriSpeech 1000 小时 · Montreal Forced Aligner 词级对齐切分 · 统一 1 秒（长随机裁剪 / 短零填充）· 词级交叉熵（解码器训练后丢弃）
    增广MS-SNSD 噪声 4–12dB；50% 概率远场仿真（房间脉冲响应）再叠 4–15dB 点源噪声
    正例Hey-Snips 筛至 40 说话人（3 注册 + 7 查询）；内部集 8 个家电词（Styler / Washer / Dryer / Hey LG / Fridge / Puricare / Oven / Hey Cloi）× 50 人 = 400 说话人，同样 3 + 7
    指标FRR @ 0.3 FA/h（每小时 0.3 次误唤醒的工作点）——误唤醒 = 设备在用户没召唤时突然录音，代价远高于漏唤醒，业界先钉死误唤醒再比漏唤醒
    零样本训练词表与全部评测关键词完全不重叠——嵌入空间靠海量无关词塑形，评测是对"通用词级表征"的纯零样本检验

    §05局限与边界

    优势场景被作者自己划清：噪声与远场；干净近场仍是 CNN/RNN 的阵地

    干净近场非最优

    内部集干净非远场：MobileNetV3 0.62 最好，本文 2.68 落后（连 GRU-ATTN 0.81 都不如）；10dB 也只 3.71 vs 3.69 持平。纯 MLP 的容量优势要在条件恶化时才兑现。

    1 秒固定窗口假设

    架构围绕 81×81 方阵设计；更长多词短语（如两句口号）未报告。嵌入级卷积对齐只允许平移这一种形变，没和可微分 DTW / 局部注意力这类更精细的对齐方案比较。

    平均池化抹掉时序

    81 帧直接平均，音素顺序与节奏不进嵌入——理论上音近词对（发音相同顺序不同）的区分上限受限，论文未做误接受词对分析来验证这个隐忧。

    单一全局阈值 + 维度未消融

    所有说话人 / 信道共用一个触发阈值，无自适应机制；嵌入维度 81 恰好等于特征维更像设计巧合，未做维度扫描实验。

    评测规模小

    Hey-Snips 筛至 40 人 × 7 条查询——每场景约 280 条正例，1 条话语 ≈ 0.36 个 FRR 点；无置信区间 / 显著性检验，2 点以内的差距要谨慎读。

    失真全仿真 + 单语种朗读

    远场与噪声全部来自仿真（无真实房间 / 回声设备验证）；训练只有英文朗读有声书——口语化、多语种场景未覆盖。

    无端侧实测

    只有参数 / MACs 代理指标——真实时延、实时率、内存峰值、功耗、100ms 滑窗的延迟分布均未上板验证。

    公平性存疑 + 注册协议单一

    本文 ASHA 搜了数百次，基线调参预算未报，视觉基线还带着 ImageNet 预训练（资源不对等）；固定 3 注册 / 7 查询协议，无 one-shot 注册曲线、无跨说话人注册评估。

    可迁移判断

    视觉架构的输入惯例对音频不是中性操作——patch 化在图像是有效归纳偏置，在 MFCC 上是负资产。迁移骨干时逐个审问每个组件的角色，小改动（换激活）的收益可以和结构改动同量级。

    表征学习与触发决策解耦是个性化的通用蓝图——训练用海量无关词塑形嵌入空间，部署时注册新词只是几次前向编码。这套路子可直接外溢到说话人验证、新颖性检测。

    余弦 over 欧氏：说话人差异和增益变化主要漂移模长、不漂移方向——度量选择本身就是一种归一化，比在特征端做归一化更稳。

    把指标钉在产品代价不对称处：误唤醒的信任代价远高于漏唤醒，先钉死 0.3 FA/h 再比 FRR——评测算什么，模型就优化什么。
