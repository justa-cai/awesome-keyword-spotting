把关键词折成一个 token，
ASR 的质量红利就能搬进唤醒词检测

TT-KWS · arXiv 2211.06478 Google × 马德里自治大学 Transformer-Transducer + MBR Hey/Okay Google · 8300h 数据
「Okay Google」识别成「Okay GOOGL」字符串匹配就失败——把关键词折叠成 <kw> 特殊 token，字符级不确定性被吸收进 token 的声学建模；再用 MBR 损失直接优化检测错误率。

一分钟版本

  • 问题：T-T/Conformer-Transducer 在 ASR 上已到 SOTA——这份质量红利能不能搬进唤醒词检测？直接 ASR + 字符串匹配不行：字符错误 AND 累积（Okay GOOGL 即失败）、关键词训练数据稀疏、硬判决无连续分数。
  • 选型：Transformer-Transducer 天然支持逐帧流式解码（常驻监听硬需求）；隐式学习声学-文本对齐——彻底免去常规 KWS 的强制对齐（顺带打通联邦学习路径）。
  • 核心一刀：训练时把转写里的关键词替换成特殊 token <kw>（75 个字素词表的一员）——检测问题变成「这个 token 有没有出现」，模型整体预测关键词的声学轮廓；所有含关键词的语句为同一个 token 贡献信号，缓解稀疏。
  • MBR 损失：训练目标从「最大化转写似然」改写为「最小化期望检测错误」——以 N-best 假设概率为权重，对该假设的关键词级假阳/假阴率加权求和；必须先用 RNN-T 训好再热启动（未收敛模型的 N-best 是垃圾假设空间）。
  • 打分：取 softmax 里 <kw> 的值、整句取 max——连续置信度支持调阈值切操作点，且训练优化什么推理就度量什么（目标与度量对齐）。
  • 主结果：token 化让小模型 EER 相对降 31%（8.24→5.68）；MBR 在低 FP 区放大收益（FN@0.5%FP 相对降 30.4%）；大模型 TT-KWS+MBR 3.27% 全面最优；融合 3.09%。
  • 规模是第一性：小配置（350K）下 T-T 全线不敌为检测定制的 SVDF（3.78%）——容量不够时损失技巧救不回来；13M 大配置才反超。
  • 两路线错误互补：常规 KWS 与 T-T 模型犯的不是同一批错误，分数求和融合在所有操作点一致占优——低 FP 区 FN 相对降 13.6%。
  • 部署分流：电池受限设备用常规小模型，插电设备（音箱/车机）用 T-T 大模型，高精度场景做融合——中间档位（高端手机常驻）是空白。
  • 边界：13M 参数是 SVDF 大配置的 3 倍多；MBR 训练要跑 beam 8 取 4-best（贵）；max 打分假设一句至多一次关键词；只验证两个固定两词英文关键词；内部数据不可复现、无效率指标。

§01问题：ASR 好不等于 KWS 好

字符串匹配方案的三个结构性缺陷

KWS 与 ASR 的核心差别在目标范围：KWS 只关心一小集合短语的检测准确率。直接把通用 ASR 用于 KWS 的三宗罪：检测精度被轻微 ASR 错误带偏（短语越长字符级出错概率越高，字素建模对拼写错误零容忍）；关键短语在训练数据中出现频率远低于普通词（梯度分配天然失衡）；字符串匹配是硬判决，无法输出连续置信度，不能按场景调节误报/漏报权衡。常规非 ASR 路线则要强制对齐产帧级标签——对齐误差传导进模型，且网络拓扑限制长上下文。

字符错误是 AND 累积

字符串匹配里关键词内部任何一个字符错了整词匹配就失败——「Okay Google」→「Okay GOOGL」检测即失效；token 化后变成「token 有没有出现」，关键词内部的字符级不确定性被吸收进 token 的声学建模。

先前 seq2seq KWS 的代价

LSTM-CTC 音素格方法需要格搜索；基于 N-best 索引搜索的 attention 模型推理昂贵——本文的 softmax 打分不需要 N-best 或格，推理计算量远低，且训练目标能对齐推理度量。

§02方法：token 化 + MBR + 对齐的打分

三个组件环环相扣的设计

图1 · 机制全景：两条老路的缺陷与 T-T 选型理由； token 化（关键词当作连贯声学事件，75 字素词表的一员）；MBR 损失（式 1–3）与两阶段训练；softmax 打分整句取 max。

FP = max(0, K_H − K_R)，FN = max(0, K_R − K_H)；L_ij = P_ij·(α·FP + β·FN)/(K_R+ε)；L = ΣΣ L_ij − λ·log P(Y|X)
人话（式 1–3，MBR 损失）：K 是假设/参考里 <kw> 的个数。以每个 N-best 假设的概率 P_ij 为权重，对它的关键词级假阳/假阴率加权求和——训练直接优化「期望检测错误」而不是转写似然。除以 (K_R+ε) 让含多个关键词的语句与只含一个的损失量级可比；λ 项保留似然防止 MBR 单独优化崩坏主任务。单句内 FP/FN 至多一个非零，α/β 在全局层面起作用。

为什么打分方式与训练目标是耦合设计：因为分数定义在模型输出端（softmax 的 <kw> 值），训练时才能直接对关键词 token 做序列判别优化（MBR）——基于格/N-best 索引的先前方法做不到「训练优化什么、推理就度量什么」。公平起见论文还给 ASR 基线设计了 bigram 编辑距离打分（e^−GEDmin），把只能硬匹配的 ASR 扩展成有分数、能画 DET 曲线的系统。

§04贡献：五条

1

TT-KWS 完整方案：用 <kw> token 把 T-T ASR 适配到 KWS——仅这一项小模型 EER 相对降 31%，从根本上解除对 ASR 字符级正确性的依赖。

2

面向 KWS 的 MBR 训练损失：把序列判别训练改造为直接最小化 N-best 假设上的期望假阳/假阴率——低 FP 操作区最高 30.4% 相对 FN 改进。

3

softmax 置信度打分：支持阈值可调的多操作点，且训练目标与推理度量对齐。

4

两条路线的系统对比与融合证据：TT-KWS 与常规 E2E KWS 错误互补，融合在所有操作点一致占优；给出按供电条件分流的部署判断。

5

方法学外溢：换关键词只改转写文本、免强制对齐——打通旧关键词模型当新关键词预训练、联邦学习训练 KWS 的路径（未做实验）。

§05局限与边界

容量是第一性，但容量也最贵

模型与解码重

大配置 13M 是 SVDF 大配置（3.9M）的 3 倍多；小配置性能又不敌 SVDF——这条路线目前只能落在「插电设备」档，中间档位（高端手机常驻检测）是空白。

MBR 训练成本与超参

训练中跑 beam 8 取 4-best 假设（开销显著高于纯 RNN-T）；必须先 RNN-T 训好再热启动（流程加长）；{α, β, λ}={1.0, 1.0, 0.01} 只给一组经验值，无敏感性分析。

打分假设与关键词覆盖

整句 max 假设一句至多一次关键词——连续两次唤醒丢次数信息；无时长平滑，瞬时尖峰鲁棒性未讨论；只验证两个两词多元音英文短语，单音节短词未测，token 化收益是否随关键词长度变化未知。

实验设计缺口

全部内部供应商数据（无公开集，不可复现、不可横向对比）；无延迟/RTF/内存/能耗数字而结论恰围绕资源展开；大模型 3.27 vs 3.38 无显著性分析；易混淆负样本仅 1.5 万条（占 360 万负句极小）且未单独报告其错误率；融合只试了分数求和一种方式。

可迁移判断（超出 KWS 也成立）

  • 把事件级检测问题塞进 token 序列生成框架：检测从「逐字正确」变成「token 出现与否」——错误从 AND 累积变成单点判断，上游字符级噪声被吸收。
  • 序列判别训练（MBR 类）要先用似然目标热启动：判别目标依赖假设空间质量，未收敛模型的 N-best 是垃圾——冷启动直接优化判别目标等于优化噪声。
  • 训练目标要与推理度量对齐（优化什么就度量什么）——这要求分数定义在模型输出端，而不是事后解析。
  • 容量不够时损失技巧救不回来：小预算下为任务定制的紧凑架构仍占优——先定容量档位再谈训练技巧。
  • 两条技术路线的系统错误往往是互补的：融合（哪怕最简单的分数求和）能在所有操作点一致占优——部署前值得先测错误相关性再决定是否融合。
