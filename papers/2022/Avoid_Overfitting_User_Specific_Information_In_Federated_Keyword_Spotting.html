知识蒸馏是「靠近教师」，这篇把教师分布整体取负——全局模型在过拟合探针概率高的地方必须输出低概率。
南大+华为：先刻意把私有模型练到过拟合当用户信息探针，再让全局模型反向远离它

Avoid Overfitting User Specific Information in Federated Keyword Spotting（FedKWS-UI）

作者：Xin-Chun Li、Jin-Lin Tang、Le Gan、De-Chuan Zhan（南京大学）；Shaoming Song、Bingshuai Li、Yinchuan Li、Yunfeng Shao（华为诺亚方舟实验室）· arXiv 2206.08864

数据：GSC 联邦划分（12 类 2,234 客户端 / 35 类 2,434）· 架构：DSCNN / MHAttRNN / ResNet / Transformer（169K–238K 同级）· 八组全胜

ALO 负蒸馏（算法层）ALT 自适应本地训练（系统层）过拟合 = 用户信息探针 调和平均效用 + 总量守恒Transformer 最大 +6.35FA/FR 双优（不调阈值）

一分钟版本

  • 问题重构：把 FedKWS 的性能退化从笼统的「non-IID 困难」重构为「本地模型过拟合用户特有信息」——两个具体失败样例：特征提取器把某用户的口音当成判别因素、分类层偏向该用户常用的词。结构性放大器：FedAvg 默认 E=50 × batch 32 = 每轮消费 ~1,600 样本点，而平均每客户端只有 20.4 条（12 类）/43.3 条（35 类）——本地数据每轮被重复约 78/37 遍：过拟合用户信息不是超参失误，是协议结构的必然行为。
  • 三重偏斜 + 双重侵蚀：数量偏斜（有人只贡献几条）+ 标签分布偏斜（爱说的词不同）+ 特征分布偏斜（口音）。据文献结论：特征偏斜主要侵蚀低层、标签偏斜主要侵蚀高层——KWS 双重偏斜下偏置弥散整个网络，针对特定层或参数空间的正则（FedProx/FedDyn/MOON）结构上打不全。且这些方法只限制「漂移量」，从不指明「哪些成分是用户特有的应当剔除」——被动距离约束而非主动信息甄别。
  • 双路设计：一算法一系统。用户特有信息既在「怎么算损失」里混进来（单客户端损失被口音和常用词支配），也在「谁训得多」里混进来（不合格与优质客户端拿同样步数）——单一层面动手术不彻底。
  • ALO（Adversarial Learning against Overfitted models）：私有-共享模型框架——每客户端额外维护一个从不上传的私有模型 fp，用纯交叉熵刻意练到过拟合（过拟合从缺陷变成工具：用户特有信息的可微分探针——当 fp 在 20 条数据上接近完美拟合，其预测分布里沉淀的正是该用户可被记忆的一切，口音与偏好词被充分放大）。全局模型的损失 = 标签平滑 CE（μ=0.2，锚住判别信号）+ λ·负蒸馏（式 2：形式完全跟随知识蒸馏但教师分布整体取负——最小化等价于要求全局模型在 fp 概率高处输出低概率——「远离教师」）。为什么取负而非 min-max：对手冻结——「对抗」是恒定推离方向，避免小样本下双模型博弈震荡。函数层面正则：不涉参数距离不对齐中间特征——绕开「偏置弥散在不同层」的结构困难。
  • λ 的量化边界（最锋利的消融）：λ=0 时 85.29、1e-4 时 86.07、1e-3 最优 86.23、1e-2 跌到 82.79、1e-1 崩至 76.99——有效窗口仅一个数量级：对抗项是导航微调而非主损失，权重大一个量级开始有害、大两个量级直接毁掉训练（反面印证「负教师里混有判别信息」）。
  • ALT（Adaptive Local Training）：效用 r_k = 调和平均(归一化样本量 n̄_k, 归一化类分布熵 e_k)——调和平均的短板效应精确刻画「两种合格都是必要条件」：量大但类倾斜（模型被带向偏好词）不该多训、类均匀但只有几条（必过拟合）也不该多训（算术平均下两个坏案例都拿中效）。每轮步数 = r₀·r_k·E，总量守恒 Σ r₀r_kE ≈ K·E——性能不靠偷偷多花钱。实测效用差一个数量级（12 类 0.15–3.49、35 类 0.21–4.70）。
  • 主结果（Figure 2，最后 5 轮平均，8 组全胜）：12 类 Transformer +6.35（72.71→79.06，最大提升）；12 类 ResNet +2.30、DSCNN +1.78；35 类 Transformer +4.51（FedOpt 崩到 54.56 时 UI 74.75）。五层读数：① 联邦化代价被量化——基线最好 86.39 vs 集中式 97.89 差 11.5 点，UI 87.29 仍差 9.9 点（止血非根治）；② 联邦下架构排序反转——MHAttRNN 最稳、Transformer 最差（缺归纳偏置，小数据客户端更脆）；④ 基线内部不稳——FedProx 有时反低于 FedAvg、FedOpt 在 35 类 Transformer 灾难崩盘（服务器自适应路线在双重偏斜下不牢靠）。
  • FA/FR 双优（Table 3，不调阈值）：FA 0.23（FedAvg 0.27 / FedOpt 0.32）、FR 2.78（5.03 / 3.19）。FedOpt 是 trade-off（FR 降 FA 升），UI 双项同时占优 = 判别边界真的变干净，不是工作点移动。
  • 消融的架构分化（有信息量）：只 ALT 时 MHAttRNN 甚至略超完整版（84.73 vs 84.60）、Transformer 基本可用，但 ResNet 差 6.40——时序建模强的架构对用户偏置本身鲁棒（调度就够）；纯前馈架构偏置吸收深，必须靠损失层显式对抗清洗。
  • 插值可视化（Figure 4，几何解释）：集中式 θ0 + 劣质用户微调 θ1 + 合格用户微调 θ2 的插值空间——沿合格方向泛化基本不掉、沿劣质方向迅速塌陷（深坑）。联邦聚合本质是多个本地解的加权平均 = 插值空间里的一个点——本地更新造成的深坑直接伤害聚合；ALO 施加后 θ̂1 更好且沿劣质方向地形变平滑（把坑填平 = 几何上解释为什么有利聚合）。
  • 边界：本地开销近翻倍（私有模型先行训练——具体步数未报；对端侧内存预算是现实压力）；负蒸馏无理论保证（λ 有效窗口仅一个数量级——跨数据集/架构超参迁移性存疑）；「充分过拟合」无可操作判据（个位数样本的客户端探针本身失效）；r_k 启发式无替代效用消融；单一数据集（直接对比对象 Leroy 用的 Hey Snips 未覆盖）；无方差/显著性（+0.18 这种领先难判显著）；FA/FR 只报一个设置；无系统成本核算（对主打系统调度的贡献是明显缺口）；未与个性化路线（含作者自己的 FedPHP）对照取舍。

§01 · 问题陈述

每个客户端都在把模型往自己身上拉

被点名的路线缺口：FedAvg 系（Leroy ICASSP 2019 大规模验证 + Hard Interspeech 2020 增强与蒸馏）没把「本地过拟合用户信息」当核心目标；FedOpt 只治聚合器不治本地污染；FedRS 只覆盖标签偏移一种；FedProx/FedMMD/FedDyn/MOON 限幅式正则不指明该删什么 + 逐层正则结构上打不全（KWS 双重偏斜弥散全网络）；系统调度层面此前零工作。
Lls = −Σ[(1−μ)·𝕀{y=c} + μ/C]·log[f(x)]c（式 1）；Ladv = −Σ[−fp(x)]c·log[f(x)]c（式 2）；L = Lls + λ·Ladv（式 3）；rk = 2n̄kek/(n̄k+ek)，步数 = r₀·rk·E，r₀ = K/Σrk
负教师 −[f_p] 在 c 上是一组非正数、和为 −1；最小化式 2 等价于最小化 Σ[f_p]_c·log[f]_c——要求全局模型在 fp 概率高（过拟合区域）处输出低概率。私有模型不上传所以通信不变。μ 用真标签（软化）把判别信号锚住——全局模型才敢在小 λ 下偏离教师。归一化把样本量（几十条）和熵（0–1）拉到同一区间；log C 分母让熵在 12/35 类间可比。

§03 · 实验与消融

8 组 × 5 方法 + 双超参扫描

Figure 2 复绘（8 组 × 5 方法，绿柱上方标注相对最优基线增益）：UI 八组全胜；12 类 Transformer +6.35 最大；FedOpt 35 类 Transformer 灾难崩到 54.56。蓝虚线 = 集中式上界（96.95–97.89）——联邦化代价 9.9–11.5 点：止血非根治。联邦下架构排序反转：MHAttRNN 最稳、Transformer 最差。

Figure 3 复绘：左——只 ALT vs 完整 UI（35 类四架构）：ResNet 差 6.40 / DSCNN 差 2.24 但 MHAttRNN 反超——时序架构对偏置本身鲁棒（调度就够）、纯前馈架构偏置吸收深（必须显式对抗）；右——μ 扫描（宽谱有益，0.1–0.3 只差 0.08 点）与 λ 扫描（窄谱高敏，窗口仅一个数量级、0.1 崩 9 点）。

Figure 4 / Table 3 复绘（地形为示意，结论有据）：左——插值空间泛化地形：沿合格用户方向基本不掉、沿劣质用户方向迅速塌陷（深坑）；聚合 = 插值空间里的加权平均点 → 本地深坑直接伤害聚合；ALO 把坑填平。右——FA/FR：FedOpt 是 trade-off、UI 双项占优（判别边界真的变干净非工作点移动）。底部：主要边界与架构层级判断。

协议细节：GSC + FedScale 联邦划分（每用户一端；测试集不切分专评全局模型）；40 维 MFCC（30ms/10ms）+ 标准增强（时移 ±100ms、0.8 概率混 0.1 音量背景噪声）——特征管线与集中式完全一致，联邦化差距只能归因训练范式与异质性。联邦设置 batch 32 / E=50 / 300 轮；基线超参扫描后取最优（FedProx/FedMMD 正则 {1e-4,1e-3,1e-2}、FedOpt {SGD,Adam}——对比厚道）。UI 超参 μ=0.2 / λ=0.001 / r₀=3.5（12 类）与 5.0（35 类）。指标 = 每 3 轮记录、最后 5 轮平均（消单轮波动）。

§04 · 主要贡献

四条贡献

1问题重构——从笼统 non-IID 到「过拟合用户特有信息」：三重偏斜 + 双重侵蚀（低层特征/高层标签）的分析框架，指明逐层正则结构上不适配 KWS。
2ALO——函数层面负蒸馏式对抗正则：过拟合私有模型当探针、推离全局模型、标签平滑锚定判别——「蒸馏形式、相反语义」的新用法，与拉近式正则形成方法论互补。
3ALT——数据质量感知的本地步数再分配（调和平均效用 + 总量守恒）：把 FL 优化从算法层延伸到系统调度层——该维度在 FedKWS 此前工作中是空白。
★大规模实证——2,234/2,434 个真实用户客户端 × 2 任务粒度 × 4 架构共 8 组全胜；Transformer 最大 +6.35；不调阈值同时降 FA 与 FR；消融与插值可视化分别验证两组件必要性与机理。

§05 · 局限与边界

双倍本地开销与无理论保证

技术局限

  • 本地开销翻倍：额外维护 + 先行训练私有模型——存储计算近似翻倍；对端侧内存预算是现实压力。通信不变（fp 不上传）但具体开销未报。
  • 负蒸馏无理论保证：为什么「远离教师」恰好删用户特有成分而保留判别成分——只有经验边界（λ 窗口一个数量级）；跨数据集/架构超参迁移性存疑。
  • 教师质量的先决条件：「充分过拟合」无可操作判据（仅称 abundant training steps）；个位数样本的客户端私有模型可能连用户信息都拟合不动——探针失效。
  • r_k 启发式：无公理化推导；未与「只用样本量 / 只用熵 / 算术平均」等替代效用做消融——无法排除其他度量同样有效甚至更优。
  • ALT 假设单维可控：忽略算力与可用性异质性（论文自认）；「多训无害」假设未做极端大用户压力测试。

实验设计不足

  • 单一数据集：全部基于 GSC——未覆盖 Hey Snips（直接对比对象 [17] 用的正是它）；silo 式联邦（机构端数据充足但偏斜）的中间形态未测。
  • Transformer 配置偏弱：4 层 0.23M（对照 KWT 原文的 5.4M）——「Transformer 联邦下最差、UI 提升最大」能否外推到主流规模存疑。
  • 无统计稳健性：无多次重复的方差；+0.18 / +0.28 量级领先是否显著无法判断；每轮客户端采样比例 |St| 未报。
  • FA/FR 覆盖窄：只在 DSCNN 12 类一个设置报告——其他架构与 35 类的误唤醒/漏唤醒行为未知。
  • 系统成本缺位：无墙钟/通信总量/私有模型算力量化——对主打系统调度贡献的工作是明显缺口；与个性化路线（FedPHP）缺取舍讨论。
自然的延伸方向（论文自提 + 笔者推断）：流式 KWS 与差分隐私结合（论文自提）；轻量化 ALO 教师——早期停止快照 / 指数滑动平均副本 / 只保留分类头的私有化（呼应「在哪里私有化」问题）——避免双倍本地训练；多维效用函数（算力/在线时长/数据时效纳入 r_k）；与 FedOpt 正交叠加（治本地 × 治服务器——低成本可补的实验空位）；真实产品场景验证（自定义唤醒词的标签偏斜比 GSC 更极端——类熵项作用机制值得单独检验）；理论补课——在特征解耦或因果表征框架下论证过拟合教师主要承载用户特有成分的条件，把 λ 窗口从经验规律变成可推导量级。
