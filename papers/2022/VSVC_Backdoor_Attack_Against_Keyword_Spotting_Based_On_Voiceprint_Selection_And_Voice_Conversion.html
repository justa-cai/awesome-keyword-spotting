不往语音里藏噪声，
直接换一个人说：音色本身就是后门触发器

VSVC · 后门攻击（防御视角深读） 河海大学 + RMIT + NUS · arXiv 2212.10103 StarGANv2-VC 音色触发 · x-vector 声纹筛选 LSTM 仅 50 个中毒样本 → 92% 攻击成功率
一句话：KWS 训练外包/众包数据时，攻击者能改训练集。VSVC 把「音色」当触发器——用 StarGANv2-VC 把良性样本整段换成指定说话人的声音（语义不变），投毒不到 1% 训练数据，就在四个强模型上平均拿到约 97% 攻击成功率；LSTM 上 50 个样本即 92%。听感上是「另一个人说同一个词」，20 人盲测 100% 无法区分——不依赖超声频段，16kHz 系统照样成立，低通滤波也滤不掉。
TL;DR（以防御视角读）
  • 威胁模型：攻击者对模型结构零知识，对训练数据完整读写——对应训练外包到云平台、众包数据集（Common Voice 等）两种现实场景。后门完全从数据侧长出来，不需要对模型做任何手术。
  • 已有触发器的三大结构性缺陷：人耳可分（本质是「无法理解的噪声」）；超声触发器被奈奎斯特定理锁死（21kHz 信号要 44.1kHz 采样，主流系统 16kHz 一半频带不存在）且低通滤波即除；全部是单目标单后门。
  • 核心洞察：音色是覆盖整段语音的全局特征——弥散在每一帧每个频带。转换后仍是自然可懂的语音（人耳层面检测失效）、在常规频带内（采样率无关、滤不掉）、时间连贯（对 LSTM 是全方位输入分布改变而非局部扰动）、取值空间大（VCTK 109 人 → N 对 N 多目标）。
  • 三阶段管线：x-vector 声纹嵌入 + 欧氏距离 + 阈值 T 贪心筛出两两可分的 N 个说话人 → StarGANv2-VC 训一个 N 对 N 转换模型（一个 VCM 服务所有目标，成本常数级）→ 按投毒率替换数据后正常 CE+SGD 训练。
  • 结果分层清晰：LSTM 最脆弱（0.63% 投毒即 ~100%，50 样本即 92%）；ResNet18 因捷径连接冲刷低层特征，局部触发器攻不动、全局音色可以；VGG16 局部空间关联最强，基线在低投毒率反超——模型归纳偏置决定攻防。
  • 功能保持：平均准确率方差 0.45%（基线 0.53%，论文视为不显著）——投毒基本不伤正常功能，被植入的模型在验收时看不出异常。
  • 防御空白：论文零防御对抗实验。声纹侧防御（一致性审核/分布异常检测/转换伪影检测）都有潜在拦截面；过空中传输鲁棒性未测——绝大多数音频后门工作的共同空白。

    • §01问题：训练供应链失控

    攻击面不是「识别错词」，是「设备执行不该执行的动作」

    为什么 KWS 是高价值目标

    KWS 是音箱/手机助手的标准入口，常驻监听、实时响应——每次误判直接等价于设备层级的误操作。知道后门的攻击者对被植入的音箱说一句话即可绕过正常唤醒校验，隐式指挥设备（论文点名自动驾驶、智慧医疗为高危场景）。

    外包 = 失去训练过程控制

    训一个满意的 KWS 要高性能硬件+高质量标注数据，多数服务商把训练外包给云计算平台——第三方便可在数据上动手脚。后门攻击瞄准的正是训练阶段：污染一小部分数据，模型学到「触发器→目标标签」的关联，干净输入上表现正常。

    超声触发器的三重死穴

    奈奎斯特：21kHz 信号无失真识别要采样率 ≥42.2kHz，GSC 等 16kHz 系统一半以上频带不存在→直接失效；一个低通滤波器就能滤掉；且只在空间维度做局部注入、忽略时间维度——攻不动 LSTM。

    攻击者的两个目标

    触发效率（越高越可能成功、需发起的查询越少——某些场景限制查询次数，低效触发=彻底失效）与隐蔽性（干净输入上必须像干净模型，触发器要让人耳无法分辨）。VSVC 用「正常语音本身」同时满足两者。

    §02方法：把后门从数据侧长出来

    声纹相似度矩阵 · 贪心选择 · 条件式语音转换
    Spk_embed_i = X-vector(Speaker_i) # K 个说话人的声纹嵌入 SM[i][j] = EucDist(Spk_embed_i, Spk_embed_j) # K×K 声纹相似度矩阵（欧氏距离） Cand = { Sᵢ : SM[Sᵢ][Sⱼ] > T, ∀Sⱼ ∈ Cand }, |Cand| = N # 贪心选择
    人话：x-vector 挑出唯一稳定可靠、表达说话人身份的特征；欧氏距离直接对应嵌入空间里「音色差异大小」——距离越大两个触发器越不易混淆。贪心规则保证 N 个触发器两两距离都超阈值 T。单目标攻击不用选，随机取一人即可。阈值 T 的取值论文未报告——复现时需自行摸索。
    触发器生成: StarGANv2-VC（音色作生成器/判别器的条件输入） → 一个 VCM 把任意输入转换成 N 个目标音色之一（N 对 N） 投毒: 良性样本 → 转换成说话人 Sᵢ 的音色（语义不变）→ 替换进训练集 绑定: 目标标签 i ↔ 说话人 Sᵢ 的音色 → 正常 CE + SGD 训练
    人话：触发器不是手工设计或梯度优化出来的，是「转换」出来的——语义保持（中毒样本仍是合法可懂的命令）、规模无限（有良性数据就能批量造，投毒率 0.2%–2% 自由调）、一个 VCM 服务所有目标（多目标的基础设施成本是常数级）。训练流程完全正常，后门是模型在普通监督学习里「顺便」学到的关联。

    多目标的内在矛盾与解法

    多个音色触发器同时植入时，音色相似 → 相互干扰 → ASR 下降；低投毒率下更糟（训练信号本来就少，音色还像，后门边界就糊了）。声纹筛选正是针对这一点：消融证实声纹选择优于随机选择，低投毒率下优势最大——避免「两个相似音色攻击不同目标」。

    全局 vs 局部：范式级差异

    超声基线在频谱图上是一小块局部补丁，只作用在局部时空区域；音色转换改变的是整张频谱图的统计纹理。1 秒语音 = 87 帧时序序列，音色在每一帧都留下印记——这不是实现细节的胜负，是触发器范式与时序模型结构之间的根本适配问题。

    图2 · 机制解剖：左是频谱图上局部补丁（超声）与全局纹理（音色）的对照及各自的攻防属性，右是声纹筛选的几何（贪心规则、太近被拒、消融证据与边界）。

    读表要点
  • 摘要总括：投毒 ≤1% 训练数据时四模型平均 ASR 接近 97%；随中毒样本数增加 ASR 快速收敛 >95% 且 AV 保持小——高效且不留验收痕迹。
  • VGG16/WideResNet 上基线低投毒率反超，但基线的两个前提（采样率 >44.1kHz、无低通滤波）在真实系统里不成立——比较要在约束下读。
  • 人类验证设计有讲究：20 名被试全部通过 CET-4（数据集是英文命令词，被试需具备基本英语听辨能力才有效），每人 20 条（10 后门+10 良性）二选一——100% 无法区分。
  • 消融只覆盖单 vs 多目标、随机 vs 声纹选择两个对照；阈值 T 敏感性、N>3、不同 VC 模型的影响均未报告。

    • §04贡献

    三条自述 + 一个更广的视角
    1

    音色触发器范式：以改变语音音色为目标的触发器——低投毒率（≤1%）下有效且隐蔽；不产生任何不可理解的噪声，比噪声类/环境音类/隐写类方法更隐蔽（四模型平均 ASR ~97%）。

    2

    摆脱采样率约束：音色分布在常规频带内，16kHz 系统照样成立——LSTM 上只投毒 50 个样本即 92% 攻击成功率（比基线高 72%）。

    3

    多目标后门攻击：音色表现形式丰富，可为不同目标植入不同触发器——实验演示 N=3 的多对多攻击。

    4

    更广视角（笔记归纳）：把后门触发器从「信号处理工件」（噪声/超声/隐写）转向「说话人身份属性」，给出可复用攻击管线（声纹筛选→条件转换→投毒）；同时是对 KWS 训练外包供应链风险的一次定量曝光。

    可迁移判断（防御视角）

    ↳ 数据供应链的说话人构成审计应成为 KWS 交付标配：改动不到 1% 的训练数据就能在 LSTM 上接近 100% 劫持指定标签，且音频听感正常、不依赖高采样率、不怕低通滤波——准确率验收对此完全失明。

    ↳ 中毒样本在说话人维度是「新来者」：同一标注来源的说话人构成突变检测、推理端说话人验证门控（唤醒词与注册音色不匹配则拒绝）、转换伪影检测——音色触发器反而给了防御一个明确的抓手。

    ↳ 模型归纳偏置决定它怕什么攻击：时序模型怕全局时间连贯的特征，深层残差怕全局纹理（局部特征被捷径冲刷），纯空间卷积怕局部补丁——选架构时值得把「抗哪种触发器」纳入威胁建模。

    ↳ 「隐蔽」要同时骗过机器和人类：只对机器隐蔽（噪声类触发器）的攻击在人工质检面前不堪一击；能通过人耳检验的攻击才是产品级威胁——质检流程里应包含人类听感抽检这一环。
