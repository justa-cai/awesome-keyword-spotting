Developing Far-field Speaker System via Teacher-Student Learning · Jinyu Li / Rui Zhao / Zhuo Chen / Changliang Liu / Xiong Xiao / Guoli Ye / Yifan Gong（微软 AI 与研究）· arXiv 1804.05166（ICASSP 2018）
一句话：教师（大 · 近讲）与学生（小 · 远场）吃同一段语音的不同声学版本，最小化输出分布的 KL 散度——域适应不需要转录、压缩不需要硬标签：WER 相对降 72.6%（回放）/ 57.2%（实时），KWS 模型压 27× 准确率不变。

1问题：Cortana 上第三方音箱的两道坎

TL;DR
  • 近讲模型进远场就崩：生产声学模型在海量近讲数据上训出，房间混响/噪声/距离衰减让 WER 大涨；远场标注数据贵且慢。
  • 大模型塞不进音箱：生产 KWS 检测器百万到千万参数，第三方音箱算力远远不够。
  • 第三方硬件是黑盒：信号处理由厂商控制——端到端联合优化做不了，只能从模型侧想办法。

2机制：软标签比硬标签教得多

软标签的信息密度

教师输出完整分布：「bat 0.7 / pat 0.2」——硬标签只有「bat 1.0」。类间相似性是免费的额外监督。

免转录适应

训练目标是教师的输出分布而非转录文本——远场数据不用标注，只需 RIR 卷积造出平行对。

平行数据构造

近讲语音（已有海量）× RIR 卷积 → 模拟远场版本——(x_near, x_far) 平行对零标注成本。

三级增益叠加

T/S 适应（主体）→ sMBR 序列训练（序列级互补）→ 实时数据微调（生产最佳）。
图 2 · 左：同一样本的硬标签 vs 教师软标签——分布里携带的类间关系是硬标签里没有的；右：平行数据构造与三级增益的叠加顺序。
L_T/S = D_KL( P_teacher(y | x_near) ‖ P_student(y | x_far) ) 压缩时：x_near 换成同一输入
人话：教师听干净版，学生听混响版，要求学生说出和教师一样的话（连「拿不准的比例」都要一样）。学生被迫在烂输入上还原教师的判断——这个「还原」过程就是适应；同一招把大教师的话让小学生背下来，就是压缩。

4边界：模拟域差距与前置条件

模拟-真实域差距

回放 72.6% vs 实时 57.2%——RIR 模拟远场与真实远场的差距始终存在，增益会漏气。

并行数据是前置

T/S 适应需要近讲/远场平行对——纯远场单独录音（无平行结构）用不了。

第三方硬件黑盒

波束成形质量由厂商决定——同一模型在不同音箱上表现可能差异显著。

教师上限即学生上限

教师模型质量直接限制学生——论文未分析差教师带来多大折损。

5判断：能带走的三句话

JUDGEMENT

域适应和模型压缩是同一件事：都是「让学生在受限条件下复现教师的输出分布」——一个受限在输入（远场），一个受限在容量（小模型）。T/S 是它们的公共解。

软标签是数据有限时的杠杆：硬标签一比特信息，教师分布携带类间相似性的连续信号——标注越少，蒸馏的边际收益越大；这就是后来「未标注数据 + 强教师」成为工业标配的原因。

模拟数据的增益要按真实数据打折验收：72.6%（回放）到 57.2%（实时）的落差就是模拟-真实域差距的标价——报告适应结果时两套数字都要看，只报模拟集是常见的自我高估。
