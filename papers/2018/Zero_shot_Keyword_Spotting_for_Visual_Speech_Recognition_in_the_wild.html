读唇术的零样本检索：新词只给文字，G2P 发音嵌入当查询向量，模型零重训

视觉 KWS（唇读）零样本检测（首个）G2P 发音嵌入3D ResNet 时空特征LRS2 in-the-wild
Zero-shot Keyword Spotting for Visual Speech Recognition in-the-wild · Themos Stafylakis / Georgios Tzimiropoulos（诺丁汉大学）· ECCV 2018 · 论文链接
一句话：唇部视频（3D ResNet 时空特征）与关键词的 G2P 发音嵌入在 BiLSTM 匹配网络中对齐——训练用大词汇学「唇动↔发音」的通用对应，测试遇到没见过的新词只给字素：现场转发音嵌入直接匹配，零重训零新数据。

1问题：为什么需要看嘴

TL;DR
  • 音频在极端噪声 / 静音监控场景完全失效——唇读是天生的补充：安防监控、嘈杂工厂、听障辅助。
  • 标注视觉语音数据极贵（精确时间边界 + 高质量唇部视频）——零样本是刚需：新警报词、新人名不可能逐个重收重训。
  • 挑战：怎么把「文本形式的关键词」变成能和视觉特征匹配的表示。
图 1 · 机制全景：四重需求 → 三组件架构（视觉流 / G2P 发音流 / 匹配网络）→ 零样本的发生机制 → 结果速览。

2机制：G2P 是零样本的钥匙

视觉流

人脸检测 → 唇部裁剪 → 3D ResNet（空间流捕唇形 + 时间流捕开合节奏）→ 每帧定长特征。

G2P 编解码器

字素 "H-E-L-L-O" → 编码 → 解码为音素 "HH AH L OW"——编码器隐状态即发音嵌入。

同音词收敛

their/there 拼写不同但读音相同——G2P 空间里距离近；唇动跟读音走，不跟拼写走。

匹配网络

BiLSTM 编码视觉序列 + 注意力对齐视觉帧↔音素位置 → 各时刻词存在概率。
图 2 · 左：their/there 在字素空间相距远、在 G2P 发音空间收敛——发音嵌入才是视觉匹配的正确坐标；右：训练学对应、测试换新词的零样本机制。
训练： 唇部视频特征 ↔ 大词汇发音嵌入（学通用对应） 测试： 新词 "banquet" → G2P → B AE NG K W AH T → 直接匹配
人话：模型不是背「哪个词配哪张嘴」，而是学「嘴怎么动对应怎么发音」的通用规律。查新词时，先把文字转成音素串（就像查词典拿拼音），再拿这个「拼音」去视频里找对应的嘴型——只要 G2P 认识这个词的文字，模型就不用重新训练。

3结果（定性）：两条对比 + 一个难例

图 3 · 三行对比（G2P > 字素嵌入 · 直接匹配 > 先转录再搜索 · 任意新词 vs 只能测训练词）+ 定性观察（时间定位准确 · 说话人/光照鲁棒 · 短词更难——视觉变化更微妙）。

4边界：视觉同音词的天生短板

视觉同音词

唇部信息量天生低于音频——p/b、m/n 等音素视觉难辨，纯视觉上限注定低于音频。

嘴部可见性依赖

侧脸 · 口罩 · 遮手 · 低分辨率——任一都严重影响性能。

G2P 语言依赖

G2P 要音标词典训练——低资源语言没这个家底。

算力与验证面

3D ResNet 重（嵌入式实时难）；仅 LRS2 英语评估，无跨语言/跨模态融合对比。
图 4 · 边界四条 + 谱系坐标：「中间表示可从文本生成 = 零样本」的通用配方——G2P 查询思想后来进入音频侧开放词汇 KWS；视觉侧走向多模态融合；本文把 KWS 概念版图扩展到视觉（ECCV 跨学科发表的标志）。

5判断：能带走的三句话

JUDGEMENT

零样本的通用配方是「中间表示可从文本生成」：查询侧只要能从文字现场算出嵌入（G2P 发音、语义编码器），训练侧学的是对应关系而非具体词——新词成本从「重收数据重训」降为「跑一次 G2P」，这是开放词汇系统的共同骨架。

表示空间要选在「与感知模态同构」的那一层：唇动跟读音走、不跟拼写走——所以匹配要在发音空间做；选错表示层（字素）会让天生同音的样本在空间里被强行拉开，几何就帮倒忙了。

直接训练检测目标优于「先转录再搜索」的级联：视觉 ASR 转录的误差会全部传进搜索，而端到端匹配让表示为检测目标优化——级联每加一级就引入一次目标错位，这也是音频侧 KWS 从 LVCSR 后处理走向端到端的同一课。
