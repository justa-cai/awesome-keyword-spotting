1989 年的老架构翻红：TDNN + 音素预训练 + 帧跳过，省 89% 算力不掉点

Efficient Keyword Spotting using Time Delay Neural Networks · Samuel Myer / Vikrant Singh Tomar（Fluent.ai）· arXiv 1807.04353（2018.07）
一句话：用 Waibel 1989 的 TDNN（每层看前一层 ±d 时间步、无循环可全并行）做 KWS——大规模音素语料预训练 + 关键词微调的两阶段训练叠加帧跳过/输出缓存推理优化：计算量省 89%，误接受误拒绝双降，251,136 参数。

1问题：端侧三选一，各有短板

TL;DR
  • CNN 卷积核固定局部上下文——长时依赖弱；RNN 能捕长依赖但顺序依赖卡死并行；DNN 只靠拼接窗口，固定且有限。
  • TDNN 卡在中间的好位置：CNN 的并行效率 + 逐层扩展的时间感受野——无隐藏状态，推理全并行。
  • 嵌入式预算要求低算力 + 低内存 + 实时流式——架构选对了还要再抠推理成本。

2机制：时间延迟连接的几何与帧跳过

时间延迟连接

每层节点接收前一层 ±d 时间步的输入——感受野逐层叠加，两层后 ±2 步；全是前馈连接，无状态可并行。

帧跳过

特征仍按 10ms 提取，但每 N 帧才做一次网络推理——中间帧插值或缓存复用；适度跳过几乎无损。

输出缓存

攒 N 帧进缓冲区批量推理——矩阵运算吃满并行，均摊每帧成本更低。

端到端无 HMM

直接用 TDNN 帧级输出 + 平滑/阈值做关键词判断——砍掉 Viterbi 解码，部署复杂度大降。
图 2 · 左：两层 TDNN 的连线图——每节点看前一层 ±1 步，感受野逐层叠起来；右：帧跳过的节奏（每 3 帧算 1 次）与极限（极端跳过漏关键帧）。
h^l(t) = f( Σ_{τ=−d}^{d} W^l(τ) · h^{l−1}(t+τ) + b ) τ 是时间偏移，不是循环
人话：每一层不只看「现在」，还看「前后各 d 拍」——就像用一组错开时间的快照拼出动态。因为看的是固定的前后几拍（不是自己上一时刻的输出），整段音频的所有帧可以一次算完，不用像 RNN 那样一帧一帧等。

4边界：老架构不是万灵药

预训练数据依赖

要大词汇音素标注语料——极低资源语言没这个家底，迁移路线用不了。

帧跳过有极限

极端跳过率漏掉短关键词的关键帧——省算力和保召回是硬权衡。

感受野固定

逐层扩展的感受野不自适应——不像注意力能动态聚焦关键时间位置。

对比不充分

与 2018 年注意力/CRNN 方法对比缺失；连续流式场景未详细评估。

5判断：能带走的三句话

JUDGEMENT

架构红利可以被推理策略再放大一层：TDNN 选对骨架只省了一部分，帧跳过和批量缓存又省一层——端侧优化的正确姿势是「架构 × 训练 × 推理调度」三层一起抠，只抠一层会剩一半的钱没捡。

通用预训练是小数据的解药：音素分类学到的声学表示与具体关键词无关——「先懂语音、再认词」的两阶段在 2018 年已是标准操作，今天只是把音素语料换成了自监督语料。

省算力与保召回存在硬边界：帧跳过率逼近关键词最短音素时长时必然漏检——「每 N 帧算一次」的 N 要按目标词的音素尺度定标，不能只看总算力节省。
