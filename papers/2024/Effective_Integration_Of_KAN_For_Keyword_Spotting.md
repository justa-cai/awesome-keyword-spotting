# Effective Integration of KAN for Keyword Spotting（KAN 在关键词检测中的有效集成）

- **作者/机构**: Anfeng Xu（南加州大学 USC，本工作在其于 Meta AI 实习期间完成）；Biqiao Zhang、Shuyu Kong、Yiteng Huang、Zhaojun Yang、Sangeeta Srivastava、Ming Sun（Meta AI）
- **发表日期**: 2024 年 9 月（arXiv:2409.08605，v3 版本于 2025 年 1 月 11 日更新）
- **链接**: https://arxiv.org/abs/2409.08605
- **关键词**: Kolmogorov-Arnold Networks（KAN）、keyword spotting、LiCo-Net、Gram 多项式、可学习激活函数、流式唤醒词检测、插入位置消融

## 问题陈述

### 问题背景和领域痛点

关键词检测（Keyword Spotting，KWS，也叫唤醒词检测）是智能设备语音助理的常驻入口：设备需要在流式音频上持续监听，只有检测到预定义关键词时才"唤醒"后续的大模型语音栈，以此来省电。这决定了 KWS 的三重工程约束：算力和内存开销必须压到最低（常驻运行意味着每一次多余的乘法都在持续烧电）、误报（false accept）必须尽量少（设备被随机唤醒是灾难级体验问题）、漏报（false reject）也必须尽量少（喊不醒同样毁体验）。论文开篇就把这个"准、快、省"的三角摆了出来，这是所有端侧 KWS 工作的共同出发点。值得强调的是这三条约束的耦合关系：误报率和漏报率天然互为代价，想在同一条权衡曲线上往好的方向挪，唯一办法就是提升模型的表达效率——用同样的参数量和算力学到更判别性的特征。所以端侧 KWS 的架构创新史，本质上是一部"单位参数表达力"的压榨史，任何新构件想进入这个领域，都必须先回答"同样预算下你到底多换来了什么"。

从模型演进看，深度学习时代的 KWS 已经轮换过三大架构家族：CNN（残差 CNN、DS-CNN、压缩 TDNN）、RNN（LSTM 加 max-pooling loss、卷积循环网络）、自注意力（Keyword Transformer、流式移动端注意力）。但论文点出一个容易被忽略的共性：这些架构的"原子构件"全是 MLP——可学习的线性层加固定的非线性激活（如 ReLU）。也就是说，过去十年的 KWS 架构创新都在改"怎么连接"，从没改过"连接本身是什么"。

2024 年提出的 Kolmogorov-Arnold Networks（KAN，柯尔莫哥洛夫-阿诺德网络，一种把"权重是数字"替换成"权重是小曲线"的网络）恰好动了这个原子构件：它把可学习线性层和固定激活合并成一组可学习的非线性激活函数。KAN 在符号公式表示类任务上同时改善了性能和可解释性，但论文同时引用了"KAN or MLP: A fairer comparison"的结论——在大多数领域里朴素地用 KAN 替换 MLP 反而更差。 Exceptions 是存在的：U-KAN 在医学图像分割的 U-Net 骨干上有效，KAN 在时间序列预测上有效。那么语音呢？语音信号精细复杂，KWS 又要求高效建模，KAN 到底是助力还是负担，在 2024 年是个没人认真回答过的问题。这就是本文的问题空间。

### 现有方法的具体不足

第一，朴素替换在参数预算下会引发"通道宽度崩塌"。KAN 每个神经元要携带 O(d) 倍于 MLP 的参数（d 是基函数个数，可以理解成描述那条"小曲线"所需的系数数量）。KWS 是参数预算极其敏感的任务，一旦在同等参数量下把 MLP 换成 KAN，网络必须把通道宽度 w 大幅调小才能维持总参数量不变——本文 Table I 里原始 LiCo-Net 的 w=72，全部替换成 GKAN 后 w 只剩 34，砍掉了一半以上。通道宽度直接决定特征的表达容量，这种崩塌在多数领域已被证明是有害的，语音端侧模型只会更敏感。

第二，没有任何先验知识告诉你 KAN 该插在深度网络的哪一层。深度网络的浅层做低级局部特征（KWS 里就是帧级的局部声学上下文），深层做高级抽象特征（子词、词的判别信息）。KAN 的曲线拟合能力和参数密度在这两种岗位上表现可能完全不同，但此前的 KAN 应用文献（医学分割、时序预测）都没有系统性地把"插入位置"当作一个变量来消融，直接整体替换了事。缺乏位置维度的指导，是 KAN 迁移到新模态时最大的认知空白。

第三，对比实验存在结构性混淆。给网络加一层 KAN，同时改变了三件事：结构深度、参数量、激活函数类型。如果不做结构对齐的对照，观察到的增益根本无法归因——到底是 KAN 的可学习激活带来的，还是单纯多了一层带来的？此前多数 KAN 应用论文没有处理这个混淆。

第四，语音领域当时基本没有 KAN 的系统探索。论文自称"据我们所知，这是最早用 KAN 做语音处理任务的探索之一"，这个空白本身就是要补的不足。

### 该论文要解决的关键挑战

概括成一句话：在参数量受严格约束的流式 1D CNN KWS 架构上，找到 KAN 的正确打开方式——既不因参数密度引发通道宽度崩塌，又能把 KAN 放在它真正擅长的工作岗位上，并用结构对齐的消融证明增益确实来自 KAN 本身，而不是来自多出来的一层。具体拆成四个子挑战：（1）替换式集成和附加式集成两大类、共六种集成方案中哪种有效；（2）在加噪等恶劣声学条件下增益是否还在；（3）在 100K/200K 的小模型规模上结论是否成立（端侧模型经常就这个量级）；（4）如何设计公平对照排除结构差异的干扰。

## 方法论

### 整体架构设计和设计动机

整体管线遵循经典的"子词分类加 WFST 解码"范式。输入是 40 维对数梅尔滤波器组能量，每 10ms 算一帧、窗长 25ms——这是 KWS 的事实标准前端配置，帧移 10ms 意味着模型每秒要跑 100 次推理，这也是为什么后续所有讨论都要死抠参数量。特征送入编码器做子词（subword，比音素更贴拼写切分的建模单元）分类，共 13 个类别：11 个子词加 SIL（静音）加 FILLER（关键词以外的任意语音）。选 40 维梅尔特征而不是更大维度，同样是参数预算的考虑——特征维度直接决定第一层的权重矩阵大小，40 维是精度和开销的老练折中。另外注意整条管线的每一级（特征前端、卷积、WFST 累积）都是逐帧因果的，没有未来帧依赖，这正是"流式"二字的工程含义：唤醒延迟被压在一帧级别。子词后验概率再交给 WFST 解码器（加权有限状态转换器，一张把子词序列累积成关键词概率的状态图），逐时刻估计预定义关键词被说出的概率。论文没有直接论证为什么选子词加 WFST 而不是整词分类，按领域惯例，子词建模能让 volume up 和 volume down 共享 "vo/lume" 子词数据、也方便不改模型就换关键词组合，这是流式 KWS 的主流选择；此点论文未展开，属于默认前提。

编码器选了 LiCo-Net（Linearized Convolution Network，线性化卷积网络）。选它的动机论文说得很清楚：简单、相对可解释、带残差连接、为流式 KWS 和硬件高效设计，且 1D CNN 家族在小参数量下已证明有竞争力。换句话说，作者刻意选了一个"干净"的实验台——结构足够简单，插入 KAN 后的归因才不会被复杂结构噪声淹没。LiCo-Net 由五个 LiCo-Block 堆叠（Fig. 3 图注），每个块三层 Conv1D：第一层是核大小 K>1 的空间卷积（实验固定 K=5），负责带局部上下文的"低级"建模；第二、三层是核大小为 1 的逐点卷积，其中第一个逐点卷积按扩张比 e（expansion ratio）把隐层维度撑大，让网络在更宽的隐空间里做"高级"建模。网络末尾再接一个 Conv1D 输出子词概率。这个"空间卷积管低级、逐点卷积管高级"的分工，正是后面所有 KAN 插入位置实验的坐标系。

### 核心算法的数学原理

KAN 的数学形式：KAN(x) = (Φ_{L−1} ∘ Φ_{L−2} ∘ … ∘ Φ_0)(x)，其中 L 是 KAN 层数，Φ_l 是一个 n_{l+1}×n_l 的矩阵——但注意，这个矩阵的每个元素 ϕ_{l,i,j} 不是一个数，而是一个可学习的激活函数。每个激活函数用基函数展开表示：ϕ = w_b·b(x) + w_s·Σ_m c_m·B_m(x)。翻译成人话：MLP 里一条边只有一个可学习的标量权重乘上去再过固定 ReLU；KAN 里一条边是一整条可学习的曲线，这条曲线由三部分拼成——一个基函数 b(x)（如 silu(x)，即 x·sigmoid(x)，提供固定的基础非线性）、一组 B 样条基 B_m（分段多项式，负责曲线的可塑部分）配上可学习系数 c_m、再加两个预定标量 w_b 和 w_s 控制两部分的占比。这里 w_b·b(x) 那一项的设计很聪明：它给曲线保底了一个已经被深度学习反复验证的合理形状（silu），可学习部分只需要在此基础上拟合"残差形状"，训练起点不比 MLP 差，这也是 KAN 能稳定收敛的一个重要工程细节。原版 KAN 用 B 样条，本文改用 Gram 多项式（离散数据点上正交的多项式族），即所谓 GKAN。

卷积版 KAN 的形式：y_{C_out,i} = Σ_{d=0}^{C_in−1} Σ_{a=0}^{k−1} ϕ_{C_out,a,d}(x_{d,i+a})。对比普通 1D 卷积 y_{C_out,i} = Σ_d Σ_a w_{C_out,a,d}·x_{d,i+a}，区别只有一处：标量权重 w 换成了曲线 ϕ。所以卷积 KAN 的直观理解非常干净——卷积核里每个"权重槽位"从乘一个数变成过一条可学习曲线，感受野、滑动方式、流式因果性全部不变。这也是它能无缝嵌进 LiCo-Net 的根本原因：结构上是即插即用的，改的只是"乘法"这一个动作。

两个关键实现选择及理由：（1）基函数用 Gram 多项式而非原版 B 样条，理由是作者自己的初步实验加上引用文献在图像分类上验证过 Gram 版本的优越性，全文阶数固定为 3；（2）这一选择没有被系统的消融支撑（基函数族对比论文未报告），属于经验性决策。阶数定在 3 也讲得通：阶数越高曲线越能弯、参数也越多，三阶已经能表达一次弯加一次回弯的形状，对语音特征这种平滑分布大概率够用，再高就会加剧参数密度问题。参数代价的数学本质：每条曲线需要 O(d) 个系数（d 为基函数个数），所以每个 GKAN 神经元的参数量是 MLP 的 O(d) 倍，网络因此变"稠密"。

### 关键技术创新一：替换式集成——先做一次"朴素对比"

第一组实验把 LiCo-Block 里的空间卷积和逐点卷积分别或全部替换成 GKAN，得到三种新架构（Fig. 3）：GKAN MLP（只换空间卷积）、MLP GKAN（只换逐点卷积）、GKAN（全换）。这一步的设计意图是回答最原始的问题——同等参数预算下 KAN 和 MLP 硬碰硬谁强。实验通过调小通道宽度 w 把各架构总参数量对齐在 394K-415K 区间（Table I），使得对比至少在参数维度上是公平的。结论是三种替换里只有 MLP GKAN（在高级建模位置换 KAN）勉强不输基线，其余两种都明显更差。这个"看似失败的实验"其实是全文最重要的证据之一：它排除了朴素替换路线，并把注意力导向了"高级位置"这个线索。

### 关键技术创新二：附加式集成——把 KAN 当"插件"而非"替身"

第二组实验不改原结构，在逐点卷积旁边插入一个额外的 GKAN Conv1D 层（输入输出维度都是 w×1），分三种位置（Fig. 4）：GKAN pre（逐点卷积之前）、GKAN post（逐点卷积之后）、GKAN mid（与逐点卷积并行）。扩张比统一 e=6。这条路线的动机直接来自第一组实验的教训：既然替换会引发通道宽度崩塌，那就保留 MLP 原有的宽度，用"增量"的方式引入 KAN。效果是通道宽度保住了——Table II 里三种附加方案的 w 在 62-64，只比原始的 72 略小，参数量 396K-412K 与基线 394K 几乎持平。结果 GKAN post 成为全文最优配置，而 GKAN mid 惨败（后面实验部分展开）。

### 关键技术创新三：结构对齐消融——把"激活函数"这个变量单独拎出来

作者意识到 GKAN post 对原始 LiCo-Net 的胜利不完全公平：多插了一层，结构和深度都变了。于是补做了对照（Fig. 6）：给原始 LiCo-Block 也加一个普通 Conv1D 层、位置与 GKAN post 完全一致，称为 MLP post（399K 参数、w=70，与 GKAN post 的 396K、w=62 对齐）。这样 MLP post 和 GKAN post 的结构一模一样，唯一的差别是那一层用固定激活的卷积还是用可学习激活的卷积——增益的归因链条这才闭合。这个消融设计是方法论上最值得学习的部分：任何"加模块涨点"的论文都应该过这一关。

### 与现有方法的技术差异

与原版 KAN（Liu 等，2024）的差异：原版主打 B 样条和整体替换 MLP 的哲学，本文换成 Gram 多项式、并且放弃整体替换改为局部插入。与"KAN or MLP: A fairer comparison"（2024）的差异：那篇的结论是参数对齐时 KAN 在多数任务上打不过 MLP，本文没有推翻这个结论，而是把它细化了——KAN 不是全局选择题，是局部填空题，放对位置（低维高级特征处）就有收益。与 U-KAN（医学分割）和 KAN 时序预测的差异：那些工作换掉整个骨干，本文保持 LiCo-Net 骨干不动、只在块内部做手术，因而能给出"插在哪"的精细结论。与 KWS 自家文献的差异：CNN/RNN/注意力路线都在改连接拓扑，本文是第一个改"连接本身"的，且明确不以刷 SOTA 为目标，而以给出 KAN 集成方法论为目标。

## 实验结果

### 使用的数据集及其规模

正样本：四个常用英文短语作关键词——take a picture、volume up、volume down、play music，数据来自众包并去标识化，按说话人独立方式切分训练/测试（同一说话人的语音不跨集）。训练集四个关键词分别约 15K、25K、22K、24K 条，来自 14957 个说话人；评测集分别约 4K、6K、5K、6K 条，来自 3801 个说话人；每条平均时长 2.5 秒。说话人独立切分在这里不是可选项而是硬要求——KWS 上线后要面对从未见过的说话人，如果同一人的语音横跨训练和测试集，测得的 FRR 会严重虚低，模型等于提前"背过"了这些人的音色；14957 个训练说话人相对关键词条数更充足，说明正样本的说话人多样性有保障。负样本：用 LibriSpeech 里不含关键词的语音，train-clean-360 和 train-other-500 作训练负例，train-clean-100 加 dev/test 的 clean/other 作评测负例（子集名对应的公开语料规模约 360 小时与 500 小时，正文未再给出具体数字）。正负训练集都做了加背景噪声和变速增广。训练细节：8 卡 GPU、batch 400、Adam（β 取 0.9 和 0.98）、学习率 0.001、共 10 个 epoch；交叉熵损失对 SIL、FILLER、11 个子词分别加权 1、2、8；子词标签用预训练声学模型做强制对齐（force alignment，用现成模型把每帧归属哪个子词切出来）得到。类权重 8 给子词的理由可以倒推：子词帧在数据里占比小但恰恰是决定漏报的类别，加权是为了在优化里保护它们。

### 评估指标的定义和选择理由

指标是四个误报工作点上的错误拒绝率：FA/h = 0.1、0.2、0.5、1.0 时的 FRR。选择理由在于 KWS 本质是检测任务而非分类任务：单看一个准确率毫无意义，必须在"多久误唤醒一次"和"喊了多经常没反应"之间画权衡曲线。FA/h = 0.1 意味着平均十小时才允许一次误唤醒，这是产品化唤醒词最苛刻的档位；报满四个工作点等于把 DET 曲线（检测错误权衡曲线）上的关键段落都采样了（Fig. 5 直接给出了 take a picture 和 volume down 两个关键词的 DET 曲线）。之所以报四个固定档而不是曲线下面积之类的汇总数，是因为真实产品只会选一个工作点部署，研究者需要让读者在任何感兴趣的工作点上都能直接对比两条曲线的高低，汇总指标反而会掩盖局部交叉（后文 Table IV 的 100K 档就真的出现了档位间交叉）。FRR 越低越好，同一 FA/h 档位下比较才有意义。这个指标体系是工业界 KWS 的标准做法，比学术界的 top-1 准确率严格得多。

### 与基线方法和SOTA的详细对比

**替换式集成（Table I，参数对齐在约 394K-415K）**：原始 LiCo-Net（w=72，394K）在四个档位 FRR 为 2.108/1.718/1.213/0.866；GKAN MLP（w=52，415K）为 2.584/2.047/1.429/1.077，全档位更差；MLP GKAN（w=42，394K）为 2.049/1.588/1.256/0.923——最苛刻的 0.1 档比基线略好（相对改善约 2.8%），但 0.5 和 1.0 档反而略差（1.256 对 1.213、0.923 对 0.866），属于互有胜负；GKAN 全换（w=34，402K）为 2.544/2.077/1.419/1.075，全档位明显更差。这张表的读法是：把 KAN 放在低级建模位（空间卷积）必败，放在高级建模位（逐点卷积）最多打平，同时通道宽度从 72 被压到 34-52。由此得出全文核心推断：GKAN 更擅长高级特征建模，且在深度网络的靠后阶段集成更有希望。

**附加式集成（Table II）**：GKAN pre（w=64，408K）为 2.226/1.863/1.272/0.974，略差于基线；GKAN post（w=62，396K）为 1.772/1.525/1.073/0.758，四档全部显著优于原始 LiCo-Net，相对改善分别约 16%、11%、12%、12%；GKAN mid（w=64，412K）为 3.446/2.537/1.939/1.444，0.1 档比基线恶化约六成，是全文最差配置。作者对 GKAN mid 灾难的解释是：MLP 和 GKAN 建模输入特征的方式差异太大，并联在一起（两路输出融合）会互相干扰，不适合并行使用。作者还给出更一般的直觉论证：KAN 每神经元参数多几倍、网络"稠密"，所以更适合在低维空间里建模复杂模式——逐点卷积后的高级特征空间维度不高但语义浓缩，正是 KAN 的舒适区；而空间卷积处理的高维原始特征会让参数代价失控。对这个"舒适区"论断可以再往深挖一层：原始梅尔特征维度高、统计分布接近连续平滑的能量面，逐点乘加这种线性操作加一个固定非线性已经足够刻画；而逐点卷积输出的高级特征是被网络压缩提纯过的低维语义向量，类间边界更弯曲、更复杂，恰好是可学习曲线擅长雕刻的形状——KAN 的容量花在刀刃上还是花在空气里，取决于它面对的是哪种特征。这也解释了为什么同样一个 GKAN 层，插前插后命运迥异。

**噪声鲁棒性（Table III）**：评测集加随机背景噪声，信噪比服从以 12.5dB 为中心、截断在 [0, 25] dB 的高斯分布。MLP 原始（w=72，394K）四档 FRR 为 8.748/7.017/4.903/4.024；GKAN post（w=62，396K）为 7.748/6.167/4.332/3.434，相对改善约 11%-15%，且是全档位一致的优势。这说明干净语音上的增益不是对安静条件的过拟合，在恶劣声学下依然成立甚至更值钱（噪声下 FRR 绝对值翻了几倍，同样比例的改善对应更多实际挽回的唤醒）。

**小模型规模（Table IV，扩张比 100K 档用 e=5、200K 档用 e=6）**：约 200K 参数档，MLP（w=50，204K）clean 为 2.55/2.04/1.39/1.09，GKAN post（w=42，196K）为 2.16/1.83/1.41/0.97——0.1 档相对改善约 15%，仅 0.5 档以 1.41 对 1.39 基本打平，总体占优；noisy 下 10.51/8.46/6.18/4.82 对 10.13/7.74/5.44/4.25，也是 GKAN post 全面更好。约 100K 参数档，MLP（w=36，104K）clean 为 3.23/2.72/1.99/1.56，GKAN post（w=30，101K）为 3.64/2.68/1.87/1.44——0.1 档反而差了约 13%，后三档略好，noisy 下同样互有胜负（12.94 对 12.56、7.58 对 7.68、5.94 对 6.17）。论文自己的措辞是"comparable（相当）"，并给出解释：通道宽度下降对小模型的伤害更大——模型本来就窄，再为 KAN 腾参数把 w 从 36 压到 30，表达容量损失超过了 KAN 曲线带来的表达收益。这个边界条件很关键：GKAN post 的收益区间在约 200K 参数以上，更小的模型上不要用。

需要说明的是，本文没有与其他 SOTA 架构（如 TC-ResNet、MatchboxNet、BC-ResNet）横向对比，基线只有 LiCo-Net 自身——这与论文"研究 KAN 集成方法论而非刷榜"的定位一致，但意味着无法从本文判断 GKAN post 相对当下最强 KWS 架构的位置。

### 消融实验的发现

核心消融（Table V、Fig. 6）：MLP post（给原 LiCo-Block 加一个与 GKAN post 同位置的普通 Conv1D，399K 参数、w=70）对 GKAN post（396K、w=62）。clean 下 MLP post 为 2.06/1.658/1.12/0.832，GKAN post 为 1.772/1.525/1.073/0.758；noisy 下 MLP post 为 9.3/7.118/5.124/3.943，GKAN post 为 7.748/6.167/4.332/3.434，noisy 0.1 档相对改善约 17%。注意一个细节：MLP post 本身就比原始 LiCo-Net 强（clean 0.1 档 2.06 对 2.108），说明"加一层"确实自带增益——这正印证了结构对齐消融的必要性；而在结构完全对齐之后 KAN 版本仍然再赢一截，这才把增益归因到可学习激活函数本身。消融的三条结论：（1）加层有增益但 KAN 加层增益更大；（2）增益在噪声下放大；（3）结合 Table II 的 GKAN mid 失败，KAN 的集成方式比"用不用 KAN"更重要。此外，位置消融（pre/post/mid，Table II）和规模消融（100K/200K，Table IV）也可视为广义消融，分别定位了"插在逐点卷积之后"和"200K 以上参数"两个甜点。基函数族（Gram 对 B 样条）和多项式阶数（3 之外）的消融论文未报告。整套消融链合起来读，可以把全文证据组织成一个干净的三段论：替换式实验定位到高级位置，附加式实验找到 post 这个甜点，结构对齐消融排除混淆完成归因——每一步都建立在前一步的意外结果上，这个推进节奏本身就是好的消融设计范本。

## 主要贡献

一、据作者所知这是最早用 KAN 做语音处理任务的探索之一，填补了 KAN 在语音模态的应用空白，为后续研究者提供了直接的参照系。

二、系统性的集成方式消融：两大类（替换式、附加式）共六种集成方案（GKAN MLP、MLP GKAN、GKAN、GKAN pre、GKAN post、GKAN mid）在同一参数预算、同一数据、同一训练配方下横向对比，外加结构对齐的 MLP post 对照，形成了一套"加新模块该怎么验证"的完整方法论模板。

三、得出了可迁移的核心判断：KAN（GKAN）在低维空间建模高级复杂特征时最有效——具体到 KWS 就是插在逐点卷积之后（GKAN post），以几乎相同的参数量（396K 对 394K）在四个误报档位全面降低 FRR，且在噪声和小到 200K 参数规模下依然成立。这个"放在哪比用不用更重要"的判断对 KAN 在其他模态的落地同样有指导价值。

四、明确画出了失败边界：低级位置必败、并行融合严重翻车（GKAN mid 0.1 档 FRR 恶化约六成）、100K 参数以下收益消失——负面结果同样是贡献，帮后来者避坑。

## 局限性与展望

### 方法的技术局限性

参数密度是原罪。KAN 每神经元 O(d) 倍的参数使得任何集成方案都要在"通道宽度"和"曲线表达力"之间做交易，本文最优的 GKAN post 也把 w 从 72 压到了 62；这个交易在 100K 档已被证明是净亏损。更深一层看，这意味着 KAN 的收益本质上被锁死在一个中间带宽区间：模型太大时 MLP 自己就有足够容量学出复杂决策边界，曲线化带来的边际收益递减；模型太小时参数密度又先杀死通道宽度。KWS 恰恰是一个两头都常见的领域——音箱端模型几十 K 参数、手机端可以放宽到几 M——GKAN post 的适用窗口需要使用者在设计前先掂量清楚。更实质的问题是：论文完全没有报告推理延迟、算力（FLOPs）和实际内存占用——KWS 是每秒跑 100 帧的常驻任务，KAN 的曲线求值（即使只是三阶多项式）相对一次乘法的硬件代价、以及参数密度对缓存友好度的影响，很可能抵消 FRR 上的几个点收益；这些关键工程数字论文未报告，而 LiCo-Net 被选中恰恰是因为"硬件高效"，这个张力论文没有正面处理。其次，KAN 招牌的可解释性（把学到的激活曲线画出来看物理含义）在本文完全没有兑现——论文未报告任何激活函数可视化分析，等于放弃了 KAN 相对 MLP 最独特的卖点。第三，基函数选 Gram 多项式、阶数定 3，都只靠初步实验和外部文献，缺少自身消融，基函数族与阶数的敏感性论文未报告。

### 实验设计的不足

数据是内部众包集，四个英文关键词、14957 个训练说话人，不公开、无法复现，也没有在 Google Speech Commands 这类公开基准上验证泛化性。训练只跑 10 个 epoch，未报告随机种子数量和方差——KWS 这种小幅增益（clean 0.1 档 0.3 个点的 FRR 差距）不做多次种子统计，显著性存疑，论文未报告置信区间。基线只有 LiCo-Net 一族，没有和任何外部 SOTA 架构对比，无法回答"这套增益搬到更强骨干上还剩多少"。噪声评测只有一种信噪比分布（12.5dB 中心、[0,25] 截断），没有分频段、分噪声类型（稳态噪声对突发敲击）的细分分析，也没有远场混响条件。DET 曲线只展示了四个关键词中的两个。此外，FRR 在 FA/h=1.0 以上的宽松档位没有测试，产品端偶尔也用高误报容忍档做灵敏度调试。

### 未来可能的改进方向

按论文结论的自然延伸和上述局限，值得做的方向包括：把"高级低维处插 KAN"的配方迁移到其他语音任务（论文自己点名的方向——语音识别、声学事件检测等）和其他模态，验证这个位置规律是不是普适；对基函数族和阶数做系统消融（Gram 对 B 样条对径向基，阶数 2 到 6），找到精度对参数的最优曲线容量；用剪枝或蒸馏把 GKAN 层的参数密度压下来，尝试挽救 100K 以下档位；正面量化 KAN 曲线求值在目标硬件（DSP、Cortex-M）上的真实时延和能耗，回答"值不值"这个端侧必答题；利用可学习激活的可解释性做唤醒词定制或子词级错误分析，把 KAN 独有的优势变现；以及在公开基准、多语言关键词、远场多噪声条件下重跑，补齐统计显著性和外部基线。这些方向里，硬件量化和可解释性变现是决定 KAN 在 KWS 里是"论文级 curios"还是"工程级选项"的两道门槛。还有一个论文完全没有触碰但值得追问的问题：子词级建模里 KAN 到底改善了哪些子词的判别（是辅音密集的 ture 还是元音开头的 a），把增益定位到语言学单元上，既能验证"高级特征建模"这个解释，也可能反过来指导关键词选取——这类细粒度归因分析论文未报告，留给后续工作。
