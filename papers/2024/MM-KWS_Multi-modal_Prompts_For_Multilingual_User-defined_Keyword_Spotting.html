文本当锚、语音当修正：双模板注册，
缺谁都能跑、有谁就更准

MM-KWS: Multi-modal Prompts for Multilingual User-defined Keyword Spotting

作者：Zhiqi Ai（艾志琦）、Zhiyong Chen、Shugong Xu（徐树公）—— 上海大学

发表：2024.06 · arXiv:2406.07310 · 代码与数据开源

文本 + 语音双模板注册冻结多语言预训练组QTAM / QAAM 双注意力 单元级辅助监督四路难例挖掘 + ZS-TTSWenetPhrase 基准在线 3.9M / 6ms

一分钟版本

  • 两条路线各自拿掉了对方的长处：QbyA（语音注册）信息贴近真实发音但注册贵、怕信道 / 噪声 / 说话状态变化——1 条注册时 SPC Acc 崩到 69.0%；QbyT（文本注册）便宜稳定但丢掉说话人实际发音——口音用户音素发错显著伤害性能。
  • 方案：注册端做成「文本 + 语音」双模板且都可缺省——查询支路 Tiny Conformer（在线）；支持支路三个冻结多语言预训练模型（DistilBERT 文本 768d + G2P 音素 64d + XLS-R 0.3B 语音 1024d → mapper 统一 128d），注册嵌入只预计算一次、推理时查表——大模型不在关键路径上，这就是「多模态 + 大模型 + 6ms 延迟」能同时成立的全部秘密。
  • 匹配：QTAM（查询+音素+文本三路拼接自注意力）与 QAAM（查询+注册语音）并行 → GRU 后验加性融合（文本为主、语音为辅）；辅助损失 Lphon/Ltext 给注意力提供单元级密集监督——消融里贡献最大（去掉后 LH EER 9.30→12.95）。
  • 结果：英语 LH 难集 EER 9.30%（3.9M 参数登顶，反超 109M 的 AdaKWS-Small 的 11.48）；普通话 WH 上 ASR 系统 AUC 全贴随机线（56-58%）而 MM-KWS 85.84%、延迟 6ms 对 300ms；零样本 SPC：纯文本注册（94.4%）已胜 QbyA 用 5 条语音（90.5%），方差还小一个量级。
  • 难例挖掘四路：音素编辑距离（音近）+ 语义余弦（义近）+ 词序排列 + LLM 生成 → ZS-TTS 合成 390 万条双语负例——LH EER 12.45→9.30 的主要功臣；代价诚实：易集轻微退化（LE 0.41→0.68、WE 1.95→4.25）——决策边界推向保守侧的权衡。
  • 成色缺口：普通话 WH 最好 EER 仍 22.06%（声调是硬骨头）；融合是最朴素加性（无置信度门控）；口音假设无专项评测；流式 / 6ms 测量条件未报告。

§01 · 问题陈述

把「关键词是什么」从模型参数搬到推理时的输入端

四代方案与量化死穴：① LVCSR 词格检索——表外词性能骤降 + 端侧太重；② 热词增强 ASR——FunASR 带热词表 300ms / Whisper-Large 316ms 单次推理（对常驻监听不可接受）；③ QbyA——1 条注册语音时 SPC Acc(close) 仅 69.0%（注册信息太少性能崩塌）；④ QbyT（CMCD / EMKWS / PhonMatchNet / AdaKWS）——单文本模态固有软肋：只告诉模型「标准上该怎么发音」，不知道「这个用户实际会怎么发音」。四个挑战：双模态融合成统一注册机制（不是二选一）；同一套系统覆盖多语言（英 + 普通话，不重训）；针对性提升易混词区分（UDKWS 错误主要来源）；融合多模态 + 多个大模型的同时把在线开销压到 6ms。

§02 · 方法论

离线大模型特征 + 在线小模型匹配的解耦

图 A·多语言策略藏在选型里：DistilBERT / G2P / XLS-R 都是多语言预训练模型，没为中文或英文分别训练任何组件——切换语言只换词表和发音词典，「多语言能力从预训练模型继承而非从 KWS 数据学」。每个输入嵌入叠加位置编码（防置换不变性把 "ni hao" 与 "hao ni" 混同）+ 模态类型编码（防注意力把音素和子词当同一种 token 混着对齐）——给每帧发「工牌 + 座位号」。

Putt = σ( Wu·(Puttt + Putta) + bu )；　Ltotal = Lutt + Lphon + Ltext
人话：两路后验简单相加再线性 sigmoid——没有学自适应权重（注册语音质量差时应自动降权 QAAM——可改进点），梯度自己校准两路相加后的量程。融合之简单与消融效果之稳形成有趣对照。

§03 · 实验结果

难集才是前沿；识别式系统在普通话音近词上集体失效

数据三司其职：LibriPhrase（英语主场）+ WenetPhrase（本文新建普通话基准：WenetSpeech 1000h 强制对齐切分，12.2 万训练类 / 5.4 万测试类 / 290 万样本，按 LibriPhrase 划 WE/WH——例：锚点「宁愿」难负例「庭院、行院、情愿」）+ SPC（零样本跨库：训练 LibriPhrase 直测 SPC，检验预训练特征是否把任务从数据分布解耦）。训练预算克制：4×4090、Adam、4 万步——算力主要花在数据合成而非模型训练。

表 1 复绘·按 LH EER 升序。参数量标注在名称下方：MM-KWS* 以 3.9M 登顶（96.25 AUC / 9.30 EER），反超 109M 的 AdaKWS-Small（11.48）——差距来自多模态注册与难例增强而非堆参数。Whisper-Small 参数量在本表为 224M（Table 2b 写 244M，论文内部不一致）。

表 2b 复绘·红色虚线为随机线（AUC 50）——四个 ASR 系统全部贴线，连带热词表的 FunASR 也只有 58.31：普通话音近词对识别式是灾难级难题。MM-KWS 在 WH 拉开 27 点以上、延迟只有对方 1/50（6ms 对 300ms）。右栏为「增强换难集收益、易集退化」的诚实账单。

表 3 复绘·零样本 = 训练 LibriPhrase 直测 SPC。最关键的读数：MM-KWS 的「最差输入模式」（纯文本 0 条语音 94.4）胜过 QbyA 的「充分输入模式」（5 条语音 90.5），且方差 ±0.18 对 ±1.67 小一个量级——文本锚点带来的不只是均值提升还有稳定性。

消融（Table 4，LH EER：完整 9.30）：① 辅助损失贡献最大——去掉 12.95（+3.65），单元级密集监督是难例区分刚需；② 易混词生成次之——去掉 12.45（+3.15），但 LE 反而好转到 0.41——增强是难集换易集的权衡；③ 语音支路贡献最小但稳定为正——去掉 10.41（+1.11）：朗读无明显口音数据上文本通路已承担大部分判别，语音通路的边际价值要到口音场景兑现——而论文恰没做口音评测（消融结论外推的边界）。自洽性加分：「去掉易混词生成」行与 Table 1 的 MM-KWS 行完全一致。未拆：音素 vs 文本嵌入各自贡献、LLM vs 规则负例占比、非零样本的注册条数曲线。

§04 · 主要贡献

可转述的四个判断

1双模板可缺省的鲁棒结构
多模态不是锦上添花而是「缺谁都能跑、有谁就更准」——纯文本注册已胜单模态的充分语音输入，方差还小一个量级。
2大模型离线跑、小模型在线跑
注册嵌入一次预取 + 查表复用——0.3B 编码器不在关键路径上，「多模态 + 大模型 + 6ms」同时成立的解耦模式可迁移。
3单元级辅助监督是对齐学习的刚需
句子级标签下注意力对齐自由不可解释；音素 / 词级密集监督给联合嵌入装上「被匹配没」的指示——消融最大单项。
4检测式 ≠ 识别式
Whisper 全系在 LH 挣扎、普通话 WH 贴随机线——「识别得好」不等于「能区分音近词」；难集才是 UDKWS 的真前沿。

§05 · 局限性与展望

普通话难集 EER 仍 22%；口音假设没有直接检验

方法局限

  • 难集绝对性能不高：WH 最好 AUC 85.84 / EER 22.06——声韵调微差、同调近音距实用差距明显。
  • 增强换易集退化：LE 0.41→0.68、WE 1.95→4.25——缺自适应难度 curriculum 或按例加权。
  • 融合过于朴素：加性融合无置信度门控——注册语音质量差时应自动降权 QAAM。
  • 离线依赖仍重：注册侧要跑 XLS-R + DistilBERT + G2P +（可选）ZS-TTS——注册算力门槛未量化；论文自认端侧部署是未完成事项。
  • 合成域差未评估：390 万负例全来自 ZS-TTS——是否学到「合成声学特征」捷径无分析。
  • 无流式方案：Conformer 与注意力按整句处理；6ms 测量条件（输入长度 / 硬件）未报。

实验设计不足

  • 口音假设未直接检验：核心动机是「语音模板修正口音」，但无带口音标注的评测集（非母语英语 / 方言普通话）——只有「加 1 条语音涨点」的间接暗示。
  • 消融覆盖不全：QTAM 内部三输入无两两消融；LLM vs 规则负例占比未拆。
  • 零样本对照单薄：只比了一个 QbyA 基线——零样本优势多少来自多模态、多少来自预训练特征本身不可分。
  • 超参不完整：学习率 / 批大小 / WenetPhrase 切分比例未报；Whisper-Small 参数量两表不一致（224M vs 244M）。
  • 延迟口径缺失：未说明注册侧还是查询侧、输入多长、什么硬件——只能相对比较。
值得追的方向：① 论文自指：统一单模型多语言框架（去拼装依赖）+ 端侧轻量化；② 加性融合升级为置信度自适应门控 + 注册语音质量估计——让语音通路权重随质量与说话人匹配度动态变化（可能有免费收益）；③ 普通话难集引入声调显式建模（声调嵌入）或对比式声调难例挖掘——WH 22.06% 说明现有音素表示对声调区分不够；④ 真实录音回灌 / 合成-真实混合训练 + 难度分级 curriculum 缓解易集退化；⑤ 口音 / 远场 / 噪声专项评测把核心卖点放到数据上验证 + 流式化查询支路（下采样 Conformer / 缓存式注意力）；⑥ LLM 角色从「批量造词」扩展到「按用户误触发日志定向造难例」——部署在环的难例闭环。
