帧与帧之间大多数神经元根本没变——
只为「变化」付费的 36nJ 关键词芯片

DeltaKWS: A 65nm 36nJ/Decision Bio-inspired Temporal-Sparsity-Aware Digital Keyword Spotting IC with 0.6V Near-Threshold SRAM

作者：Qinyu Chen、Kwantae Kim、Chang Gao（共同一作）等 7 人 —— 苏黎世大学 / ETH INI × 代尔夫特理工

发表：2024.05 · IEEE TCASAI 接收 · arXiv:2405.03905

一分钟版本

  • 两条领域事实：① 已报导 KWS 芯片中权重 SRAM 一项占整芯片功耗 40-60%——模型想变大先被存储功耗卡死；② 片外 DRAM 读 6.2 kB ≈ 1 µJ，而本文整芯片一次决策只要 36 nJ（差近两个数量级）——权重必须片上，且片上存储本身要做省。
  • 没人挖过的稀疏维度：已有芯片用激活稀疏（≤70%）、权重位稀疏、整帧跳过（76%，粗粒度）——没有任何工作把「激活值的变化量」当能效来源。语音相邻帧高度相关：循环网络隐状态绝大多数分量不变，计算冗余不在「值是多少」而在「值变了没有」。
  • 方案：ΔRNN——每个神经元算时间差分 Δx/Δh，只有 |Δ| 超过阈值 ΔTH 才更新（零阶保持预测器，生物启发：皮层神经元只在变化超阈值时发放）；GRU 门控数学不动，只改「什么时候需要算」。配套硬件：ΔEncoder 筛事件 → ΔFIFO 广播 → 8 MAC + State Assembler 保证状态一致性。
  • 设计点 ΔTH=0.2：87% 时间稀疏，精度只掉 <0.6 点（12 类 89.5%），能量 121.2→36.11 nJ（3.4×）、时延 16.4→6.9 ms（2.4×）；能量降幅大于时延——省下的正是被跳过的权重 SRAM 读取。
  • 另两个电路杠杆：IIR BPF 特征提取器三连优化（混合精度 12b/8b + 系数对称性换乘位 + 10 通道）功耗 5.7×↓ 面积 4.7×↓；0.6V 近阈值全定制 SRAM 读功耗 6.6×↓，存储占比 40-60%→18%（代价面积 ×2——always-on 场景里漏电是每秒支付的持续成本，面积是一次性成本）。
  • 边界：65nm 上 36 nJ 不是绝对 SOTA（28nm 的 Tan ISSCC24 做到 1.73 nJ）——价值主张是「成熟工艺 + 12 类全标签任务」；麦克风前端 / ADC / 时钟 / 电源管理均未集成；只测了 GSCD 干净条件。

§01 · 问题陈述

常开芯片的三重硬约束：微瓦功耗、小面积、精度不塌

图 A·三个设计难题对应三个核心模块：ΔRNN 落成数字电路（状态一致性、跨时钟域握手）；IIR 定点化的位数-稳定性平衡；0.6V SRAM 读容限恶化要电平移位 / 字线提升兜底。

§02 · 方法论

一个算法杠杆 + 两个电路杠杆，收益相乘

既不算乘加、也不触发权重 SRAM 读取； 多出来的那部分能量收益正是省下的存储访问功耗。ΔFIFO 排队动态事件：事件多时 8 个 MAC 排干队列、少时提前收工——稀疏度随内容自适应（静音帧约省 40% 时延，Fig. 11）

图 B·GRU 门控数学完全不动，改的只是「什么时候需要算」——ΔTH 是唯一精度-能耗旋钮，且是训练后仍可调的运行时旋钮（区别于剪枝 / 量化那种部署时一次性定死的压缩）。双时钟域：SPI 接口快时钟、片内滤波与网络慢时钟各用独立分频器。

Δx = xt − xt−1；　仅当 |Δ| > ΔTH 才更新该神经元；　xt = xt−1 + Δxt
人话：每个神经元配一个零阶保持预测器——预测值就是上一帧值，只有预测误差超过 ΔTH 才「发射事件」执行更新。事件发生率 = 时间稀疏度，直接决定被跳过的乘加数量与权重读取次数。ΔTH=0 退化为稠密 GRU；0.2 时 87% 稀疏、精度只掉不到 0.6 点。

§03 · 实验结果

65nm + 12 类全标签语境下的 36nJ；三组扫描构成完整消融链

设置与测量：GSCD 12 类全标签（Silence/Unknown + 10 命令词），同时按文献惯例报 11 类（去 Unknown）。测试板 MiniZed（Zynq 7007S FPGA）初始化并喂入；ΔRNN 125 kHz。指标自洽校验：5.22 µW × 6.9 ms ≈ 36 nJ ✓（ΔTH=0：7.36 µW × 16.4 ms ≈ 121 nJ ✓）。训练细节（增强 / 轮数 / 量化感知）论文未报告——回溯团队前作（FEx 为 ISCAS 2023）。

表 II 复绘·对数轴按能量降序。Frenkel 的 ReckOn 是通用脉冲 RNN 处理器（Spiking Heidelberg Digits 2 类单关键词任务）；Seol 的 76% 稀疏是帧级跳过的粗粒度方案。跨工艺能量排名需谨慎——本文的价值主张是成熟工艺 + 最难任务设定下的 36 nJ。

设计点联动复绘·四指标各自归一化（柱高按各指标自身量程）。87% 稀疏换来能量 3.4× / 时延 2.4× / 功率 1.4× 下降，精度只掉 0.6 点——能量降幅大于时延，差额正是被跳过的权重 SRAM 读取功耗。

三杠杆图·独立收益相乘。近阈值 SRAM 的面积代价（×2）在 always-on 场景是划算交易：漏电与读能量是每秒支付的持续成本，面积是一次性成本。

消融三连（每一步边际贡献单独标定）：① FEx 通道扫描（Fig. 6 仿真）：12 类精度拐点在 10 通道之后——10 通道（516 Hz–4.22 kHz）是精度无损的最省配置，砍 6 通道换 30% FEx 功耗（保留 16 通道重构能力留扩展）；② FEx 优化分解（Fig. 7）：混合精度系数（b 12b / a 8b——统一位宽是浪费，各滤波器动态范围不同）2.4× 功耗 / 2.6× 面积，系数对称性换乘位再 1.8× / 1.8×，合计 5.7× / 4.7×；③ ΔTH 扫描（Fig. 12 实测）：精度 / 能量 / 稀疏 / 时延四条曲线联动，0.2 是甜点、部署者可按产品需求重选工作点。模块拆解交叉验证：功耗 FEx 25% / ΔRNN 57% / SRAM 18%；面积 11% / 41% / 48%（0.084 / 0.319 / 0.381 mm²）——正文把两句都写成「功耗占比」，按数值交叉验证第一句实为面积（原文小笔误）。FEx 横向（Table I）：65nm 0.084 mm² 只比 28nm FFT 方案大 1.5 倍，特征 12b/12b 为四方案最高（对手 16b/8b、10b/8b、16b/8b），数据存储仅 200 字节（FFT 方案 256/512），16 ms 帧窗比对手 32 ms 更细，且只需 12b ADC（对手多要 16b）。

§04 · 主要贡献

可转述的四个判断

1新开一条稀疏轴线
首个把 ΔRNN 细粒度时间稀疏落成 KWS 集成电路——「激活变化稀疏」此前无人挖掘，与激活 / 权重位 / 整帧稀疏正交、原则上可叠加。
287% 稀疏只付 <0.6 点精度
ΔTH 是训练后仍可调的运行时旋钮，整条精度-稀疏-能量-时延曲线可选——不同于剪枝 / 量化的一次性定死。
3正面拆掉存储瓶颈
近阈值全定制 SRAM + 字线电平移位 + 片上 booster：读功耗 6.6×↓，存储占比 40-60%→18%——「用 2 倍面积换 6.6 倍读功耗」的系统账本示范。
4算法-架构-电路三层协同
Δ 编码（算法）+ FIFO 广播与状态拼装（架构）+ 近阈值存储（电路）：证明生物启发稀疏计算可以不牺牲精度地映射到数字 VLSI。

§05 · 局限性与展望

绝对能效不是 SOTA；系统完整性缺麦克风/ADC/时钟/电源

方法局限

  • 工艺代差封顶：65nm 的 36 nJ 对 28nm Tan 的 1.73 nJ——绝对数字非 SOTA，价值主张必须放回「成熟廉价工艺 + 12 类全标签」语境。
  • SRAM 面积 ×2 + 双电源 0.6V/0.65V 妥协（I/O 电平移位器单向性质）；单电源方案论文自己指出但本芯片未实现。
  • ΔTH 静态配置：运行中不能变，而稀疏度本身内容相关（静音帧自动省 40%）——最坏情况设计仍按活跃语音负载算，运行时策略潜力未释放。
  • 精度交换非零成本：更高 ΔTH 区间的精度崩塌点只在 Fig.12 曲线中，未给数值。
  • FEx 是固定设计：非可学习前端，特征天花板由设计期网格搜索决定。

实验设计不足

  • 只测 GSCD 干净条件：无远场混响 / 加噪 / 多说话人 / 真实唤醒词——而 always-on 设备恰在嘈杂远场工作。
  • 训练与模型细节缺失：增强 / 轮数 / 量化感知 / 精确参数量未报告（24 kB 8b 反推约两万多权重）。
  • 跨工艺对比公平性：Table II 混合 65/40/28nm 三代工艺，能量数字脱离工艺语境直接排名不严谨，无工艺归一化。
  • 系统口径：输入是 SPI 数字音频流——麦克风前端、ADC、片上时钟（来自 FPGA 分频）、电源管理未集成；Seol 的功率含 AFE 而本文不含，对比需留意；6.9 ms 时延也非最低（Kosuge 1.2 / Tan 2 ms）。
  • 文档瑕疵：功耗/面积拆解两句均标 total power（交叉验证第一句应为面积）；Table I 128k 与 Table II 125k 不一致；无 PVT / 良率数据。
最可迁移的判断（笔记结语）：在常开边缘计算里，「挖掘信号在时间上的不变量、只对变化付费」是一条与压缩 / 剪枝 / 量化正交且可叠加的节能轴线；代价是架构复杂度（状态一致性、跨时钟域、事件调度），本文用 0.78 mm² 原型证明这笔交换在 65nm 上划算。后续方向：单电源近阈值 SRAM；内容自适应 ΔTH（运行时按语音活动度调稀疏-精度旋钮，静音激进稀疏 / 语音回退稠密）；迁 28nm 冲亚 nJ；Δ 化推广到注意力 / TCN 等端侧负载；滤波器组与网络联合训练变可学习前端；集成 ADC / 麦克风前端 / 片上时钟 / 电源管理走向可部署器件。
