插对位置白赚 16%，插错位置倒贴六成

Effective Integration of KAN for Keyword Spotting

作者：Anfeng Xu（USC，Meta 实习）、Biqiao Zhang 等 7 人 —— Meta AI

发表：2024.09 · arXiv:2409.08605（v3 更新于 2025.01）

KAN 可学习激活Gram 多项式 GKANLiCo-Net 流式骨干 GKAN post 甜点结构对齐消融说话人独立评测

一分钟版本

  • 问题空间：端侧 KWS 的架构创新史是一部「单位参数表达力」压榨史——但 CNN/RNN/注意力三大家族的原子构件全是 MLP（可学习线性层 + 固定激活），十年只改「怎么连接」，从没改过「连接本身是什么」。2024 年的 KAN（权重从数字变成小曲线）恰好动了这个原子件——但「KAN or MLP」公论是参数对齐时 KAN 多数任务更差。语音没人回答过。
  • 朴素替换的下场：KAN 每神经元 O(d) 倍参数，同参数预算下通道宽度必崩——LiCo-Net 的 w=72 全换 KAN 后只剩 34（砍半以上）。实测：换空间卷积（低级位）全档位更差、全换更差、换逐点卷积（高级位）最多打平。替换路线整体排除。
  • 附加式的甜点：保留 MLP 宽度、在逐点卷积旁插一层 GKAN——GKAN post（插在逐点卷积之后）以几乎同参数（396K 对 394K）四档 FRR 全降 11-16%，加噪下 −11~−17%，200K 档仍赚 15%；GKAN mid（并联）0.1 档恶化 63%——集成方式比用不用更重要。
  • 归因闭合：给基线也加一层普通 Conv1D（MLP post，结构完全对齐）——加层本身自带增益，但结构对齐后 KAN 版仍再赢一截 → 增益确实来自可学习激活。这个消融设计是「加新模块该怎么验证」的方法论模板。
  • 失败边界：低级位置必败、并联严重翻车、100K 参数以下反噬（0.1 档 +13%）——宽度被压到 30 时表达容量损失超过曲线收益。收益区间锁定 ~200K 以上。
  • 成色缺口：零延迟 / FLOPs / 内存数字（KWS 每秒跑 100 帧，多项式求值 vs 一次乘法的硬件代价未答）；KAN 招牌的可解释性完全没兑现；内部数据不可复现、无外部 SOTA 横向对比、无多种子方差。

§01 · 问题陈述

准快省三角下，「同样预算你多换来了什么」是必答题

四个认知空白：① 通道宽度崩塌——KAN 每神经元 O(d) 倍参数，KWS 参数预算极敏感，同参数换 KAN 必须把 w 从 72 砍到 34-52，通道宽度直接决定表达容量；② 插入位置无先验——浅层做帧级局部声学（低级）、深层做子词判别（高级），KAN 的曲线拟合在两种岗位上表现可能完全不同，此前 KAN 文献（医学分割 / 时序预测）都整体替换了事、从没把「位置」当变量消融；③ 结构性混淆——加一层 KAN 同时改变深度、参数量、激活类型三件事，不结构对齐就无法归因；④ 语音空白——论文自称最早用 KAN 做语音处理的探索之一。

§02 · 方法论

实验台刻意选「干净」：LiCo-Net 五块，每块三层 Conv1D

图 A·卷积版 KAN 的直观理解很干净：卷积核里每个「权重槽位」从乘一个数变成过一条可学习曲线——感受野、滑动方式、流式因果性全部不变，这就是它能无缝嵌进 LiCo-Net 的根本原因。基函数选 Gram 多项式（离散点正交）而非原版 B 样条、阶数 3——均为经验决策，无自身消融。

KAN(x) = (ΦL−1 ∘ … ∘ Φ0)(x)，Φ 的每个元素 φ 是可学习激活：φ = wb·b(x) + ws·Σ cm·Bm(x)；　卷积版：y = Σ Σ φ(x)
人话：MLP 一条边只有标量权重乘上去再过固定 ReLU；KAN 一条边是整条可学习曲线——silu 基底（保底已验证形状）+ 三阶 Gram 多项式（可塑部分）+ 两个预定标量控制占比。每条曲线 O(d) 个系数 → 每神经元参数是 MLP 的 O(d) 倍——这就是通道宽度崩塌的数学根源。

§03 · 实验结果

三段论消融：替换定位高级位 → 附加找到 post → 结构对齐完成归因

数据与协议：四个英文关键词（take a picture / volume up / volume down / play music），众包去标识，说话人独立切分（同一人语音不跨集——否则 FRR 严重虚低，模型等于提前「背过」音色）；训练正例 15-25K 条/词、14,957 说话人，评测 4-6K 条/词、3,801 说话人，平均 2.5s；负例取 LibriSpeech 不含关键词语音（train-clean-360 + train-other-500 训练 / clean-100 + dev/test 评测）。指标：四个误报工作点 FA/h = 0.1/0.2/0.5/1.0 下的 FRR——0.1 档 = 平均十小时一次误唤醒（产品最苛刻档）；报四档而非汇总数，因为真实产品只选一个工作点部署、汇总指标会掩盖局部交叉（Table IV 的 100K 档真出现了交叉）。训练：8 卡、batch 400、Adam、10 epoch；子词标签由预训练声学模型强制对齐；类权重 SIL/FILLER/子词 = 1/2/8（子词帧少但决定漏报）。

表 I / II 复绘·横轴为误报工作点 FA/h（越右越宽松），纵轴 FRR（越低越好）。左：替换式——通道宽度从 72 崩到 34-52，低级位全败；右：附加式保住宽度（62-64），GKAN post 四档全优、mid 并联灾难（0.1 档 3.446 对基线 2.108）。

表 V / III 复绘（归因链）·MLP post 本身就比原始基线强（加一层自带增益）——这正印证结构对齐消融的必要性；结构完全对齐后 KAN 版仍再赢一截，增益才归因到可学习激活本身。噪声下（右）MLP post 在 0.1 档甚至比原始更差（9.3 对 8.748），而 GKAN post 仍全面领先——增益在恶劣声学下放大。

表 IV 复绘（规模边界）·0.1 FA/h 最苛刻档：400K 与 200K 档 GKAN post 稳定赚（−16% / −15%），100K 档反噬（3.64 对 3.23，+13%）——w 从 36 压到 30 时表达容量损失超过曲线收益。100K 档其余三个工作点与加噪结果互有胜负，论文措辞 comparable。

三段论推进（好的消融设计范本）：第一步替换式实验「失败」——排除朴素替换路线、留下「高级位置」线索；第二步附加式实验找到 post 甜点、mid 灾难（MLP 与 GKAN 建模方式差异太大，并联互相干扰）；第三步结构对齐消融排除「多一层」的混淆完成归因——每一步都建立在前一步的意外结果上。规模消融（Table IV）定位「200K 以上」甜点：100K 档把 w 从 36 压到 30，表达容量损失超过曲线收益——论文自己的措辞是 comparable。未消融：基函数族（Gram vs B 样条）、多项式阶数（3 之外）、扩张比。

§04 · 主要贡献

可转述的四个判断

1KAN 不是全局选择题
把「KAN or MLP」的公论细化成「局部填空题」：KAN 在低维空间建模高级复杂特征时最有效——插在逐点卷积之后，同样参数四档全降、噪声与小规模下成立。
2六方案 + 结构对齐的方法论模板
替换式 3 种 + 附加式 3 种在同一预算、同一数据、同一配方下横比，外加 MLP post 结构对齐对照——任何「加新模块涨点」的论文都该过这一关。
3明确的失败边界
低级位置必败、并联融合翻车（+63%）、100K 以下反噬——负面结果帮后来者避坑，比正结果更省别人的时间。
4语音模态的首个参照系
最早用 KAN 做语音处理的探索之一——位置规律若在其他模态复现，「放在哪比用不用更重要」就是普适判断。

§05 · 局限性与展望

曲线求值的硬件代价没答；可解释性这个招牌卖点没兑现

方法局限

  • 参数密度是原罪：收益被锁死在中间带宽区间——模型太大时 MLP 自己够容量（曲线边际收益递减），太小时参数密度先杀宽度。KWS 恰好两头都常见（音箱几十 K / 手机几 M）。
  • 零工程数字：无推理延迟 / FLOPs / 内存——KWS 每秒 100 帧，三阶多项式求值 vs 一次乘法的硬件代价、参数密度对缓存友好度的影响可能抵消 FRR 几个点收益；LiCo-Net 被选恰因「硬件高效」，这个张力论文没正面处理。
  • 可解释性零兑现：没画任何学到的激活曲线——放弃了 KAN 相对 MLP 最独特的卖点。
  • 超参无消融：Gram 基函数、阶数 3 都靠初步实验 + 外部文献。

实验设计不足

  • 内部数据不可复现：四关键词众包集不公开，未在 GSC 等公开基准验证泛化。
  • 无统计稳健性：10 epoch、无随机种子数量与方差——clean 0.1 档 0.3 点量级差距的显著性存疑。
  • 基线只有 LiCo-Net 一族：无 TC-ResNet / MatchboxNet / BC-ResNet 横向对比——增益搬到更强骨干还剩多少无法回答。
  • 噪声单一：只有一种 SNR 分布（12.5dB 中心），无分频段 / 分噪声类型 / 远场混响；DET 曲线只展示四个关键词中的两个；FA/h>1.0 宽松档未测。
两道门槛 + 值得追的方向：硬件量化与可解释性变现，决定 KAN 在 KWS 里是「论文级 curios」还是「工程级选项」。具体：① 配方迁移到其他语音任务（ASR / 声学事件检测）与其他模态，验证位置规律普适性；② 基函数族（Gram / B 样条 / 径向基）× 阶数（2-6）系统消融，找精度-参数的最优曲线容量；③ 剪枝 / 蒸馏压 KAN 参数密度，挽救 100K 以下档位；④ DSP / Cortex-M 上实测曲线求值时延与能耗；⑤ 用可学习激活做唤醒词定制或子词级错误分析；⑥ 公开基准 + 多语言 + 远场多噪声重跑补显著性；⑦ 子词级归因（KAN 到底改善了 ture 还是 a 这类子词的判别）——既验证「高级特征建模」解释，也可能反过来指导关键词选取。
