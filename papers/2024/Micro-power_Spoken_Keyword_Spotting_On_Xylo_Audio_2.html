常驻监听的账单看 idle 不看峰值：
216µW 待机的音频芯片把 Aloha 榜单四项下限全刷新

Micro-power Spoken Keyword Spotting on Xylo Audio 2

作者：Hannah Bos、Dylan R. Muir —— SynSense（瑞士苏黎世）

发表：2024.06 · arXiv:2406.15112（技术报告，SYNS61210 芯片实测）

一分钟版本

  • 第一性约束：KWS 是 always-on 负载——功耗直接换算成电池体积与产品形态；毫瓦级对纽扣电池 / 能量采集设备仍太贵（10mW 持续监听，CR2032 数周耗尽——笔记推算）。神经形态切入的逻辑：活动稀疏与「绝大多数时间没有唤醒词」的负载特征天然咬合。
  • 被忽视的不公平：以往 Aloha 基准的全部平台都在宿主机上算 MFCC 再喂设备——预处理能耗不计入成绩单，跨平台能效对比系统性偏乐观；而 MFCC 前端恰是常驻 KWS 的能耗大头之一。
  • 方案：整条链路进一颗芯片——模拟前端（LNA 0/6/12dB）→ 16 通道二阶带通（Q=4，40-16940Hz）+ 整流 + LIF 的片上事件编码（等效实时稀疏时频表示，<50µW）→ SynNet 前馈 SNN（线性矩阵 + LIF 交错，τ 金字塔：浅层短时间常数保毫秒级瞬态、深层长常数积分到秒级）→ 单读出 LIF（发没发事件即判决，省掉 softmax）。
  • 训练（PeakLoss）：目标样本只要求「峰后 140ms 平均膜电位达 1.5」——对关键词位置不敏感、直接优化部署判决量；非目标整条贴零且权重 ×1.4（补偿 3:1 欠采样压误唤醒——笔记解释）。
  • 账本（全部物理实测）：idle 216µW（比 Loihi 低 134×——全年 1.9Wh 对 254Wh）、动态 291µW、动态能量 6.6µJ/Inf（比 GPU 低 4495×、比 SpiNNaker2 低 7%）、活跃能量 11µJ；量化部署后 95.31% > 93% 基准线。
  • 量化行为迁移：461 模型量化后整体只掉 1.57 点，但 TPR 掉 6.25 的同时 FPR 降 3.13——读出整体变保守；对唤醒词这是划算交易（误唤醒代价 > 漏唤醒）。缺口：192 条测试集粒度 0.52 点、无方差；零鲁棒性测试；单关键词单读出；严格实时模式功耗未报。

§01 · 问题陈述

给神经形态能效主张一次公平的检验

用 Table II 实测给现有方案「验伤」：① 通用处理器功耗数量级完全不对——GPU 动态 22860mW / 29.67mJ/Inf，为吞吐而生，事件稀疏性无从兑现；② 嵌入式加速器不解决常驻底噪——Movidius idle 仍 210mW，而常驻 KWS 绝大多数时间静默、烧的全是 idle；③ 第一代神经形态芯片拉低两个数量级但 idle 仍高——Loihi 两份报告 idle 都是 29mW（全年 ~254Wh，电池设备背不动）；SpiNNaker2 动态能量 7.1µJ 出色但活跃能量未报（另文报整体 390mW）；④ 预处理被系统性排除在对比外；⑤ 精度基准线 93%——省电方案必须守住否则能效无意义。四件咬合的事：编码要稀疏（否则活动稀疏无从谈起）、网络要小（否则动态压不下来）、量化要不掉线、测量要真实（不接受仿真 / datasheet 推算）。

§02 · 方法论

滤波器组 + 整流 + LIF：不用 MFCC 的三个理由

图 A·推理核是同步数字 CMOS 整数逻辑处理器（16b 状态 / 8b 权重），主时钟仅 6.25MHz（比通用 SoC 低约三个数量级）——微功耗的第一来源；活动稀疏（无事件不计算）是第二来源。定位差异：Xylo 为「实时流式单路信号」裁剪而非推理加速器——这解释了为什么它推理率全场最低（40-102 Inf/s）而能效全场最高：同一枚硬币的两面。

PeakLoss：y=1 → MSE( (1/M)·Σk=m..m+M xk, g )，m = argmax x；y=0 → wl·MSE(x, 0)；（M=140ms, g=1.5, wl=1.4）
人话：目标样本不要求 3 秒全程高，只要求冲一个峰、峰后 140ms 平均达到 1.5；非目标全程贴零且权重放大。LIF（漏电积分发放）像电容充放电——输入攒膜电位、漏电往下拖、过阈值才发一个脉冲。

§03 · 实验结果

四项下限全刷新；精度与规模解耦

数据与测量：Aloha 基准（Blouw 2019）——训练 ~2000 条 / 96 说话人 / 目标:非目标 3:1，测试 192 条（笔记从 TPR/FPR 都是 1/96 整数倍反推为各 96 条均衡集）；样本统一 3s。功耗三拆：idle（部署后无输入测 5s）/ active（流式送入整个测试集）/ dynamic = active − idle——常驻账单 = 全天候 idle + 有声期动态，只报动态会低估。测量：开发板载电流监测 1280Hz 采样、主时钟 6.25MHz、全部物理器件实测。「1 次推理 = 10 时间步」沿用 Blouw 口径保历史可比。

表 II 复绘·对数横轴。左：动态能量——Xylo 6.6µJ 仅比 SpiNNaker2 低 7%，但 SpiNNaker2 的活跃能量未报告（另文报其整体功耗 390mW，若计入将显著恶化）。右：idle——所有对比平台的整机/整卡口径对 always-on 是压倒性劣势。活跃能量（含 idle 摊销）：Xylo 11µJ，次优 Loihi 复测 130µJ。

表 I 复绘·仅绘笔记给出确切数值的五个尺寸 + 量化对照（†）。461 是唯一有量化对照的模型；虚线为 Discussion 给出的 93% 基准线——所有模型（含量化后 95.31%）都在线之上。推理率与动态能量随尺寸单调变化：102→40 Inf/s、2.4→7.3µJ/Inf。

尺寸扫描四读数（Table I 即最接近消融的实验）：① 精度与规模解耦——最小 221 神经元就 97.40%、FPR 1.04 全场最低；甜点是 341（98.44% / TPR 100% / FPR 3.12%）——单关键词小任务 + 192 条测试集下 221 已容量过剩，加宽不再购买精度；② 非单调抖动落在噪声量级（测试粒度 0.52 点、每架构只训一次无方差）；③ 真正的杠杆是功耗与推理率——推理率随尺寸 102→40 Inf/s、动态能量 2.4→7.3µJ/Inf（全连接每步计算 ≈ 正比神经元数）——尺寸扫描实际标定的是「功耗-精度」帕累托而非「精度-容量」曲线，选型逻辑 = 满足精度取最小模型；④ 量化只做一次对照（461）——未报告其余尺寸的量化行为与 τ 排布 / 损失超参 / 16 通道 / 主时钟的任何消融。

§04 · 主要贡献

可转述的四个判断

1常驻账单看 idle 不看峰值
216µW idle 对 Loihi 29mW = 134×（全年 1.9Wh 对 254Wh）——always-on 视角下最有说服力的差距；只报动态 / 峰值会系统性误导。
2把预处理纳入计量口径
片上事件编码 <50µW 实测——「除麦克风本体外整条音频链路半毫瓦内」首次可验证，同时暴露以往基准排除预处理的不公平。
3低推理率 ≠ 低价值
流式 in-sensor 设计点在高吞吐加速器统治的指标外开辟能效维度——40-102 Inf/s 与 6.6µJ/Inf 是同一枚硬币的两面。
4量化行为迁移可以是有利交易
量化噪声让读出变保守（TPR −6.25 / FPR −3.13）——误唤醒代价高于漏唤醒的产品语境下，这是划算的方向性偏移。

§05 · 局限性与展望

192 条测试集与零鲁棒性数据；严格实时模式未测

方法局限

  • 单关键词单读出：多词表需多读出 + 竞争机制，神经元预算与功耗如何随词表规模变化未讨论。
  • 纯前馈的上下文上限：长时程证据全压在最深层长 τ 突触上，深度受功耗预算限制——秒级以上语境任务（连续命令 / 对话）不适合。
  • 前端频率分辨率粗：16 通道 Q=4 比常规 20-40 通道梅尔组粗，精细共振峰未必保留；无加噪 / 远场 / 混响 / 跨麦克风测试。
  • 实时余量存疑：基准跑在 >4× 加速模式；严格实时单流下更深网络或多类任务会吃光余量——该模式功耗未报。
  • idle 仍是底噪：216µW 对能量采集应用仍是主要开销；麦克风本体与模拟链路 / ADC / 电源效率未计。

实验设计不足

  • 测试集太小：192 条、Acc 粒度 0.52 点——尺寸间差异大半在噪声内；无多种子无方差。
  • 零鲁棒性维度：无噪声 / 远场 / 多说话人 / 口音分层——常驻 KWS 的真实失败模式恰在这些条件。
  • 无超参消融：τ 金字塔、M/g/w_l、16 通道全部单点直出——「架构本质」与「这组超参的运气」不可分。
  • 跨平台条件不统一：Table II 数字来自不同文献（时钟 / 批量 / 含否预处理各异）；SpiNNaker2 活跃能量缺失；能量/推理依赖「10 时间步」约定。
  • 口径含糊：事件 100ms 分箱与 10 时间步换算未展开；HDK 依赖 USB 供电与 PC——独立电池系统演示未报。
值得追的方向：① 多读出 + 胜者通吃，标定「神经元数-功耗-词表规模」scaling 曲线回答容量边界；② 严格实时流式模式功耗曲线 + 事件驱动唤醒 / 时钟门控进一步压 idle，补「频率-推理率-功耗」scaling 支撑选型；③ 加噪 / 远场 / 多说话人下的 TPR-FPR 工作点 + 与 MFCC 前端 ANN 等精度比能效——回答「事件编码到底牺牲了多少鲁棒性」；④ 推动 Aloha 类基准强制计入预处理能耗——Xylo 的片上前端在该口径下反而放大优势；⑤ 向 VAD / 声学事件检测 / 工业声学监测迁移（Rockpool + Xylo 工具链可直接复用）；⑥ 更低比特量化与系统性的「量化-精度-功耗」三角。
