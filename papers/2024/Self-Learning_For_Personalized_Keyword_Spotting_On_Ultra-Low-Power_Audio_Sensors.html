三条录音冷启动，设备自己收割环境数据、自己练自己——
毫瓦级传感器上的自学习闭环

Self-Learning for Personalized Keyword Spotting on Ultra-Low-Power Audio Sensors

作者：Manuele Rusci、Tinne Tuytelaars（KU Leuven）；Francesco Paci、Marco Fariselli、Eric Flamand（GreenWaves Technologies——GAP9 芯片厂商本身）

发表：arXiv 2408.12481（2024-08，v2 2025-03）· 真机：Vesper VM3011 麦克风 + GAP9 处理器

3 条用户录音初始化伪标签 + triplet 抗噪双阈值死区打标 常开标注 6.1–8.2mW最高 +19.2%84% 伪标签错误率仍正收益

一分钟版本

  • 两个刚性痛点：「训练一次、到处部署」范式下，用户想加自己的唤醒词 / 适配自己口音和环境，只能传服务器-人工标注-重训-重烧录，成本延迟隐私都不可接受；且部署分布 ≠ 训练分布——作者用扬声器在办公室回放公开数据集实录（HeySnips-REC），预训练 DS-CNN-L 从干净集 84.4% 掉到 60%。
  • 个性化 KWS 的结构性天花板：few-shot 路线（嵌入 + 原型 + 距离判类）天然支持开集，但特征提取器是冻结的——通用语料学的度量空间对特定用户 / 环境不是最优（ResNet15 10-shot 仅 ~80%）。要突破就必须在设备端、部署后、无标签条件下微调特征提取器本身——这就是标题里 self-learning 的确切含义。
  • 三阶段闭环：① 校准——用户录 3 正 3 负，设备自动导出原型 cp、双阈值 ThL/ThH、滤波长度 α（零调参零服务器）；② 常开标注——1s 窗 / 0.125s 步长滑窗，距离序列低通滤波取 min，双阈值死区筛选伪正例 / 伪负例，中间地带弃用（把检测器改造成数据收割器）；③ 训练——攒够伪正例触发，triplet 微调特征提取器 + 每个 batch 锚定用户 3 条真例，训完重算原型（特征面和分类面一起动）。
  • 为什么不会被伪标签毒死（最关键设计）：triplet 是软约束——只要求同类近 + 间隔 < 异类距离，不要求样本真是正例；错标样本仍可被拉近用户真例、推远伪负例来纠正位置。实证：HeySnapdragon 伪正例错误率 48%–84%，微调后准确率仍大涨（ResNet15 82.6→94.6%）。
  • 结果：FAR=0.5/h 工作点、3 样本初始化——HeySnips 最高 +19.2%（DS-CNN-S 62.5→81.6），HeySnapdragon 最高 +16.1%；真实环境 HeySnips-REC 上 DS-CNN-L 60→73.4。跨说话人标准差同步收窄——不仅提精度还提稳定性。
  • 最强的对照论据：augment 基线（DEMAND 增强 3 个样本微调）在 HeySnips 上全线负收益（ResNet15 −15.6%）——与其在 3 个样本上做同分布增强，不如去无监督收割环境真实数据，多样性和数量由环境免费提供。
  • 能耗账算平了：常开标注 6.1–8.2mW（占空比 4–12%），睡眠模式 0.66–0.88mW（电池月级）；单次全参数训练 DS-CNN-S 仅 20.6s / 1.5J；「训练能耗 = 标注 / 10」的临界采样间隔 6.1s（DS-CNN-S）到 262s（ResNet15）——中小模型可密集收割，ResNet15 性价比最差。
  • 边界：只支持单新类；训练无验证集无早停（部分说话人自学习后反降且论文承认无法解释）；天花板由预训练模型在新域的判别力决定——域偏移更极端时死区可能收窄到采不到伪正例（HeySnips-REC 已出现训练不触发的说话人）。

§01 · 问题陈述

冻结的特征提取器，封死了 few-shot 个性化的上限

为什么必须「部署后自己学」：唤醒词检测跑在电池供电的超低功耗 MCU 上全天候监听。工业范式「训练一次、到处部署」暴露两个刚性痛点：① 个性化缺失——加自定义唤醒词 / 适配口音环境的唯一途径是服务器回传-标注-重训-重烧录；② 分布不一致——办公室实录实验直接证明预训练模型从 84.4% 掉到 60%。个性化 few-shot 路线（特征提取器 + 原型 + 距离判类，天然开集）绕开了服务器，但特征提取器冻结：通用度量空间对特定用户 / 环境不是最优，10-shot 场景 ResNet15 只有约 80%——突破上限必须在设备端、部署后、无标签条件下微调特征提取器本身。
三族相关工作各自的缺口：
① few-shot 个性化族（ProtoNet / 余弦原型 / dummy 原型开集）：特征冻结封顶精度；评测全用 GSC 这类已切好 1 秒定长的数据集，回避了真实音频不定长、关键词起止未知的问题；自家前作 IEEE Micro（~20mW few-shot 推理）同样只吃 1s 定长、开集只测 5 个未知类、不支持训练。
② 自学习 / 伪标签族：Noisy Student-Teacher 靠 250 万语料的强教师产出高质量伪标签（错误率 1.83%→0.78%）——本文只有 3 条录音初始化的距离规则，伪标签质量天差地别；TinyTrain 需 30 个标注样本（本文只有 3），数据增强只能在几个样本上做同分布变换，无法扩分布多样性。
③ 设备端训练族：TinyOL / TinyTL / 稀疏更新都在压反向传播内存，但都假设新数据带真实标签，不解决标签从哪来；此前唯一的个性化 KWS 硬件原型整机 100mW，比本文预算高一个数量级。
四个具体挑战：伪标签从哪来、错了怎么办（预训练分类器本身只有 62.5%，自学习经典误差累积回路在 few-shot 下被急剧放大）；不定长音频如何打标签（需要一个从滑窗序列提炼单值判决 + 挡住不确定样本的机制）；训练能不能塞进 MCU（0.5M 参数卷积网络的反向传播激活远超 1.5MB 片上 RAM）；能耗账能不能算平（标注常开 + 训练偶发，必须落在电池预算内——这决定自学习传感器是真实产品还是论文演示）。

§02 · 方法论

闭环三阶段 + 按「常开 / 突发 / 偶发」切分硬件负载

图 1/2/3 复绘：闭环最后一处设计最关键——微调对象是特征提取器本身而非冻结特征加分类头，原型在新空间重算，特征面和分类面一起动；硬件按三种负载切分电压频率域，支撑细粒度电源门控。

loss = (1/Ntr) Σ max( d(zp1, zp2) − d(zp1, zn) + m, 0 )，  m = 0.5
式 1 · triplet loss（预训练与微调用同一个损失，超参全部沿用——刻意不引入新超参，降低现场失效风险）。预训练语料 MSWC 语料最多的 500 类共 2.7M 样本；选 triplet 而非原型损失的依据是同团队 Interspeech 2023 开集对比结论：triplet 编码器精度更高。软约束结构是抗伪标签噪声的关键（见上图下方说明）。
Th(τ) = distp + τ · (distn − distp)，τL < τH；  mint distf(t) < ThL → 伪正例，  > ThH → 伪负例，  中间 → 弃用
式 4–9 · 流式打标与免调参校准：min 算子从不定长语音的多个滑窗里挑对齐最好的一窗；低通滤波（长度 α）平滑窗间抖动；双阈值死区把置信区与不确定区分开——度量学习把不同关键词推向远处，离原型很远基本不可能含目标词（当负例安全），中间地带是分类面模糊区，采进训练集只会注入标签噪声。τ 甜点在 τL∈{0.3,0.4}、τH=0.9：τL=0.5 假阳性过多、τL∈{0.1,0.2} 伪正例太少训练集多样性不足；τH 在 0.7–1.1 几乎不敏感（降低 τH 时假阴性与伪负例规模同速增长，错误比例近似恒定）——这个不敏感降低了现场调参负担。
塞进 MCU 的训练内存分层：三层设计——权重 + 梯度驻留片上 RAM（DS-CNN-L 需 1.54MB）；新采集数据只存 MFCC 特征图（比存 16bit 原始音频省 34 倍内存，400 张图仅 0.36MB）；各卷积层前向激活溢出到外部 64MB PSRAM（DS-CNN-L 需 32.28MB）——外部 RAM 平时断电、仅训练时上电。训练 16bit 半精度（PULPTrainLib 多核向量化），训完 4 条样本 PTQ 校准回 8bit 衔接卷积加速器，混合精度切换零精度损失。反向传播复用 PULPTrainLib——多核 RISC-V MCU 上第一个性能驱动的设备端训练库。

§03 · 实验与消融

两个公开集 + 一个真实声学环境 + 一笔能耗账

数据与协议：预训练 MSWC 500 类 2.7M 样本。评测：HeySnips（自适应集 5347 正 + 31830 负；测试 20 说话人）与 HeySnapdragon（自适应集仅 462 正 + 31830 负）——协议为 FAR=0.5 次/小时工作点的逐说话人平均准确率（唤醒词产品的真实工况由误报率定义，精度必须在固定误报约束下比较）；自采 HeySnips-REC（扬声器回放 + 办公室实录，含混响与非平稳噪声）负样本仅 11.6 分钟，退而报 FAR=0 工作点。四个模型：DS-CNN-S/M/L（21K/132K/407K 参数）+ ResNet15（482K）。对比对象：pretrained（冻结特征 + 原型 = few-shot SOTA）、self（本文）、augment（增强微调基线）、oracle（全部真实标签上界）。

Table III：模型越小涨幅越大（DS-CNN-S +19.2/+16.0）——冻结特征对小模型的封顶效应更狠；跨说话人标准差同步收窄（DS-CNN-S 从 30.6 降到 23.6）。oracle 上界 98.4–100%。

Fig 7：真实声学环境下的验证——自学习在办公室混响 + 非平稳噪声下仍有 +11.9 到 +19.5 的涨幅；但干净集排名在噪声下翻转，且部分说话人伪正例不足 10 条训练未触发（Fig 8）。

伪标签质量的直接度量：HeySnips 上 ResNet15 伪负例错误率仅 2%、伪正例 1–3%（DS-CNN-S 差一些：7% / 19%）；HeySnapdragon 上伪正例错误率暴涨到 48%–84%（负例翻转仅 1%）——原因是该集自适应正例少（462 条）且分布更难。精度仍然大涨，triplet 软约束 + 真例锚定扛住了极端标签噪声。oracle 上界 98.4–100%，self 与 oracle 的差距由标签噪声解释；个别案例自学习甚至超 oracle 达 +43%（8–11 号说话人、DS-CNN-S）——论文承认这个极低数据量区间的反常需要后续分析，没有强行解释。

Table IV：设备端训练成本与可持续性判据——对中小模型，训练能耗相对常开标注可忽略；ResNet15 的 22 分钟 / 86.8J / 262s 间隔是本框架里大模型不划算的直接证据。

消融两条腿：① 阈值扫描（τL∈{0.1..0.5}×τH∈{0.6..1.2}）——τH 不敏感、τL 双端翻车，最终 τL∈{0.3,0.4}、τH=0.9；② 滑窗步长与滤波长度（Fig 6，HeySnapdragon 50 说话人 / HeySnips 61 说话人）——步长 0.25s→0.125s 精度最高 +16%，再缩到 0.0625s 只再涨 6%/2% 但推理能耗翻倍，0.125s（窗长 1/8）是精度-能耗甜点；滤波长度 α 呈数据集依赖：「Hey Snips」发音短、α=2/3 峰值，「Hey Snapdragon」更长、α=1 最好——滤波长度本质上在匹配关键词的时长尺度。量化：8bit PTQ（4 样本校准）无精度损失。

§04 · 主要贡献

四条贡献

1第一个超低功耗传感器节点的个性化 KWS 自学习框架：部署后用目标环境无标注数据增量微调特征提取器，打破冻结特征封顶的精度上限；相对 few-shot SOTA 最高 +19.2%（HeySnips）/ +16.0%（HeySnapdragon），ResNet15 仅 3 条初始化即达 93.7% / 94.6%。
2面向不定长连续音频的伪标签策略：滑窗取 min + 低通滤波 + 双阈值死区，全部参数（α、ThL、ThH）由设备端 6 条录音自动校准——免人工调参、免服务器，自学习闭环能在现场成立的前提。
3首个完整系统级落地与能耗账：真实节点常开实时标注 6.1–8.2mW（睡眠模式 0.66–0.88mW、电池月级寿命）；首次给出设备端训练的时延 / 内存 / 能量估计，并给出「训练能耗 = 标注 / 10」的可采样间隔判据（6.1s–262s）。
4两条方法学结论：triplet 软约束 + 锚定真例能在伪正例错误率高达 84% 的极端标签噪声下仍正收益；仅靠增强 3 个样本微调在该量级是负收益——无监督环境数据不可替代。
可迁移的工程判断：当手里只有一个不准的分类器却要产训练数据时，出路不是清洗标签，而是选一个对标签错误天然鲁棒的损失结构（软约束 + 真例锚定）+ 一个把不确定样本挡在门外的置信筛选（死区）——前者保证错了也朝对的方向优化，后者控制进入训练集的噪声率。两者分别作用于「训练目标」与「数据入口」，缺一不可。

§05 · 局限与边界

单类、无早停、精度与系统实测解耦

技术局限

  • 只支持单新类：全按「单一唤醒词 + unknown」展开；多新类、类别递增的持续学习留作未来——多原型距离分布重叠会直接冲击双阈值死区的校准逻辑。
  • 无验证集、无早停：固定 epoch 返回最后一组权重，无法防止对伪标签集过拟合——Fig 8 部分说话人自学习后精度反降（幅度通常 <10%）且与标签错误率不相关，论文承认无法解释。方法鲁棒性上最实在的一块阴影。
  • 天花板由标注回路决定：整套方法取决于预训练模型在新域的判别力；域偏移更极端（远场、强噪声）时死区可能收窄到采不到伪正例——HeySnips-REC 已出现伪正例不足 10 条、训练不触发的说话人。
  • ResNet15 性价比最差：1339s 时延 / 58.64MB 激活 / 86.8J 能量 / 262s 临界间隔，真实噪声集上精度还最低（57.4%）——大模型在本框架里最不划算。

实验设计不足

  • 精度与系统实测解耦（最大缺口）：学习实验全在服务器跑（算法一致），设备端只实测标注任务；训练时延 / 能耗是估算（PULPTrainLib 例程 + 8 核半精度假设），端到端「在节点上完成训练并刷新模型」的闭环演示未报告。
  • 自采集太小：HeySnips-REC 负样本仅 11.6 分钟只能报 FAR=0；回放-录音管线引入扬声器与房间信道畸变；单房间、单麦克风型号、单回放音量，泛化证据薄弱。
  • 对比面偏窄：未与 dummy prototype / 余弦原型等同代方法直接对比；augment 在 HeySnapdragon 上 ResNet15 达 99.2% 反超 self 的 94.6%，论文仅以「平均更稳」带过，未深挖两者互补的条件边界。
  • 假设未披露：电池月级寿命的电池容量假设、10% 声学活动率估算均未报告；K=3 条负例估计 distn 方差很大（负例空间本身是开集），阈值对负例选择顺序的敏感性未验证。
值得补的方向：多类与持续学习扩展（新类随时间加入、原型集动态增长，需解决多原型死区校准与旧类灾难遗忘）；部分层微调 / 稀疏更新 / 偏置级适应与自学习闭环正交可叠加（直接缓解 ResNet15 的 262s 间隔）；标签质量的自适应控制（置信度加权 triplet、在线重校准阈值、高噪声域主动拒识——把死区从静态参数变成随域漂移动态调整的量）；训练触发事件驱动化（凑满 NpB 即触发、多次小步替代一次大训练，更贴合流式到达）；更宽部署面验证与训练闭环端到端实测。代码开源于 github.com/mrusci/ondevice-learning-kws，自采数据开源于 KU Leuven RDR。
