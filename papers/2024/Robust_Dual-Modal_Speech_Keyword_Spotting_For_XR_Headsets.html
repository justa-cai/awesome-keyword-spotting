噪声吵到失准、安静到没法出声、旁人闲聊被误触发——
一只麦克风把语音和唇动一起收了

Robust Dual-Modal Speech Keyword Spotting for XR Headsets（VE-KWS）

作者：Zhuojiang Cai*、Yuhan Ma*、Feng Lu（北航 虚拟现实技术与系统全国重点实验室；*共同一作）

发表：arXiv 2401.14978（2024-01，IEEE TVCG 投稿格式）· 真机平台 HoloLens 2

频带复用 5kHz / 17kHzFMCW 超声唇动 · 距离分辨率 0.357cm 可靠性门控融合echoic 模型压缩 >100×−10dB 噪声 WER 降 15.68% 免手动模式切换

一分钟版本

  • 三条痛点，条条打在信息源上：发声 KWS 靠空气传导的语音——街头商场被人声频段噪声污染（失准）；旁边有人办公休息、隐私尴尬时发不了声（功能直接归零，不是掉点）；头显麦克风没有强的说话人方向选择性，旁人说话被当指令（误触发）。模型层再优化也补不回物理性缺失的信息源，出路在模态层。
  • 核心洞察（全文性价比最高的设计）：语音能量 100Hz–5kHz、超声回波 17–23.5kHz，中间隔着大片空白频带——同一只 48kHz 商用麦克风一次采集、带通滤波一分为二，vocal + echoic 双模态零新增传感器（只加一块 ESP32 和四个网购量产换能器，藏在镜片下缘）。
  • echoic 模态怎么「看」唇动：两扬声器发 FMCW 超声（17–20 / 20.5–23.5kHz 错开 ≥0.5kHz，chirp 12ms），回波与发射信号逐 chirp 互相关（距离分辨率 0.357cm）堆叠成 Echo Profile，再沿时间差分——滤掉头显与脸的静态反射，只留唇动。
  • 融合不做朴素平均：可靠性门控 RB——N-best 似然差 L（第一名领先多少）+ 散度 D（候选内部乱不乱）双阈值判每个模态可不可用，四分支路由：双可靠对数域加权、单可靠择优、双不可靠拒识。静默场景自动走「仅 echoic」，全程免手动切换。
  • 结果：−10~10dB 全部 SNR 下融合 WER 低于两个单模态；−10dB 最强噪声处 MLP 融合相对 vocal / echoic 降 15.68% / 16.57%；静默时 vocal 全变删除错误而融合紧贴 echoic；旁人干扰下 vocal 错误率近半、融合插入错误近乎清零（误触发闭环）；六类噪声场景两单模态强弱随频谱翻转，只有融合吃到两边上包络。
  • 轻量化甜点：echoic 通道 ResNet-18（11.22M / 1.84G MAdd）经「宽度裁剪 × DS 卷积」8 变体消融，选 1/4-DS（109.9K / 24.74M，压缩超 100×），WER 只付 0.91 个百分点；1/8 再砍开始伤表达能力（方差 ±1.26 全表最大）。
  • 边界要记住：走路使 echoic WER +50%、摇头 +33%（几何在晃，差分管不住低频晃动）；运动中的超声源 1m 处 +7%（差分抑制的前提是干扰近似静止）。更关键：静默实验是「删掉 vocal 通道」模拟的，真实无声发音的唇动分布未测——这是静默卖点成立与否的关键缺口。

§01 · 问题陈述

三条真实使用情境，指向同一个结构性矛盾

为什么是 KWS 而不是 ASR：XR 头显正集体放弃控制器转向语音 / 手势 / 视线交互，语音承担菜单选择、locomotion、配合视线移动物体等高频任务。相比 ASR，KWS 不需要云端连接、算力需求低、没有隐私外泄——是端侧常开（always-on）交互的更合理载体。但发声 KWS 在 XR 场景下有三条硬伤，每条对应一个真实情境：
① 噪声环境失准：街头、商场、公共交通上准确率显著退化——不是模型不行，是信息源（空气传导语音）本身被人声频段噪声污染；
② 安静场合彻底失效：旁边有人办公休息、隐私或社交尴尬不便出声——功能直接归零，不是准确率下降；
③ 旁人说话误触发：麦克风无强的说话人方向选择性，讨论会 / 教室里旁人的话被当成指令——高密度人声下误触发比漏检更伤体验。
结构性矛盾：单一发声模态的信息源在某些场景物理性缺失或被污染，模型层补不回来——必须从模态层引入失效条件不同的第二信息源。
静默语音接口（SSI）已有积累，但缺口明确：接触式（磁强计入口腔、超声成像、EMG、应变片贴肤）长时间佩戴不适、头显上集成困难；摄像头方案（C-Face / TieLent / SpeeChin）高功耗 + 隐私 + 社交接受度存疑；主动声学（EchoWhisper / CELIP / EchoSpeech）低功耗高性能、最可落地——CELIP 要求换能器正对嘴且器件偏大，EchoSpeech 藏在眼镜下缘形态最隐蔽。但它们全是单 echoic 模态系统，「与常规发声 KWS 融合以获得更强性能、更宽适用场景」的潜力此前完全没被探索——这就是本文的切口。而单 echoic 自己也有软肋（走路 +50%、摇头 +33%，见 §05）：vocal 怕噪怕静默、echoic 怕剧烈运动——失效条件不同，正是融合的价值空间。
四条关键挑战：① 不加感知负担拿到双模态（头显对功耗 / 重量 / 极度敏感，不能加摄像头或贴肤传感器）；② 失效模态的隔离——静默场景 vocal 管线会输出 silence 这类无效预测，朴素加权融合反而被拖累，必须「双可靠才融合、单可靠择优、双不可靠拒识」；③ echoic 模型算力瘦身——前身 EchoSpeech 用 ResNet-18（11.22M 参数、1.84G MAdd），比 vocal 通道重一个量级，要砍小一到两个数量级而不明显掉点；④ 不能停在仿真——要在 HoloLens 2 上搭出可实时运行的完整系统，在三类困难场景下系统验证。

§02 · 方法论

频带复用 → 差分回波图 → 可靠性门控

图 2/3/4 复绘：器件沿用 EchoSpeech 在眼镜架上验证过的构型（鼻侧扬声器和麦克风相距 7.2cm、对内间距 1.8cm、距嘴 ~3.9cm）；频带复用是全文的物理根基；vocal 管线直接复用 BC-ResNet，创新预算花在 echoic 特征与融合层。

f(t) = fl + (fh − fl) · t / T
FMCW 发射信号：chirp 内频率随时间线性爬升（f_l / f_h 为上下界，T 为 chirp 周期 12ms）。两个频段 17–20 与 20.5–23.5kHz 错开 ≥0.5kHz，让两路回波在频域可分——一只扬声器对、两只麦克风覆盖。
回波 × 发射信号 互相关 → 距离维剖面（分辨率 0.357cm）→ 堆叠 → 差分
逐 chirp 互相关：峰值位置正比于「扬声器—嘴周皮肤—麦克风」路径差，48kHz 采样下距离分辨率 0.357cm——足以分辨说话时嘴周皮肤的厘米级运动，这是 echoic 能区分发音动作的量化保证。沿时间差分的物理意义：滤掉静态反射（头显与脸的固定几何），只留随时间变化的部分即唇动——也是后文「静止超声源干扰可忽略」的原因。

式 1–5 复绘：可靠性指标思路继承自视听语音融合的 N-best 方案，作用对象从连续 ASR 的观测级融合迁移为 KWS 概率向量级门控，并针对 silence/unknown 这两个 KWS 特有辅助类做了修正。8 个参数（4 阈值 + 4 权重）用遗传算法全局搜索 + 拉丁超立方初始化；权重只与两个 KWS 模型有关、不随数据变化——换数据集不重调。

第二条融合路线：朴素 MLP：完全放弃手工特征，三层 MLP（输入 / 隐藏 / 输出）学「两模态预测向量拼接 → 融合结果」。亮点在训练增强与实验场景一一对应——每条样本随机四选一：保持清晰；叠 DEMAND 环境噪声（对应噪声场景）；叠 Google Speech Commands 人声（对应旁人干扰）；直接丢弃一部分 vocal 数据（把「vocal 通道缺失」塞进训练分布，对应静默场景）。「实验里会怎么难看，训练里就先怎么练。」
echoic 模型轻量化的消融思路：以 ResNet-18 为基线做「宽度裁剪（1/2、1/4、1/8）× 常规 / 深度可分离 DS 卷积」双因子消融，共 8 个变体。砍宽度的理由是结构性的：ResNet-18 本为图像分类这类信息负载更重的任务设计，差分 Echo Profile 的信息量撑不起这个容量——减宽既减参数又降过拟合风险；DS 卷积把标准卷积拆成 depthwise + pointwise，同宽度 MAdd 约再砍一半。结果见 §03 帕累托图。

§03 · 实验与消融

消融找甜点，三类困难场景逐一闭环

数据与指标：自录双模态数据集——15 名参与者（2 女 13 男，20–27 岁）× 10 个命令词 × 30 遍 = 4500 条，加 25 个辅助词 × 5 遍 = 1875 条（标注 unknown，教系统拒绝非命令词）+ 静默数据，48kHz 采样。GSC 三个用途：词表迁移 + vocal 模型在大数据集上联合训练（让 vocal 基线吃饱数据红利，双模态的赢不靠对手训练不足）、v2 人声做旁人干扰源、MLP 增强源；DEMAND 做环境噪声。指标 WER = (S+D+I)/N——选它的深层理由在 I：插入错误 = 误触发，对常开头显伤害大于漏检，所以按 S/D/I 分色拆解。

Table 1：三层读法——甜点在 1/4 宽度（1/2→1/4 只 +0.34pp，1/4→1/8 跳 +1.88pp 边际代价陡增）；DS 卷积同宽度 MAdd 约砍半、WER 代价仅 0.1~0.4pp；最终选型 1/4-DS 全局权衡（>100× 参数压缩换 0.91pp）。

噪声实验（Fig 6 / 7a）：DEMAND 噪声按 −10~10dB SNR 叠加，四条曲线对比——全部 SNR 下两种融合的 WER 都低于两个单模态；噪声最狠的 −10dB 处融合收益最大（MLP 相对 vocal / echoic 降 15.68% / 16.57%），因为噪声主打 vocal、超声近场反射不受人声频段噪声影响，融合层持续从干净一侧取信息。六个具体场景还有结构性翻转：高频噪声为主的场景（如 Domestic）vocal 强于 echoic，低频扰动为主的场景（如 Public）echoic 反超——没有任何单模态全场景占优，只有融合能吃到两边的上包络。这组结果回答了「为什么不选一个更好的模态而是融合」。

Fig 7b/7c 结构示意：原文只给曲线 / 柱状图无逐条数值表，本图按图结构与笔记结论重绘、锚点数字均有出处。A 面板 vocal 段被替换为随机静音——「静默」是从信息层面消除 vocal 通道；B 面板旁人语音只污染 vocal 通道，超声回波来自近场皮肤反射、旁人能量被人声频段滤掉——这是抗旁人干扰的物理机制。

系统级验证：作者开发了一个游戏 + 实时演示视频验证结论——与 vocal KWS 比：各类噪声下更稳、滤除旁人干扰、支持静默；与静默语音方法比：继承 SSI 能力，且在 SSI 会显著退化的场景（过强噪声、剧烈身体活动、超声干扰）可无缝切回 vocal，避免系统失效也省掉手动模式切换。（延迟 / 功耗未量化，见 §05。）

§04 · 主要贡献

四条贡献 + 一条可迁移判断

1真机双模态系统：HoloLens 2 + 两对量产级换能器 + ESP32 搭出完整系统；利用语音（100Hz–5kHz）与超声回波（≥17kHz）的频带空白在同一只麦克风上复用两个模态，不引入摄像头或贴肤传感器——KWS 适用场景从「安静出声」扩展到噪声 / 静默 / 旁人干扰。
2消融驱动的轻量化：宽度裁剪 × DS 卷积 8 变体系统消融，echoic 通道从 11.22M 压到 109.9K（超 100×）、MAdd 1.84G→24.74M（约 74×），WER 只付 0.91 个百分点——常开管线的算力削减直接换成功率与时延预算。
3两种融合策略 + 一致验证：手工路线的可靠性门控 RB（N-best 似然差 / 散度双阈值 + 对数域自适应加权 + 对 silence/unknown 辅助类的修正）与学习路线的 MLP 融合，在全部 SNR、六类场景、静默、旁人干扰实验中一致优于单模态。
4可复现三件套：开源代码（github.com/caizhuojiang/VE-KWS）+ 演示视频 + 游戏化验证——对 HCI / 系统类工作，这是可信度的重要组成部分。
可迁移的工程判断：当两个信息源的失效条件互补（vocal 怕噪声与静默、echoic 怕剧烈运动），带可靠性门控的融合可以在不设手动模式切换的前提下同时拿到两边的上包络；而融合层对「辅助类输出（silence / unknown）要降权、但 vocal 的 silence 是『嘴没动』的强证据要特殊对待」这类细节的处理，往往决定融合系统在边界场景下是加分还是减分。

§05 · 局限与边界

运动是最大软肋，「静默」本身还没被真正测过

技术局限

  • 身体活动冲击：走路使 echoic WER 上升约 50%、摇头约 33%（vocal 仅轻微受影响）——头显相对嘴部的几何在晃、全身运动污染差分 Echo Profile 里的「运动」信号，特征层静态抑制管不住低频晃动；可用含活动数据的融合优化缓解，但优势确实被削弱。
  • 运动中的超声源：静止超声源多方向多距离影响可忽略（差分抑制静态干扰）；但运动中的超声源 1m 处平均 WER +7%、更近更强——运动破坏「干扰近似静止」这一差分前提，是原理性盲区，论文未解决。
  • 频段下沿的听觉风险：17–20kHz 下沿贴近年轻人可听阈上沿，论文未做任何可听性人因测试——对 20 岁上下用户是否存在可感知啸叫 / 疲劳，产品化前必须补。
  • 附加硬件未消零：仍是 add-on 板 + 四个换能器外挂商用头显，未做到零增量（论文自列未来方向）。

实验设计不足

  • 人群覆盖窄：15 人仅 2 名女性、20–27 岁；麦克风到嘴 3.9cm 等几何参数对脸型 / 性别 / 年龄的敏感性未分层，说话人无关性未评估。
  • 词表规模小：10 命令词 + 25 辅助词，全是 GSC 短命令；更长命令、连续语流中的检测未测。
  • 仿真式造难：噪声靠 DEMAND 叠加、旁人靠 GSC 人声叠加、静默靠 vocal 段换静音——全部离线仿真，无真实场景在线录音，SNR 只测到 −10dB。
  • 静默的构造性偏差（最要害）：自录数据全是出声朗读，「静默」是删 vocal 通道模拟的——echoic 通道对应的是出声朗读时的唇动；真实无声发音幅度更小、更不完整，echoic 在该分布上的性能未报告。
  • 系统指标缺失：端到端延迟、功耗、推理帧率均未报，「实时」只有定性结论；RB（遗传算法搜参）与 MLP（在线前向）的运行时开销对比、MLP 隐藏层宽度等超参也未给。
值得补的方向：运动鲁棒性要特征层 / 几何层根本治理（惯性传感器辅助运动补偿、自适应基准差分），不能只靠融合层兜底；运动超声源的干扰对消；采集真实无声发音数据重评 echoic 通道（静默卖点成立与否的关键实验）；利用 RB 权重「只与模型有关、不随数据变化」做跨场景迁移与在线自适应；与说话人验证结合，把旁人防御从频带物理层升级到声纹层；端侧量化 + 实际功耗测量，补全轻量化叙事最后一环。
