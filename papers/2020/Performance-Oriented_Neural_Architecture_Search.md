# Performance-Oriented Neural Architecture Search

**作者/机构**: Liam O'Neil, Simon OSuilleabhain, Md. Asifuzzaman Jishan, Rishabh Mehra, Darragh Nash, Joe Timoney (Trinity College Dublin)

**发表日期**: 2020年1月 (arXiv:2001.02976)

**链接**: https://arxiv.org/abs/2001.02976

**关键词**: 神经架构搜索, 性能估计, 关键词检测, 模型优化, 代理模型

## 问题陈述

神经架构搜索(NAS)的核心瓶颈在于:评估每个候选架构的性能需要完整训练该架构,计算成本极高。在KWS领域,典型的NAS流程需要:
- 搜索空间中包含数千甚至数百万个候选架构
- 每个架构的训练需要数小时(即使在GPU上)
- 完整搜索可能需要数百甚至数千GPU小时

这种"训练后评估"的范式严重限制了NAS的实用性。如果能够不经过完整训练就准确预测一个架构的性能,则可以大幅加速搜索过程。

性能预测器(Performance Predictor)是一种有前景的方法:训练一个代理模型(Surrogate Model),学习从架构描述到性能指标的映射,从而快速评估候选架构而无需训练。

## 方法论

### 架构编码(Architecture Encoding)

将神经网络架构编码为数值向量,作为代理模型的输入:

**编码方案**:
- 将架构的每层信息编码为固定维度的向量
- 编码内容包括:操作类型(卷积、池化等)、参数配置(卷积核大小、通道数等)、连接模式(跳跃连接等)
- 使用one-hot编码或嵌入编码表示离散选择
- 所有层的编码连接形成完整的架构描述向量

### 代理模型(Surrogate Model)

**模型选择**:
- 使用简单的回归模型(如MLP、随机森林)或神经网络
- 输入:架构编码向量
- 输出:预测的性能指标(如分类准确率)

**训练数据构建**:
- 从搜索空间中随机采样一组架构
- 完整训练这些架构并获得真实性能
- (架构编码, 真实性能)对构成代理模型的训练集

**迭代细化**:
- 初始代理模型基于少量训练数据
- 随着搜索的进行,新评估的架构数据不断加入训练集
- 代理模型持续更新,预测精度不断提高

### 搜索流程

1. **初始化**: 随机采样N个架构,完整训练并获得真实性能
2. **代理训练**: 使用当前数据训练代理模型
3. **候选生成**: 从搜索空间中生成大量候选架构
4. **代理评估**: 使用代理模型快速预测所有候选的性能
5. **选择**: 选择代理预测性能最高的K个候选
6. **验证**: 完整训练这K个候选,获得真实性能
7. **更新**: 将新数据加入训练集,返回步骤2
8. **终止**: 达到搜索预算后返回最优架构

### KWS搜索空间

定义了包含多种卷积操作的搜索空间:
- 标准卷积(不同卷积核大小)
- 深度可分离卷积
- 池化操作
- 跳跃连接

## 主要贡献

1. **基于代理模型的NAS**: 提出了使用性能预测器(代理模型)加速NAS搜索的方法,大幅减少了需要完整训练的架构数量。从"训练所有候选"转变为"训练少量候选+代理预测大量候选"

2. **高效的性能预测**: 代理模型能够高精度地预测架构性能,与真实训练性能的相关系数达到较高水平,使搜索过程更加可靠

3. **KWS领域的应用**: 将代理模型NAS成功应用于关键词检测任务,发现了与手工设计相当甚至更优的架构

4. **搜索成本显著降低**: 相比需要训练数千个架构的标准NAS方法,该方法仅需完整训练数十到数百个架构

## 实验结果

### 实验设置
- Google Speech Commands数据集
- 搜索空间:多种卷积操作和连接模式
- 初始训练集:50-100个随机采样架构
- 搜索迭代:5-10轮

### 主要结果
- **预测精度**: 代理模型的性能预测与真实训练性能之间具有较高的相关性
- **发现的架构**: 代理模型引导的搜索发现了与手工设计相当或更优的KWS架构
- **搜索效率**: 相比暴力搜索,总搜索成本降低了一个数量级
- **迭代改进**: 随着搜索迭代的进行,代理模型预测更准确,发现的架构性能逐步提升

### 代理模型分析
- MLP代理模型在架构编码较简单时表现良好
- 随着搜索空间增大,需要更多初始训练数据才能建立准确的代理模型
- 代理模型对搜索空间中数据稀疏区域的预测可靠性较低

## 局限性与展望

### 方法局限
- **初始训练数据需求**: 代理模型需要初始的一组"训练-评估"数据,这些数据的获取仍需计算资源
- **预测可靠性**: 代理模型在训练数据覆盖不足的区域可能给出不准确的预测
- **搜索空间依赖**: 搜索空间的定义仍需要领域专业知识
- **与SOTA NAS方法对比有限**: 与同期最先进的NAS方法(如DARTS、ENAS)的系统性对比不足
- **泛化性**: 代理模型在一个搜索空间上训练,是否可以迁移到其他搜索空间未验证

### 未来方向
- 研究零成本NAS(Zero-Cost NAS)方法,使用无需训练的性能指标(如参数量、FLOPs、梯度信息)作为架构评分
- 探索跨搜索空间的代理模型迁移,减少每次新搜索的初始训练开销
- 结合可微分NAS和代理模型的混合搜索策略
- 研究多目标代理模型,同时预测精度、延迟、能耗等多个指标
- 将代理模型方法扩展到更多语音任务和更大规模的搜索空间
