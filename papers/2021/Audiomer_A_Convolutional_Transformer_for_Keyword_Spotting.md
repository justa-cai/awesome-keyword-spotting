# Audiomer: A Convolutional Transformer for Keyword Spotting

- **作者/机构**: Surya Kant Sahu, Sai Mitheran, Juhi Kamdar, Meet Gandhi - 乔治梅森大学/独立研究
- **发表日期**: 2021.09
- **链接**: https://arxiv.org/abs/2109.10252
- **关键词**: Transformer, 卷积, 混合架构, Performer注意力, 关键词检测, 自注意力, 线性复杂度

## 问题陈述

关键词检测（KWS）模型需要有效地从短语音片段（通常1秒左右）中提取判别性特征。基于CNN的模型通过局部卷积核捕获频谱图中的局部时频模式，在KWS领域取得了主导地位，但CNN的感受野受限于卷积核大小和网络深度，难以直接建模语音中的长程时间依赖关系。对于KWS任务而言，虽然语音片段较短，但整个片段上的全局韵律模式、音调变化轨迹以及跨越多个音素的时间结构仍然对关键词的判别至关重要。

纯Transformer架构通过自注意力机制可以捕获全局上下文，理论上非常适合建模这种长程依赖。然而，标准自注意力的计算复杂度为O(n^2)，对于序列长度较大的输入计算成本过高。更重要的是，在KWS场景中，边缘设备对延迟和功耗有严格要求，纯Transformer的二次复杂度成为实际部署的瓶颈。此外，Transformer缺乏CNN的平移不变性和局部性归纳偏置，在小数据集上可能需要更多数据才能达到最佳性能。

该论文要解决的核心问题是：如何设计一种混合架构，既能够通过CNN高效提取局部时频特征，又能够通过高效的注意力机制建模全局上下文，同时保持适合KWS部署的计算效率。这一问题的解决对于推动Transformer架构在资源受限的KWS场景中的应用具有重要意义。

## 方法论

### 整体架构设计
Audiomer采用经典的"CNN主干 + Transformer头部"混合架构设计，这是一种在视觉（ViT之前的混合模型）和语音处理中被广泛验证有效的范式。整体流程为：原始音频 -> MFCC/频谱图特征提取 -> 一维残差卷积网络（1D Residual Network）-> Performer注意力层 -> 分类头。这种设计的核心思想是：CNN负责将原始的时频表示转化为高级特征序列，而Performer则在这些高级特征上建立全局依赖关系。

### 一维残差卷积网络（1D ResNet）
Audiomer的卷积前端使用一维残差网络对输入的频谱图特征进行处理。与传统的二维卷积（同时沿时间和频率维度卷积）不同，一维卷积沿时间轴对频谱图进行卷积操作，将频率维度作为通道维度处理。这种设计的动机在于：

- **语音的时序结构是关键词识别的核心信息**：关键词的判别性主要体现在音素的时间序列模式上（如"yes"中/y/, /E/, /s/的时间序列），一维时间卷积天然适合捕获这种时序结构。
- **参数效率**：减少了参数量（相比二维卷积），有利于小footprint部署。一维卷积的参数量与频率维度无关，仅取决于卷积核大小和通道数。
- **残差连接的梯度流动**：深层网络中的残差连接保证了梯度的有效传播，使得网络可以学习更复杂的时序特征而不出现梯度消失。

每个残差块包含：1x1卷积（通道降维，减少计算量）-> 批归一化 -> ReLU激活 -> 时间卷积（捕获时序模式）-> 批归一化 -> 残差跳跃连接（保持信息流）-> ReLU激活。这种瓶颈结构（bottleneck）设计参考了ResNet的成功经验，在保持表达能力的同时降低了计算开销。

### Performer注意力机制
Audiomer的核心创新在于使用Performer注意力替代标准的多头自注意力。Performer（Choromanski et al., 2020）通过随机特征映射（Random Feature Mapping）和FAVOR+算法（Fast Attention Via Orthogonal Random features）将标准softmax注意力的二次复杂度O(n^2)降低到线性复杂度O(n)：

**标准注意力**：Attention(Q,K,V) = softmax(QK^T / sqrt(d)) * V，计算QK^T需要O(n^2 * d)的时间复杂度和O(n^2)的空间复杂度。

**Performer注意力**：利用softmax核函数可以被随机特征近似这一数学性质，使用随机特征函数phi(.)将softmax核近似为phi(Q) * phi(K)^T。具体来说：

phi(x) = (1/sqrt(r)) * [exp(w_1^T * x + b_1), ..., exp(w_r^T * x + b_r)]

其中w_i是从特定分布中采样的随机向量，r是随机特征维度。通过这一近似，注意力计算变为：

Attention(Q,K,V) = (phi(Q) * (phi(K)^T * V)) / (phi(Q) * (phi(K)^T * 1))

这使得计算复杂度从O(n^2 * d)降低到O(n * d * r)，其中r是可控的随机特征维度（通常远小于序列长度n）。关键是，这一近似可以证明是无偏的，且方差可控。

这使得Audiomer能够高效地建模卷积特征序列中的长程时间依赖，而不受序列长度的计算瓶颈限制。即使在处理较长的语音片段时，Performer仍然保持线性的计算复杂度。

### 位置编码与分类头
在Performer注意力层之前，对卷积输出的特征序列添加可学习的位置编码（Positional Encoding），以注入位置信息。由于Performer的随机特征近似破坏了位置感知能力（不同于标准注意力可以通过QK^T计算隐式编码位置差异），位置编码是不可或缺的。

分类使用CLS token方法：在序列开头添加一个特殊的分类token，经过Performer层后取该token的输出送入全连接分类头。CLS token作为全局信息的聚合器，通过注意力机制从所有补丁中收集相关信息。

### 训练策略
使用标准的交叉熵损失训练，采用Adam优化器配合学习率warmup（前10%的训练步数线性增加学习率）和余弦退火调度（cosine annealing schedule，学习率按余弦函数衰减）。这种学习率调度策略在Transformer训练中被广泛使用，warmup阶段有助于稳定初始训练，余弦退火则有助于收敛到更优的局部最小值。

## 主要贡献

1. **引入Performer注意力用于KWS**：首次将Performer这种线性复杂度的注意力机制应用于关键词检测，有效解决了标准Transformer在KWS场景下的计算效率问题。这一选择使得模型能够在不牺牲全局建模能力的前提下保持高效的推理速度。相比同期使用标准注意力的KWS-Transformer方法，Audiomer在长序列处理上具有显著的计算优势。

2. **一维残差卷积与Performer的混合架构**：提出了一种简洁但有效的混合架构，一维残差卷积负责局部特征提取，Performer负责全局上下文建模。两者形成互补：CNN提供平移不变性和局部特征的高效提取（这些是Performer缺乏的归纳偏置），Performer提供全局交互建模（这是CNN受限于局部感受野无法实现的）。

3. **证明了线性注意力在KWS中的有效性**：通过实验表明，Performer的近似注意力在KWS任务上能够达到接近标准注意力的性能，同时具有显著的计算优势。这一发现对KWS领域具有重要意义——它表明在实际的短序列KWS任务中，注意力的精确计算并非必需，近似注意力已经足够。

4. **一维卷积处理频谱图的新范式**：将频率维度视为通道维度的一维时间卷积处理方式，为KWS领域的频谱图处理提供了新的思路，这种处理方式在参数效率和时序建模能力上具有优势。

## 实验结果

### 数据集
- **Google Speech Commands (GSC) v2**：12类子集，包含"yes"、"no"、"up"、"down"、"left"、"right"、"on"、"off"、"stop"、"go"、"silence"、"unknown"等常用命令词。
- 评估使用标准的测试集划分，确保结果的可复现性。
- 输入特征为40维MFCC，覆盖约1秒的语音片段。

### 主要性能
- 在GSC v2（12类）上取得了具有竞争力的准确率（约95-96%），超过了纯CNN基线模型（DS-CNN约94-95%）。
- 混合架构相比纯Transformer和纯CNN均有优势：
  - **相比纯CNN**：全局上下文建模带来了准确率提升约1%，特别是在容易混淆的词对上（如"go" vs "no"）。
  - **相比纯Transformer**：局部特征提取更高效，模型收敛更快，所需训练数据更少。
- 对未见说话人表现出更好的泛化能力，这得益于Performer层捕获的全局韵律模式（如语调曲线、节奏特征）。
- 模型在处理可变长度语音时表现出鲁棒性，因为Performer的线性复杂度使得处理不同长度的输入不会导致计算成本的急剧增加。

### 与其他方法的对比
- 与标准自注意力Transformer相比，Performer在序列较长时展现出明显的速度优势（约2-3倍加速），而在短序列（如KWS的典型序列长度）上速度差异较小。
- 与DS-CNN等经典KWS模型相比，Audiomer在准确率上有约1%的提升，但模型参数量略大。
- 与KWT（Keyword Transformer，使用标准注意力）相比，Audiomer在性能相当的情况下具有更好的可扩展性。

### 消融实验（有限）
- 移除Performer层（仅使用CNN主干）导致准确率下降约1%，证实了全局注意力的贡献。
- 使用标准注意力替代Performer在短序列上性能接近，但推理时间增加。

## 局限性与展望

### 技术局限性
- **模型大小与延迟**：Performer层虽然计算复杂度为线性，但额外的随机特征映射和线性投影仍然增加了参数量和延迟，相比纯CNN模型更适合计算资源较充裕的边缘设备。Performer的常数因子（由随机特征维度r决定）在实际实现中可能使得推理速度不如预期。
- **论文篇幅限制**：该论文为2页的短文（workshop/extended abstract形式），实验分析不够充分，包括消融实验、不同配置下的详细对比、错误分析等。许多重要的实验细节和超参数设置未被报告。
- **流式处理能力**：Performer注意力虽然降低了计算复杂度，但仍然需要完整序列输入（非因果的随机特征映射），尚未适配流式/因果推理模式。实际KWS系统通常需要帧级别的实时处理。
- **随机特征的不稳定性**：Performer使用的随机特征映射可能在不同的随机种子下产生不同的性能，论文未分析这种方差对KWS性能的影响。

### 实验设计不足
- 仅在Google Speech Commands数据集上评估，未在噪声、远场或更多样化的数据集上验证。GSC是最基础的KWS基准，但在更困难的条件下方法的鲁棒性尚不清楚。
- 未与其它高效注意力机制（如Linformer、Nystromformer、线性Transformer）进行对比，无法确定Performer是否是KWS任务上的最优选择。
- 缺少模型压缩（量化、剪枝）后的部署性能分析，对于面向边缘部署的KWS研究而言这是一个重要遗漏。
- 未报告推理延迟和模型大小的具体数字，使得难以评估实际的部署可行性。
- 缺少统计显著性分析（如多次运行的方差）。

### 未来改进方向
- 探索因果Performer用于流式KWS推理，通过修改随机特征映射使其仅依赖于当前和过去的特征。
- 结合模型蒸馏技术将Audiomer的知识迁移到更小的学生模型，实现真正的边缘部署。
- 在更多语言（特别是声调语言如中文）和声学条件下验证方法的泛化性。
- 与Conformer架构结合，探索卷积增强的Performer在KWS上的表现。
- 对KWS领域的启发：Performer等线性注意力机制为在资源受限设备上部署Transformer类模型提供了可行路径。Audiomer的CNN-Performer混合范式为后续的KWS模型设计提供了有价值的参考。
