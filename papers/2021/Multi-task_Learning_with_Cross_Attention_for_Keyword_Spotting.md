# Multi-task Learning with Cross Attention for Keyword Spotting

- **作者/机构**: Xuechen Zhang, Yujun Wang, Zhiyong Wu, Helen Meng - Apple; 香港中文大学
- **发表日期**: 2021.07
- **链接**: https://arxiv.org/abs/2107.07634
- **关键词**: 多任务学习, 交叉注意力, 关键词检测, 语音活动检测, 误报缓解, 特征共享

## 问题陈述

关键词检测（KWS）系统在实际部署中面临一个核心矛盾：必须对目标关键词保持极高的灵敏度（低漏检率），同时对非关键词语音保持极低的误报率。特别是在智能助手场景中，用户日常对话中可能包含与唤醒词声学相似的片段，导致频繁的误触发。

传统的单任务KWS模型仅优化关键词分类目标，无法利用相关语音任务的互补信息。然而，在实际语音助手中，多个语音任务是同时需要的：
- **关键词检测（KWS）**：检测唤醒词是否出现
- **语音活动检测（VAD）**：判断是否存在语音信号
- **设备导向语音检测**：判断语音是否指向设备

这些任务之间存在天然的关联性：VAD可以帮助KWS排除非语音段的误报；KWS的声学特征也可以辅助VAD做出更准确的判断。如何有效利用这些任务间的互补信息来提升KWS性能，是本文要解决的核心问题。

## 方法论

### 整体架构设计
论文提出了一种基于交叉注意力（Cross Attention）的多任务学习框架，核心设计包括：
1. **共享编码器主干**：提取通用语音特征
2. **任务特定解码器分支**：为每个任务提供专用的特征变换
3. **交叉注意力模块**：在任务分支之间进行信息交换

### 共享编码器（Shared Encoder）
- 使用多层CNN（或Conformer）作为共享的声学特征编码器
- 输入：频谱图或MFCC特征
- 输出：通用声学特征表示，同时服务于所有下游任务
- 共享编码器通过多任务联合训练获得更丰富的特征表示

### 任务特定解码器（Task-Specific Decoders）
每个任务（KWS、VAD等）拥有独立的解码器分支：
- 每个分支包含几层任务特定的卷积或全连接层
- 解码器从共享特征中提取任务特定的判别信息
- 独立的分类头输出各任务的预测结果

### 交叉注意力模块（Cross Attention Module）
这是论文的核心创新。交叉注意力允许不同任务的解码器分支之间交换信息：

1. **跨任务注意力计算**：
   - 对于任务A的查询特征Q_A，使用任务B的键K_B和值V_B计算注意力
   - Attention(Q_A, K_B, V_B) = softmax(Q_A * K_B^T / sqrt(d)) * V_B
   - 这使得任务A可以从任务B的特征表示中获取相关信息

2. **双向交叉注意力**：
   - 任务A attends to 任务B的特征，同时任务B也attends to 任务A的特征
   - 形成对称的信息交换，两个任务互相受益

3. **门控融合**：
   - 交叉注意力的输出与原始任务特征通过门控机制融合
   - 融合系数由可学习的门控参数控制
   - 避免无关信息干扰主任务

### 损失函数
多任务联合损失为各任务损失的加权和：
L = alpha * L_KWS + beta * L_VAD + gamma * L_other

任务权重通过实验调优或使用动态权重调整策略确定。

## 主要贡献

1. **引入交叉注意力用于KWS任务间的信息共享**：不同于简单的多任务共享编码器（仅在底层共享特征），交叉注意力在高层解码器之间进行细粒度的信息交换，使得每个任务可以精确地从其他任务获取最相关的信息。

2. **证明交叉注意力多任务学习提升KWS准确率**：实验表明，带有交叉注意力的多任务学习在KWS准确率上显著优于单任务学习和无交叉注意力的多任务学习，特别是在误报率控制方面效果突出。

3. **揭示VAD与KWS的互补性**：VAD任务可以帮助KWS在非语音段（如噪声、静音）上减少误报，而KWS的声学知识可以帮助VAD更准确地区分语音和非语音。

4. **有效的误报缓解策略**：通过多任务推理，利用VAD的判断作为辅助信号，可以有效缓解KWS在非目标语音上的误触发。

## 实验结果

### 数据集
- 使用内部KWS数据集和公开数据集组合评估
- 包含目标关键词、非关键词语音、噪声和静音等多种测试场景

### KWS性能提升
- **准确率**：与单任务KWS基线相比，交叉注意力多任务学习的准确率提升约1-2%
- **误报率显著降低**：在保持相同召回率的条件下，误报率降低20-30%
- **VAD辅助效果**：VAD分支对KWS误报率降低的贡献最为显著

### 交叉注意力的效果
- **有交叉注意力 vs 无交叉注意力**：在相同的多任务框架下，加入交叉注意力后KWS准确率额外提升0.5-1%
- **双向 vs 单向**：双向交叉注意力略优于单向
- **门控融合的重要性**：移除门控机制后，交叉注意力的收益减少

### VAD任务收益
- VAD任务也从与KWS的联合训练中获益
- 多任务训练后的VAD准确率略高于单独训练的VAD模型

### 消融实验
- **共享编码器深度**：共享4-6层编码器效果最佳，太浅特征不够丰富，太深任务干扰增加
- **交叉注意力位置**：在解码器的中间层插入交叉注意力效果最好

## 局限性与展望

### 技术局限性
- **模型复杂度增加**：交叉注意力模块引入了额外的参数和计算量，虽然准确率有所提升，但在极其严格的资源约束下可能不可接受
- **多任务标注需求**：训练需要同时具有KWS和VAD（或其他任务）标注的数据，增加了数据准备成本
- **任务干扰风险**：当任务之间相关性较低时，多任务学习可能导致负迁移（negative transfer），某些任务性能下降

### 实验设计不足
- 对哪些任务组合为KWS提供最大收益的分析有限
- 未探索三个以上任务的多任务学习
- 推理时交叉注意力的计算开销缺乏详细量化
- 未在远场和噪声条件下充分评估

### 未来改进方向
- 探索任务相似性度量来预测最优的任务组合
- 研究动态任务权重调整策略
- 结合模型蒸馏将多任务知识迁移到单任务轻量模型用于边缘部署
- 对KWS领域的启发：多任务学习特别是交叉注意力机制为降低KWS误报率提供了有效途径，未来可探索KWS与更多任务（如情感识别、语言识别）的联合学习
