# WaveSense: Efficient Temporal Convolutions with Spiking Neural Networks for Keyword Spotting

- **作者/机构**: Bryan Feys, Sadique Sheik - SynSense AG
- **发表日期**: 2021.11
- **链接**: https://arxiv.org/abs/2111.01456
- **关键词**: 脉冲神经网络, 时间卷积, 关键词检测, 类脑计算, 能量高效, 低功耗, LIF神经元, 代理梯度

## 问题陈述

关键词检测（KWS）系统通常需要以"始终在线"（always-on）的模式运行在电池供电的边缘设备上（如智能手表、无线耳机、物联网传感器）。传统的深度学习方法（CNN、RNN、Transformer）虽然在准确率上取得了优异的表现，但其计算过程涉及大量的浮点乘加运算，持续运行时的能耗较高，对电池寿命造成显著影响。

脉冲神经网络（Spiking Neural Network, SNN）是第三代神经网络，其计算范式更接近生物大脑的工作方式：神经元之间通过离散的脉冲（spike，0或1的二值信号）进行通信，而非连续的实数值。SNN的理论计算能耗可以比等效的ANN低1-3个数量级，因为：

1. **脉冲计算替代乘加运算**：突触权重与脉冲（0或1）的乘法退化为简单的条件加法（如果脉冲为1则累加权重，否则不操作），省去了昂贵的浮点乘法。
2. **事件驱动的稀疏计算**：只有当神经元产生脉冲时才进行计算，大多数神经元在大多数时间步不产生脉冲（稀疏激活），大幅减少了有效计算量。
3. **类脑硬件加速**：专用的神经形态芯片（如Intel Loihi、IBM TrueNorth、SynSense Speck/Xylo）可以高效实现SNN的脉冲计算，实现极低功耗推理。

然而，将SNN应用于KWS面临几个核心挑战：
1. **训练困难**：脉冲神经元的发放函数（阶跃函数）不可微，无法直接使用标准的反向传播算法训练。
2. **准确率差距**：SNN在大多数任务上的准确率仍然落后于等价的ANN，特别是对于需要精细特征区分的KWS任务。
3. **架构设计经验不足**：如何在SNN框架中设计有效的KWS架构（替代成熟的CNN架构）仍缺乏系统性的研究。

本文要解决的核心问题是：如何设计一种基于时间卷积的SNN架构用于KWS，使其在保持可接受准确率的同时实现显著的理论能耗降低，并为部署到类脑硬件提供实用方案。

## 方法论

### 整体架构：WaveSense
WaveSense的架构设计借鉴了ANN中成功的TCN（Temporal Convolutional Network）架构，将时间卷积操作迁移到脉冲域：

整体流程为：原始音频 -> MFCC/频谱特征提取 -> 脉冲编码 -> 堆叠的脉冲时间卷积块 -> 读出层 -> 分类输出。

### 脉冲编码（Spike Encoding）
将连续值的声学特征转换为脉冲序列，是连接ANN输入和SNN处理的桥梁：

- **输入特征**：使用MFCC特征（40维）或Mel频谱图特征作为起始点。
- **编码方法**：
  - **速率编码（Rate Coding）**：将特征值归一化到[0,1]范围，然后以该值为概率在T个时间步中独立地生成0/1脉冲。特征值越大，该位置在T步中产生脉冲的频率越高。
  - **首次脉冲时间编码（Time-to-first-spike Coding）**：特征值越大，首次产生脉冲的时间步越早。这种编码在时间上更高效（不需要多个时间步来传递信息），但实现更复杂。
  - **论文选择**：使用速率编码，在T=20-50个时间步内编码特征。

### 漏电积分发放（LIF）神经元
LIF（Leaky Integrate-and-Fire）神经元是SNN中最常用的神经元模型，WaveSense使用LIF作为基本计算单元：

- **膜电位更新**：U(t) = beta * U(t-1) + W * X(t)
  其中U(t)是时刻t的膜电位，beta是泄漏因子（0 < beta < 1），W是突触权重，X(t)是输入脉冲。
- **脉冲生成**：S(t) = Theta(U(t) - V_th)
  如果膜电位超过阈值V_th则产生脉冲S(t)=1，否则S(t)=0。Theta是阶跃函数。
- **膜电位重置**：当产生脉冲后，膜电位减去阈值：U(t) = U(t) - V_th * S(t)
- **泄漏机制**：beta < 1使得膜电位在没有新输入时逐渐衰减，模拟生物神经元的膜电位泄漏特性，有助于处理时序信息。

### 脉冲时间卷积（Spiking Temporal Convolution）
WaveSense的核心构建块是脉冲时间卷积层：

- **结构**：将标准的一维时间卷积（1D Convolution）迁移到脉冲域。卷积核的权重W与输入脉冲序列进行卷积操作，输出馈入LIF神经元。
- **计算过程**：
  1. 输入脉冲序列与卷积核权重进行卷积（加法操作，因为输入是0/1脉冲）
  2. 卷积输出作为LIF神经元的输入电流
  3. LIF神经元根据膜电位更新规则产生输出脉冲
- **多时间步展开**：SNN在时间维度上展开，每个时间步执行一次卷积+LIF更新。整个序列需要T个时间步才能完成一次推理。
- **残差连接**：在脉冲时间卷积块之间使用残差连接（类似于ResNet），将前一层的脉冲输出跳跃连接到后一层，帮助梯度在时间维度上的传播。

### 代理梯度训练（Surrogate Gradient Training）
由于LIF神经元的阶跃发放函数不可微（梯度在阈值处为无穷大，其余位置为零），无法直接使用反向传播。WaveSense采用代理梯度（Surrogate Gradient）方法：

- **代理梯度函数**：在反向传播中，用一个可微的函数近似阶跃函数的导数。常用选择包括：
  - Sigmoid代理：sigma'(x) = sigma(x)(1-sigma(x))，其中sigma是sigmoid函数
  - 快速Sigmoid代理：使用1/(1+|pi*x/2|)^2作为导数近似
  - ArcTan代理：1/(1+(pi*x)^2)

- **时间反向传播（BPTT）**：在时间维度上展开网络并使用标准的BPTT计算梯度。代理梯度在每个LIF神经元的脉冲生成步骤替代真实的不可微梯度。

- **损失函数**：在最后一个时间步使用读出层（rate readout：统计最后一层每个神经元在T个时间步中的脉冲频率）进行分类，使用标准的交叉熵损失。

### 读出层（Readout Layer）
由于脉冲输出是二值的，需要一种方式将脉冲序列转换为连续的分类概率：

- **频率读出（Rate Readout）**：统计最后一层每个神经元在T个时间步中的总脉冲数（或平均脉冲频率），然后通过softmax输出分类概率。
- 这种设计使得读出层的输出是连续值（脉冲频率在[0,1]范围内），可以使用标准的交叉熵损失训练。

## 主要贡献

1. **在SNN框架中引入时间卷积层用于关键词检测**：首次系统性地将时间卷积（TCN）架构迁移到脉冲神经网络中用于KWS。脉冲时间卷积结合了CNN的局部特征提取能力和SNN的低功耗特性，为SNN在KWS中的应用提供了新的架构选择。

2. **证明SNN可以以显著更低的理论能耗实现具有竞争力的准确率**：WaveSense在GSC v2（12类）上实现了约93%的准确率，虽然低于SOTA的ANN模型（约97-98%），但理论能耗降低高达30倍。这展示了准确率-能耗权衡的可能性和SNN在极端低功耗场景下的潜力。

3. **提供了一种高效映射到类脑硬件的实用架构**：WaveSense的架构设计（时间卷积 + LIF神经元 + 速率编码）与现有的类脑芯片（如SynSense Speck/Xylo、Intel Loihi）的计算模型高度匹配，可以直接映射到硬件实现。

4. **表明代理梯度训练可以在脉冲域中实现有效学习**：通过精心设计的代理梯度函数和BPTT训练策略，WaveSense能够在脉冲域中有效地训练深层SNN，证明了代理梯度方法在KWS等实际语音任务上的可行性。

5. **ANN-to-SNN转换的替代方案**：不同于先训练ANN再转换为SNN的传统方法，WaveSense直接在脉冲域训练，避免了转换过程中的精度损失。

## 实验结果

### 数据集与设置
- **Google Speech Commands v2**：12类子集（"yes", "no", "up", "down", "left", "right", "on", "off", "stop", "go", "silence", "unknown"）
- **输入特征**：40维MFCC，速率编码到T=20-50个时间步
- **评估指标**：分类准确率、理论能耗（基于脉冲操作数估计）、推理延迟（时间步数）

### 分类准确率
- **WaveSense**：在GSC v2（12类）上实现了约93%的准确率。
- **与等效ANN的对比**：具有相同架构的ANN（使用ReLU替代LIF）达到约95-96%的准确率。SNN版本比ANN版本低约2-3%，这一差距在可接受范围内。
- **与SOTA ANN方法的对比**：SOTA的ANN模型（如BC-ResNet、KWT）达到约97-98%的准确率，WaveSense低约4-5%。这是SNN的准确率-能耗权衡的代价。

### 理论能耗分析
- **脉冲操作 vs 乘加操作**：SNN中的脉冲操作（条件加法）的理论能耗约为ANN中浮点乘加操作的1/30（基于SRAM访问和计算的理论能耗模型）。
- **稀疏性**：WaveSense中神经元的平均脉冲发放率约为10-20%（即每个神经元在80-90%的时间步不产生脉冲），进一步降低了实际计算量。
- **总能耗估计**：WaveSense的理论能耗约为等效ANN的1/30（约30倍降低），主要来自脉冲计算的简化（乘法变为条件加法）和脉冲稀疏性。

### 时间步数的影响
- 增加推理的时间步数T可以提升准确率（更多的时间步提供更精确的信息编码和决策积累），但也会线性增加延迟和能耗。
- T=20：准确率约89%，延迟约20ms
- T=30：准确率约91%，延迟约30ms
- T=50：准确率约93%，延迟约50ms
- T=100：准确率约93.5%，但延迟过长

### 与其他SNN方法的对比
- 与基于ANN-to-SNN转换的方法相比，直接训练的WaveSense在相同时间步数下准确率更高（约93% vs 约90%），因为直接训练可以更好地优化脉冲域的决策边界。
- 与纯全连接SNN相比，脉冲时间卷积的准确率高约3-5%，验证了时间卷积在SNN中的有效性。

### 消融实验
- **泄漏因子beta**：beta=0.8-0.9时效果最佳。过低的beta（如0.5）导致时间信息丢失过快，过高的beta（如0.99）导致信息积累过多难以区分。
- **代理梯度选择**：快速Sigmoid代理在准确率和训练稳定性上表现最佳。
- **残差连接**：移除残差连接后准确率下降约2-3%，特别是对于更深的网络。

## 局限性与展望

### 技术局限性
- **准确率差距**：WaveSense的准确率（约93%）仍落后于SOTA的传统神经网络方法（约97-98%），差距约4-5%。在对准确率要求极高的商业KWS系统中，这一差距可能不可接受。SNN在精细特征区分（如区分声学相似的关键词对"yes"/"yeah"）方面仍然弱于ANN。
- **仅理论能耗估计**：论文提供的能耗降低是基于理论模型（计算脉冲操作数 * 单次操作的理论能耗），而非实际硬件上的测量值。实际能耗取决于芯片的实现细节（如时钟频率、IO开销、SRAM/DRAM访问模式等），理论估计可能与实际测量有显著差异。
- **推理延迟**：SNN需要多个时间步（T=20-50）才能完成一次推理，导致推理延迟约为等效ANN的T倍。虽然每个时间步的计算量远小于ANN，但总的推理延迟可能更长。
- **训练复杂度**：代理梯度训练虽然解决了不可微问题，但训练过程比标准ANN训练更复杂（需要沿时间维度展开BPTT），且对超参数（学习率、代理梯度函数、泄漏因子等）更加敏感。
- **脉冲编码的信息损失**：速率编码将连续值特征转换为二值脉冲序列，引入了信息量化损失。增加时间步数T可以减少这一损失，但增加了延迟。

### 实验设计不足
- 仅在Google Speech Commands数据集上评估，未在噪声、远场或自定义关键词等更具挑战性的场景下验证。
- 缺少在实际类脑硬件（如SynSense Speck、Intel Loihi）上的实测数据（实际能耗、延迟、准确率），这使得论文的"低功耗"声明缺乏实证支持。
- 未探索更先进的脉冲编码策略（如基于注意力的自适应编码、直接处理原始波形的SNN等）。
- 对不同类型关键词（短词 vs 长词、常见词 vs 罕见词）的细粒度分析不足。

### 未来改进方向
- 在实际的神经形态芯片上部署和测量WaveSense的实际能耗，验证理论估计的准确性。
- 探索混合ANN-SNN架构：前端使用ANN提取特征（更准确），后端使用SNN进行分类（更省电），在准确率和能耗之间取得更好的平衡。
- 研究混合精度SNN（不同层使用不同的时间步数或脉冲精度），将计算资源集中在最关键的层。
- 结合ANN-to-SNN知识蒸馏：先训练高精度ANN教师模型，然后使用蒸馏损失训练SNN学生模型，缩小ANN-SNN的准确率差距。
- 探索事件驱动的特征提取：使用动态传感器（如音频事件检测器）在SNN输入端实现事件驱动的稀疏化，进一步降低功耗。
- 对KWS领域的启发：SNN在KWS领域的应用仍处于早期阶段，但在"始终在线"的极端低功耗场景中具有不可替代的潜力。随着类脑硬件的成熟和SNN训练方法的改进，SNN-based KWS有望在物联网和可穿戴设备中找到重要的应用场景。WaveSense为这一方向的研究提供了有价值的基线和架构参考。
