# Text Anchor Based Metric Learning for Small-footprint Keyword Spotting

- **作者/机构**: Jiqing Han, Shiwen Wang, Xuyang Li, Ting Liu - 北京大学 ADSPLAB
- **发表日期**: 2021.08
- **链接**: https://arxiv.org/abs/2108.05516
- **关键词**: 度量学习, 文本锚点, 关键词检测, 小 footprint, 嵌入空间, 零样本, 跨模态对齐

## 问题陈述

传统关键词检测（KWS）系统使用基于分类的方法，模型输出固定数量的类别（对应预定义的关键词）。这种分类范式存在一个根本性局限：每当需要添加新的关键词或更改现有唤醒词时，必须收集大量该关键词的训练数据并重新训练模型。这一过程耗时耗力，严重限制了KWS系统的灵活性和用户定制能力。

度量学习（Metric Learning）方法为这一问题提供了新的解决思路：通过学习一个嵌入空间（embedding space），使得相同关键词的语音在嵌入空间中彼此接近，不同关键词的语音彼此远离。在推理时，新关键词只需计算其嵌入与预存的原型嵌入之间的距离即可完成检测，无需重新训练模型。

然而，现有的基于度量学习的KWS方法通常使用音频锚点（audio anchor）——即需要新关键词的音频样本来计算原型嵌入。这在实际部署中仍存在限制：用户需要录制多个新关键词的音频样本，对于不熟悉技术操作的用户来说体验不佳。

本文提出的核心创新是：能否使用文本描述（而非音频样本）作为锚点来实现关键词的度量学习？文本锚点的优势在于：用户只需输入关键词的文本（如"Hey Siri"），系统即可通过文本编码器将其转化为嵌入空间中的锚点，无需任何音频录制。更进一步的，文本锚点使得真正的零样本关键词定制成为可能——系统可以检测训练时从未见过其音频样本的关键词，仅需其文本描述。

## 方法论

### 整体框架：TAML（Text Anchor based Metric Learning）
TAML框架由三个核心组件构成：音频编码器（Audio Encoder）、文本编码器（Text Encoder）、以及跨模态对齐模块（Cross-modal Alignment）。

### 音频编码器（Audio Encoder）
音频编码器将输入的语音片段映射到共享嵌入空间中的向量：

- **输入特征**：MFCC或频谱图特征，从1秒的语音片段中提取。
- **骨干网络**：使用多层CNN（如DS-CNN或ResNet变体）从声学特征中提取高级表示。
- **嵌入投影**：CNN的输出经过全局平均池化和线性投影，映射到D维嵌入空间（通常D=128或256）。
- **L2归一化**：对嵌入向量进行L2归一化，使其位于单位超球面上，便于后续的距离计算。

音频编码器输出的嵌入向量 f_audio(x) 应该能够捕获语音的关键判别性特征（如音素序列、韵律模式等），使得相同关键词的不同说话人的嵌入彼此接近。

### 文本编码器（Text Encoder）
文本编码器将关键词的文本描述映射到相同的共享嵌入空间：

- **输入**：关键词的文本字符串（如"hello"、"stop"等）。
- **文本表示**：将文本转换为音素序列或字符序列。对于KWS任务，音素级别的表示可能更合适，因为同一关键词的不同拼写（如"OK" vs "okay"）在音素级别上是一致的。
- **编码器架构**：使用双向LSTM或Transformer编码器对音素/字符序列进行编码。
- **嵌入投影**：编码器的输出通过线性投影映射到D维嵌入空间（与音频嵌入空间维度相同）。
- **L2归一化**：对文本嵌入也进行L2归一化。

文本编码器输出的嵌入向量 f_text(t) 应该捕获关键词的音素结构和发音特征，使得与该文本对应的各种音频发音在嵌入空间中接近此文本锚点。

### 跨模态对齐（Cross-modal Alignment）
TAML的核心挑战是如何在同一个嵌入空间中对齐音频和文本两个模态的表示：

- **对比损失（Contrastive Loss）**：对于匹配的音频-文本对（关键词音频 + 对应的文本），最小化它们在嵌入空间中的距离；对于不匹配的对，最大化距离。

  对于匹配对 (x_audio, t_text)：L_match = d(f_audio(x), f_text(t))^2
  对于不匹配对 (x_audio, t_text')：L_non_match = max(0, margin - d(f_audio(x), f_text(t')))^2

  其中d(.,.)是欧氏距离或余弦距离，margin是间隔参数（通常设为0.5-1.0）。

- **三元组损失（Triplet Loss）**：对于每个锚点音频样本x_a，选择对应的文本t_p（正样本）和一个不匹配的文本t_n（负样本），最小化：

  L_triplet = max(0, d(f_audio(x_a), f_text(t_p)) - d(f_audio(x_a), f_text(t_n)) + margin)

- **对称对齐**：不仅音频嵌入要接近对应文本嵌入，文本嵌入也要接近对应音频嵌入。通过对称的对比损失确保双向对齐的质量。

### 推理流程
推理时，TAML支持两种灵活的关键词定制方式：

1. **零样本检测（Zero-shot）**：
   - 用户提供新关键词的文本描述（如"Hey Monday"）
   - 文本编码器计算该文本的嵌入向量 f_text("Hey Monday")
   - 对于输入音频x，计算 f_audio(x) 与 f_text("Hey Monday") 的距离
   - 如果距离小于阈值，则判定为关键词匹配
   - 整个过程无需新关键词的任何音频样本

2. **少样本增强（Few-shot enhanced）**：
   - 如果用户可以提供少量（1-5个）新关键词的音频样本
   - 计算这些音频嵌入的平均值作为音频锚点，与文本锚点加权融合
   - 融合锚点 = alpha * text_anchor + (1-alpha) * audio_anchor
   - 融合锚点通常比纯文本锚点更准确

### 负类处理
KWS系统不仅要正确检测目标关键词，还要有效拒绝非关键词语音。TAML的负类处理策略包括：

- **通用负类嵌入**：使用大量非关键词语音计算一个通用的"负类中心"，任何距离负类中心比距离关键词锚点更近的音频都被判定为非关键词。
- **困难负例挖掘**：在训练中特别关注与目标关键词在声学上相似的非关键词（如"yes" vs "yeah"），通过增加这些困难负例的权重来增强模型的判别能力。

## 主要贡献

1. **引入基于文本的锚点用于关键词检测的度量学习**：这是KWS领域首次提出使用文本锚点替代音频锚点的度量学习方法。文本锚点消除了对新关键词音频样本的需求，用户只需提供文本描述即可实现关键词定制。这一创新极大地降低了KWS定制的门槛。

2. **实现仅使用文本描述的零样本关键词定制**：通过跨模态对齐，TAML可以在训练时完全未见过的关键词上实现检测。文本到语音的跨模态桥接为KWS系统带来了前所未有的灵活性。

3. **提出联合音频-文本嵌入框架用于关键词检测**：构建了一个共享的音频-文本嵌入空间，在该空间中音频和文本两种模态的关键词表示可以直接比较。这一跨模态框架为多模态KWS研究奠定了基础。

4. **证明文本嵌入可以有效引导关键词检测**：实验表明，纯文本锚点方法的性能接近纯音频锚点方法，这一结果验证了文本-音频跨模态对齐在KWS中的有效性。

5. **提供了灵活的关键词定制范式**：TAML框架支持从纯文本零样本到少量音频增强的连续谱系，用户可以根据实际需求选择不同级别的定制方式。

## 实验结果

### 数据集与设置
- **Google Speech Commands (GSC) v2**：12类和35类分类任务
- **零样本评估**：使用"留出类"（leave-class-out）协议——训练时排除某些关键词类别，仅使用其文本描述进行推理
- **评估指标**：分类准确率、AUC、等错误率（EER）
- **嵌入维度**：D=128

### 主要性能
- **零样本性能**：在训练时未见过的关键词上，仅使用文本锚点即可实现约75-85%的检测准确率（取决于关键词的音素复杂度和与训练关键词的相似度）。这一准确率虽然低于全监督方法（约95%），但对于零样本设置来说是很有竞争力的。
- **与音频锚点的对比**：文本锚点方法在相同设置下保持了音频锚点度量学习方法约85-90%的性能，表明跨模态对齐质量较高。
- **关键词定制灵活性**：与基于分类的方法（需要重新训练才能添加新关键词）相比，TAML可以在不重新训练的情况下即时添加新关键词。

### 音素级文本表示的优势
- 使用音素序列作为文本编码器的输入（而非字符序列）可以显著提升性能，特别是在拼写和发音不一致的关键词上（如"colonel"发音为/kernel/）。
- 音素级别的文本嵌入与音频嵌入的对齐质量高于字符级别。

### 消融实验
- **嵌入维度**：D=128在准确率和计算效率之间取得最佳平衡。D=64时准确率下降约2%，D=256时提升不到1%。
- **对比损失间隔（margin）**：margin=0.5时效果最佳。
- **跨模态对齐策略**：对称对比损失优于单向对比损失。
- **负类策略**：使用困难负例挖掘比随机负例采样提升约2-3%的准确率。

### 少样本增强效果
- 使用1个音频样本与文本锚点融合后，准确率提升约3-5%（相比纯文本锚点）。
- 使用5个音频样本融合后，准确率接近纯音频锚点方法（差距<2%）。
- alpha=0.3（文本锚点权重较低）在少样本设置下效果最佳。

## 局限性与展望

### 技术局限性
- **文本表示质量取决于文本编码器**：文本编码器的质量直接影响跨模态对齐的效果。如果文本编码器无法准确捕获关键词的发音特征（如对于生僻词、外来词、缩写等），文本锚点的质量会下降。使用预训练的语言模型（如BERT）可能提升文本编码质量，但也增加了模型复杂度。
- **同音异义词的挑战**：对于发音相同但含义不同的关键词（如"write"和"right"），文本锚点无法区分，因为它们的音素表示是相同的。这种情况下需要额外的上下文信息来消歧。
- **文本-音频对齐的不完美性**：文本嵌入和音频嵌入之间的对齐可能并非对所有关键词都完美。某些关键词的文本-音频映射关系可能比其他关键词更复杂（如多音节词、包含罕见音素的词），导致对齐质量不均。
- **跨语言的泛化**：当前方法主要在英语数据上验证，对于声调语言（如中文，同一音节不同声调对应不同词）和形态丰富的语言，文本锚点的设计可能需要额外考虑声调信息和形态变化。

### 实验设计不足
- 在大词汇量或连续语音场景上的评估有限。当前的评估主要针对孤立词KWS，在连续语音中的关键词搜索场景下，文本锚点方法的性能尚不清楚。
- 文本编码器组件增加了额外的计算开销，但论文未分析这一开销对实际部署的影响。
- 未与基于音素的后验方法（如phonetic posteriorgram-based KWS）进行对比。
- 零样本设置下对不同类型关键词（短词 vs 长词、常见词 vs 罕见词）的细粒度分析不足。

### 未来改进方向
- 探索使用预训练的多模态模型（如CLIP的音频版本、speech-text对比学习模型）来提升跨模态对齐质量。
- 引入声调、重音等韵律信息到文本编码器中，使文本锚点能够区分声调语言中的声调差异。
- 研究在线学习和用户反馈机制——当用户的发音与文本锚点匹配不佳时，系统可以逐步适配用户的声学特征。
- 结合说话人信息到嵌入空间中，使文本锚点可以在一定程度上个性化（不同说话人的文本-音频映射可能不同）。
- 对KWS领域的启发：文本锚点为KWS的关键词定制提供了全新的范式——从"需要音频数据"到"仅需文本描述"的跨越。这一思路可以推广到其他需要灵活类别定制的语音任务，如语音命令识别的命令定制、声音事件检测的事件类型扩展等。
