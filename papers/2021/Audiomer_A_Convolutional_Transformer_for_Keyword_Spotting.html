CNN 管局部、注意力管全局：
但注意力要线性复杂度的——Performer 进 KWS

Audiomer · 乔治梅森大学 arXiv 2109.10252 · 2 页 workshop 短文 1D ResNet + FAVOR+ 随机特征 + CLS GSC 12 类约 95–96%（DS-CNN +1%）· 长序列 2–3× 加速
一句话：CNN 主导 KWS 但感受野有天花板，纯 Transformer 能建模全局韵律却背着 O(n²) 的复杂度。Audiomer 的混合方案：一维残差卷积沿时间轴提局部特征（频率维当通道），Performer 用 FAVOR+ 随机特征把注意力的平方复杂度降到线性 O(n·d·r)，再配可学习位置编码与 CLS token 分类。GSC 12 类约 95–96%，比 DS-CNN 高约 1 个点——混淆词对（go vs no）受益最大，因为这正是全局时间结构才能区分的信息。
TL;DR
  • 两边各缺一半：CNN 的局部卷积核感受野受限，全局韵律模式、音调轨迹、跨音素时间结构建不了模；纯 Transformer 能捕全局但 O(n²) 在边缘设备的延迟/功耗预算下是部署瓶颈，且缺平移不变性与局部性归纳偏置（小数据要更多数据）。
  • 流水线：40 维 MFCC → 1D ResNet（时间轴卷积 · 频率当通道 · 瓶颈残差块）→ 可学习位置编码 → Performer 注意力 → CLS token → FC 分类。「CNN 主干 + Transformer 头部」是视觉/语音广泛验证的混合范式，增量在把头部换成线性注意力。
  • Performer 的核心是 FAVOR+：softmax 核可被随机特征近似 φ(q)·φ(k)，再用结合律换序——(φ(Q)φ(K)ᵀ)·V → φ(Q)·(φ(K)ᵀ·V)，先算与序列长度无关的 d×d 小矩阵——复杂度 O(n²d) → O(n·d·r)，近似无偏、方差可控。
  • 位置编码从可选变必需：标准注意力里 QKᵀ 隐式编码位置差异，随机特征近似破坏了这一点——省掉它模型就不知道谁在前谁在后。
  • 结果（约值）：GSC 12 类 95–96% vs DS-CNN 94–95%；混淆词对（go vs no）受益最大——区分这类词对靠的恰是全局时间结构；去 Performer 层掉约 1%；对未见说话人泛化更好（全局韵律）；变长输入鲁棒（线性复杂度不吃长度）。
  • 诚实的边界：KWS 的典型序列长度落在「标准注意力还不慢」的区间——线性注意力的 2–3× 加速要在长序列才兑现；常数因子（随机特征维度 r）让实际推理未必如理论线性好看；非因果（需要完整序列）流式未适配。
  • 证据边界：2 页 workshop 短文——无延迟/模型大小实测数字、无 Linformer/Nyströmformer 等横比、无量化分析、无方差统计、仅 GSC 干净数据。定位是「证明可行」而非给出成品。

    • §01问题：两边的天花板

    局部感受野 vs 二次复杂度

    CNN 的感受野天花板

    局部卷积核捕获时频局部模式高效，但感受野受核大小与深度限制——音素序列的长程依赖（如 go 与 no 在时间结构上的差异）要靠堆很深才勉强覆盖，参数效率随之崩坏。

    Transformer 的两块短板

    O(n²) 的自注意力在边缘延迟/功耗预算下不可部署；缺乏平移不变性与局部性归纳偏置——小数据集上要更多数据才能到最佳性能，而 KWS 数据恰恰不大。

    短音频也要全局

    1 秒的片段听起来不长，但整段上的韵律模式、音调变化轨迹、跨多音素的时间结构对判别至关重要——全局建模不是奢侈品，是混淆词对（go vs no）的判别力来源。

    混合的分工哲学

    CNN 提供 Performer 缺的归纳偏置（平移不变、局部高效、小数据友好），Performer 提供 CNN 做不到的全局交互——各补对方没有的那一半，互补而非替代。

    §02方法：结合律换序的魔法

    FAVOR+ 随机特征 · 位置编码的必要性 · CLS 聚合
    标准: Attention(Q,K,V) = softmax(QKᵀ/√d)·V # O(n²·d)，先物化 n×n 大矩阵 Performer: φ(x) = (1/√r)·[exp(w₁ᵀx+b₁), …, exp(w_rᵀx+b_r)] # 随机特征 Attention ≈ φ(Q)·(φ(K)ᵀ·V) / φ(Q)·(φ(K)ᵀ·1) # O(n·d·r)，r ≪ n
    人话：标准注意力必须先把每个查询和所有键两两点积，物化出 n×n 的大矩阵——平方复杂度的根源。Performer 分两步拆掉它：① softmax 核可以用随机特征的内积近似（无偏、方差由 r 控制）；② 换结合律，先算 φ(K)ᵀ·V 这个与 n 无关的 d×d 小矩阵，再左乘 φ(Q)——n 从平方降为线性。

    1D ResNet 的三个理由

    时序结构是核心判别信息（yes = /j/ /ɛ/ /s/ 的序列）——一维时间卷积天然匹配；参数量与频率维无关只取决于核与通道——小足迹友好；瓶颈残差块（1×1 降维 → BN → ReLU → 时间卷积 → BN → skip → ReLU）保证深网梯度流动。

    训练配方

    标准 CE + Adam + warmup（前 10% 步线性升学习率）+ 余弦退火——Transformer 系的标准调度：warmup 稳定初期训练，余弦退火收敛到更优的局部最小。CLS token 在序列开头，经注意力从所有帧收集信息后送 FC 分类。

    读表要点
  • 最有信息量的一条消融：短序列上标准注意力与 Performer 性能接近——说明注意力的精确计算并非必需，近似已足够；那 Performer 的价值就只在长序列的速度与可变长鲁棒性上。
  • 对未见说话人泛化更好：Performer 捕获的全局韵律（语调曲线、节奏特征）是跨说话人相对稳定的线索——这解释了泛化红利。
  • 引用提醒：论文未报任何延迟/模型大小实测数字，「适合边缘部署」目前只是复杂度层面的推断；数字均为笔记记录的约值。

    • §04贡献

    四点：从首次引入到范式确认
    1

    首次把 Performer 用于 KWS：线性复杂度注意力解决标准 Transformer 在 KWS 场景的计算效率问题——不牺牲全局建模能力的前提下保持高效推理。

    2

    1D 残差卷积 + Performer 混合架构：局部特征提取与全局上下文建模互补——CNN 补归纳偏置，Performer 补全局交互。

    3

    证明线性注意力在 KWS 的有效性：近似注意力达到接近标准注意力的性能——短序列 KWS 任务上注意力的精确计算并非必需。

    4

    频谱图的一维处理新范式：频率维当通道维的一维时间卷积——参数效率与时序建模能力的双重优势，为 KWS 频谱图处理提供新思路。

    §05局限与判断

    常数因子 · 非流式 · 2 页短文的证据密度
    图4 · 边界与延伸：左技术边界（常数因子陷阱、参数略大、非因果、随机方差、篇幅限制），右实验边界（仅 GSC、无注意力横比、无压缩分析）+ 延伸方向。
    可迁移判断

    ↳ 选线性注意力之前先算一算自己的 n：KWS 的典型序列长度落在 O(n²) 还不是瓶颈的区间——线性注意力的加速要在长序列兑现。复杂度级别的「更优」不等于你的工作负载上的「更快」。

    ↳ 混合架构的分工要显式设计：CNN 补归纳偏置（小数据、快收敛）、注意力补全局交互（混淆词对、跨说话人韵律）——两边各自的价值都该有对应消融格子，否则「混合」只是堆叠。

    ↳ 改注意力机制要重新检查位置信息：QKᵀ 隐式携带位置差异——任何近似掉这层信息（随机特征、低秩、局部窗口）的改动，都要把位置编码从可选升为必需。

    ↳ workshop 短文的正确读法：价值在「证明可行」——近似注意力在 KWS 够用；成品化（流式、量化、实测延迟）是留给后续工作的空地，引用时别把「可行」当「已落地」。
