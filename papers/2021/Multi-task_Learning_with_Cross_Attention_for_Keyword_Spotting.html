误报砍三成的办法：
让 KWS 和 VAD 在解码器里互相对话

Cross-Attention Multi-Task · Apple + 港中文 arXiv 2107.07634 · KWS + VAD 联合 共享编码器 + 双向交叉注意力 + 门控融合 误报 −20–30%（同召回）· 准确率 +1–2%
一句话：KWS 部署的头号痛点是误报——用户日常对话里常有与唤醒词声学相似的片段。语音助手本来就同时需要 KWS 和 VAD，两个任务天然互补（VAD 帮 KWS 拒非语音段，KWS 的声学知识反哺 VAD），但传统多任务只在编码器底层共享特征——高层互补信息传不过去。本文在任务解码器之间加双向交叉注意力（各自的 Query 去检索对方的 K/V）+ 门控融合：误报率降 20–30%（同召回），准确率升 1–2%，交叉注意力本身再贡献 0.5–1%。
TL;DR
  • 核心矛盾：对目标词要极高灵敏度（低漏检），对非目标语音要极低误报——日常对话中与唤醒词声学相似的片段导致频繁误触发，这是单任务模型的结构性短板。
  • 天然互补被浪费：语音助手同时需要 KWS（词出现吗）+ VAD（有语音吗）+ 设备导向检测（是对设备说的吗）——VAD 可帮 KWS 排除噪声/静音段的误报，KWS 的声学知识可帮 VAD 更准——但单任务模型各自为战。
  • 简单共享不够：传统多任务只在编码器底层共享——高层解码器各走各路，任务间细粒度的互补信息（哪些帧有语音、哪些帧像词）传不过去。
  • 交叉注意力：Attention(Q_A, K_B, V_B)——任务 A 用自己的查询去检索任务 B 的特征表示：KWS 从 VAD 特征里取「这里有没有语音」的证据，VAD 从 KWS 特征里取「像不像词」的声学证据。双向对称交换，两个任务互相受益。
  • 门控融合必需：外来信息并非总有用——可学习的门控系数控制混入量（有用多混、无关压低）。消融：移除门控后交叉注意力收益明显减少。
  • 三组件框架：共享编码器（CNN/Conformer，4–6 层甜点）→ 任务特定解码器 → 解码器中间层插双向交叉注意力。损失 L = α·L_KWS + β·L_VAD + γ·L_other。
  • 结果（约值）：准确率 vs 单任务 +1–2%；同召回下误报 −20–30%（VAD 分支贡献最大）；交叉注意力在多任务框架上再 +0.5–1%；双向略优于单向；VAD 也从联合训练获益（略高于单独训练的 VAD）。
  • 边界：交叉注意力增加参数与计算（推理开销未量化）；训练数据要同时有 KWS 与 VAD 标注；任务相关性低时有负迁移风险；内部数据为主复现性受限。

    • §01问题：误报与被浪费的互补

    单任务的结构短板 + 多任务的共享天花板

    误报是部署头号痛

    用户对话中与唤醒词声学相似的片段、电视声、相似词——每条都是潜在误触发。误报直接伤用户信任（「它自己就醒了」），商用系统宁可牺牲召回也要压误报。

    级联 VAD 的硬边界

    传统做法是推理时级联一个 VAD 做前置过滤——硬门限、独立训练、错误不可逆。联合建模让「VAD 的判断」作为软证据进入 KWS 的判决过程，比外挂级联更可学。

    任务关联的天然性

    KWS 要判断「是不是唤醒词」，VAD 要判断「是不是语音」——前者蕴含后者（唤醒词必是语音）：逻辑包含关系让两个任务的表示天然相关，联合训练有理论依据。

    底层共享的信息瓶颈

    共享编码器只在底层交换通用声学特征——任务特有的判别信息（VAD 的语音边界、KWS 的词形模式）在高层才形成，底层共享传不了这些——需要在解码器层建立第二条通路。

    图1 · 机制全景：上半是误报痛点与任务互补，中段是三组件框架与双向交叉注意力、门控融合的架构图，底部是消融甜点与关键数字。

    §02方法：跨分支检索 + 可控混入

    交叉注意力的查询语义 · 门控的必要性
    交叉: Attention(Q_KWS, K_VAD, V_VAD) # KWS 检索 VAD 的特征 Attention(Q_VAD, K_KWS, V_KWS) # VAD 检索 KWS 的特征（双向） 门控: out = g · cross_out + (1−g) · self_out # g 可学习 损失: L = α·L_KWS + β·L_VAD + γ·L_other
    人话：交叉注意力的本质是「跨分支检索」——KWS 拿着自己的查询（我在找什么样的证据）去 VAD 的特征库里翻（那里有没有语音的存在证明）。检索回来的信息不直接替换原特征，而是经门控按需混入——门控是保险丝，防止无关信息污染主任务。

    门控与残差同构

    门控融合在结构上就是加权残差：新通路（交叉注意力）的价值要在「可控混入」的前提下才能兑现——直接相加等于强迫每个样本都接受外来信息，噪声段的外来证据对 KWS 可能是有害的。

    两个甜点都有先例

    共享 4–6 层（太浅无红利、太深任务干扰）与交叉注意力插解码器中间层——与 LDF 的位置消融、注意力插入位置的结论第三次同构：中间层是信息交换的黄金窗口，这条规律在本系列至少四篇论文中独立出现。

    图2 · 机制解剖：左是交叉注意力的数据流（双向检索、各自的查询语义、门控融合回分支），右是门控的必要性与两个甜点消融（共享深度、插入位置）。

    读表要点
  • 误报收益主要来自多任务本身（−20–30%），交叉注意力主要是精度增量（+0.5–1%）——拆开看两个贡献源，工程上可按需取舍（预算紧时只做多任务）。
  • 「VAD 也获益」值得注意：联合训练不是零和——KWS 的声学知识让 VAD 更准，说明两个任务的表示确实互补而非竞争（负迁移没有发生在任务相关性高的一对上）。
  • 证据边界：内部数据为主（复现受限）、交叉注意力推理开销未量化、远场/噪声评估不充分、未探索 3+ 任务组合——绝对数字不可直接引用，相对量级可迁移。

    • §04贡献

    四点：从机制到误报策略
    1

    交叉注意力用于 KWS 任务间信息共享：区别于底层共享的多任务——在高层解码器间细粒度交换，每个任务精确获取最相关的信息。

    2

    证明交叉注意力多任务提升 KWS：显著优于单任务与无交叉注意力的多任务——误报控制尤其突出。

    3

    揭示 VAD 与 KWS 的互补性：VAD 帮 KWS 拒非语音段，KWS 声学知识帮 VAD 判别——双向互利有实验证据。

    4

    有效的误报缓解策略：多任务推理用 VAD 判断作辅助信号——为 KWS 误报问题提供系统级方案而非单点技巧。

    §05局限与判断

    复杂度 · 标注成本 · 负迁移风险
    图4 · 边界与延伸：左技术边界（交叉注意力开销、双标注需求、负迁移风险），右实验边界（内部数据、远场噪声、3+ 任务未探索）+ 延伸方向（含「多任务训、单任务部署」的蒸馏路线）。
    可迁移判断

    ↳ 多任务训、单任务部署：联合训练的价值在表示质量（互为免费的辅助监督），不必把整个多任务模型搬上端侧——蒸馏到单任务轻量模型就能保留大部分收益，部署复杂度不增。

    ↳ 跨分支检索比底层共享传得更细：底层共享传「通用特征」，交叉注意力传「任务特有判别信息」——两个任务有逻辑包含关系（唤醒词 ⊂ 语音）时，后者是前者的必要补充。

    ↳ 辅助任务的选择看相关性：VAD 与 KWS 高相关所以互利；任务相关性低时负迁移会出现——共享深度的甜点（4–6 层）正是干扰边界的量化。选辅助任务先问「它的输出是否蕴含我任务的先验」。

    ↳ 新通路要配保险丝：交叉注意力、动态滤波、任何引入外部信息的模块都需要门控/残差式的可控混入——「无脑融合」的收益在消融里从来都不稳定。
