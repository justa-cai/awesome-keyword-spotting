换唤醒词不用重训：
新词只是嵌入空间里的一个新坐标

Triplet Loss KWS · 托木斯克国立大学 + NTR Labs arXiv 2101.04792 · FaceNet 式度量学习进 KWS 三元组 + 半难负样本挖掘 + 原型匹配 新词 5–10 样本 → 85–90% · 开集 EER 3–5%
一句话：分类式 KWS 的词表焊死在输出层——加词、删词、自定义词都要重训整个模型。本文把人脸识别的 triplet loss 系统搬进 KWS：DS-CNN 骨干学一个嵌入空间（同词靠近、异词远离、L2 归一化到单位球），新关键词 = 几个样本的嵌入均值（原型），推理比距离即可——零重训。12 类约 94–95%（比 CE 低约 1 个点，买的是换词自由），开集验证 EER 3–5%，5–10 个新词样本即达 85–90%。
TL;DR
  • 分类模型的硬边界：输出类别数固定——厂商加新唤醒词、用户自定义词、多语言扩展全都卡在「重训整个模型」这一步。度量学习把问题改写：学空间而不是学分类头。
  • 三元组损失：L = max(0, d(a,p) − d(a,n) + margin)——锚点与同词样本的距离加上 margin 后仍小于与异词样本的距离则零损失，否则推动类内收紧、类间拉开。margin 甜点 0.3（0.2 间隔不够、0.5 多数三元组满足不了）。
  • 半难负样本挖掘是训练成败的关键：随机负样本大多太远（损失为零、无信号）；半难负样本（比正样本远但在 margin 带内）信号最强又不像最难负样本那样让训练不稳——比随机策略高 2–3%。每 ~100 步重挖一次。
  • 架构：DS-CNN 风格骨干（标准卷积起手 + DS 块 + GAP）→ FC 投影到 D 维 → L2 归一化到单位球（欧氏 ≡ 余弦，还 +1% 与更稳训练）。
  • 两种推理形态：闭集分类（最近原型）与开集验证（最近原型距离 < θ 判该词，否则「未知」）——后者才是 KWS 的真形态（非词表输入要能拒识）。
  • 结果（约值）：12 类 94–95%（CE 95–96%）；35 类 92–93%；类内距离 0.3–0.4 vs 类间 0.8–1.0（清晰分离）；嵌入维度甜点 64–128（32 容量不足、256 只多 <0.5%）。
  • 新词适配（核心卖点）：5–10 个样本算原型 → 85–90% 检测准确率，全程不动嵌入网络；建议每词 10–20 个不同说话人的样本做原型更稳。
  • 代价与边界：闭集精度比 CE 低约 1 个点；三元组训练对超参敏感（可能坍缩）；声学近邻词（yes/yeah、on/off）拉不开间隔；距离无概率含义（校准负担）；推理 O(K·D) 随词表涨。

    • §01问题：词表焊死在输出层

    改词 = 重训的三重痛

    加词删词都要重训

    分类 KWS 的输出节点数 = 词表大小——厂商上新唤醒词、用户自定义个性化词、多语言扩展，每次都要重新训练和部署整个模型。迭代节奏被训练周期绑架。

    语音的高变异性

    同一个关键词在不同说话人、语速、噪声条件下差异巨大——嵌入空间必须在容纳这些变化的同时保持类内紧凑；还要支持音素级精细区分（yes 与 yeah 只差尾音素）。

    度量学习的改写

    不学「类别 → 节点」而学「样本 → 坐标」：同词样本在嵌入空间聚成簇、异词远离。新词 = 簇中心（原型），加词变成加坐标——模型本身不变。

    来自人脸识别的成熟方案

    triplet loss 在 FaceNet 上已大获成功——人脸识别同样要「同身份靠近、异身份远离 + 新身份免重训注册」，与 KWS 的新词适配需求同构。本文的工作是系统适配而非发明。

    §02方法：margin 的几何与挖掘的艺术

    三元组距离关系 · 半难负样本 · L2 归一化
    L = max( 0, d(f(x_a), f(x_p)) − d(f(x_a), f(x_n)) + margin ) 半难负样本: d(a,p) < d(a,n) < d(a,p) + margin # 恰好贴着间隔边界 原型: c_k = (1/N_k) · Σ f(x_i) # 建议每词 10–20 样本（不同说话人） L2 归一化: 嵌入映射到单位超球面 → 欧氏距离 ≡ 余弦距离
    人话：三元组只看三个点的相对关系——正样本要比负样本至少近一个 margin。随机选的负样本几乎总是太远（损失恒为零，模型学不到东西），所以要主动挑那些「差点就违规」的半难负样本——它们才是有信息的训练信号。

    margin 的甜点逻辑

    margin 是类间隔的最低保证：0.2 时簇间挨得太近（易混淆），0.5 时间隔要求太苛刻（多数三元组永远满足不了，训练困难）——0.3 在准确率与稳定性之间平衡。这个值与数据的固有混淆度相关，换任务要重扫。

    挖掘的工程复杂度

    半难挖掘要求定期（每 ~100 步）重算全部样本嵌入、重新挑负样本——训练管线多了一个调度环节。这是 triplet 系方法的固有税，后来的 Proxy-NCA/ArcFace 用代理点绕开了它。

    读表要点
  • 嵌入空间的健康证据：类内距离 0.3–0.4 vs 类间 0.8–1.0——两个分布明显分离；t-SNE 上高频词（yes/no/up/down）簇最紧凑，go/no 簇近但可分。
  • 校准是被低估的痛点：softmax 输出天然带概率含义，距离没有——θ 的选择完全依赖验证集调优，换场景可能要重调。这是所有距离判别系统的共同软肋。
  • 词表规模的隐性账：推理要跟全部 K 个原型算距离（O(K·D)）——词表超百词后这本身成为开销项，与分类头 O(D) 的单次前向不同。

    • §04贡献

    五点：从系统研究到灵活性证明
    1

    三元组损失在 KWS 的系统应用：架构、训练策略、负样本挖掘、空间分析的完整方案——不是单点技巧而是一套可复用的配方。

    2

    换词免重训的灵活性证明：简单原型计算即可添加新关键词，无需改动嵌入网络——为快速定制提供实用方案。

    3

    分类与验证双支持：嵌入空间同时服务闭集分类（最近原型）与开集验证（阈值判断）——覆盖 KWS 的两种核心需求。

    4

    嵌入维度系统分析：32→256 的扫描给出 64–128 甜点——容量够放词表结构即可，更高只买开销。

    5

    半难负样本挖掘的验证：比随机策略 +2–3%——确认挖掘策略对 KWS 三元组训练至关重要。

    §05局限与判断

    训练敏感 · 校准缺失 · 近邻词混淆
    图4 · 边界与延伸：左技术边界（超参敏感与坍缩风险、近邻词拉不开、距离无概率含义、O(K·D) 推理、挖掘工程税），右实验边界（噪声远场有限、无度量损失横比、无联合训练）+ 延伸方向。
    可迁移判断

    ↳ 新词是坐标不是输出节点：把分类改写成距离匹配后，加类别的成本从「重训」降到「求均值」——凡是词表/类表频繁变动的系统（自定义命令、多语言、个性化），都该认真评估这 1 个点的精度税值不值。

    ↳ 训练信号密度决定度量学习成败：随机负样本让 99% 的三元组零损失——挑「差点违规」的样本训练才有信息。半难挖掘的原则（挑边界样本）与 AUC 优化的成对采样、主动学习的不确定性采样同源。

    ↳ L2 归一化是小动作大收益：一行代码换来度量等价（欧氏=余弦）+ 1% 准确率 + 训练更稳——嵌入学习的默认第一步应该是把表示钉到单位球上。

    ↳ 距离的校准是隐藏成本：softmax 有概率含义、距离没有——开集部署时要为阈值调优单独立项。选度量学习方案前，把「θ 怎么定、多久重定」写进工程预算。
