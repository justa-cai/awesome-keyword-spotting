# Zero-Shot Federated Learning with New Classes for Audio Classification

- **作者/机构**: Gautham Krishna Gudur (爱立信全球 AI 加速器), Satheesh Kumar Perepu (爱立信研究院)
- **发表日期**: 2021.06
- **会议**: Interspeech 2021（亦在 ICLR 2021 的 DPML 和 HAET Workshops 接收）
- **链接**: https://arxiv.org/abs/2106.10019
- **关键词**: 联邦学习, 零样本学习, 音频分类, 新类别识别, 匿名数据印象, 类别相似性矩阵, 关键词检测, 城市声音分类, 边缘设备, k-medoids 聚类

## 问题陈述

联邦学习（Federated Learning, FL）是一种在分布式用户设备上训练模型的去中心化方法，通过安全地共享模型更新而非原始用户数据来保护隐私。然而，在实际的联邦学习场景中，面临着一系列复杂的挑战，其中最为突出的是**新类别动态出现**问题：不同用户的设备上可能随时出现全新的、未见过的数据类别，其数据分布完全不同于已有类别。由于联邦学习的隐私约束，全局服务器和其他用户无法访问任何设备的原始数据，这使得识别和整合跨设备的新类别变得极为困难。

具体而言，该论文要解决的核心问题包括：
1. **新类别的零样本识别**：当某个用户设备上出现全新的音频类别时，全局模型如何在不接触原始数据的前提下，识别该新类别是否与其它用户设备上的新类别相同或不同？
2. **类别标签的两种获取场景**：用户设备可能（a）报告新类别的标签名称，也可能（b）不报告标签名称。后者场景下，需要完全无监督地区分不同新类别。
3. **统计异构性处理**：在联邦学习的不同通信轮次和不同用户设备之间，存在标签分布异构、数据分布异构和模型架构异构等多重挑战。

传统的联邦学习假设所有客户端具有相同的类别集合和模型架构，但在音频分类的实际应用中（如个性化关键词检测、城市环境声音识别），这些假设往往不成立。本文旨在提出一种**统一的零样本联邦学习框架**，在保护用户隐私的同时，优雅地处理新类别动态出现和多重统计异构性问题。

## 方法论

### 整体框架设计

论文提出的框架基于经典的联邦学习范式，包含 M 个节点（设备），每个节点持有私有本地数据 D_i = {x_i,j, y_i,j}，同时所有节点和全局服务器共享一个公共数据集 D_0 = {x_0, y_0}。公共数据集在 FL 训练期间不暴露给本地模型，仅用于测试阶段的一致性评估。整个框架包含三个核心步骤：

**Step 1: Build（构建）**：每个本地用户使用其私有本地数据在当前 FL 迭代中创建自己的模型。

**Step 2: Local Update（本地更新）**：根据新类别是否被报告，分为两种处理策略。

**Step 3: Global Update（全局更新）**：全局服务器汇总所有本地更新，根据是否有新类别报告采取不同策略。

### 场景一：新类别标签未被报告

当用户不报告新类别标签时，框架退回到传统 FL 设置。本地更新采用加权 alpha 更新机制：

f^i_{D_m}(x_0) = f^I_G(x^{l_m}_0) + f^{D_m}(x_0)

其中 f^I_G(x^{l_m}_0) 是全局模型在用户 m 的标签集 l_m 上的分数，alpha = len(D^i_m) / len(D_0) 控制新旧模型的贡献比例。

全局更新采用标签级别的加权平均，权重 gamma 根据标签是否唯一来确定：如果标签在用户间唯一，gamma = 1/M；如果标签重叠，gamma 与各本地模型在该标签上的测试准确率成正比。

### 场景二：新类别标签被报告——核心创新

当用户报告新类别标签时，论文提出了一套基于 **Anonymized Data Impressions（匿名数据印象）** 的零样本学习机制。这是论文的核心创新，包含三个关键步骤：

#### 2.1 类别相似性矩阵（Class Similarity Matrix, CSM）

利用模型最后一层全连接层的权重，构建类别间的相似性矩阵：

C(i, j) = (w_i^T * w_j) / (||w_i|| * ||w_j||)

其中 w_i 是连接倒数第二层到类别 i 的权重向量。如果两个类别相似，它们的全连接层权重向量也会相似。CSM 矩阵 C ∈ R^{K×K} 编码了 K 个类别之间的相似性信息。

#### 2.2 从 Dirichlet 分布采样 Softmax 值

基于 CSM 矩阵，从 Dirichlet 分布中采样 softmax 值：

Softmax = Dir(K, C * epsilon)

其中 C * epsilon 是浓度参数，控制 softmax 值在类别标签上的分布集中程度。如果类别相似，采样得到的 softmax 值会集中在这些相似类别上。

#### 2.3 生成匿名数据印象

通过求解以下优化问题，从采样的 softmax 值反向生成合成数据特征：

x* = argmin_x L_CE(y^k_i, M(x))

其中 y^k_i 是第 k 个类别的第 i 个 softmax 向量，M(x) 是模型的输出。初始化 x 为随机输入，通过迭代最小化交叉熵损失来获得合成数据特征。该过程对每个类别重复执行，从而在不接触原始数据的情况下，为每个新类别生成匿名数据印象。

### 新类别识别与聚类

生成各用户的匿名数据印象后，框架执行以下步骤：
1. **聚合**：对拥有相同新类别标签 k 的所有用户的 DI 取平均，X_i = Σ_{m ∈ MS_k} X^i_m
2. **k-medoids 聚类**：对所有报告新类别的用户的 DI 进行 k-medoids 无监督聚类，聚类数等于新类别数量 l_new
3. **更新公共数据集**：将聚类后获得的匿名数据印象 X_i 添加到公共数据集，D_new = D_0 ∪ X_i
4. **更新标签集**：将新标签 l_new 添加到各用户的标签集和全局标签集 Y

k-medoids 聚类的一个关键优势是：即使用户不报告新类别的具体名称，聚类也能根据数据印象的特征相似性自动区分相同和不同的新类别。

### 异构性处理

框架同时处理三种统计异构性：

**标签异构性**：每个 FL 迭代中，每个用户的每个标签随机生成 200-300 个音频帧（GKWS）或 40-50 个音频帧（US8K）。标签在用户间可以唯一也可以重叠，模拟非 IID 分布。

**模型异构性**：不同用户使用不同架构的本地模型（2 层 CNN、3 层 CNN、3 层深度可分离 CNN、1 层 CNN、3 层 ANN），甚至在不同的 FL 迭代中切换模型架构和激活函数（ReLU/Softmax）。

**数据异构性**：通过跨 FL 迭代的数据分布变化来模拟实际场景中用户行为的时变性。

### 输入特征处理

- **GKWS（关键词检测）**：采样频率 14400 Hz，提取 MFCC 特征，分为 20 个窗口，每个窗口 50ms
- **US8K（城市声音分类）**：使用类似的 MFCC 预处理流程

## 主要贡献

1. **提出零样本联邦学习框架**：首次在音频分类的联邦学习设置中引入零样本学习机制。通过合成匿名数据印象（Anonymized Data Impressions），在完全不接触原始用户数据的前提下，实现了跨设备新类别的识别和知识共享。这一机制有效解决了 FL 中"新类别动态出现"这一长期被忽视的问题。

2. **双重场景覆盖**：设计了两套完整的新类别处理方案——当用户报告标签时使用基于 CSM 和 DI 的方法，当用户不报告标签时退回到传统 FL 设置。这种灵活性使框架能够适应不同的实际部署场景。

3. **无监督新类别区分**：创新性地使用 k-medoids 聚类算法在匿名数据印象上进行聚类，能够自动识别不同用户设备上的新类别是否相同。即使多个用户出现相同的新类别但使用了不同的标签名称，聚类也能正确地将它们映射在一起。

4. **全面处理统计异构性**：框架同时处理标签异构、模型异构和数据异构三种统计异构性。不同用户可以拥有不同架构的本地模型，标签分布可以不同，甚至同一用户在不同 FL 迭代中也可以切换模型架构。

5. **边缘设备验证**：在 Raspberry Pi 2（900MHz 四核 ARM Cortex-A7 CPU，1GB RAM）上进行了完整的实验验证，证明了框架在资源受限的 IoT 设备上的实际可行性。

## 实验结果

### 数据集与实验设置

**GKWS（Google Keyword Spotting）**：选取 10 个关键词（Yes, No, Up, Down, Left, Right, On, Off, Stop, Go）。初始公共数据集包含 8 个关键词 × 300 帧 = 2400 帧。新引入 Stop（迭代 4、8）和 Go（迭代 8）两个类别。

**US8K（UrbanSound8K）**：包含 10 类城市声音。初始公共数据集包含 8 类 × 50 帧 = 400 帧。新引入 Siren 和 Street Music 两个类别。

用户模型架构设置：
- User 1: 2 层 CNN (16, 32), Softmax 激活
- User 2: 3 层 CNN (16, 16, 32), ReLU 激活
- User 3: 3 层深度可分离 CNN (16, 16, 32), ReLU 激活
- 模型大小：520 kB, 350 kB, 270 kB

### 场景一：仅新类别（无统计异构性）

3 个用户，10 个 FL 迭代，仅引入新类别不引入异构性：

**GKWS 结果**：

| 用户 | 本地更新准确率 | 全局更新准确率 | 提升 |
|------|---------------|---------------|------|
| User 1 | 89.684% | 93.166% | +3.482% |
| User 2 | 91.888% | 95.280% | +3.391% |
| User 3 | 91.517% | 94.727% | +3.211% |
| **平均** | **91.030%** | **94.391%** | **+3.361%** |

**US8K 结果**：

| 用户 | 本地更新准确率 | 全局更新准确率 | 提升 |
|------|---------------|---------------|------|
| User 1 | 76.526% | 80.214% | +3.688% |
| User 2 | 75.272% | 77.944% | +2.672% |
| User 3 | 77.610% | 81.838% | +4.228% |
| **平均** | **76.469%** | **80.000%** | **+3.529%** |

在所有用户和所有 FL 迭代中，全局更新的准确率均高于本地更新，证明了框架在新类别出现时仍能有效聚合知识。

### 场景二：新类别 + 统计异构性

10 个用户，30 个 FL 迭代，同时引入标签异构、模型异构和数据异构：

| 更新类型 | GKWS 准确率 | US8K 准确率 |
|---------|------------|------------|
| 本地更新 | 92.500% | 78.240% |
| 全局更新 | 96.541% | 82.498% |
| **提升** | **+4.041%** | **+4.258%** |

即使在新类别动态出现和多重异构性共存的复杂场景下，框架仍实现了平均约 4% 的确定性准确率提升，证明了其鲁棒性。

### k-medoids 聚类分析

通过 PCA 降维可视化 k-medoids 聚类结果：
- **不同类别**：当两个用户出现不同的新类别时，DI 特征在 PCA 空间中形成明显分离的聚类
- **相同类别**：当两个用户出现相同的新类别时，DI 特征自然聚为一类
- 聚类数与新类别数精确对应，验证了无监督新类别识别的有效性

### 类别相似性矩阵分析

GKWS 的 CSM 矩阵揭示了关键词之间的声学相似性。例如，"Yes" 和 "No" 的权重相似度较高，反映了它们在某些声学特征上的重叠。CSM 还揭示了模型的误分类模式，为进一步优化提供了线索。

### 边缘设备性能

在 Raspberry Pi 2 上的计算时间：

| 过程 | 时间 |
|------|------|
| 每个 FL 迭代中每个 epoch 的训练时间 | 1.2 秒 |
| 推理时间 | 11 毫秒 |

这一结果表明框架的轻量化程度足以在 IoT 设备上实际部署。

## 局限性与展望

### 技术局限性

1. **匿名数据印象的保真度**：DI 是通过优化方法从模型权重反向生成的合成数据，其分布可能无法完全覆盖原始数据的真实分布。对于声学变化较大的类别（如环境噪音中的声音事件），DI 的代表性可能不足。

2. **对公共数据集的依赖**：框架假设所有用户和全局服务器共享一个公共数据集 D_0，这在实际部署中可能难以保证。公共数据集的质量和规模直接影响框架的性能。

3. **Dirichlet 分布参数敏感性**：类别相似性矩阵到 softmax 采样的转换依赖于浓度参数 epsilon 的选择，不同参数可能导致不同的 DI 质量。论文未深入讨论参数敏感性分析。

4. **新类别数量已知假设**：k-medoids 聚类需要预先知道聚类数（即新类别数量），这在实际场景中可能需要额外的自动类别数估计机制。

5. **模型异构性的局限**：虽然框架支持不同架构的本地模型，但所有模型都是基于 CNN 的变体。对更根本的架构差异（如 CNN vs. RNN vs. Transformer）的处理能力未经验证。

### 实验设计不足

1. **用户和迭代规模有限**：最大实验设置仅包含 10 个用户和 30 个 FL 迭代，与实际大规模联邦学习场景（百万级用户、数千轮迭代）存在数量级差距。

2. **缺少与基线方法的对比**：论文未与其他处理新类别的 FL 方法（如增量学习 FL、元学习 FL）进行直接比较，仅展示了框架自身的本地-全局准确率提升。

3. **安全性分析缺失**：未评估框架对恶意攻击（如模型投毒、后门攻击）的鲁棒性。DI 生成过程是否可能被攻击者利用来注入恶意信息是一个重要的开放问题。

4. **通信开销未详细分析**：虽然展示了计算时间，但未详细分析传输 DI 和模型权重的通信开销，这对带宽受限的 IoT 设备至关重要。

### 未来改进方向

1. **结合对比学习**：将对比学习目标（如 SimCLR、MoCo）引入 FL 框架，可能产生更具判别性的特征表示，从而提升 DI 的质量和聚类准确性。

2. **自适应聚类**：引入基于密度或层次聚类的方法（如 DBSCAN、HDBSCAN），自动确定新类别的数量，消除对预设聚类数的依赖。

3. **差分隐私集成**：在模型更新和 DI 传输过程中引入差分隐私机制（如 DP-SGD），为框架提供形式化的隐私保证。

4. **更大规模验证**：在更大规模的真实联邦学习平台上（如 TensorFlow Federated、PySyft）进行验证，评估框架的可扩展性。

5. **多模态扩展**：将框架扩展到视频、文本等多模态分类任务，验证其通用性。

### 对 KWS 领域的启发

本文为个性化 KWS 系统的联邦学习部署提供了重要启发。在智能语音助手的实际使用中，不同用户可能希望添加自定义的唤醒词或命令词，而这些新关键词的数据不应离开用户设备。该框架通过零样本学习机制，在保护用户隐私的同时实现了跨设备的新关键词知识共享。匿名数据印象的创新设计为联邦学习中的知识传递提供了一种新的范式——不传递数据也不传递模型参数，而是传递从模型权重中提炼出的类别"印象"。
