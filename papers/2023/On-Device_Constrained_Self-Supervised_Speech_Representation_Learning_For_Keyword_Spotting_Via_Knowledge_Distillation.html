偏差的域内数据训自监督模型会「编码虚假噪声制造对比」——Amazon 的解法是偷教师的码本、
用交叉相关取代逐帧距离蒸馏，回放噪声下相对 FAR 最多降 23.8%

On-Device Constrained Self-Supervised Speech Representation Learning for Keyword Spotting via Knowledge Distillation

作者：Gene-Ping Yang（爱丁堡大学 CSTR，†Amazon 期间）；Yue Gu、Qingming Tang、Dongsu Du（Amazon Alexa）；Yuzong Liu（Zoom，†Amazon 期间）

发表：arXiv 2307.02720（2023-07）· 数据：Alexa 内部 16600 小时真实录音 · 教师：wav2vec 2.0（95M，LibriSpeech 960h）

端侧约束 SSL 蒸馏双视图交叉相关 DVCC教师码本蒸馏（偷码本） 学生砍 CNN 吃 LFBE21M（−78%）/ 1.6M（−98%）蒸馏教师 5–8 层最优

一分钟版本

  • 两道墙：① 体积墙——S3RL 特征虽好（线性可分、接个线性层就能用），但 12 层 transformer 95M 参数端侧跑不动；② 数据偏差墙（真正的立论点）——工业关键词数据按「是否含唤醒词」组织、负样本多样性先天不足，对比式自监督在这种数据上会编码虚假噪声（spurious noise）来制造对比——把 S3RL 直接搬到域内数据从头预训练，学到的表示可能是有毒的；域内也训不出好码本。
  • 管线：冻结 wav2vec 2.0 教师（95M，LibriSpeech 960h——朗读语音、说话人和内容远比关键词语料多样，教师身上带着域外多样性）→ 蒸馏进 3 层 transformer 学生（21M 隐藏 768 / 1.6M 隐藏 256）。学生砍掉 7 层 CNN 直接吃 64 维 LFBE（省 ~33% 计算；端侧芯片自带 LFBE 前端，不在神经网络里重复付费提特征）。语句级而非帧级蒸馏：时间平均池化压成 [d] 再对齐，避免学生复现教师单帧波动（帧级波动对关键词分类未必有意义）。
  • 技术一：双视图交叉相关蒸馏（DVCC）——Barlow Twins 的语境迁移（交叉相关从「同一网络两个增强视图」换成「教师 vs 学生」）。特征视图 d×d 方阵 C 逼近单位阵（对角=1 维度对齐，非对角=0 维度去相关 = 蒸馏的同时做特征白化，更紧凑学生）；batch 视图 b×b 方阵 G 逼近单位阵（对角=1 同语句师生高相关，非对角=0 不同语句互不相关——对比学习意图，但用连续相关系数取代 InfoNCE 离散分类）。式 7 停止梯度自归一化省掉手工配平两项量级。
  • 技术二：教师码本蒸馏——学生仍用原生 wav2vec 2.0 掩码预测+对比目标，但正/负样本全部取自教师码本产生的量化向量（学生自己不训码本）。一招解三题：① 注入域外多样性（教师码本 = 960h 多样语音的紧凑表示）；② 防码本学域内噪声；③ 免掉码本多样性正则。蒸馏只需教师 ~5% 参数（CNN 层+码本）。
  • 主结果（Table 1，固定基线 FRR 操作点的相对 FAR）：双视图对基线改善 14.6%（正常）/ 21.3%（回放）——回放多赚 7 点，蒸馏带来的是噪声鲁棒性不只是精度。对语句级 DistilHuBERT 复现两条件均超 8%（交叉相关 > 纯距离度量）。Combined large（双视图+码本）全场最优 0.850/0.762（累计 −15.0%/−23.8%）。
  • 三组消融的统一规律：收益都在噪声条件兑现。① 视图消融——干净下三配置打平（单视图够用），噪声下 dual 领先 2.6–3 点（样本间对比性质 = 鲁棒性来源）；② 码本消融——正常条件几乎没差（0.4 点），回放差 4.3 点（「见过世面」的量化目标只在噪声时值钱）；③ 干净语音上表示已经够好，加什么收益都有限。
  • 最锋利的发现：蒸馏教师 5–8 层最优（Table 2 + Figure 3）。探针观察：冻结教师特征训线性分类器，第 5–8 层在 KWS 上最优、最后一层最弱（过度特化于预训练目标）。只蒸 5–8 层拿全场最好 0.806/0.713；挖掉 5–8 只蒸其余层（0.855/0.790）几乎等于全层（0.854/0.787）——全层蒸馏的效果本质上就是「其余层」贡献的，可学习加权和（Figure 3 权重集中在 0/2/4 层）根本没捕捉到中层信息。蒸馏时对下游任务无知——简单的探针选层就能白拿收益。
  • 1.6M 档的收获与天花板：无蒸馏基线掉到 1.17/1.22，加蒸馏回到 1.07/1.09——比同体积基线好 10%、与 21M 基线相当，但仍追不平 21M 档自己（0.850/0.762）——容量瓶颈蒸馏无法完全跨越。
  • 边界：标题主打 on-device 但只有参数量证据——无延迟/内存/功耗实测（transformer 的内存访问模式在 MCU 上是否优于 DS-CNN/MatchboxNet 无数据）；单一专有数据集（16600h 内部，唤醒词/语言/信道不公开）；全部指标是相对值无绝对错误率（相对改善 14.6% 发生在极低错误率系统还是粗糙系统上意义完全不同）；无监督基线对照（自监督蒸馏 vs 直接监督训练同体积模型未比）；单操作点无 DET 曲线；式 8 的负样本数/码本条目数/掩码比例等超参未披露；5–8 层结论换教师/换任务大概率漂移。

§01 · 问题陈述

偏差数据 × 端侧预算 × 判别任务的三重耦合

既有工作的三个缺口：① S3RL 研究追 SUPERB 榜单、模型偏大——几乎没人检验过 S3RL 在偏差数据集上的有效性（KWS 恰是偏差最严重的场景）；② 既有蒸馏（DistilHuBERT / LightHuBERT）只做逐帧距离匹配——强迫学生复现教师每帧波动（对下游未必有意义），且把每个样本、每个维度当独立个体，完全不考虑样本之间和维度之间的相互依赖；③ 域内数据训不出好码本——正负样本选取和未见条目表示都出问题，自监督目标本身在域内难以成立。
LDVCC = LC/sg(LC) + LG/sg(LG)（式 7）；Lcombined = LDVCC + γ·Lt-code（式 9，γ=1）
sg = 停止梯度：前向数值参与缩放、反向不传梯度——每一项除以自身后恒为量级 1，省掉手工调两个损失的权重（d×d 与 b×b 矩阵元素数差几个数量级，手工配平要么扫参要么靠运气）；α、β=5e-3 沿用 Barlow Twins 小值只控非对角惩罚强度。训练配置：蒸馏 Adam 15 epoch × 5000 步 batch 512；微调线性头 + 交叉熵 30 epoch batch 2048；蒸馏目标是教师全部隐藏层的可学习加权和。

§02 · 方法论

蒸馏损失不必是距离；码本可以跨模型继承

Figure 1 / 式 3–9 复绘：两道墙（体积墙 + 数据偏差墙）；蒸馏管线（95M 教师 → 砍 CNN 吃 LFBE 的 21M/1.6M 学生 → 联合损失）；DVCC 双视图（特征视图 d×d 逼近单位阵 = 蒸馏同时做特征白化；batch 视图 b×b = 用连续相关系数泛化对比操作；停止梯度自归一化合并）；教师码本蒸馏「一招解三题」（注入域外多样性 / 防码本学域内噪声 / 免多样性正则）。

§03 · 实验与消融

固定 FRR 操作点的相对 FAR

Table 1 复绘：相对 FAR（实心 = 正常、半透明 = 回放，红虚线 = 基线 1.0）。双视图对基线 −14.6%/−21.3%（回放多赚 7 点 = 噪声鲁棒性）；对语句级 DistilHuBERT 复现两条件均超 8%；Combined large 全场最优 0.850/0.762；1.6M 档比同体积基线好 10% 但追不平 21M 档自己——容量瓶颈蒸馏无法完全跨越。

Table 2 + Figure 3 复绘（权重柱为示意形态，集中层位有据）：只蒸教师中层 5–8 拿全场最好 0.806/0.713；挖掉 5–8 只蒸其余层（0.855/0.790）≈ 全层（0.854/0.787）——全层蒸馏的效果本质上就是「其余层」贡献的；Figure 3 显示可学习权重集中在 0/2/4 层、恰好绕开 5–8。探针选层（冻结特征训线性分类器）是免费的午餐。

4.2/4.3 节复绘：视图消融与码本消融的统一规律——干净条件下单视图够用、码本几乎没差；噪声条件一到，双视图的样本对比性质（领先 2.6–3 点）和教师码本的域外多样性（差 4.3 点）才开始兑现。两个机制都在最需要鲁棒性的地方起作用。

数据与指标口径：16600h 去标识化真实录音（多前端条件）→ 64 维 LFBE（25ms 窗 / 10ms 移）→ 85h 验证 / 85h 测试 / 其余训练；测试分正常（干净）与回放（噪声加大）两个子集；标签人工标注 + 质检；蒸馏与微调用同一份数据。指标 = 固定基线 FRR 操作点上的相对 FAR（部署逻辑：漏唤醒是产品体验红线，该约束下比误唤醒越低越好）。注意论文未报告任何绝对 FAR/FRR 数值。

§04 · 主要贡献

三条贡献 + 两条可迁移判断

1端侧约束下的 KWS 自监督模型——95M 教师压进 21M（−78%）/ 1.6M（−98%）学生，砍 CNN 吃 LFBE 省 33% 计算；回放条件相对 FAR 最多改善 23.8%。
2两项新蒸馏技术——DVCC（维度去冗余 + 样本对比双视图，Barlow Twins 语境迁移）与教师码本蒸馏（域外多样性注入、防噪声编码、免多样性正则）。
3立体消融——视图消融定位鲁棒性来源（batch 视图）、码本消融定位收益条件（噪声）、层选择消融揭示全层蒸馏稀释关键中层的现象——「5–8 层最优」对所有做语音模型蒸馏的工作有直接参考价值。
★两条可迁移判断：① 蒸馏损失不必是距离——带结构约束的统计量（交叉相关）能在偏差数据上比 L1/余弦蒸馏多拿 8 个点以上；② 自监督目标的组件（码本）本身可以跨模型继承——为「在偏差域内数据上做自监督预训练」提供绕开数据补采的路径。

§05 · 局限与边界

「on-device」只有参数量证据

技术局限

  • 无部署证据：标题主打 on-device 但无延迟、实时率、内存、功耗测量——3 层 transformer 的自注意力内存访问模式在 MCU 类硬件上是否优于 DS-CNN / MatchboxNet，没有数据。
  • 1.6M 档天花板：1.07/1.09 仍劣于 21M 基线的 1.0/1.0——超小容量下蒸馏收益封顶；容量与可蒸馏性的权衡未做进一步分析（固定 1.6M 扫层数/宽度）。
  • 关键超参未披露：式 8 负样本数 N、码本条目数、掩码比例均未报告——复现有障碍；学生输入的增强/失真形式一笔带过。
  • 层选择结论外推性存疑：5–8 层最优是在这一个教师（LibriSpeech 版 wav2vec 2.0）一个任务上测的——换 HuBERT / WavLM 或换任务，最优层窗口大概率漂移。

实验设计不足

  • 单一专有数据集：16600h 内部数据，唤醒词内容、语言、信道不公开——无法复现、无法判断跨关键词/跨语言的稳健性（论文自认 solely focused on KWS）。
  • 全相对值无绝对错误率：相对改善 14.6% 发生在绝对错误率极低的系统还是粗糙系统上，工程意义完全不同——读者无法判断。
  • 缺监督基线与同期架构对照：所有对比都在自监督蒸馏家族内部——无直接监督训练同体积模型、无 CNN 系端侧 KWS SOTA——「自监督蒸馏 vs 监督路线谁优」无法回答。
  • 单操作点 + 无显著性：只在一个 FRR 操作点比 FAR，无 DET 曲线扫描；无随机种子或置信区间。
自然的延伸方向：其他下游任务、不同数据集验证泛化（作者自述）；层选择自动化——带层注意力约束的蒸馏或任务感知层加权，让「选层」从手工探针变成可学习组件；与量化、剪枝（BiFSMN 式二值化）正交叠加，检验表示蒸馏与数值压缩是否可复合；补真机延迟/内存/功耗把 on-device 落到测量；码本蒸馏推广到 HuBERT 式掩码预测目标（教师伪标签做掩码目标）+ 更大多样的教师码本（多语言、多信道）进一步稀释域内偏差。
