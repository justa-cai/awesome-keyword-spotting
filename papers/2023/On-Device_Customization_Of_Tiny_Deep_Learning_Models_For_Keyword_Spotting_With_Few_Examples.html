On-Device Customization of Tiny Deep Learning Models for Keyword Spotting with Few Examples

作者：Manuele Rusci（MSCA 博士后）、Tinne Tuytelaars（KU Leuven 鲁汶大学）· IEEE MultiMedia（2023-09，TinyML 专题）

硬件：GAP9（9 核 RISC-V + 卷积加速器，240MHz / 0.65V / 25.5mW）· 数据：MSWC 英语（源）→ GSC（目标），完全不相交

端侧零反向传播定制triplet + 原型分类器γ=m 免标定开集阈值 跨域词级泛化8bit PTQ 无损「MAC 少 ≠ 硬件上快」

一分钟版本

  • 痛点在「定制」不在「推理」：几十万参数的 DNN KWS 已经能跑在 MCU 上——但换一个部署环境、换一组目标词，整个「采集 + 标注 + 服务器重训 + 回部署」链条就要重走一遍。端侧直接做反向传播不现实：需暂存激活（ResNet15 最大激活 537.3k）+ 等量梯度 + 优化器状态，数倍于推理工作集直接爆 RAM。「让用户用几个录音教会设备新命令」是被内存和能耗约束逼出来的算法设计问题。
  • 方案：学习与部署彻底解耦。阶段一（离线一次性）：在 MSWC 英语 top-500 类 / 270 万条上用 triplet 损失训练特征提取器，冻结 + 8bit PTQ 烧进 Flash。阶段二（设备端）：用户每词录 K 条 → K 次前向 → 平均成原型向量；另存静音 + 未知两根预计算原型，合计 N+2 根向量（8bit 不足 1KB）。推理 = L2 最近原型 + 阈值 γ——定制动作里没有任何梯度。
  • 三个关键「为什么」：① triplet 不用交叉熵——交叉熵优化固定标签集可分性，对未见类无距离语义；triplet 优化「同类聚拢、异类拉开 ≥ m」的相对几何，可迁移到新类。② 必须做嵌入 L2 归一化——压到单位球面后距离有界且跨样本可比，单一固定阈值 γ 才在数学上成立。③ 不做 softmax 归一化——softmax 把距离变成「候选间相对竞争」，破坏绝对幅度，而「离所有原型都远」正是开集拒识的唯一证据；消融证实不加 softmax 系统性更优。
  • γ = m 是最巧妙的免标定设计：把 FAR 调到目标值常规需要目标域标注负样本——端侧定制恰恰没有。triplet 训练本身驱动「类内距 + m ≤ 类间距」，m 就是训练保证的同类距离尺度——用 m 当接受半径 = 由训练过程背书、无需任何标定数据。代价是保守：类簇松的大模型会把正样本推出 γ 球（ResNet15 固定阈值下只剩 54%，换 FAR 低至 0.1–0.2%）。
  • 少样本精度（Table 2，后验调阈值 FAR=5%，十词）：ResNet15 十样本 0.80、五样本 0.78、三样本 0.74、单样本 0.55——1→3 条增益最大（~19 点）、5→10 边际递减，甜点在 3–5 条；骨干排序稳定 ResNet15 > DS-CNN-L > M > S ≈ TCResNet8。
  • GAP9 部署账单（Table 3）：ResNet15 前向 9.21ms + 嵌入 0.48ms = 9.7ms 处理 1 秒语音、246.9µJ/次（TCResNet8 的 8.7 倍，换 ~10 点准确率）；执行效率 66.8 MAC/cyc 全场最高。三个硬件发现：ResNet15 的 MAC 是 DS-CNN-L 的 8.4 倍但只慢 2.25 倍（加速器 3×3 卷积 100 MAC/cyc、pointwise 只有 40——「MAC 少 ≠ 这块硬件上快」）；DS-CNN 的 LayerNorm 头跑在集群核上占其总负载 44%；8bit PTQ 全骨干无损（ResNet15 的 BN 无法折叠，改投 FP16 修复）。
  • 范式分水岭（Table 4）：γ=0 时原型法与迁移学习线性头准确率相当（0.88 vs 0.87），但压到 FAR=5% 时迁移学习崩到 0.56、原型法保 0.80——线性头没有距离幅度语义的拒识能力，开集稳健性才是两种范式的真正分水岭。端到端全数据 0.95、同域 kNN 0.98——差距 15–18 点就是「跨域 + 少样本 + 免训练」三重代价。
  • 固定阈值的容量反转（Fig. 3）：γ=m 免标定下小容量模型反而更准（DS-CNN-L 58% vs ResNet15 54%）——大模型以放松类内紧致度换更强类间距离，绝对阈值下正样本更易掉出 γ 球；但 ResNet15 的 FAR（0.1–0.2%）是 DS-CNN-L（0.6%）的 1/3。后验调阈值的最优骨干 ≠ 免标定部署的最优骨干——阈值策略与骨干选型是耦合决策。
  • 失败模式安全（Fig. 4）：错误以「判为未知」为绝对主体（on 行 261 判未知 vs 134 正确），跨词严重错误极小——保守漏检而非张冠李戴，对唤醒应用是安全方向。stop 79%/yes 78%/no 75% 最高（擦塞音结构 + 时间支撑长），on 34%/up 45%/off 47% 最低（短单音节功能词难聚拢——恰是语音命令高频词，这是明确短板）。
  • 边界：绝对精度差距（0.80 vs 0.95/0.98；免标定下只剩 54%）；阈值两难（免标定 vs 需标注数据不可兼得）；单样本仅 0.55、注册质量决定原型质量；短功能词系统性劣化；GSC 目标域干净近讲无远场噪声；语言泛化未验证（MSWC 多语但只做英语）；能耗单工作点、无系统级电池寿命。

§01 · 问题陈述

从「少样本学习」收紧为「跨域、开集、免训练、量化友好的少样本学习」

四条既有路线的缺陷：① 端到端 softmax 多分类（DS-CNN 系）——类别集合焊死在网络结构里，新增词全量重训；闭集分类器对未知词和静音没有原则性拒识机制。② KWS 少样本度量学习（ProtoNet / triplet+kNN / SVM）——训练测试同域（GSC→GSC，同域红利抬升数字如 0.98）；多数只报目标词准确率完全不分析 FAR（误触发恰是常驻传感器第一等风险）；kNN 存全部样本、SVM 存支持向量——内存随数据增长与 MCU 预算冲突；没有一个落到 TinyML 部署。③ QbE 的 RNN 方案——访存受限型负载在目标硬件等级效率低至 28 倍；原型验证板是 Cortex-A7 应用处理器等级远超 MCU。④ 迁移学习少样本（EfficientNet + 线性头）——骨干 1100 万参数超 MCU 内存；测试时仍需 8 epoch 反向传播；Table 4 证明其开集下显著更易误接受（FAR=5% 时准确率 0.87→0.56 崩落，本文只 0.88→0.80 缓降）。

§02 · 方法论

所有「学习」前置到一次性度量空间

Fig. 1 / Table 1 / 式 1–3 复绘：两阶段管线——离线一次性（MSWC top-500 类 270 万条 triplet 训练 → 冻结 + 8bit PTQ 烧进 Flash）与设备端零反向传播原型注册（K 条录音 → K 次前向 → 平均 → 存 N+2 根向量）；三个「为什么」（triplet vs 交叉熵 / L2 归一化的数学前提 / softmax 破坏绝对幅度）；γ=m 免标定设计；五个骨干的参数/算力/激活/嵌入维账目与硬件感知选型逻辑。

§03 · 实验与消融

两个 regime 的诚实协议

Table 2 复绘：少样本准确率随注册条数 K（1/3/5/10）的曲线，FAR=5% 后验调阈值、十关键词。骨干排序稳定；1→3 条增益最大（约 19 点）、5→10 边际递减到 2 点——注册成本与精度的甜点在 3–5 条；单样本 0.55（原型退化）。FAR=1% 时 ResNet15 十样本 0.70；加 softmax 列系统性更低。

Table 3 复绘：GAP9 部署账单（延迟实心、能耗半透明）+ 三个硬件层发现——① ResNet15 MAC 是 DS-CNN-L 的 8.4 倍但只慢 2.25 倍（加速器 3×3 卷积 100 MAC/cyc vs pointwise 40，「MAC 少 ≠ 这块硬件上快」）；② DS-CNN 的 LayerNorm 头占其总负载 44%（跑在集群核）；③ 8bit PTQ 无损 + BN 改投 FP16 的修复配方。

Table 4 / Fig. 3 / Fig. 4 复绘：左——范式对照（灰条 = 同域全数据不同质仅供参考）：γ=0 时原型法与迁移学习相当（0.88 vs 0.87），FAR=5% 时 0.80 vs 0.56——线性头没有距离幅度语义的拒识能力，开集稳健性是两种范式的分水岭。右上——固定 γ=m 的容量反转：小模型更准、大模型 FAR 低 3 倍——阈值策略与骨干选型耦合。底部——失败模式保守漏检而非张冠李戴（对唤醒应用安全），短单音节功能词是明确短板。

协议细节：评测分两个 regime——(a) 后验调阈值至 FAR=5%/1%（Table 2，可达性能上界）；(b) 部署保真的固定 γ=m（Fig. 3，用户开箱即用的真实性能）。为什么必须有 (b)：此前少样本 KWS 工作或者同域训练测试、或者只报准确率不报 FAR——都系统性高估可用性；诚实的定制场景就是「目标词没见过、负样本没见过、没有标注校准集」。ACC = GSC+ 正确分类占比；FAR = GSC-（其余 20 词类）误判为目标词占比。每个测试重复 10 次取平均（消除少样本抽取偶然性）。负样本度量专设、静音原型用 GSC 背景噪声生成。

§04 · 主要贡献

三条贡献

1首个（论文自称）TinyML 域内免反向传播的端侧 KWS 定制方案——跨域十样本 80%（FAR 5%），25mW 级 MCU 上 9.7ms / 246.9µJ 每次推理，完整落进内存与能耗预算。
2一套完整设计方法论——冻结 triplet 特征提取器 + 设备端原型注册 + γ=m 免标定开集阈值，五个骨干横向给出精度/延迟/内存/能耗完整账目。
★多条可迁移工程洞察——softmax 损害开集性能；固定阈值下骨干容量趋势反转（阈值策略与骨干选型耦合）；层类型执行效率（3×3 卷积 100 MAC/cyc vs pointwise 40）与集群核归一化算子的隐藏开销（44%）决定真实预算——骨干选型必须硬件感知；BatchNorm 量化改投 FP16 的修复配方。

§05 · 局限与边界

三重代价与短功能词短板

技术局限

  • 绝对精度差距：0.80 vs 端到端 0.95 / 同域 kNN 0.98；免标定固定阈值下更只剩 54%——跨域 + 少样本 + 免训练三重代价都在这个缺口。
  • 阈值两难：γ=m 免标定但保守；后验调阈值性能好但需目标域标注负样本——两者不可兼得，论文没给中间道路。
  • 原型脆弱：单样本仅 0.55，注册录音质量直接决定原型质量；运行期无对实际使用者声音的自适应。
  • 短功能词系统性劣化：on 33.8% / up 44.5%——单原型无法覆盖散布类簇，而这类短词恰是语音命令高频词。
  • 最大模型账单：537.3k 激活（RAM 压力）、235.1 MMAC、246.9µJ——精度最优解与资源最优解分离。
  • 假设理想化：未知原型假设随机词不含目标词；静音/未知各只有一根向量，无法表达负空间多样性。

实验设计不足

  • 目标域过干净：GSC 是干净、近讲、均衡的 1 秒孤立词——无远场、混响、加性噪声、连续语流、词重叠；FAR 只在 20 个词类上度量。
  • 词表规模固定：十（部署 4+2）——类别数 N 增大时 ACC/FAR 缩放规律未报告。
  • 对照不完整：迁移学习基线只在 DS-CNN-L 上 8 epoch 复现；无 ProtoNet 式交叉熵情景训练的同设置对照；端到端/kNN/SVM 数字来自各自同域全数据协议（严格说不同质）。
  • 能耗单工作点：只在 240MHz/0.65V 按 25.5mW 包络换算——无 DVFS、无系统级电池寿命数据。
  • 账目用代理量：固件内存（Flash/RAM 字节）未逐项报告，只有参数量与最大激活两个代理。
  • 训练成本未报：总时长、服务器能耗、top-500 类选择的敏感性均未消融。
自然的延伸方向：注册后自适应（设备端原型迭代精炼 / 只用前向的嵌入校准 / 无标注流式自标注——关键是保持反向传播免费或近免费）；更好的免标定阈值（从注册样本自身类内距离分布估计每类接受半径，或对负样本距离建极值模型）；骨干与硬件协同（替掉吃 44% 负载的集群核 LayerNorm 头；向 3×3 友好结构倾斜吃满 100 MAC/cyc）；每类多原型覆盖 on/up/off 散布类簇、注意力加权原型、说话人条件归一化、远场增广；学习离群类/密度模型替代单一未知原型；从 1 秒孤立窗推进到滑窗流式唤醒（产品化必经之路）。
