CATT-KWS 是「ASR 模型借来做 KWS」，U2-KWS 是「为 KWS 重训两遍模型」——流式分支用声学查关键词、
校验分支用关键词查整段音频，一个 <eok> token 撑起结束信号+时间戳锚点+目标边界三处机制

U2-KWS: Unified Two-pass Open-vocabulary Keyword Spotting with Keyword Bias

作者：Ao Zhang、Kaixun Huang、Lei Xie（西北工业大学 ASLP@NPU）；Pan Zhou、Yong Zou、Ming Liu（理想汽车 Space AI）· ICASSP 2024

数据：1000h 车载普通话 + AISHELL-1 · 模型：4.75M（常驻增量仅 0.04M）· 成绩：0.5 FA/h 下唤醒率相对 +41%

为 KWS 重训（非 ASR 借用）双路异构注意力方向关键词采样 + <eok> spike 免对齐时间戳常驻增量 0.04M胜过 9 倍大模型

一分钟版本

  • 根本问题：声学模型为 ASR 优化，对 KWS 欠优化。CATT-KWS 类方法只改两遍模型的推理流程（识别+重打分 → 多级 KWS），模型仍按 ASR 准则训练——为全体词均匀分配建模容量，对用户真正关心的那几个音素序列没有额外倾斜。多级系统的另一个痛点：每级独立模块、分别训练调参、级间接口手工设计——构建迭代成本高。U2-KWS 的本质：把「多级系统的级间传递」变成「同一模型内部的两次前向」，训练时联合优化，时间戳接口由模型自身 CTC 后验提供。
  • 双路异构注意力（辨识度所在）：以往 keyword bias 工作各选一边——声学查询注意力（Q=声学、K/V=关键词）可逐帧处理天然流式但单帧信息有限；关键词查询注意力（Q=关键词、K/V=整段音频）建模全局依赖但不能流式——在「能流式」和「看得全」之间二选一。U2-KWS 按分支分配方向：流式分支（第一级）用声学查询做帧级偏置；非流式分支（第二级校验器）用关键词查询做全局一致性建模——各取所长且都在一个模型内。
  • <eok> 一个 token 撑起三处机制：① CTC 结束信号——正样本目标「关键词+<eok>」教流式分支在关键词说完时发显式信号；② 时间戳锚点——<eok> 后验最高的帧即尾帧；③ 解码器目标边界。负样本的 CTC 目标不含 <eok> → 流式分支对没出现的词永不发结束信号——这正是压虚警的机制。
  • 关键词采样训练（免标注）：训练语料是普通 ASR 转写、没有关键词标注——正样本 = 从转写随机选连续词子序列当关键词；负样本 = 词典随机组词（句中不存在）。自监督式模拟用户自定义关键词。解码器被重定义为「关键词重打分 token 分类器」：输入固定为「<sos>+关键词」（不是第一级的解码假设——假设重打分仍是 ASR 思维；直接喂关键词把任务收缩为二分，任务更简单监督更集中）。
  • spike 时间戳裁剪（免对齐）：尾帧 = <eok> 峰值帧；首帧 = 从尾帧回数非 blank spike（后验超阈值的 token），超过关键词序列长度的最后一个 spike。消融（图 4）：不裁剪最差（搜索任务全压给解码器）；CTC 对齐在干净样本准但负样本和困难样本输出过长/过短——不稳定；spike 从峰值数量而非具体内容推导——级间接口质量取决于困难样本上的「稳定」而非「精确」。
  • 因果/全解码器：因果 = 直接复用流式编码器输出重打分（零额外编码开销）；全 = 把候选段以全块模式重喂编码器（动态 chunk 训练使同一编码器两用）——上下文更完整的表示换少量额外延迟。与 U2 ASR 两遍重打分同构，但重打分对象是关键词而非识别假设。
  • 增量收益（内部车载集，0.5 FA/h）：+关键词偏置 +20%（只花 0.04M 常驻参数——核心假设「注入关键词信息非常有效」的单独验证）→ +因果解码器 +6% → +全解码器 → 总计 +41%（全解码器在 0.25 FA/h 下 +10%）。AISHELL-1 上 4.75M 模型显著超过 9 倍大的 baseline——堆参数不如改训练方式：瓶颈不是容量而是任务对齐。
  • 词长洼地（结构性短板）：2 字关键词全模型 F1 也只 0.807（4 字达 0.977）——短序列上解码器「充分利用上下文」的优势变小、短词更易虚警——短词场景更依赖第二级校验却从校验中获益最少。
  • 端侧账本：总 4.75M（编码器 3.75M + 注意力解码器 0.6M + CTC 0.2M + 关键词编码器 0.16M + 偏置模块 0.04M）；关键词编码器只在初始化（用户注册）跑一次、解码器只在候选触发时激活——常驻增量 = 0.04M。
  • 边界：两级阈值耦合（第一级漏掉的候选第二级永远救不回；阈值取值未报、每个新词可能都要重调——开放性在阈值层打折扣）；spike 裁剪冗余靠解码器韧性兜底（长语音/极端语速未做边界分析）；full decoder 延迟未量化（无 RTF/毫秒数）；负样本只是词典随机组词——近音难负样本（同音词、含关键词的更长短语）没有挖掘，而这恰是开放式 KWS 的主要虚警来源；仅 30 个 2–4 字中文词、英文/多词/多关键词并行未测；AISHELL 测试集与训练同采样法（分布同源偏乐观）；无 CATT-KWS/QbyE 同表对比；关键数值依赖图读。

§01 · 问题陈述

三样东西要同时拿到

① 第一级的流式检测能力（常驻低延迟发现候选）；② 第二级的高精度校验（大幅压虚警）；③ 对用户自定义关键词的显式敏感性（从「ASR 通才」变「KWS 专才」）。端侧约束：常驻额外参数足够小（做到 0.04M）、校验分支只在检出候选时激活。最终：0.5 FA/h 下相对传统自定义 KWS 系统 +41% 唤醒率。路线定位：文本注册（不需录音、对说话人稳定）优于 QbyE（录音依赖、注册质量敏感）——代价是需要 G2P 前端。
Attention(Q,K,V) = softmax(QKT/√dk)V（式 1）；流式：h̃a = Attn(Q=Linear(ha), K/V=Linear(hk))；非流式：h̃k = Attn(Q=Linear(hk), K/V=Linear(ha))；L = λLctc + (1−λ)Latt（式 6）
两种偏置只是 query 的取法相反——流式侧每帧只查询固定长度小集合（关键词 token 数）故可逐帧做；非流式侧关键词对整段声学聚合故必须看到全段。「按约束分配注意力方向」是全文最核心的设计判断。训练两阶段：先纯 CTC 训流式分支，再联合优化整个两遍模型（λ 取值未报告）。

§03 · 实验与消融

增量归因 + 词长 + 裁剪策略

数据与指标：内部车载集 = 1000h 混动车普通话训练 + 正测试 30 词 × 200 条（2–4 字）+ 独立 60h 负测试（闲聊/命令/电台）——训练测试同真实车载环境，结论对车载唤醒有直接工程意义；AISHELL-1 保公开可复现。指标：ROC（每关键词正样本 + 60h 负集生成，相同虚警率下平均所有词的拒识率）——KWS 极度非平衡，必须在漏唤醒-虚警权衡曲线上比；F1 补充单点汇总。

§04 · 主要贡献

五条贡献

1首个为 KWS 重训的统一两遍框架——从损失、样本构造、解码器输入输出三层面把两遍模型训练成「检测+校验」专才，解决 ASR 欠优化问题。
2双路异构关键词偏置——首次在统一框架内按分支的流式约束分配注意力方向（声学查询流式 / 关键词查询全局），两者兼得。
3关键词采样 + <eok> 标签增强——免关键词标注的 ASR 语料即可模拟自定义关键词训练；<eok> 一 token 三机制。
4spike 免对齐时间戳裁剪——峰值计数替代外挂对齐器，困难样本上比 CTC 对齐更稳定（图 4 消融验证）。
★端侧友好的激活式架构——关键词编码器仅初始化运行、解码器仅候选激活：常驻增量 0.04M、总 4.75M；0.5 FA/h 下 +41%，AISHELL-1 胜 9 倍大 baseline——「改任务对齐」胜过「堆容量」。

§05 · 局限与边界

阈值耦合与短词洼地

技术局限

  • 两遍级联的阈值耦合：第一级漏掉的候选第二级永远救不回；两级阈值需联合调优而取值未报——每个新关键词可能都要重调，「开放性」在阈值层打折扣。
  • spike 裁剪引入冗余：靠解码器冗余韧性兜底；长语音/极端语速下回数 spike 的判据是否稳健未做边界分析。
  • full decoder 延迟未量化：全块重编码要重新前向编码器——只说「最小延迟」无 RTF/毫秒数，严格低延迟场景（耳机）适用性无法判断。
  • 负样本偏简单：词典随机组词——近音难负样本（同音词、含关键词的更长短语）无显式挖掘，而这恰是主要虚警来源。
  • 第一级只有帧级偏置：全局一致性建模只留给按需激活的校验器——第一级误检率高则第二级算力浪费随之上升。

实验设计不足

  • 关键词规模类型有限：仅 30 个 2–4 字中文词——英文、多音节长词、多关键词并行注册未测。
  • AISHELL 测试集与训练同采样法：负样本分布同源——评估可能偏乐观；缺独立开放词表评测协议。
  • 无同类 SOTA 同表对比：只有自家 baseline 与放大版——CATT-KWS、audio-text agreement、QbyE 均无数字；「相对传统系统 41%」的参照系未展开成表。
  • 关键数值依赖图读：AISHELL 只有 ROC 曲线；λ、spike 阈值、各虚警率绝对拒识率均未报——复现需自行摸索。
  • 单一车载环境：安静家居、远场、多说话人未覆盖；说话人泛化、口音鲁棒性未分析。
自然的延伸方向：端到端联合训练与阈值学习（可微检测损失或强化学习联合优化检测-校验-门控——减少部署期调参）；难负样本挖掘（按音素重叠度构造近音负样本、发音混淆网络生成对抗负例——专攻第一级误检与短词虚警）；短词专项强化（2 字洼地 0.807——音素级声学模型、更长上下文流式编码器、帧同步校验）；多关键词与在线注册（attention 容量分配、零样本即时生效、注册后少量音频自适应——产品化路径）；与 transducer 结合或有限右上下文近似全解码器（延迟与精度更便宜的折中）；跨语言与 G2P 鲁棒性（音素格输入缓解 G2P 错误）。
