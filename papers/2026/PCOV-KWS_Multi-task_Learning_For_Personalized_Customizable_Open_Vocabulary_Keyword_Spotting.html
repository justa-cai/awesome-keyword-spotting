PCOV-KWS
自定义关键词 + 主人声纹：一个轻量网络的双重门槛

PCOV-KWS: Multi-task Learning for Personalized Customizable Open-Vocabulary Keyword Spotting

作者：Jianan Pan, Kejie Huang（通讯）—— 浙江大学

发表：2026.03 · arXiv:2603.18023

开放词表 KWS说话人确认多任务学习 SphereFace2梯度冲突 PCGradTDResNeXt 轻量编码器

一分钟版本

  • 需求：传统 KWS 全家共享一个唤醒词、谁喊都醒——常驻监听下「任何人能唤醒」本身就是隐私暴露。理想入口是双门槛：自定义关键词（别人猜不到）+ 主人声纹（别人学不来）。
  • 方案：底层共享 TDResNeXt 编码器 + 顶层 KWS/SV 双子编码器 + SphereFace2 二元化余弦分类器（消除 softmax 类间零和竞争 → 开放词表）+ PCGrad 冲突感知加权。
  • CIB 置信度集成块：Φ = αΦ_k + (1−α)Φ_v——一次训练三种用法（纯 KWS / 纯 SV / 个性化）。
  • 结果：211k/376k 参数（PhonMatchNet 655k 的 1/3~57%）、1.13M FLOPs（BC-ResNet8 的 1/79）；GSC 零样本 96.9% 超多个全样本基线；消融显示纯关键词模型的个性化 AUC 只有 51%（随机水平）——SV 支路是刚需。

§01 · 问题陈述

两个能力，从未在同一个轻量网络里成立

§02 · 方法论

共享底层 + 分裂顶层 + 二元化分类头

g(z) = 2·((z+1)/2)^t − 1（t=5 最优）—— 相似度动态范围扩展：把挤在一起的负对分数展开、拉开正负分布重叠区，阈值选择变清晰
SphereFace2 二元化：L⁺ = λ·log(1+e^{−s·g(C(e)_{y},t)+b})，L⁻ = (1−λ)·Σ_{j≠y} log(1+e^{s·g(C(e)_j,t)+b})，λ=0.7 最优（偏向正样本项——正对分布方差大、更需要拉紧）。

§03 · 实验结果

零样本超全样本，SV 支路是刚需

设置：训练 MSWC 英文子集，G2P 过滤后 130 万+ 样本 / 7,757 词 / 7,908 人（剔除 ≤5 音素短词——音近混淆主要来源；每词每人 ≥30 条——SV 学「词内辨人」的前提）。评测：GSC v1（闭集）+ LibriPhrase-E/H（开放词表）+ 自建 LibriPhrase-PCOV（正对 = 同词同人）。

其他消融：共享编码器 vs 双网络——211k 对 396k，参数省近半而 OV-KWS/PCOV 反而更好（硬共享红利）；CIB 网格搜索 α 优于手工定值（PCOV EER 3.98→3.85——「个性化任务最优融合比例」不是想当然的 0.5 对 0.5）。

进化链读法：temporal dsconv 是 FLOPs 最大的一刀（6.86M→1.61M，精度只回退 0.4 点）；维度反转精度大涨但计算回升（通道排布对精度敏感）；GRN 单步提升最大（+2.04 点）。整条链证明：KWS 编码器的现代化不需要推倒重来——把 2020 年代视觉卷积的工程经验（大核平坦、GELU、少激活少归一、LN、GRN、分组卷积）系统移植到时序卷积骨架即可。

§04 · 主要贡献

四条可以带走的东西

1PCOV-KWS 多任务框架
首次把开放词表定制与说话人判别统一进一个轻量网络——填补 KWS+SV 多任务「无法自由定制关键词」的空缺。
2SphereFace2 二元化准则
多类改写为 K 个独立二元分类消除类间竞争——开放词表零样本检测的前提；配 PCGrad 冲突感知加权。
3CIB 一次训练三种用法
同一模型 α 切换即分别充当 OV-KWS / SV / 个性化 KWS——网格搜索 α 优于手工 0.5 定值。
4TDResNeXt 编码器
NAS + ConvNeXt 现代化配方，17 步消融链：精度 78.21→85.87%，FLOPs 6.86M→1.13M（-83.5%）。

§05 · 局限与展望

音近硬负样本与端侧证据链

方法本身的技术局限

  • 音近硬负样本未彻底解决：LPH 上 PCOV-S 的 EER 仍略差于 PhonMatchNet；只用声纹门槛间接对冲，无音近混淆词对的专门实验。
  • CIB 线性插值表达力有限：α 依赖验证集网格搜索，换数据集要重调；「声纹极低时一票否决」等非线性交互无法表达。
  • SV 是文本相关风格：未在通用文本无关说话人基准验证，声纹嵌入泛化能力未知。
  • 轻量化只到 FLOPs 层：无实测时延/内存/流式方案——1.13M FLOPs 在真实 MCU/DSP 兑现多少无从判断。
  • 关键细节未展开：边际调度器细节与新词注册原型的构造方式需回溯原文献。

实验设计的不足

  • 纯英语：MSWC 覆盖 50 种语言却只用英文子集；多语言/跨语言泛化零验证。
  • PCOV 协议是合成的：无真实设备注册-使用闭环——注册噪声、远场混响、数月声纹漂移未考察；注册样本数-性能曲线未报。
  • 与前作无数字对比：只有自家双网络对照，「前作不能定制关键词」停留在定性层面。
  • 长度分析只给曲线：无数值表，未覆盖 4 词以上短语。
  • GSC v1 较老：未在 v2 或多语开放词表基准复核。
值得跟进的方向：① MSWC 多语言子集/跨语混合训练，检验开放词表与声纹判别的语言无关性；② LPH 式音近协议上做硬负样本挖掘或对比学习增强，正面解决文本注册误触发短板；③ 可学习门控/注意力融合替代线性插值，研究「声纹一票否决」对安全性的影响；④ 补齐端侧证据链（流式实现、实测时延、内存、量化兼容、真实远场注册-使用回归测试）；⑤ 注册样本数-性能曲线给部署侧可操作建议；⑥ 与 KWS+SV 前作统一协议系统对比。
