模块化网络扩展
让「不碰坏旧词」成为数学恒等式，而不是运气

Scalable Keyword Spotting via Modular Network Expansion

作者：Viktor Khaymonenko, Dzmitry Saladukha, Aliaksei Rak, Alexander Rost —— Yandex 嵌入式语音输入团队

发表：2026.07 · arXiv:2607.19918

类增量扩词灾难性遗忘参数高效微调 构造性非回归core-first 级联端侧部署

一分钟版本

  • 工业级痛点：出货后要加新唤醒词——原始训练数据拿不回来（隐私合规）、全量重训会在旧词上回归（用户依赖「停止」大半年，OTA 弄坏它比新词不好用严重得多）、模型增长严格有界。
  • 方案：全冻结基座（连 BN 统计量一起冻——只冻权重不冻 running stats，表示照样漂移）+ 外挂链式扩展分支（10k 参数硬顶，小核时间卷积）+ 独立新头双 softmax。
  • 核心立场：非回归保证来自构造而非正则化——旧词 logits 与阈值规则对所有输入恒等（式 3+5），不是「实验上没观察到回归」。
  • 结果：新词 FRR 4.37%（LoRA 6.41 / Ensemble 6.46 / Adapters 8.05，8 种子 CI 不重叠）；同 10k 参数下 MACs 增量仅为 Adapters 的 1/2.7、LoRA 的 1/4.3。

§01 · 问题陈述

出货之后才发生的更新场景

核心挑战：安全最容易的做法是 Head-Only（只训新头），但新词 FRR 高达 22.30%（冻结表示对新类判别力不够）；安全另一个极端是独立训 10k 新模型（Ensemble 6.46%），但零特征复用太浪费。
甜点区：零风险地「偷用」基模型已学到的语音表示 + 不碰任何影响核心输出的计算图 + 参数/MACC 转换率压到比 PEFT 更低。

§02 · 方法论

冻结基座 + 参数封顶外挂 + 双头输出

ℓ_core^exp(x) ≡ ℓ_core^base(x), ∀x —— 非回归是恒等式（式 3）：Core Head 计算被冻结且不依赖扩展路径
式(3)+式(5) 合起来才是完整非回归：分数一致 + 阈值规则一致。训练目标只更新 θ_exp、只吃 D2、CE 只加在 New Head（p_new 自带背景类——新头必须自己学会拒绝，这是独立阈值判决的前提）。Head-Only 即 L=0 的退化情形——消融谱系天然连续。

§03 · 实验结果

构造性安全 + 新词双优

设置：GSC v2 标准 10 命令；五组留出易混对（{left,right}/{on,off}/{stop,go}/{up,down}/{yes,no}）——一对作新词 Y₂、其余八个作核心 Y₁；基模型只在 D1 训，扩展只在 D2（无 D1 访问权）。工业级评测协议：负样本校准用 Common Voice v17（外部语料，非 GSC 自身）；固定 1% FAR 工作点报宏 FRR；每配置 8 种子 + 95% t 置信区间——比多数 GSC 论文只报 accuracy 更接近工业验收。

核心词侧：基模型 2.71%（±0.12）；所有冻结核心路径的方法（本文/Adapters/LoRA/Ensemble）核心词结果与基模型逐比特一致（表 2 中省略）。EWC 的 4.47% 恰好演示「软保护」不够软也不够硬。诚实细节：EWC 在 {left,right} 上（5.44）优于本文（6.69）但违约束；{left,right} 是几乎所有方法的最难对——作者特意挑最难场景做深度消融，结论偏保守。

为什么按最坏情况口径：常驻在线、时延必须固定的检测器，容量规划必须按最坏情况（核心头始终拒绝、扩展每帧都跑）——平均省的算力没有部署意义。

§04 · 主要贡献

五条可以带走的东西

1非回归从概率问题变拓扑问题
全冻结（含 BN 统计量）+ 计算图隔离 + 独立新头——恒等式式(3)+(5)，EWC/LwF/PEFT 的结构性替代。
210k 硬预算内新词+开销双优
FRR 4.37%（比 Ensemble 低 2.09 点）；MACs 16.34M 显著低于同预算 Adapters/LoRA。
3core-first 级联
「保 logits ≠ 保产品行为」——出货阈值规则原样嵌入推理管线，补全决策级非回归。
4复用深度的定量刻画
「浅语义不足、4 层最优、深过度特化」的倒 U 形——模块化扩展的可复用设计先验。
5工业级评测协议
外部负样本校准 + 固定 1% FAR 宏 FRR + 五组易混对 + 8 种子 t 区间。

§05 · 局限与展望

系统级 FAR 与真机证据缺口

方法本身的技术局限

  • 非回归只覆盖核心词：原来输出 ∅ 的音频现在可能接受新词——系统级总 FA 预算随词表膨胀，合并 FAR 未分析。
  • 级联耦合下界未量化：核心头在新词语音上误触发 → 新头永远得不到评估 → 新词 FRR 有理论地板。
  • 每次扩展独立预算：10k/次、单次一对词；多轮扩展参数是否线性累积、扩展块之间是否复用——完全未探索（作者列为未来工作）。
  • 10k 是硬顶非最优解：更大预算/一次加多词的行为未报告。
  • 仅报 MACs：无实测时延/SRAM/Flash/功耗。

实验设计的不足

  • 数据面窄：全部结论在 GSC 10 命令 1 秒切分上；无产品规模数据、无远场/多信道/强噪声——动机来自 Yandex 出货产品，实验却未接上。
  • 基线配置单一：Adapters/LoRA 被刻意配置为匹配本文算力而非各自调优；EWC 单一 λ 无扫描；开放词表/少样本路线只定性讨论。
  • 消融单薄：只有深度一个维度、只在 {left,right} 一对上；通道宽度/核宽/训练轮数无消融。
  • 背景分布细节未交代：D1/D2 中彼此命令词音频是折叠为 ∅ 还是剔除。
值得跟进的方向（作者自列 + 笔者补充）：① 多阶段序列扩展——扩展路径的参数复用与累积，避免每轮线性 +10k（直接决定能否支撑产品级词表长期演化）；② 去除核心-新词耦合（用 D2 上核心头行为做诊断，或改并行打分 + 全局阈值分配）；③ 真机 DSP/MCU 时延/内存/功耗；④ 远场混响/多说话人/跨语区负样本/一次多词 + 与开放词表少样本方法正面对比；⑤ 扩展深度自动化（NAS 搭线位置）。
