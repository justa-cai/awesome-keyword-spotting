# Perforated Neural Networks for Keyword Spotting（用于关键词检测的穿孔神经网络）

- **作者/机构**: Vishy Gopal (Purdue University); Aris Ilias Goutis (Renesas Electronics); Ralph Crewe, Erin Yanacek, Rorry Brenner (Perforated AI)
- **发表日期**: 2026年5月（arXiv:2605.15647v1，2026年5月15日）
- **链接**: https://arxiv.org/abs/2605.15647
- **关键词**: Perforated Backpropagation（穿孔反向传播）, artificial dendrites（人工树突）, keyword spotting（关键词检测）, edge deployment（端侧部署）, model compression（模型压缩）, Cascade Correlation（级联相关）, Edge Impulse

## 问题陈述

### 问题背景和领域痛点

边缘机器学习面对的是一套云端大规模部署不会遇到的约束：严格的内存预算、有限的算力、不可协商的精度阈值，三者必须同时满足（摘要）。模型太大，无论精度多高都跑不上目标硬件；模型太小，即使装得进内存，也可能达不到产品可靠运行所要求的最低精度线（第1节）。关键词检测正是这种多重约束下最典型的工作负载之一：常开的语音接口、智能家居设备、工业监测系统，都要求模型在真实噪声条件下可靠地检测一个小词汇量的触发词，同时在一块电池供电的设备上不间断运行（第1节，引文[26,30]）。正因如此，任何声称能同时改进精度和模型体积的技术，KWS 都是它的天然试金石。

这篇论文还有一个更深层的、来自建模本身的动机，而不只是压缩工程层面的动机。人工神经元作为计算单元，从 1943 年 McCulloch 与 Pitts 的数学形式化[18]和 1958 年 Rosenblatt 的感知机[22]以来基本没有变过：突触前神经元直接连接到细胞体，一个标量连接权重是这个模型的唯一参数，这反映的是 1943 年的神经科学认识，而不是现代理解（第2.1节，引文[28]）。反向传播由 Rumelhart、Hinton、Williams 于 1986 年提出[23]之后，激活函数、优化器、学习率调度器、大规模架构都发生了剧烈演化，但核心的神经元单元和梯度下降学习规则本身从未被触动（第1节）。与此同时，现代神经科学已经明确证实：生物神经元在计算上远比人工对应物丰富，其中最突出的例子就是树突执行的主动、非线性计算[17]。论文的基本立场因此可以概括为一句话：把 1943 年版本的单权重神经元升级成带树突计算的版本，本身就是一条长期被忽视的性能来源，而且这条来源与架构设计、压缩技巧是相互独立的。

从神经科学侧看，生物树突绝不是把突触前激活被动传送到胞体的导管，而是在信号沿树突分支传导的过程中执行复杂的非线性计算（第2.1节）。具体机制是：树突分支可以产生局域化的 NMDA 受体介管的尖峰。NMDA 受体是大脑中主要的兴奋性神经递质受体，其电流—电压关系呈现出依赖谷氨酸浓度的特征性 N 形曲线：在中等谷氨酸浓度下会出现一个不稳定的电压阈值，膜电位一旦越过该阈值就会快速去极化到一个高电压稳定态（第2.1节，引文[16]）。这构成了一种有阈值、全或无的响应，而且阈值电压本身还随谷氨酸浓度变化。结果是：单条树突分支就能实现非线性的符合检测（coincidence detection）与特征门控，使单个生物神经元拥有传统人工神经元需要多层堆叠才能复现的计算能力。甚至有研究者主张，树突而不是整个神经元才应当被视为神经系统的基本功能单元[2]。这个观点直接构成了向人工网络添加树突模块的动机。

### 现有方法的具体不足

论文从三条线梳理现有工作的缺口。

第一，主流压缩与优化技术只能在资源之间做交换，很少能同时改善精度与模型体积（摘要）。剪枝、量化、知识蒸馏、神经架构搜索被广泛用于削减边缘部署的模型体积[10]；MobileNet[11] 及其后续是专为资源受限目标从头设计的架构典范。但这一整类方法的共同模式是"接受精度损失以换取压缩"（第3节原文：accepting an accuracy penalty in exchange for compression）——工程师只能在固定的精度—体积权衡曲线上选一个点，没有任何一种技术承诺把整条曲线向左上方推移。

第二，已有的树突式机器学习模型没有兑现潜力。把树突结构引入人工神经元的思想至少可以追溯到 2003 年的形态感知机[21]；早期形态感知机工作证明，树突状结构可以通过超立方体划分完美分类任意训练数据集[25]；一个面向硬件的树突架构在 Nature Nanotechnology 上展示了高能效推理[15]。但 2021 年一篇综述[6]的结论是：被调查的所有树突模型没有一个达到当时的最优精度，不过它们在等参数量下持续优于传统网络——说明树突结构确实携带有效信号，只是既有实现方式没能把信号转化为最优结果。此外，这些方法在工程形态上都是替代式架构：要求修改模型定义、训练超参数或数据集，采用成本高；其中只有极少数把树突节点引入了多层架构；而且没有一种方法给神经元节点和树突节点分别配置不同的学习规则（第3节）。

第三，从工作流角度看，端侧 KWS 工程师如今已经在 Edge Impulse 这类托管平台上完成训练、评估和向嵌入式目标的部署[7]，其标准 NN 块可以把音频、传感器、图像数据训练出的 CNN 导出到种类繁多的 MCU 和 SoC（第4.1节）。任何新方法如果要求更换工具链、更换数据格式或重写模型代码，就很难被工程实践真正接纳。因此论文必须证明树突方法能以"插件"形态进入真实部署管线并在其中胜出，而不是只在离线脚本环境里有效。

### 该论文要解决的关键挑战

综合以上背景，论文要解决的挑战可以拆成三层：

1. 机制层：如何在不替换现有架构的前提下，把树突式计算嫁接到标准卷积网络上——也就是如何定义树突节点的学习目标和学习规则，使其专门拟合主网络的残差误差，同时不破坏主网络自身的梯度下降过程。这本质上是"两套学习规则如何在一个网络里共存"的问题。
2. 工程层：如何在 Edge Impulse 的 KWS 教程管线（MFCC 特征输入 + 可配置 CNN + 全连接头）内实现上述机制，并保持从训练、评估到导出部署的全链路兼容，使树突模型仍能落到任意 MCU/SoC 上。
3. 证据层：如何证明增益不是一次幸运的超参数抽签，而是在整个精度—参数权衡面上的普遍支配。这一点对 KWS 尤其关键，因为其性能要求本质上是二元的：模型要么装得上目标硬件要么装不上，要么达到精度阈值要么达不到（第5.4节）——工程师被任意一维约束住时都应当能从该方法获益，这要求优势在两个维度的所有交点上同时成立。

## 方法论

### 整体架构设计和设计动机

论文的基础网络不是重新设计的，而是直接采用 Edge Impulse 平台标准的 Neural Network Impulse Block：一个可配置的卷积神经网络加上全连接分类头，可在音频、传感器、图像数据上训练，并导出到大量 MCU 和 SoC（第4.1节）。关键词检测教程管线使用从短音频窗提取的 MFCC 特征作为网络输入，目标是检测小词汇量的触发词（第4.1节）。选择这个"不另起炉灶"的起点是刻意的设计：论文的核心主张是 PB 属于可以套在任何现有管线上的增强件，用平台原生基线作为对照最能干净地检验这一主张，同时也排除了"专门为树突手工设计网络"带来的混淆变量。

在此之上，作者实现了自定义的 Dendritic NN Impulse Block（第4.2节）：它扩展现有 NN 块，保留与 Edge Impulse 训练和部署管线的完全兼容，同时引入第2节所述的交替 neuron/dendrite 训练日程；用户可以访问原块提供的全部配置项，树突选项作为新增项并列提供。全部模型代码开源在 Perforated AI 的 GitHub 仓库（第4.2节，引文[20]）。这一设计的三重动机：（1）实验公平性——树突模型与传统模型走完全相同的训练与导出路径，性能差异只能归因于树突机制本身；（2）可复现与可推广性——社区可以直接在真实产品流程里试用该方法，而论文的结论也因此可以被独立验证；（3）扫描可行性——只有把树突超参暴露为块级配置项，才可能用外部工具做数百次自动化扫描。

部署形态上有一个容易被忽略但很关键的细节：树突节点在训练结束时被冻结并并入前向传播（第2.3节），所以最终部署的模型仍然是一张普通的前向计算图，部署侧不需要任何特殊运行时或专用算子支持——这正是"可以导出到任意 MCU/SoC"这一声明的技术前提，也意味着树突方法与平台的部署后端（量化、C++ 导出等）天然兼容。

### 核心算法的数学原理

在标准反向传播[23]穿过多层感知机时，神经元 j 的误差项为（第2.3节公式(1)）：

$$\Delta_j = g'(in_j) \sum_i W_{i,j} \Delta_i$$

其中 $g'(in_j)$ 是作用于神经元 j 总输入的激活函数导数，$W_{i,j}$ 是从突触后节点 i 到突触前节点 j 的连接权重（按论文记号方向）。PB 对这个方程的修改方式是：把突触后节点分裂为神经元节点（下标 i）与树突节点（下标 k）两类，并在反向传播过程中把树突节点的误差项显式置零（公式(2)）：

$$\Delta_j = g'(in_j) \left( \sum_i W_{i,j} \Delta_i + 0 \cdot \sum_k W_{k,j} \Delta_k \right)$$

"穿孔"（perforation）一词正来源于此：反向传播图被打了孔，梯度信息无法穿过树突节点回传，树突节点在架构上被保持在梯度下降图之外——这一性质与生物树突在胞体动作电位生成之外所扮演的角色构成明确的类比（第2.3节）。

树突节点的误差 $\Delta_k$ 不走反向传播，而是用一套修改版的 Cascade Correlation 规则单独计算。在每个 mini-batch 内（公式(3)）：

$$\Delta_k = \left( g(in_k) - \bar{g}(in_k) \right) \left( \Delta_i - \bar{\Delta}_i \right)$$

其中 $g(in_k)$ 是树突节点的激活值，$\bar{g}(in_k)$ 是该激活值的滑动平均，$\bar{\Delta}_i$ 是所属神经元节点误差的滑动平均。这个表达式本质上是一个去均值后的相关项：只有当树突节点的输出波动与所属神经元的误差波动在统计上系统性同向或反向时，乘积才会持续非零，随机不相关的波动会被滑动平均结构抵消。树突节点输入连接的权重更新规则为（公式(4)）：

$$\frac{\delta \Delta_k}{\delta w_j} = \sigma \left( \Delta_i - \bar{\Delta}_i \right) g'(in_k)$$

其中 $\sigma$ 是树突节点输出与所属神经元误差之间平均相关的符号函数。换言之，树突权重的更新方向由"该节点应与残差正相关还是负相关"这个全局符号决定，更新幅度则由树突节点自身的局部激活导数门控。

训练过程在两个阶段之间交替进行（第2.3节）。神经元阶段：整个网络以标准梯度下降训练，直到验证性能进入平台期。树突阶段：冻结全部神经元权重，向每个神经元添加树突节点，用公式(3)(4)训练直到相关性进入平台期；然后每个神经元只保留表现最好的一个树突节点，将其冻结并并入前向传播；随后神经元阶段恢复训练。这个循环持续重复，直到继续添加树突节点不再改善验证性能为止。

为什么必须采用这种双规则设计，而不是让树突节点与主网络一起做梯度下降？论文给出的理由是架构性的：如果误差梯度穿过树突节点，它们就退化成了普通的额外层，失去"专门拟合残差"的功能分工，其误差信号还会与主网络互相污染；把树突保持在梯度图之外，既保留了与生物树突的对应关系，也让 PB 可以实现为只对现有模型代码做最小改动的 PyTorch 包装器（第2.3节，引文[19]）。从优化角度看还有一个隐含的好处：主网络的最优解不会被树突节点的梯度扰动，两套参数在时间上错开更新，交替训练天然带有坐标下降的性质。

### 关键技术创新一：把 Cascade Correlation 泛化为"逐神经元残差目标"

Cascade Correlation[9] 的原始形态是为单层感知机网络设计的：候选节点在既有权重冻结的情况下被训练去与网络的输出误差建立最大相关；最优候选随后被冻结并加入网络，输出节点以新节点为额外输入恢复标准学习；后续加入的级联节点还接收所有先前级联节点的输入（第2.2节）。PB 的关键泛化在于：把"感知机输出误差"这个网络级目标，替换为深度网络中每一个神经元的反向传播误差梯度（第2.2节）。为什么这一步是整个方法的枢纽：深度网络中每个神经元都有自己的残差，逐神经元挂树突等价于给全网的每个计算单元配一台专用纠错器，而不是只在输出端补一个全局修正节点；这也正是 PB 能够作为插件套在任意深度架构（线性层、卷积层）上而无需重写架构的原因。

### 关键技术创新二：穿孔式交替训练日程与冻结部署形态

"先训练主网络到收敛，再打孔加树突，冻结每神经元最优的一个树突，恢复主网络训练，循环直到验证性能饱和"这一日程设计，其动机可以从三方面理解。其一，主网络必须先形成稳定的表征，树突节点才有稳定的残差可拟合；若从头联合训练，残差本身在剧烈漂移，基于滑动平均的相关学习根本无从收敛。其二，每轮每神经元只保留最优一个树突并冻结，控制了部署模型的体积膨胀速度，也让"最优"的筛选在验证集上完成，与模型选择纪律一致。其三，循环的终止条件绑定验证性能而非固定轮数，避免无界增加节点导致部署体积失控。配合"树突并入前向图"的冻结形态，整套机制在部署侧的表现就是一个普通的、可被标准工具链导出的前向网络。

### 关键技术创新三：平台级开源块 Dendritic NN Impulse Block

把整套训练机制封装为 Edge Impulse 生态系统内的自定义块并开源（第4.2节[20]），让树突超参数成为与 dropout、学习率并列的常规可扫描配置项。这个看似工程性的贡献实际上是论文能完成 800 次超参数扫描、并拿下 Edge Impulse 2025 黑客松（2025年12月）Best Model 奖（摘要，引文[8]）的直接前提：没有平台级集成，就不存在公平的对照与大规模扫描。

### 与现有方法的技术差异

- 与树突模型谱系（形态感知机[21,25]、硬件树突架构[15]、2021 年综述[6]所调查的模型）相比：PB 不是替代架构而是包裹在现有深度架构外的插件，不要求修改模型定义、训练超参或数据集；是把树突节点引入多层架构的极少数方法之一；也是唯一给神经元节点和树突节点配置分离学习规则的方法（第3节）。
- 与压缩谱系（剪枝、量化、蒸馏、NAS、MobileNet[10,11]）相比：这些技术在固定的精度—体积前沿上选点，PB 的差异在于它可以移动前沿本身——既能以固定体积换更高精度，也能以固定精度换更小体积，具体往哪个方向走取决于与原架构的集成选择（第3节）。论文还暗示两类方法正交，可以叠加使用，但本文未做叠加实验。
- 与原生 Cascade Correlation 相比：训练目标从全局输出误差改为逐神经元误差梯度；训练流程从一次性递归级联改为与梯度下降交替的多轮循环；节点从级联式互联改为围绕每个神经元的局部结构。

## 实验结果

### 使用的数据集及其规模

实验数据来自 Edge Impulse 关键词检测教程管线所使用的数据（第4.1节），原始数据被划分为训练、测试、验证三个子集（第4.3节）。输入特征明确为从短音频窗提取的 MFCC 系数（第4.1节）。但关于数据本身的全部关键规格——词汇量大小、类别数目、样本条数、总时长、音频采样率、MFCC 维数、帧长帧移、加噪条件——论文均未报告。因此无法将其绝对精度与 Speech Commands[26] 等公开基准上的已发表数字直接对表，这一点在评估结论的外部效度时必须牢记。

### 评估指标的定义和选择理由

论文使用的指标只有两个：测试精度（及由其导出的错误率，例如 Table 1 中基线 0.921 的精度对应 0.079 的错误率）与最终部署模型的总参数量（第5.2节散点图横轴的定义）。选择理由在第5.3节和第5.4节有明确论述：对边缘部署而言最重要的 KPI 就是模型体积与精度两项；而 KWS 的性能要求本质是二元的——模型要么装得上目标硬件要么装不上，要么达到精度阈值要么达不到——所以在这两个维度构成的所有交点上占优，就意味着对任何一维受约束的工程师都有实际价值。此外论文执行了严格的模型选择纪律：测试分数记录在验证性能最高的那个 epoch，而不是测试峰值所在的 epoch（第4.3节），并与先前的 PB 评估实践保持一致——这是为了避免用测试集挑选早停时机造成乐观偏差，属于应当肯定的实验卫生。

论文未报告的指标：推理延迟、RAM/Flash 占用、每推理 MAC 数或 FLOPs、误唤醒率与漏唤醒率、DET/ROC 曲线、多次随机种子下的方差、任何统计显著性检验。对一篇主打边缘部署的论文，缺少部署侧硬件指标是明显的空白（详见局限性一节）。

### 与基线方法和SOTA的详细对比

基线（第5.1节）：Edge Impulse 标准 KWS 模型取得测试精度 0.921，参数量 3,859。

全景扫描（第5.2节，图1）：全部 800 次试验被绘制在"总参数量（对数横轴，覆盖 100 到 2,000,000）× 测试精度"的平面上，蓝色点为传统（非树突）模型，粉色点为 GD 树突模型，黄色点为 CC 树突模型；图1 展示的是其中精度高于 0.920 的聚焦视图。两个全局模式清晰可见（第5.2节）：其一，在每条水平精度阈值线上，最左边的点（以最少参数达到该精度）是树突模型；其二，在每条垂直参数预算线上，最高精度的点也是树突模型。

关键模型对比（第5.3节与 Table 1）：

- 超过基线精度的最小模型是树突模型，约 1,556 参数、测试精度 0.933：相对基线错误率下降 16%（0.079 降至 0.067），同时参数量减少 60%（3,859 降至 1,556）。摘要中的"1,500 参数对约 4,000 参数"是这组数字的取整表述。
- 全场最高精度模型同样是树突模型：测试精度 0.958、11,421 参数；参数量最接近的传统模型为 10,595 参数，错误率比它高 29%（第5.3节；对应 Table 1 中树突模型错误率 0.042）。
- Table 1 的"optimal change"行给出参数量 −60%、错误率 −46%。按数字核对：−60% 对应最小模型（3,859→1,556），−46% 对应最准模型（0.079→0.042，降幅约 46.8%），即该行是把两个不同模型各自的最优变化组合在了一行里；论文正文未对这一口径作明确说明（此判断由 Table 1 数字直接推算得出）。
- 面向两类从业者的结论（第5.3节）：以最大精度为首要 KPI 的人，会发现树突模型达到每一个精度等级所需的参数都比任何传统模型少；以最小体积为首要 KPI 的人，会发现树突模型在每个体积档位上的精度总是更高。

与 KWS 领域最优方法的对比：论文未报告。全文没有与 DS-CNN、MatchboxNet、BC-ResNet 或 MLPerf Tiny 基准[1]的任何直接数字对比，相关工作部分仅把它们作为背景引用（第3节）。所有定量结论都是同一管线内部"树突 vs 传统"的对照。先前 PB 工作在其它领域的数字（第3节，仅供参照，不属于本实验）：药物毒性预测（TrimNet 在 Tox21 上）平均错误率降低 13.6%；股票趋势预测（HIST 在 CSI300 上）平均提升 8.6%；ICU 死亡率预测（mTAN 在 PhysioNet 上）；以及以不到十分之一参数达到精度平价的压缩结果；后续研究[4]进一步报告最高 90% 的无损压缩、最高 16% 的精度提升、GPU 云硬件上最高 38 倍的推理成本下降。

### 消融实验的发现

论文没有传统意义上的逐项消融表；800 次超参数扫描（第4.3节）本身承担了消融的角色。被扫描的维度包括四组：

- 网络架构：卷积总层数、线性总层数、网络宽度、宽度增长模式（各层通道均匀增长如 [8,8,8,8]，或倍增增长如 [8,16,32,64]）；
- 正则化与训练：dropout 率、高斯噪声标准差、学习率、早停耐心值；
- 树突专属参数：每神经元最大树突数、树突切换阈值、树突初始化幅度、树突前向函数、穿孔哪些模块（仅线性层 vs 线性层加卷积层）；
- 模型格式：传统神经网络、GD 树突（树突权重用标准梯度下降训练）、CC 树突（用修改版级联相关训练）。

扫描覆盖的架构尺寸从远小于基线参数量到明显超过基线的宽范围（第4.3节）。可以从中提取的消融级发现有三条。第一，格式消融：传统、GD、CC 三种格式同场竞争，最终占据每个最优位置的全部是树突模型；但 GD 与 CC 两种树突变体之间的分组统计差异（谁更优、在哪个参数段更优）论文未报告。第二，穿孔位置消融：仅线性层与线性加卷积层两种方案作为扫描维度存在，但其独立结论论文同样未报告。第三，也是作者最强调的一条：普遍性本身就是核心发现（第5.4节）——树突优势跨越所有参数量级成立，这比找到单个高性能配置更有说服力，因为它说明树突机制提供的是一致的信号改进，而不是只在特定架构条件下才显现的偶然效应；作者还指出 KWS 领域特别适合展示这种普遍性，因为其性能要求的二元性质使得"在两个轴的所有交点上占优"具有直接的工程含义。

## 主要贡献

1. 首次将 Perforated Backpropagation 与人工树突节点引入音频关键词检测与真实边缘部署平台，并在 Edge Impulse 2025 黑客松（2025年12月）获得 Best Model 奖（摘要，引文[8]）。
2. 以 800 次超参数扫描建立了"全权衡面支配"的证据形态：在每个参数预算上树突模型精度最高，在每个精度阈值上树突模型参数最少——是支配性结论而非单点结论（第5.2、5.3节）。
3. 最佳单一模型同时实现错误率降低 16% 与参数量减少 60%（1,556 参数、精度 0.933，第5.3节、Table 1），打破了"压缩必付精度税"这一默认交换关系，证明精度与体积可以被同时改善。
4. 平台工程贡献：开源的 Dendritic NN Impulse Block[20] 使任何 Edge Impulse 用户可以在原有全部配置项之上直接启用树突训练，方法可以即刻进入真实产品流程。
5. 把 PB 的跨域验证记录扩展到音频与边缘推理域；此前 PB 已在化学图网络（药物毒性）、金融时序（股票预测）、医疗时序（ICU 死亡率）、NLP、蛋白质生物学、图像识别等领域报告了增益（第5.4节、第3节），跨域一致性强化了"树突结构抓住的是神经网络学习的普遍性质"这一主张。

## 局限性与展望

### 方法的技术局限性

- 训练流程复杂度上升：交替的 neuron/dendrite 双阶段外加多轮"冻结—加节点—回训"循环，直到验证性能饱和（第2.3节），训练总时长与调参成本必然高于单阶段训练；具体的时间开销论文未报告。
- 超参数空间扩大：在常规超参之外新增了五类树突超参（每神经元最大树突数、切换阈值、初始化幅度、前向函数、穿孔模块范围），对首次接触该方法的用户构成新的搜索负担，论文也未给出这些超参的推荐值或敏感性分析。
- 树突节点加宽了前向计算图：每个神经元最多可挂多个树突节点，推理阶段的额外计算量、访存量与潜在的串行化代价，需要用延迟和内存数据来衡量；论文只报告了参数量这一个体积代理，实际部署开销论文未报告。
- "每神经元每轮只保留最优一个树突"是启发式规则：被丢弃的次优树突是否携带有用信号、保留多个树突的成本收益曲线如何，论文未讨论。
- 公式(3)(4)中的滑动平均窗口长度、树突学习率等实现细节论文未报告，精确复现需要依赖开源代码[19,20]。

### 实验设计的不足

- 数据集透明度不足：词汇规模、类别数、样本量、噪声条件、MFCC 配置全部未报告，第三方既无法精确复现实验，也无法把 0.921/0.933/0.958 这些绝对精度值与任何公开基准对齐。
- 缺少与领域最优方法的直接对比：没有 DS-CNN、MatchboxNet、BC-ResNet 或 MLPerf Tiny 的数字；所有结论都是管线内对照。基线 0.921 的绝对水平由 Edge Impulse 教程管线与数据决定，并不能代表公开数据集上的竞争力，结论的正确读法是"树突对同架构的相对改进"，而非"树突模型达到 SOTA"。
- 缺少统计检验：800 个点的"每个交点支配"结论没有显著性分析，也未报告随机种子方差；且图1 只呈现精度高于 0.920 的聚焦视图，全范围（100 至 2,000,000 参数）的结论依赖正文文字描述，读者无法从图中独立核验低精度大模型端的支配关系。
- 缺少部署侧证据：论文以边缘部署为标题场景，却没有在真实 MCU/SoC 硬件上报告延迟、RAM/Flash 占用或功耗——这些恰恰是摘要中"严格内存预算、有限算力"约束的直接度量，参数量只是其中一个间接代理。
- GD 树突与 CC 树突两种变体的系统比较结果未报告，读者无法评估修改版级联相关相对朴素梯度下降训练树突的净贡献；同样缺失的还有穿孔模块范围（仅线性 vs 线性加卷积）的分组结果。
- Table 1 的"optimal change"行把来自两个不同模型的最优变化（参数 −60% 来自最小模型，错误率 −46% 来自最准模型）并列呈现，口径未加说明，容易被误读为单一模型同时达成两项数字。

### 未来可能的改进方向

论文自述的方向（第6节）：应用到更多音频架构；在嵌入式部署基准上做系统评估；与硬件感知神经架构搜索集成，让 NAS 直接在包含树突的搜索空间中优化。

从读者视角还可以延伸：与量化、剪枝等压缩技术做叠加实验，验证论文暗示的正交性主张；在公开数据集（如 Speech Commands[26]）和更大词汇量上复现，补齐外部可比性；报告流式常开场景下的误唤醒/漏唤醒权衡，这是 KWS 产品化的真正门槛指标；对公式(3)(4)的残差相关学习给出理论刻画，解释为什么逐神经元拟合残差能转化为全局精度提升；公开扫描数据中 GD vs CC 与穿孔位置的分组统计，把已扫描但未报告的消融维度补全；最后，在真实 MCU 上测量树突模型相对传统模型的延迟与能耗，把"参数更少"落实为"部署更省"，这是该方向从获奖演示走向工程标配所必需的最后一块证据。
