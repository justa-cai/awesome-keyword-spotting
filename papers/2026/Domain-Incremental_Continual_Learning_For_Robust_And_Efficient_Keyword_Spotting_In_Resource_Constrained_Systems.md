# Domain-Incremental Continual Learning for Robust and Efficient Keyword Spotting in Resource Constrained Systems

- **作者/机构**: Prakash Dhungana, Sayed Ahmad Salehi - 肯塔基大学（University of Kentucky）
- **发表日期**: 2026.01（arXiv 2601.16158v1，2026 年 1 月 22 日提交）
- **链接**: https://arxiv.org/abs/2601.16158
- **关键词**: keyword spotting（关键词检测）, domain-incremental continual learning（域增量持续学习）, catastrophic forgetting（灾难性遗忘）, rehearsal buffer（重演缓冲区）, class prototype（类原型）, on-device learning（设备端学习）, quantization（模型量化）

## 问题陈述

### 问题背景和领域痛点
关键词检测（KWS）是智能音箱、可穿戴设备等边缘设备上语音交互的常驻入口，模型必须同时满足低复杂度、小内存占用和高能效才能在微控制器（MCU）级硬件上实时运行。但这类模型的训练数据集与真实部署环境之间存在系统性的**域漂移（domain shift）**：新说话人、新口音、新背景噪声、新录音条件都会改变输入分布。论文引用的实测证据是：训练与部署环境不一致时，KWS 模型精度最多可退化 27%[论文引文 1]。对常驻监听的唤醒词系统而言，这不是一次性问题——设备搬个房间、换个街道、旁边开了台洗衣机，域就变了。

传统的应对是把数据传回云端重新训练再推模型下发，但在三个约束下不可行：其一，原始音频回传有隐私风险（论文明确把隐私敏感场景列为目标场景）；其二，反复全量重训的算力与人力代价高；其三，边缘设备的部署周期内无法依赖人工介入。持续学习（Continual Learning, CL）因此成为候选路径——让模型在设备上自主吸收新域数据，同时保住旧知识不发生灾难性遗忘。CL 按场景分三类：类增量（新增类别）、任务增量（同类数新任务）、**域增量（同一分类任务、输入分布随域变化）**。本文选择域增量：分类头永远是"Yes/No"，变的是噪声环境。

但把 CL 搬到 MCU 上比搬到服务器上难得多：训练本身需要反向传播的中间激活内存，而 MCU 的 SRAM 只有几百 kB 量级；运行时数据没有人工标注，伪标签错误会毒化重训；模型通常是 INT8 量化的，量化参数上直接做梯度更新需要额外机制。这些约束共同构成了本文的问题空间。

### 现有方法的具体不足
论文从"端侧深度学习"和"域适应 CL"两条线梳理了现有方案的缺口：

- **推理侧模型太重，撑不起端侧训练**。MobileNet、MCUNet、ODDA 用的 DSCNN 等架构参数量在 23.7k~480k 之间，推理尚可，但一旦要在设备上开启学习，反向传播的额外内存和计算会显著推高每个样本的处理延迟。模型越大，"哪些层能更新"就越被迫收缩。
- **ODDL[4]：只更新分类器层**。它用 0 dB SNR 的预标注样本混噪重训 DSCNN 的分类器层，且把噪声划分为训练时"已见"与"未见"两类分别评估。这留下三个问题：特征提取主干完全冻结，无法适应新域的特征统计漂移；验证只做了 0 dB 单一信噪比；实现依赖 GAP9 多核并行处理器，硬件门槛高。更关键的假设缺陷是：它假定部分部署噪声在训练时已经见过，而真实部署中噪声是全新出现的。
- **Lin 等[14]（MCUNetv3 系）的端侧训练限定特定层/参数**，用 Quantization Aware Scaling（QAS）、稀疏更新（sparse update）和 Tiny Training Engine（TTE）组合的专有方案，在常规 GPU 上模拟嵌入式环境完成验证——离真实 MCU 部署有距离。
- **TAP-SLDA[16] 只更新高斯原型不动主干**，比不做更新的高斯原型最多提升 11% 精度，但表示能力的上限锁死在原型统计量里。
- **Vu 等[15] 的二值网络 CL 面向类增量**——靠扩展分类器层容纳新类，不处理域漂移。
- **重演类 CL（iCaRL、GEM、DER 等）**虽已证明排练缓冲对抗遗忘有效，但此前主要用于类增量和任务增量，没有与"运行时伪标签监督"结合用于域增量。

归纳起来，现有方法的共同短板是：**更新范围受限（只动分类器层或稀疏选层）导致骨干特征无法跟进新域；验证噪声条件单一（多为 0 dB）；且默认训练阶段已见过部分部署噪声**。

### 该论文要解决的关键挑战
论文要回答的核心问题是：能否在一个 MCU 级参数预算（千级参数）内，构建一个不依赖人工标注、不需要并行加速器、在 −10 dB 到 10 dB 宽信噪比范围内都能维持 94% 左右精度的域增量 CL 闭环。拆开是五个子挑战：（1）模型必须小到可以**全参数更新**而不只是动分类器层，否则域适应能力受限；（2）运行时无标注，必须有一套可靠的伪标签筛选机制，避免错误样本污染重训；（3）输入特征的可靠性要先保证——去噪不可靠时，分类和伪标签筛选会一起崩；（4）训练要能在 INT8 量化模型上闭环；（5）重训必须对抗遗忘，干净域的旧知识不能丢。

## 方法论

### 整体架构设计和设计动机
整体框架分两个阶段运行：**运行时有效样本判定**（每条输入推理时顺带判断"这条样本值不值得存下来当训练素材"）和**固定间隔的 CL 重训**（累积到周期点，用"排练缓冲 + 增强排练缓冲 + 有效样本"拼成 mini-batch 重训整个模型，并同步更新类原型和距离阈值）。

支撑这个闭环的是一条四组件 KWS 管线：**小波去噪（原始波形域）→ 特征提取（CMSIS-DSP 整数 MFCC + Mel 谱）→ 谱去噪（特征域）→ 量化 CNN 分类器**。每个组件的位置选择都有明确的"为什么"：

- **小波去噪放在最前面**，是因为非平稳噪声在波形域处理能同时保住时间和频谱结构的完整性（论文原话是"removes nonstationary noise while preserving the temporal and spectral integrity"）；输出直接量化到 [−128, 127]，让整条前端保持整数运算。
- **特征提取用 CMSIS-DSP 库的整数 MFCC**，是为了绕开浮点运算的延迟和内存代价——这是低端 M4 内核上的真实瓶颈。
- **Mel 谱作为第二路输入零额外代价**：LogMel 本来就是 MFCC 计算流水线的中间产物，把它一并送进分类器等于免费拿到第二视角的特征。
- **谱去噪放在特征域**，负责清理小波阶段残留的、以及特征统计中随环境漂移的噪声分量；先把特征图归一化到 [0,1] 再做后续操作，是为了获得幅度不变性——不同录音音量下掩码阈值仍然稳定。
- **分类器是三层 5×5 Conv2D + Flatten + FC**，全部无零填充（no zero padding）。去填充不是随手省事：论文明确说实验验证了零填充对精度影响极小，去掉后后续层的特征图更小、内存和计算双降。
- **隐层表示（latent representation）取第三层 Conv2D 的输出**，这是一个纯资源驱动的选择：该位置隐层只有 160 字节，而第一、二层之后分别是 960 和 192 字节；用 MAE 算一次原型距离只要 160 次算术运算（MSE 要 320 次）。原型比较发生在每条运行时样本上，这里的每次节省都是乘以全部流量的。

### 核心算法的数学原理

**第一级：小波域 VisuShrink 去噪。** 音频按 1024 样本的不重叠分帧，每帧做单级 Haar 小波分解，得到近似系数和主要承载高频信息的细节系数。噪声方差用细节系数的中位数绝对偏差（MAD）估计：

$$MAD = \frac{\text{median}(|d - \text{median}(d)|)}{0.6745}$$

其中 $d$ 为 Haar 小波的细节系数。全局收缩阈值为：

$$\tau = MAD \cdot \sqrt{2 \log N}$$

$N$ 为窗口长度。低于 $\tau$ 的系数经软阈值压制（衰减而非硬置零，避免振铃），再经逆 Haar 变换重构去噪帧并与相邻帧拼接，最后量化到 [−128, 127]。VisuShrink 的特点是"单一全局阈值 + 偏好平滑重建"，实现开销极小。

**第二级：特征域谱去噪。** 设 $x_n$ 为归一化到 [0,1] 的特征图（MFCC 或 Mel 谱），沿时间轴和频率轴分别做均值减：

$$x_t = x_n - \mu_t(x_n), \quad x_s = x_n - \mu_f(x_n)$$

再构造二值掩码，只保留高于各自均值的分量（论文的直觉：背景噪声在两个轴上趋于均匀分布，减均值后只剩低于均值的弱分量；语音谐波和瞬态这类显著结构会高于均值）：

$$M_t = \mathbb{1}[x_t > \mu_t(x_t)], \quad M_s = \mathbb{1}[x_s > \mu_f(x_s)]$$

最终去噪特征由掩码分量与原始特征按衰减系数 $\alpha$ 重组（式 5，按论文原文照录）：

$$x_d = (1-\alpha)\big(\alpha\, x_s M_s + (1-\alpha)\, x_t M_t\big) + \alpha\, x_n$$

$\alpha$ 控制去噪激进度与信号保留的权衡：$\alpha$ 越小越偏重去噪，$\alpha$ 越大越保留原始数据（$\alpha = 1$ 时退化为直通）。论文把谱减、掩码和归一化三种思路揉进这一个轻量公式，专门面向时频表示。（写作细节：Fig 6 的图注引用的是"Equation 7"，而正文公式按组编号只到 (5)；若把式 3/4 的每一行单独编号，$x_d$ 一式恰好是第 7 个——论文自身编号不一致。）

**类原型与距离。** 每个类的原型就是该类样本隐层表示的均值向量，维度与隐层相同（单输入模型 160 字节，双输入模型翻倍到 320 字节）。样本与原型的相似度用 MAE 度量。原型接受阈值不是固定常数，而是随类分布自适应的：

$$d_{th} = \mu + n\sigma$$

其中 $\mu$、$\sigma$ 是 mini-batch 内同类样本到原型距离的均值和标准差，$n$ 为经验系数。这个设计把"离群"的定义跟随类分布的紧致程度缩放：类分布散，接受窗就宽；分布紧，接受窗自动收窄。

**CL 更新（算法 2）。** 对量化模型先反量化（$F_\theta, F_h \leftarrow D_Q\{f_\theta, f_h\}$），在 mini-batch 上算交叉熵损失 $l \leftarrow L_{CE}(F_h(F_\theta(X_i)))$，反向传播得梯度后按初始训练相同的学习率 0.001 更新权重（论文的理由：沿用同一学习率可以控制更新幅度、保证重训稳定），再把更新后的权重重量化为 INT8，最后用新模型重算类原型 $P_{class} \leftarrow \frac{1}{N}\sum_{i=1}^{N} f_\theta(X_i)$、距离均值与标准差。原文中更新步写作 $w_m \leftarrow |F|$、$F' \leftarrow f - \delta_\theta \odot w_m$，即以参数幅值对梯度做逐元素缩放——这一步的设计动机论文没有展开解释，属于可复现性上的一个模糊点。

### 关键技术创新一：双特征输入的紧凑 CNN 与"全模型可更新"的资源论证
分类器有单输入和双输入两个版本。单输入版：输入 20×16 的 MFCC 图（1 秒音频），经三层 5×5 无填充 Conv2D，特征图依次为 16×12 → 12×8 → 8×4（每层两个维度各减 4，与无填充卷积的几何完全一致），再 Flatten 接 FC 层（原文表述为 FC 含 160 个参数）。双输入版：MFCC 与 LogMel 两路并行，各自过独立的三层 Conv2D（结构与单输入版相同），Flatten 后拼接成单一向量进入 Dense 层完成分类；**拼接层的输出被选为隐层表示/类原型的载体**，理由是它同时携带倒谱域和时频域两路信息，且沿用单输入版"隐层取最末卷积位置"的内存论证——维度是单输入版的两倍（320 字节）。

双输入的收益有干净数据背书：GSCD v2 测试集上单输入 97.45%，双输入 99.63%，提升 2.18 个百分点，代价为零（LogMel 是 MFCC 流水线的中间产物）。论文将增益归因于 MFCC（倒谱域）与 Mel 谱（时频域）提供的不同谱时特征互补。

这个架构更深层的作用是**为"全模型更新"提供可行性论证**——这是本文与所有前作的分水岭。模型总参数只有 1,595（Table IV 记 1.64k），全参数反传的激活内存和更新开销在 MCU 预算内可以承受。前作被迫"只动分类器层"或"稀疏选层"，根源是模型太大；本文把模型压到千级参数后，域适应能力的天花板从"分类边界微调"上升到"整个特征提取器跟进新域"。（论文未显式给出各卷积层的输出通道数；由 8×4 共 32 个空间位置与 160 维隐层可反推第三层输出通道为 5，此为笔记推断，非原文陈述。）

### 关键技术创新二：小波域 + 特征域的两级整数化去噪
两级去噪不是冗余设计，各自针对不同的噪声残留层。第一级在波形域用 Haar-VisuShrink 清除非平稳噪声；第二级在特征域用双轴均值减 + 掩码 + $\alpha$ 重组清理特征统计中残留的噪声分量。第二级的归一化前置（[0,1] 缩放）提供了幅度不变性，使掩码阈值对不同录音增益稳定——这是部署环境音量不可控时的必要保护。

去噪设计还有一个容易被忽略的间接作用：**它同时服务于有效样本判定**。伪标签筛选依赖分类置信度和隐层-原型距离，两者都以"进来的特征可靠"为前提；论文在贡献声明里明确把"保证分类和有效样本判定的特征可靠"列为双级去噪的目标之一。消融数据也支撑了两级的分工：不重训时，−10 dB 下"仅谱去噪"88.62% 反而高于"小波+谱"的 86.38%（小波在重度污染下会引入失真）；但开启重训后，"小波+谱+重训"达到 92.94% 成为最佳——论文据此论证那些失真主要来自噪声源而非音频特征本身，且失真可以被 CL 阶段吸收。

### 关键技术创新三：置信度 × 原型距离的双门控有效样本筛选
运行时每条样本过一遍 INT8 量化推理，同时拿到最终预测和隐层表示，然后按算法 1 做两级门控：

1. **置信度门**：预测概率最大值超过 $P_{th}$（取 85%，经验值）才继续；否则直接放弃。先查置信度再算距离是刻意的算力节省——距离计算并非免费（MAE 160 次运算），绝大多数低置信样本不值得算。
2. **原型距离门**：隐层与所属预测类的原型算 MAE，距离落在 $|d_p - \mu|$ 阈值内才被标记为**有效样本（effective sample）**，存入内存供下次 CL 使用，伪标签即预测类。

双门控缺一不可的逻辑：只用置信度，过度自信的错误样本（噪声域下并不罕见）会带着错标签进重训集；只用原型距离，无法处理类间边界上"离两个原型都近"的模糊样本。$\mu + n\sigma$ 自适应阈值则把接受窗限制在"能提供新信息、又不至于向类原型引入歧义信息"的范围内——论文用图示把这个区域画成绿色带，带内样本（黄点）入选、带外（红点）拒绝。这套机制的本质是把无监督的运行时流变成一个**高置信子集的半监督流**。

### 关键技术创新四：量化模型的全参数 CL 闭环与特征域重演缓冲
CL 阶段（算法 2）的完整闭环是：反量化 → 交叉熵损失 → 反向传播 → 学习率 0.001 更新**全部**权重 → 重量化 INT8 → 用重训后的模型更新类原型、原型距离的均值/标准差阈值。重训的 mini-batch 由三部分拼成：重演缓冲（GSCD 训练数据子集的 MFCC + LogMel 特征）、增强重演缓冲（用部署环境录的 1 秒噪声谱特征与缓冲特征混合生成）、运行时攒下的有效样本。

两个资源导向的设计值得展开。**其一，重演缓冲存特征而不存音频**：直接省掉原始波形存储，且增强样本已经在特征域，混合后只需过谱去噪一级，跳过小波去噪和特征提取两级前端——增强的计算成本被压到最低。**其二，重训按固定周期触发**：相邻两次重训之间间隔 1024 个样本；mini-batch 由从 300 秒环境噪声中随机取的 8 秒噪声与各 64 条"Yes"、"No"样本混合构成；论文报告的是 25 次重训迭代完成后的平均精度。这个周期化设计把"何时学"从事件驱动简化为计数驱动，实现上零额外判断开销。

### 与现有方法的技术差异
与最接近的两条线对比，差异集中在四个维度。**更新范围**：ODDL[4] 只重训 DSCNN 分类器层，Lin 等[14] 做特定层的稀疏更新，本文更新完整模型加原型——前提是把模型压到 1.64k 参数，这是架构选择换来的 CL 自由度。**噪声假设**：ODDL 把噪声分为训练已见/未见两档、且只在 0 dB 验证，本文假设所有噪声都在部署后才出现（全部视为未见），并在 −10 到 10 dB 五档验证。**硬件依赖**：ODDL 需要 GAP9 多核并行处理器，Lin 等用 GPU 模拟嵌入式环境，本文目标是单核 Cortex-M4（TM4C123GXL），不需要并行能力。**监督来源**：TAP-SLDA[16] 这类原型方法只更新原型统计量，本文把原型更新和全模型监督重训（伪标签有效样本 + 带标签重演缓冲）结合——论文自述这是"把原型半监督策略与监督 CL 桥接"的空白点。

## 实验结果

### 使用的数据集及其规模
- **训练/干净测试**：Google Speech Commands Dataset v2（GSCD v2），超过 105,000 条时长 1 秒或更短的 16 kHz 音频，覆盖 35 个关键词、2,618 名说话人。本文取"Yes"和"No"两个词做二分类，用 GSCD v2 官方测试集评估干净性能。
- **噪声源**：DEMAND 数据集，六大环境类别（Domestic、Nature、Office、Street、Public、Transportation），每类 3 个录制环境，每段噪声 300 秒、48 kHz 录制后重采样到 16 kHz。实际选用 4 个环境：DWASHING（居家洗碗机）、NFIELD（自然田野）、OOFFICE（办公室）、TCAR（交通车厢）。（原文先说"六类"后说"用了五类中的四类"，数字表述不一致，实际使用的是上述 4 个。）
- **评估集构造**：GSCD v2 测试样本与 DEMAND 单秒噪声混合，SNR 从 −10 dB 到 10 dB、步长 5 dB 共五档，每个噪声环境生成 169,695 条评估样本。
- **CL 模拟流程**：先用重演缓冲加该环境 300 秒噪声中的随机段做谱域特征混合完成初始适配；随后进入推理模式，运行时判定并保存有效样本；每 1024 个样本触发一次重训（8 秒随机噪声 + 各 64 条 Yes/No 混合构成 mini-batch）；报告 25 次重训迭代完成后的平均精度。

### 评估指标的定义和选择理由
主指标是**分类准确率**，选择理由直接：二分类任务的核心度量，且与 ODDL、MCUNet 等前作同数据集可直接对比。嵌入式维度用 TinyML 四件套：**参数量、FLOPS、每样本时延（ms）、每样本能耗（µJ）**——这四个量共同决定方案能否落在 MCU 预算内。需要指出的是，KWS 领域常用的误警率/误拒率（FA/FRR）、AUC、DET 曲线，以及 CL 领域常用的遗忘度量（适应后旧域精度回退），**论文均未报告**。

### 与基线方法和 SOTA 的详细对比
**干净性能（Table I）**：单输入（MFCC）97.45%，双输入（MFCC + LogMel）99.63%。此后所有 CL 实验均用双输入模型。

**四噪声环境 × 五档 SNR 的 CL 结果（Table II，双输入模型）**：

| 适配环境 | −10 dB | −5 dB | 0 dB | 5 dB | 10 dB |
|---|---|---|---|---|---|
| DWASHING | 93.84 | 94.88 | 95.62 | 95.22 | 95.20 |
| NFIELD | 91.44 | 92.56 | 94.91 | 96.22 | 95.09 |
| OOFFICE | 92.94 | 92.50 | 94.34 | 94.94 | 94.31 |
| TCAR | 94.56 | 95.25 | 95.28 | 94.78 | 95.22 |

最差点是 NFIELD 在 −10 dB 的 91.44%，最好点之一是 NFIELD 5 dB 的 96.22%；四个环境在 −10 dB 全部保持在 91% 以上，0 dB 起全部超过 94%。论文的读法是：仅 25 次重训就显著拉高了噪声鲁棒性，且随 SNR 恶化的精度衰减斜率被压平。

### 消融实验的发现
**组件消融（Table III，OOFFICE 环境，双输入模型）**：

| 重训 | 小波去噪 | 谱去噪 | −10 dB | −5 dB | 0 dB | 5 dB | 10 dB |
|---|---|---|---|---|---|---|---|
| 否 | 否 | 是 | 88.62 | 94.50 | 96.72 | 97.97 | 98.03 |
| 否 | 是 | 是 | 86.38 | 92.16 | 95.47 | 95.69 | 96.41 |
| 是 | 否 | 是 | 92.88 | 94.53 | 96.59 | 96.31 | 97.03 |
| 是 | 是 | 是 | 92.94 | 92.50 | 94.34 | 94.94 | 94.31 |

三个发现：（1）**重训的收益集中在低 SNR**：−10 dB 下重训把精度从 88.62/86.38 拉到 92.88/92.94，提升超过 4 个百分点；而 10 dB 下重训反而略降（98.03 → 94.31），说明域漂移本来就小时 CL 无增益，重演缓冲的混合分布与干净分布存在轻微错配。（2）**小波去噪的价值需要重训配合才兑现**：无重训时它在 −10 dB 反而损失 2.24 个百分点（88.62 → 86.38），说明重度噪声下小波去噪引入了失真；有重训时它反超仅谱去噪配置，论文以此论证失真源于噪声而非音频特征、且可被 CL 吸收。（3）谱去噪单独就相当能打——无重训、仅谱去噪在 −10 dB 仍有 88.62%，是两级中去噪性价比最高的一级。

**谱去噪衰减系数 α 敏感性（Fig 6）**：α 在 [0.4, 0.9] 全区间性能稳定，0–10 dB 各环境精度保持在 94–96% 以上；只有 −10 dB 的 NFIELD 和 OOFFICE 在 α 过强或过弱时偶有下探，且无尖锐最优——结论是去噪算法对参数选择鲁棒，无关键退化点。

**置信度阈值 $P_{th}$ 敏感性（Fig 7）**：阈值从 0.70 扫到 0.85，各环境各 SNR 精度变化小于 0.5%，曲线几乎平坦。这说明 INT8 量化后的预测置信度校准良好、正确与错误预测的置信分离可靠，CL 机制对该超参不敏感。

**原型距离阈值敏感性（Fig 8）**：阈值在 [1.7, 2.4] 全区间精度变化小于 1–1.5%，无尖峰最优，−10 dB 下 NFIELD 方差稍大。结论同上：距离门控不依赖精细调参，隐空间的决策边界天然分离良好。

## 主要贡献
1. **新的域增量 CL 框架**：以运行时伪标签的"有效样本"和重演缓冲共同驱动，实现完整量化模型的增量更新（而非仅分类器层或稀疏层），同步更新类原型——把端侧域适应的能力上限从分类边界推进到整个特征提取器。
2. **双级去噪嵌入特征管线**：小波域（Haar-VisuShrink）与特征域（谱减+掩码+归一化）两级整数化去噪，同时保障分类精度与有效样本判定的特征可靠性。
3. **双特征输入分类器**：MFCC + LogMel 并行流，干净数据 99.63%（比单输入高 2.18 个百分点），第二路特征借 MFCC 流水线中间产物零额外计算获得。
4. **宽条件验证与极致资源占用**：−10 到 10 dB 五档 SNR、四类噪声环境全部保持 91% 以上精度；1.64k 参数、0.89M FLOPS，可在 TM4C123GXL 级 Cortex-M4 上部署，比 ODDL 的 DSCNN-M 少 98.81% 参数且精度更高。

## 局限性与展望

### 方法的技术局限性
- **二分类边界**：整个框架（双类原型、FC 输出、µ+nσ 阈值、各 64 条的均衡重演）都按 Yes/No 二类设计。多类场景下原型数增长、类不均衡的排练配比、逐类距离阈值的维护都要重新设计——论文在结论中承认这是当前边界。
- **时延偏高且为估算值**：95.11 ms 单样本时延对 1 秒窗是实时的，但对低延迟流式唤醒场景偏大；且该数字与能耗一样来自 ARM M4 数据手册估算（Table IV 中 ** 标注），并非板级实测，"优化 M4"一行 64.45 µJ 的优化手段论文也未说明。
- **对重训发生的依赖**：消融显示小波去噪在无重训、−10 dB 时引入失真（88.62 → 86.38）。这意味着管线的鲁棒性依赖"重训按周期发生"；若两次重训之间遭遇剧烈域变，存在一个性能凹陷窗口。
- **超参均为经验设定**：置信度阈值 85%、α、µ+nσ 中的 n 都是经验值。敏感性分析证明了平坦性（这本身就是贡献），但没有给出可迁移到其他数据集的选取方法论。
- **隐层维度低**：160/320 字节的隐层表示决定了原型的表达容量上限，类间音素重叠度高时区分余量存疑；论文未做隐层位置/维度的消融。
- **算法细节的可复现性缺口**：算法 2 中 $w_m \leftarrow |F|$、$F' \leftarrow f - \delta_\theta \odot w_m$ 的逐元素缩放步骤未解释设计动机；初始训练的优化器、轮数、数据增强细节、QAT 配置论文均未报告。

### 实验设计的不足
- **Table IV 的 94.31% 未注明口径**：未说明对应哪个噪声环境与 SNR（数值恰与 Table II 中 OOFFICE@10 dB 一致，疑为该配置，但论文未明示），与 ODDL/MCUNet 的精度对比因此不完全对齐（后者口径同样未统一到同一噪声条件）。
- **摘要表述偏乐观**：摘要称 −10 dB 下"各噪声环境超过 94%"，但 Table II 的 −10 dB 列为 91.44–94.56，仅 TCAR 一项过 94%。
- **数字与写作瑕疵**：DEMAND"六类"与"五类中选四类"矛盾；Fig 6 图注引"Equation 7"而正文公式组编号止于 (5)；"98.81% fewer parameters"的括注 DSCNN-S 按算术应对应 DSCNN-M。
- **关键维度缺失**：未报告重演缓冲的具体容量（样本数或字节数）与系统总 RAM/Flash 占用——这恰是端侧 CL 最核心的资源账；未报告 CL 之后在干净测试集上的精度（遗忘度量）；未报告误警率等 KWS 业务指标；未报告随机种子与方差（结果是否稳定复现无从判断）；未报告有效样本的伪标签错误率（双门控的实际过滤纯度没有直接证据）；也没有"仅重演缓冲 vs 重演+有效样本"的消融来隔离有效样本机制的独立贡献。
- **域的定义偏窄**：域漂移只用加性环境噪声模拟，未覆盖混响、远场、麦克风信道失真、说话人与口音变化——而后几类同样是论文引言中列出的域漂移来源。
- **缺少 CL 方法间的同台对比**：TAP-SLDA、iCaRL 等只在相关工作里引了数字，没有在同一框架下的直接对照。

### 未来可能的改进方向
- **多类域增量扩展**：论文自述的下一步，目标是 KWS-35 等多类任务（论文同时列出了 MNIST、CIFAR-10、CIFAR-100 这类视觉数据集，反映出作者把该框架定位为通用域增量方案而非 KWS 专属）。
- **板级实测与真实部署**：用实测能耗/时延替换数据手册估算，并在真实 always-on 设备上验证固定周期重训的行为。
- **域类型扩展**：把混响、远场、信道失真、说话人自适应纳入域增量的定义与评估。
- **CL 机制细化**：类不均衡下的排练配比、原型漂移的在线检测、事件驱动的重训触发（替代计数驱动，压缩域变后的性能凹陷窗口）。
- **与联邦学习结合**：论文结论展望域增量学习在 TinyML 与联邦学习中跨异构传感器泛化的角色——多设备协同的域适应是该框架的自然延伸。
