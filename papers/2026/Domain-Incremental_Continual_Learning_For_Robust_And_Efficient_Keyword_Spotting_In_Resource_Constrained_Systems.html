域增量持续学习
让千级参数的 KWS 在设备上自己适应新环境

Domain-Incremental Continual Learning for Robust and Efficient Keyword Spotting in Resource Constrained Systems

作者：Prakash Dhungana, Sayed Ahmad Salehi —— 肯塔基大学（University of Kentucky）

发表：2026.01 · arXiv:2601.16158 · 端侧学习 / TinyML 方向

域增量持续学习灾难性遗忘重演缓冲 伪标签双门控INT8 量化训练Cortex-M4

一分钟版本

  • 问题：训练数据与部署环境之间系统性域漂移（新噪声/新说话人/新录音条件），精度最多退化 27%；云端重训有隐私、成本、无人值守三重不可行。
  • 方案：把模型压到 1.64k 参数，让 MCU 上能全参数更新（前作只能动分类器层）；运行时用「置信度门 + 原型距离门」双门控筛选有效样本当伪标签，每 1024 条样本触发一次重训（重演缓冲 + 增强缓冲 + 有效样本）。
  • 前端双级整数去噪（Haar 小波 VisuShrink + 特征域掩码），MFCC + LogMel 双路输入白拿 2.18 个点（97.45% → 99.63%）。
  • 结果：−10~10 dB 五档 SNR × 四类噪声全部 ≥ 91%；比 ODDL 最小模型少 93% 参数精度还高 3.6 个点，跑在单核 Cortex-M4 上。

§01 · 问题陈述

设备搬个房间，域就变了

现有方案的共同短板

方案更新范围验证条件硬件缺口
ODDL只重训分类器层仅 0 dB 单档GAP9 多核骨干冻结跟不上域漂移；假定部分噪声训练时已见过
MCUNetv3 系（Lin 等）特定层稀疏更新GPU 模拟—专有方案（QAS+TTE），离真实 MCU 有距离
TAP-SLDA只更新高斯原型——表示上限锁死在原型统计量
重演类 CL（iCaRL/GEM/DER）—类/任务增量—未与运行时伪标签结合用于域增量
核心问题：能否在 MCU 级参数预算（千级）内，构建不依赖人工标注、不需要并行加速器、−10~10 dB 宽信噪比都维持 ~94% 的域增量 CL 闭环？
五个子挑战：全参数可更新（否则域适应受限）· 可靠伪标签筛选 · 输入特征先可靠（去噪不可靠则分类和筛选一起崩）· INT8 上训练闭环 · 对抗遗忘。

§02 · 方法论

一个闭环：推理时攒样本，计数触发重训

设计巧思：隐层取第三层 Conv2D 输出（仅 160 字节，比前两层的 960/192 字节都省）；MAE 算原型距离 160 次运算（MSE 要 320 次）——原型比较发生在每条运行时样本上，这里的每次节省都乘以全部流量。

双门控：把无监督流变成高置信半监督流

两级去噪：不是冗余，各清一层噪声

第一级（波形域）：MAD = median(|d − median(d)|)/0.6745，阈值 τ = MAD·√(2 log N)，软阈值压制后重构、量化 [−128,127]。
第二级（特征域）：归一化 [0,1] → 时间轴/频率轴各自减均值 → 双轴二值掩码只保留高于均值的分量 → 按系数 α 重组：x_d = (1−α)(α·x_s·M_s + (1−α)·x_t·M_t) + α·x_n。直觉：背景噪声在两个轴上趋于均匀分布（减均值后只剩弱分量），语音谐波和瞬态高于均值得以保留。α∈[0.4,0.9] 全区间稳定。

§03 · 实验结果

−10 dB 也不下 91%，参数少两个数量级

设置：GSCD v2（Yes/No 二分类，干净测试 99.63% 双输入）；DEMAND 四环境（洗碗机/田野/办公室/车厢）× 五档 SNR（−10~10 dB），每环境 169,695 条评估样本；25 次 CL 重训迭代后的平均精度。目标硬件单核 Cortex-M4（TM4C123GXL）。

四环境 × 五档 SNR 全景（Table II）

读法：论文摘要称 −10 dB 下「各环境超过 94%」略偏乐观——实际 91.44~94.56，仅 TCAR 一项过 94%。但「压平衰减斜率」的主张成立：从 10 dB 到 −10 dB，最差环境只掉不到 4 个点。

系统级对比：参数-精度全景（Table IV）

关键读数：1.64k 参数 / 0.89M FLOPS，精度超过 ODDL 全部三档（比最小的 DSCNN-S 少 93% 参数还高 3.6 点）和 MCUNetv3。代价维度：95.11 ms 单样本时延高于 GAP9 的 6.74~32.95 ms，但硬件档位完全不同（单核入门 M4 vs 多核 GAP9），对 1 秒分析窗仍属实时；时延与能耗均为 ARM 数据手册估算值（非板级实测），「优化 M4」可把能耗 200.87 → 64.45 µJ。

消融：重训的收益藏在低 SNR（Table III）

三个发现：① 重训收益集中在低 SNR（−10dB +4 点以上；10dB 反而略降 98.03→94.31，域漂移本来就小时 CL 无增益）；② 小波去噪的价值要重训配合才兑现——无重训时它在 −10dB 反而损失 2.24 点（重度噪声下引入失真），有重训时反超，论文据此论证失真源于噪声且可被 CL 吸收；③ 谱去噪单独已很能打（两级中性价比最高的一级）。另：α∈[0.4,0.9]、P_th∈[0.70,0.85]、距离阈值∈[1.7,2.4] 三个超参全区间平坦（Fig 6-8）——不依赖精调。

§04 · 主要贡献

四条可以带走的东西

1新的域增量 CL 框架
运行时伪标签「有效样本」+ 重演缓冲驱动完整量化模型增量更新（而非仅分类器层），同步更新类原型——端侧域适应上限从分类边界推进到整个特征提取器。
2双级去噪嵌入特征管线
小波域（Haar-VisuShrink）+ 特征域（谱减+掩码+归一化）两级整数化去噪，同时保障分类精度与有效样本判定的特征可靠性。
3双特征输入分类器
MFCC + LogMel 并行流，干净数据 99.63%（比单输入高 2.18 点）——第二路特征借 MFCC 流水线中间产物零额外计算获得。
4宽条件验证 + 极致资源占用
−10~10 dB × 四类噪声全部 ≥ 91%；1.64k 参数、0.89M FLOPS，单核 Cortex-M4 可部署，比 ODDL DSCNN-M 少 98.81% 参数且精度更高。

§05 · 局限与展望

二分类边界与估算值

方法本身的技术局限

  • 二分类边界：双类原型、µ+nσ 阈值、各 64 条的均衡重演都按 Yes/No 设计；多类需重设计原型配比与逐类阈值。
  • 时延偏高且为估算：95.11 ms 对 1 秒窗是实时的，但对低延迟流式唤醒偏大；时延/能耗均出自数据手册估算而非板级实测。
  • 依赖重训按周期发生：两次重训之间遭遇剧烈域变存在性能凹陷窗口（小波去噪无重训时会引入失真）。
  • 隐层维度低：160/320 字节隐层决定原型表达容量上限；未做隐层位置/维度消融。
  • 可复现性缺口：算法 2 的逐元素梯度缩放步骤未解释动机；初始训练的优化器、轮数、QAT 配置均未报告。

实验设计的不足

  • 关键资源账缺失：重演缓冲容量（样本数/字节数）与总 RAM/Flash 占用未报告——这恰是端侧 CL 最核心的账。
  • 无遗忘度量：未报告 CL 后干净测试集精度（旧知识保住没有，无从判断）。
  • 对比口径未对齐：Table IV 的 94.31% 未注明噪声环境与 SNR（数值恰与 OOFFICE@10dB 一致，疑为该配置）。
  • 域定义偏窄：只用加性环境噪声模拟，未覆盖混响、远场、信道失真、说话人变化。
  • 无 CL 同台对比：TAP-SLDA、iCaRL 只引数字未直接对照；摘要 −10dB「超 94%」表述偏乐观。
值得跟进的方向：① 多类域增量扩展（KWS-35；作者把框架定位为通用方案，还列了 MNIST/CIFAR）；② 板级实测替换估算 + 真实 always-on 设备验证；③ 混响/远场/信道/说话人纳入域定义；④ 事件驱动重训触发（压缩域变后的凹陷窗口）+ 类不均衡排练配比；⑤ 与联邦学习结合——多设备协同的域适应是自然延伸。
