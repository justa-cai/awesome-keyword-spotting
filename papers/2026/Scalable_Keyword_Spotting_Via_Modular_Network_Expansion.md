# Scalable Keyword Spotting via Modular Network Expansion：冻结整个基座、外挂轻量扩展分支的端侧唤醒词无损扩容

- **作者/机构**: Viktor Khaymonenko, Dzmitry Saladukha, Aliaksei Rak, Alexander Rostov - Yandex（俄罗斯/白俄罗斯，嵌入式语音输入团队 Embedded Voice Input Team）
- **发表日期**: 2026.07
- **链接**: https://arxiv.org/abs/2607.19918
- **关键词**: keyword spotting（关键词唤醒）, modular network expansion（模块化网络扩展）, class-incremental learning（类增量学习）, catastrophic forgetting（灾难性遗忘）, parameter-efficient tuning（参数高效微调）, embedded deployment（端侧部署）, non-regression guarantee（非回归保证）

## 问题陈述

### 问题背景和领域痛点

关键词唤醒（KWS）是资源受限设备上免手操语音入口的核心部件，小模型必须在各种说话人和声学条件下长期保持准确可靠。但部署出去的产品不是静态的：新功能、新语区、新用户需求会不断要求往词表里加新唤醒词。这篇来自 Yandex 嵌入式语音输入团队的论文盯住的正是这个"出厂之后才发生"的更新场景，它有三个工业级痛点：

其一，原始训练数据拿不回来。出于隐私合规和存储成本，线上模型对应的训练音频在更新阶段往往不可用，任何依赖"回放旧数据"的方案直接出局。其二，全量重训算力昂贵，而且即便算得起，也极易在旧关键词上引入回归——用户已经依赖"停止"这个词大半年，一次 OTA 更新把它弄坏了，其严重程度远高于新词不好用。其三，端侧模型的增长必须严格受限：唤醒检测是常驻运行、固定时延的单检测器，不可能为每个新词挂一个独立大模型，也不可能接受推理时需要任务身份（task ID）来选分支的多柱结构。

论文把这个问题严格定义为类增量关键词扩展（class-incremental keyword expansion）：在原始训练数据不可用、模型增长严格有界、已出货检测器对旧关键词的输出和阈值判决规则对所有输入都必须精确不变这三重约束下，最大化新关键词的检出性能。

### 现有方法的具体不足

论文系统梳理了四条现有路线，每条都卡在至少一条约束上：

- **固定词表小模型**（CNN 系、SVDF 流式结构）：精度和时延/内存平衡最好，但扩词表就要重训加类别再平衡，更新随时可能在旧词上回归。
- **开放词表 / 查询式（QbE）与少样本度量学习**（原型网络等）：免重训、可加用户自定义短语，但在嵌入式设定下鲁棒性系统性落后于固定词表模型，尤其在高噪声和音近词（论文实验里 on/off、stop/go 这类对）区分上。更麻烦的是，模型一旦更新，旧词集上的稳定性能难以维持——在拿不到原始数据时尤其严重。
- **持续学习**：正则系（EWC、LwF）约束参数漂移，回放系（experience replay、生成回放）复述旧样本。但前者只是"软保护"——它降低遗忘概率，给不出任何严格保证，论文实验里 EWC 仍把核心词 FRR 从 2.71% 推高到 4.47%；后者前提是旧数据可存可复用，直接违反无 D1 设定。且 EWC 需要 D1 导出的 Fisher 信息，严格说也不满足无原始数据约束。
- **参数高效微调**（Adapters、LoRA）：可训参数确实少，但它们插在共享计算路径上，改了路径就改了旧关键词的 logits，结构上无法保证行为不变；要保留旧行为还得额外交推理算力。

最接近的近亲是渐进式神经网络（PNN）：冻结旧柱、加新柱带侧连接，天然防遗忘。但 PNN 是任务增量设定——推理时已知任务身份、知道该跑哪根柱子。本文面对的是一个始终在线、固定时延的单检测器，推理时没有任务标签可选分支，这是 PNN 结构无法直接搬来的根本原因。

### 该论文要解决的关键挑战

核心挑战可以一句话概括：如何让"非回归保证"来自构造（by construction）而不是来自正则化或复训运气，同时不让这份安全性把新词性能和推理开销拖垮。安全性最容易的达成方式是不动基模型只训新头（Head-Only），但论文实验显示其新词平均 FRR 高达 22.30%——冻结表示对新类判别力不够；另一个安全极端是独立训一个 10k 新模型并联（Ensemble，6.46%），但它完全不复用基模型的中间特征，10k 预算从头学太浪费。真正的甜点区在于：既要零风险地"偷用"基模型已学到的语音表示，又不能在计算图上碰任何会影响核心输出的东西，还要把参数/MACC 转换率压到比对标 PEFT 方法更低。

## 方法论

### 整体架构设计和设计动机

整体方案是"冻结基座 + 参数封顶扩展分支 + 独立新词头"三件套。

基座是一个约 150k 参数的小足迹 SVDF 风格架构：每个 Base（Encoder）Block 依次是 SVDF、批归一化（BN）、hard-swish 激活、dropout，编码器输出做时间池化后接核心分类头（Core Head），在 $\Y_1 \cup \{\emptyset\}$ 上出 logits 再 softmax。选 SVDF 系而非 CNN/RNN，动机是它是为流式低时延 KWS 设计的因子化结构（引 Alvarez & Park 2019、Nakkiran 2015 的秩约束拓扑），与 Yandex 的真实出货管线一致——这篇论文的方法论立场是"贴着部署管线做研究"，基座选型服从这一点。

扩展路径由 $L$ 个 Expanded Block 加一个新词头（New Head）组成，总新增参数（Expanded Blocks + New Head）封顶 10k，最终模型约 160k 参数。每个 Expanded Block 从冻结的 Base Block 激活上"搭线"（tap），与上一个 Expanded Block 的输出在通道维拼接，过一个轻量变换：小核时间维 Conv1D → BN → hard-swish。第一个 Expanded Block 是特例，只吃冻结编码器激活、没有上一个扩展输出，拼接退化为恒等。最后一个 Expanded Block 的输出做时间池化喂给 New Head，在 $\Y_2 \cup \{\emptyset\}$ 上出 logits。

为什么每个设计决策都这样选：

- **全冻结，连 BN 一起冻**：论文特意强调冻结"包括 BN 仿射参数和滑动统计量"。这是很多"冻结 backbone"实现会踩的隐形坑——只冻权重不冻 BN running stats，扩展训练阶段的 forward pass 仍会更新统计量，基座表示随之漂移，核心 logits 就变了，非回归保证瞬间失效。所以"构造性保证"的完整表述是：计算路径隔离 + 统计量隔离，二者缺一不可。
- **扩展变换用小核时间卷积而不是全连接或大核**：参数-算力转换率是本文反复暗线的问题。10k 参数预算下，每个 block 用小核 Conv1D 能把 MACC 压到远低于 Adapters/LoRA 的水平（详见实验对比），且时间卷积与基座的流式处理对齐。
- **块内 BN + hard-swish 复刻基座 block 配方**（引 MobileNetV3 的 hard-swish）：扩展分支保持与基座相同的归一化/激活动力学，减少两路特征分布的错配。注意扩展块内部的 BN 是新参数、只服务新路径，与被冻结的基座 BN 互不干扰。
- **时间池化收口**：最后一个 Expanded Block 的输出沿时间维池化后才进 New Head，与基座"编码器输出池化后进 Core Head"的收口方式对齐，保证两头在同样的时间聚合粒度上做判决，1 秒语音出一次词级判决。
- **双头独立 softmax 而不是合并成一个大头**：直觉做法是把新旧词拼进一个 $(|\Y_1|+|\Y_2|+1)$ 类的联合头，但联合头要么改核心 logits（违反式 (3)）、要么要求在新旧两套数据上联合校准 softmax 的归一化分母（拿不到 D1 就做不到）。两个各带背景类的独立 softmax 把归一化范围限制在各自标签集内，阈值校准也各自独立完成，正是无 D1 设定下唯一能落地的输出结构。单一背景标签 $\emptyset$（而不是每词一个负类）则是小足迹 KWS 的标准做法，背景类吸收全部非目标音频，避免负类爆炸稀释正类监督。
- **链式拼接（residual 风格）**：每个 Expanded Block 同时吃"冻结的底座特征"和"自己的前序状态"，让扩展路径能逐步建立起独立于底座词汇的序列状态，同时每层都被底座特征重新锚定，防止 10k 参数的小分支在 D2 上过拟合漂移。

### 核心算法的数学原理

**问题形式化**。设 $x$ 为输入语音，$\Y_1$ 为已部署核心词集，$\Y_2$ 为不相交的新词集（$\Y_1 \cap \Y_2 = \emptyset$），$\emptyset$ 为单一背景标签（"没有任何目标词"）。基模型 $f_{\text{base}}(x;\theta_{\text{base}})$ 在 $\mathcal{D}_1$（标签 $\Y_1 \cup \{\emptyset\}$）上训练；扩展阶段只拿到 $\mathcal{D}_2$（标签 $\Y_2 \cup \{\emptyset\}$），对 $\mathcal{D}_1$ 无访问权。目标是得到 $f_{\text{exp}}(x;\theta_{\text{base}},\theta_{\text{exp}})$：新增参数量小、只在 $\mathcal{D}_2$ 上训练、在 $\Y_1$ 上满足严格非回归、在 $\Y_2$ 上性能最大化。

**双头输出与恒等保证**。扩展模型输出两个独立 softmax：

$$p_{\text{core}}(y \mid x) = \mathrm{softmax}(\ell_{\text{core}}(x)), \quad y \in \Y_1 \cup \{\emptyset\} \tag{1}$$

$$p_{\text{new}}(y \mid x) = \mathrm{softmax}(\ell_{\text{new}}(x)), \quad y \in \Y_2 \cup \{\emptyset\} \tag{2}$$

由于 Core Head 的计算被冻结且不依赖扩展路径，对任意输入 $x$：

$$\ell_{\text{core}}^{\text{exp}}(x) \equiv \ell_{\text{core}}^{\text{base}}(x) \;\Rightarrow\; p_{\text{core}}^{\text{exp}}(y \mid x) \equiv p_{\text{core}}^{\text{base}}(y \mid x), \; \forall y \in \Y_1 \cup \{\emptyset\} \tag{3}$$

式 (3) 是全文的逻辑支点：非回归不是"实验上没观察到回归"，而是恒等式。

**训练目标**。只更新 $\theta_{\text{exp}}$，只吃 $\mathcal{D}_2$，交叉熵只加在 New Head 上：

$$\min_{\theta_{\text{exp}}} \; \mathbb{E}_{(x,y)\sim \mathcal{D}_2}\left[-\log p_{\text{new}}(y \mid x)\right] \tag{4}$$

注意 $p_{\text{new}}$ 自带背景类 $\emptyset$——新头必须自己学会拒绝，这是它能独立做阈值判决的前提。

### 关键技术创新一：构造性非回归（冻结基座 + 参数封顶扩展分支）

创新点本质是把"安全性"从算法问题降维成计算图拓扑问题。为什么这样做：正则化方法（EWC/LwF）的安全边界是概率性的，取决于超参和 Fisher 估计质量，对" unacceptable regression"这种产品级红线只能祈祷；回放方法需要旧数据；PEFT 改动共享路径。唯一在数学上不可违反旧行为的做法，是让旧输出在计算图上与新参数完全断开——式 (3) 的恒等性由此免费获得，不需要任何额外训练技巧。参数封顶在 10k（对 150k 基座约 6.7% 增量）则回应"模型增长严格有界"的部署约束：扩展预算是硬顶，不是软目标，所有加容量的方法都被拉到同一预算线下比较。

### 关键技术创新二：core-first 级联决策规则

论文的一个容易被忽略但很关键的洞察：**保住 logits 不等于保住产品行为**。已出货检测器对用户承诺的是"阈值判决规则"，所以必须连决策规则一起保留，于是设计核心优先（core-first）两段级联：

$$\hat{y}_{\text{core}}(x) = \begin{cases} y^*_{\text{core}}(x), & \text{score}^{\text{core}}_{y^*_{\text{core}}(x)}(x) > \tau^{\text{core}}_{y^*_{\text{core}}(x)} \\ \emptyset, & \text{otherwise} \end{cases} \tag{5}$$

其中 $y^*_{\text{core}}(x) = \arg\max_{y \in \Y_1} p_{\text{core}}(y|x)$，阈值 $\tau^{\text{core}}_y$ 沿用出货模型的原阈值，一个字节都不改。**仅当**核心检测器输出 $\emptyset$（拒绝）时才评估新头：

$$\hat{y}(x) = \begin{cases} \hat{y}_{\text{core}}(x), & \hat{y}_{\text{core}}(x) \neq \emptyset \\ y^*_{\text{new}}(x), & \text{score}^{\text{new}}_{y^*_{\text{new}}(x)}(x) > \tau^{\text{new}}_{y^*_{\text{new}}(x)} \\ \emptyset, & \text{otherwise} \end{cases} \tag{6}$$

级联的好处是双重的：对旧词，判决路径与出货系统逐比特一致（式 (3) 保证分数一致 + 式 (5) 保证规则一致，合起来才是完整非回归）；对新词，新头只需在 $\Y_2 \cup \{\emptyset\}$ 这个小标签空间上建模，10k 参数才够用。代价是系统决策顺序化——新词检测排在核心检测之后，这带来一个论文未量化的耦合：如果核心头在新词语音上误触发（输出非 $\emptyset$），新头永远得不到评估机会，新词 FRR 存在一个由核心误授行下界托底的理论地板，论文未报告这个交互效应的大小。

### 关键技术创新三：链式特征复用与最优复用深度

Expanded Block 的设计回答"从冻结基座偷什么"：每个 block 把冻结 Base Block 激活与前一扩展状态沿通道拼接后过 Conv1D→BN→hard-swish。复用深度 $L$ 不是拍脑袋，而是消融实验（图 3）给出的：只搭浅层（1–3 个 block）新词 FRR 高，语义抽象不足——浅层特征偏 acoustic，音近词分不开；扩到 4 个 block 时 FRR 中位数最小；再往上性能平台化甚至轻微退化，因为基座最深层已过度特化到核心词表 $\Y_1$，迁移价值有限。这个"浅了不够语义、深了过度特化"的倒 U 形是迁移学习的经典权衡在 KWS 扩展上的具体体现，最终全文采用 4-block 配置。论文同时指出 Ensemble 基线的根本缺陷正在于复用深度为零：完全不碰基模型中间特征，同样 10k 预算要从随机初始化学起。

### 与现有方法的技术差异

和各路线的本质区别可以列成一个矩阵：Full Finetune 改路径、改输出，无任何保证；EWC 改路径，软保护，且违反无 D1（需要 Fisher）；Adapters/LoRA 改共享路径，无保证，且同参数预算下 MACC 更高；Ensemble 不改路径但零特征复用；PNN 保证不遗忘但要求推理时已知任务身份；本文方法不改路径、复用中层特征、推理时是单检测器无任务标签、参数和 MACC 双双封顶。与 Head-Only 的关系尤其干净：Head-Only 就是本文方法取 $L=0$ 的退化情形，这使消融谱系天然连续。

## 实验结果

### 使用的数据集及其规模

主实验在 Google Speech Commands v2（GSC）官方 train/validation/test 划分上做。目标词表是标准 10 命令集 {left, right, on, off, stop, go, up, down, yes, no}，GSC 中所有其他词加静音段折叠为背景标签 $\emptyset$。扩展任务用五个留出对来消除单一关键词选择的敏感性并覆盖不同混淆模式：{left, right}、{on, off}、{stop, go}、{up, down}、{yes, no}——每一对都是易混命令对。每个任务中，一对命令构成新词集 $\Y_2$，其余八个命令构成部署核心集 $\Y_1$；基模型在 $\mathcal{D}_1$（GSC train 限制到 $\Y_1 \cup \{\emptyset\}$）上训练，扩展只用 $\mathcal{D}_2$（限制到 $\Y_2 \cup \{\emptyset\}$），无 $\mathcal{D}_1$ 音频访问权。论文未明确 $\Y_2$ 的音频在 $\mathcal{D}_1$ 中（及 $\Y_1$ 音频在 $\mathcal{D}_2$ 中）是被折叠为背景还是被剔除，这个细节影响背景分布构成，属于未报告项。

关键实验设计：负样本校准不用 GSC 自身（其背景词分布偏窄、有偏），而用 Mozilla Common Voice v17（CV）作为纯负样本语料；所有报告结果中正样本来自 GSC test，FAR 校准负样本来自 CV test。这模拟了真实产品里"负样本必须远比测试集丰富"的工程事实。

特征与训练配置：16 kHz 单声道，40 维 log-Mel 滤波器组，25 ms 窗 / 10 ms 跳；训练时在 log-Mel 特征上直接施加 SpecAugment（时间掩蔽 + 频率掩蔽）提升信道和说话风格鲁棒性；Adam 优化器配余弦学习率调度；基模型在 $\mathcal{D}_1$ 上训 40 epoch，扩展阶段在 $\mathcal{D}_2$ 上训 10 epoch。扩展训练量小是有意为之——新词数据天然稀缺。

### 评估指标的定义和选择理由

指标是**固定误授率工作点下的宏平均拒识率**（macro FRR @ 1% FAR）。选择理由直接对应产品逻辑：唤醒系统的运营契约是"每天误唤醒次数封顶"（FAR 预算），在此预算下比较漏唤醒率（FRR）才有意义，滑动阈值比曲线下面积更贴近部署。具体做法：对每个关键词 $y$，在 CV test 分区上校准阈值 $\tau_y$ 使 FAR 恰为 1%（核心词用 Core Head 分数，新词用 New Head 分数），然后在 GSC test 上算 FRR，再对评估集内关键词做宏平均。统计稳健性上，每个（方法，词对）配置跑 8 个独立随机种子，报告样本均值和 95% 置信区间 $\bar{x} \pm t_{0.975,7}\, s/\sqrt{8}$。这套协议（外部负样本校准 + 固定 FAR 工作点 + 多种子 t 区间）本身比多数 GSC 论文只报 accuracy 的做法更接近工业验收。

### 与基线方法和SOTA的详细对比

**开销对比（表 1，1 秒语音在部署 core-first 管线下的最坏情况计算量）**：基座 150K 参数 / 15.08M MACs（1.00×）；Full Finetune 与 EWC 不加参数，同为 15.08M；Head-Only 151K / 15.16M（1.01×）；Ensemble 160K / 16.14M（1.07×）；Adapters 160K / 18.45M（1.22×）；LoRA 160K / 20.52M（1.36×）；本文方法 160K / 16.34M（1.08×）。同样 10k 新增参数，本文的 MACC 增量只有 1.26M，而 Adapters 是 3.37M、LoRA 是 5.44M。论文没有直接解释这个差距的机理，合理推断是：Adapters/LoRA 的模块插入在并行 top-L 分支的每一层、在满通道宽度上做变换，而本文的扩展块是链式的、用小核时间卷积，参数-算力转换率更低（此为笔者基于结构描述的解读，论文未展开）。

**核心词表现（表 2 Core Phrases）**：基模型平均 FRR 2.71%（±0.12），各对在 2.37%–3.29% 之间。Full Finetune 把核心词 FRR 推到平均 69.08%（±1.98），最惨的 {left, right} 对高达 82.94%——灾难性遗忘的教科书式演示。EWC 缓解到 4.47%（±0.18），仍显著差于基线，且它依赖 D1 导出的 Fisher 信息，违反严格无 D1 设定（论文取 $\lambda = 5\times10^5$）。所有冻结核心路径的方法（Adapters/LoRA/Ensemble/本文）核心词结果与基模型逐比特一致，表中省略。

**新词表现（表 2 New Phrases，平均 FRR）**：Full Finetune 2.35%（±0.27）最好但如上不可用；Head-Only 22.30%（±4.27）且方差巨大（{left,right} 上 ±16.44），证明冻死表示完全不够；Adapters 8.05%（±0.35）；EWC 7.95%（±0.64）；Ensemble 6.46%（±0.42）；LoRA 6.41%（±0.66）；**本文 4.37%（±0.33）**。相对参数匹配的独立模型基线（Ensemble），绝对提升 2.09 个百分点，相对提升约 32%。逐对看，本文在全部五个词对上都优于或持平于所有满足部署约束的方法：{left,right} 6.69（±1.04）、{on,off} 2.68（±0.39）、{stop,go} 4.56（±0.86）、{up,down} 4.57（±0.73）、{yes,no} 3.36（±0.38）。一个诚实的细节：EWC 在 {left,right} 对上（5.44%）优于本文（6.69%），但它以违反两条约束（改核心路径 + 需要 D1）为代价；本文最弱的也是 {left,right} 对，提示扩展分支在音近新词对上仍有空间。

**统计可分性**：看置信区间而不是只看点估计。本文（4.37 ± 0.33）与 LoRA（6.41 ± 0.66）、Ensemble（6.46 ± 0.42）、EWC（7.95 ± 0.64）、Adapters（8.05 ± 0.35）的区间完全不重叠，与最强合规基线 LoRA 的差距（约 2 个点）在 8 种子协议下是稳健的，不是随机波动。反观 Head-Only 在 {left,right} 上的区间（42.55 ± 16.44）宽到没有工程意义——冻死表示后新头学习对种子极度敏感，这本身就是"零复用不可行"的证据。Full Finetune 的核心词区间（{up,down} 上 54.33 ± 13.55）同样极宽，说明灾难性遗忘的深度不可预测，这正是产品侧"不可接受回归"的技术根源。

**最坏情况口径的含义**：表 1 特意标注是"部署 core-first 管线下的最坏情况计算量"，即假设核心头始终拒绝、扩展路径每个分析帧都要执行。对常驻在线、时延必须固定的唤醒检测器，容量规划必须按最坏情况做，平均情况省下的算力没有意义——这就是为什么论文用 16.34M（1.08×）这个口径而不是平均值来跟 Adapters/LoRA 的 18.45M/20.52M 对比。顺带一提，实际平均开销通常低于最坏值（新头仅在校核拒绝后评估），但论文未报告平均口径的数字。

### 消融实验的发现

唯一的消融是扩展深度 $L$（图 3，$\Y_2 = \{left, right\}$）：搭 1–3 个 block 时新词 FRR 高（语义抽象不足）；4 个 block 时 FRR 中位数最小；继续加深平台化或轻微退化，因为基座最深层过度特化于核心词表、迁移价值有限。结论是 4-block 为最优配置并用于全部主对比。这个结果与表示学习里"中层特征迁移最好"的一般规律吻合：太浅只有声学细节，太深绑定源任务的决策边界——对 KWS 而言源任务的决策边界就是八个核心命令，新词要用恰恰得绕开它。值得注意的跨方法模式是：{left,right} 是几乎所有方法的最难词对（Head-Only 42.55%、Ensemble 8.77%、EWC 5.44%、本文 6.69% 均为各自最差），而它在消融中被选作唯一实验对象，说明作者特意挑了最难场景做深度分析，结论偏保守而非偏乐观。论文未报告其他维度的消融（如扩展块通道宽度、卷积核尺寸、扩展训练 epoch 数、新头温度等），也未报告 $L$ 在其他词对上是否同为 4 最优。

## 主要贡献

1. **把端侧 KWS 扩词的非回归保证从概率问题变成拓扑问题**：全冻结基座（含 BN 仿射参数与滑动统计量）+ 计算图隔离 + 独立新头，使旧词 logits 与阈值判决规则对所有输入恒等（式 (3)+(5)），保证"由构造成立"，这是对 EWC/LwF/PEFT 路线的结构性替代。
2. **在 10k 参数硬预算内同时做到新词性能和推理开销双优**：新词平均 FRR 4.37%，比参数匹配的独立模型基线低 2.09 个绝对点，比 Adapters/LoRA 分别低 3.68/2.04 个点；最坏情况 MACs 16.34M，显著低于同预算的 Adapters（18.45M）和 LoRA（20.52M）。
3. **core-first 级联决策规则**：明确指出"保 logits ≠ 保产品行为"，把出货检测器的阈值规则原样嵌入扩展系统的推理管线，补全了决策级非回归，且让新头只在核心拒绝时才被评估。
4. **特征复用深度的定量刻画**：给出"浅层语义不足、4 层最优、深层过度特化"的迁移深度权衡，为后续模块化扩展工作提供了可复用的设计先验。
5. **一套更接近工业验收的评测协议**：外部负样本语料（CV v17）校准阈值、固定 1% FAR 工作点报宏 FRR、五组留出易混词对、8 种子 t 置信区间。

## 局限性与展望

### 方法的技术局限性

- **非回归保证覆盖的是核心词集，不是系统整体误授率**。扩展系统在原来会输出 $\emptyset$ 的音频上现在可能接受新词，系统级总 FA 预算随词表增长而膨胀；论文只把每个新词阈值各自校准到 1% FAR，未分析合并后的系统级 FAR 变化（未报告）。
- **级联引入核心-新词耦合下界**：新头仅在校核检测器拒绝时才被评估，若核心头在新词语音上误触发，新词必然漏检；这一交互对新词 FRR 地板的贡献论文未量化。
- **每次扩展的容量是独立预算**：10k/次、单次只加一对词。连续多轮扩展下参数是否线性累积、扩展块之间是否也需要复用，完全未探索（作者自己列为未来工作）。
- **10k 预算是硬顶而非性能最优解**：摘要明确方法在 10k 预算内工作，更大的扩展预算或更大的新词集（一次加多于 2 个词）下的行为未报告。
- **仅报告 MACs**：无实际硬件时延、SRAM/Flash 占用、功耗测量（均未报告），对"固定时常常驻检测器"的部署主张而言这是缺一环的。

### 实验设计的不足

- **数据面窄**：全部结论建立在 GSC v2 的 10 命令、1 秒切分音频上，无真实产品规模数据、无远场/多信道/强噪声条件测试，而论文动机恰恰来自 Yandex 的出货产品（团队此前发表过多信道噪声 KWS 工作，本文反而未接上）。基座在真实部署词汇上的规模也未报告。
- **基线配置单一**：Adapters/LoRA 的 L 和秩被刻意配置为匹配本文的计算量而非各自调优，EWC 只取单一 $\lambda = 5\times10^5$ 无扫描；开放词表/少样本路线（原型网络等）只在相关工作里定性讨论、未进实验对比。
- **消融单薄**：只有扩展深度一个维度，且只在 {left,right} 一对上做；扩展块内部结构（通道数、核宽）、训练轮数、新头容量都没有消融。
- **背景分布细节未交代**：$\mathcal{D}_1$ 与 $\mathcal{D}_2$ 中彼此命令词的音频是折叠为 $\emptyset$ 还是剔除未说明，影响新头学到的背景分布。
- 另一处需说明：论文附有生成式 AI 使用披露（ChatGPT GPT-5.2 用于英文润色，技术内容作者负责），不影响技术结论。

### 未来可能的改进方向

- **多阶段序列扩展**（作者明确指出的方向）：新词集逐批追加，重点研究扩展路径的参数复用与累积，避免每轮线性加 10k；这直接决定方法能否支撑产品级词表长期演化。
- **去除核心-新词耦合**：研究让核心头在新词语音上的误授行可控（例如用 $\mathcal{D}_2$ 上的核心头行为做诊断），或把级联改为并行打分 + 全局阈值分配，量化系统级 FAR 预算的分配问题。
- **真机验证**：在目标 DSP/MCU 上报时延、内存、功耗，把 16.34M MACs 的纸面优势落到部署证据。
- **更难的评测面**：远场混响、多说话人、跨语区负样本、一次加多个新词，以及与开放词表/少样本方法的正面实验对比，才能回答该方法与灵活性路线的真实边界。
- **扩展深度的自动化**：把"4 层最优"从人工消融变成可学习/可搜索的选择（类似神经架构搜索搭线位置），适配不同基座和新词特性。

## 术语速查

- **SVDF**：单值分解滤波器，把全连接分解为低秩两阶段因子化结构，面向流式低时延 KWS 的经典层型。
- **FRR / FAR**：拒识率（说了没唤醒）/ 误授率（没说却唤醒）；固定 FAR 比较下限 FRR 是唤醒系统标准评测姿势。
- **macro FRR**：对评估集内每个关键词分别算 FRR 后取算术平均，小类不受大类样本量稀释。
- **EWC**：弹性权重固化，用 Fisher 信息对重要参数加二次惩罚的正则式持续学习方法。
- **LoRA / Adapters**：参数高效微调两大家——低秩旁路矩阵 / 瓶颈插件模块，均改动共享计算路径。
- **PNN**：渐进式神经网络，冻结旧任务柱、新任务加柱带侧连接，依赖推理时任务身份。
- **non-regression by construction**：靠计算图隔离（而非正则/数据回放）使旧行为在数学上恒等不变的保证方式。
- **core-first decision rule**：核心优先级联判决，先跑旧检测器、其拒绝时才评估新头的推理规则。
