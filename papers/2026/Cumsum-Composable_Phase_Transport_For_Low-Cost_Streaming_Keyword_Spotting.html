Cumsum-Composable Phase Transport
用前缀和可组合的相位传输构建低成本流式关键词检测

Cumsum-Composable Phase Transport for Low-Cost Streaming Keyword Spotting

作者：Mahesh Godavarti（A Carrot, Inc · 独立研究者）

发表：2026.07 · arXiv:2607.20086 · 自称 draft（阶段性报告）

相位传输前缀和 cumsum流式推理 酉旋转状态空间模型的替代Speech Commands v2

一分钟版本

  • 问题：一秒左右的短命令 KWS 上，SSM「渐进线性」的大 O 优势被实现常数因子吃掉——最普通的 torch.cumsum 比选择性扫描的 Triton 内核快 3.2~4.5 倍（Table 5）。
  • 方案：把时序聚合原语换成「酉相位传输 + 前缀和 + 窗口差分」三件事——训练用一次 torch.cumsum（批式），推理用一步前缀更新（流式），两者数学上精确等价（命题 1，证明只有一行）。
  • 为什么必须「酉」：衰减式记忆写成前缀形式会出现 ρ−τ 尺度爆炸；酉旋转的逆保持范数恒一，前缀累加器数值良态——遗忘不放在传输里，外置到读出端（硬窗口/块衰减）。
  • 结果：24.8K 参数 96.8%、最强 97.3%，与受控紧凑 CNN 基线（97.1%）相当；匹配对比下比 scan 模型延迟低 42%、精度还高 0.49 点，且零自定义内核。

§01 · 问题陈述

渐进线性的大 O，救不了一两百帧的序列

流式语音系统的核心矛盾：必须在严格的延迟和成本约束下持续保留时间维度上的证据。KWS 是这矛盾最尖锐的场景——音箱、耳机、可穿戴设备常年常驻监听，单帧延迟、内存、能耗都极度敏感，又不允许漏检。现代状态空间模型（S4/S5/Mamba）用紧凑递归状态替代注意力的两两关注，被视作流式语音的有力候选；但作者指出，在一秒左右的短命令上，实际的权衡完全不同——一条短命令是有限的局部模式，紧凑 CNN 早已能很好映射到商用硬件；一个必须依赖 scan 内核的 SSM，其线性复杂度优势在序列只有一两百帧时，会被实现层面的常数因子劣势彻底吃掉。

硬数字：在最普通的序列原语层面，扫描内核就要付出三倍以上的墙钟代价，且需要维护非标准自定义内核代码。这就是标题「低成本」三个字指向的痛点——不是模型表达力，而是训练与推理在商用 GPU（Tesla T4）上的真实开销。

更深一层的不足：衰减递归破坏前缀表示

「训练用并行批算、推理用流式递归」这条最省事的路径，对衰减模型天然不友好：指数衰减记忆改写成前缀和形式，前缀累加器里会出现对衰减因子的除法（ρ−τ），有限精度下产生尺度分离、溢出风险和低位信息丢失——训练与流式推理两套实现之间存在数值上的裂缝。

前端两条路各有短板

FFT + log-mel 是强归纳偏置（前端实验之首 97.1%）但非可学习；LEAF 类学习前端依赖卷积和非瞬时滤波器；原始波形 Conv1d 只有 91.0%——同等参数预算下直接从样本学习明显吃亏。

四条挑战：(1) 时序原语的批式训练形式与流式推理形式精确等价（不是近似）；(2) 等价性建立在数值良态的结构假设上；(3) 精度与紧凑 CNN 基线有竞争力、参数同量级（2~3 万档）；(4) 不加自定义扫描内核做到更低延迟。

§02 · 方法论

三个式子撑起的全部数学骨架

主架构（表 1）：固定 mel 前端胜过学习前端（附录表 11–14），所以最强模型把 cumsum 放在 mel 之后而不是替换 mel。取模读出让判别依据对相位旋转不变、落在能量包络上，与 max 池化配合适合不定时对齐的命令模式。

直觉：什么是「相位传输」

为什么必须「酉」：衰减传输的数值反例

酉传输：Ut−1 = Ut*，‖Ut−1z‖ = ‖z‖ → 前缀各项与投影值同一数值尺度。
反例：取衰减传输 At = ρtUt（0<ρ<1）套同样前缀形式，累加器里会出现 Aτ−1zτ = ρ−τUτ−1zτ —— 精确算术下最终读出能抵消缩放，但前缀状态本身包含对越来越小的数的除法：有限精度下尺度分离、溢出、低位丢失。遗忘因此被外置——硬窗口减法或块级几何加权（式 6），而不是衰减在传输里。

紧凑化配方：小窗 × 深堆 × 权重绑定

读法：cumsum 应作为带非线性门控的局部时序构件使用，而非一个大而无差别的累加器。叠加权重绑定（各层共享投影与 GLU，仅频率和 BN 独立）：82,252 → 24,012 参数（≈3.4×），96.3% → 95.2%——「重复局部传输 + 共享投影」本身就是紧凑时序混合器。

§03 · 实验结果

精度打平紧凑 CNN，延迟低四成

设置：Google Speech Commands v2（12 类），本地训练集约 36K 样本（少于社区常用 85K 划分——绝对数字与外部文献不可直接横比）；Tesla T4 + PyTorch 2.6；Adam lr 10⁻³，batch 128；全部单种子。

精度-参数全景（Table 2）

关键读数：绑定 51.6K 参数达到与 160K 未绑定模型同值的 97.3%（省 3.1×）；最干净的效率点 24.8K 参数 96.8%，与 25.6K 的 CNN 基线（97.1%）几乎重叠——cumsum 可组合原语在精确流式前缀表示下与受控 CNN 精度相当。

匹配对比：cumsum vs scan（Table 4）

最有解释力的发现：scan 模型学到的衰减值隐含 3–21 帧有效窗口——学习型递归记忆在这个任务上本来就收敛成短局部滤波器，而硬窗口 cumsum 直接供给了这个短记忆。这是「有限记忆假设」的直接证据。注意匹配基准绝对精度（94.8%）低于主表 97.3%——采用了不同的 hop/宽度/epoch 组合，论文未拆解差距来源。

前端消融的信息量（附录）

学习相位 + 实虚部信道：hop 400 下 90.8% → 93.6%（冻结 mel 相位 92.0% → 94.0%）——滑动 cumsum 的幅度是更噪的谱估计，相位信道把窗内相位信息交给下一层补回来。对照：Hann 加窗卷积滤波器组反而最强（95.7%）且不需要实虚部——因为其幅度谱估计更干净，反衬 cumsum 前端的幅度噪声。

cumsum 前端的工程优化

原始波形 cumsum 前端经内存布局优化（连续 (B,N,T) 布局、先索引步进位置）：第一层单例延迟 5.8 ms → 284 µs，最终 337 µs，与 FFT+log+嵌入的 359 µs 打平——同一原语可以前移到 mel 之前，输出流式声学帧。

§04 · 主要贡献

六条可以带走的东西

1形式化相位传输层
有限窗口表示可由累加和计算、且具有精确流式等价形式（式 1–3 + 命题 1）。
2阐明酉传输的结构作用
逆传输范数恒一 → 前缀因式分解数值良态；遗忘外置到读出端——「在哪里实现遗忘」的完整答案。
3配套流式前端
音频转低延迟 mel 或学习谱帧，每帧一次 cumsum 状态更新，从有限窗口状态发出滚动关键词分数。
4精度竞争力证据
堆叠局部 mel+cumsum 与紧凑 CNN 基线相当，最高 97.3%（表 2）。
5参数效率证据
绑定局部 cumsum 层小参数量保持强精度：24.8K 参数 96.8%。
6匹配系统基准
对学习衰减 scan 的匹配对比：更低延迟、相当精度、零自定义内核（表 4、5）。
宏观视角：这篇论文把「SSM 式紧凑流式状态」与「最便宜的原语（前缀和）」焊接在一起，并指出焊接处的数值条件性由酉性保证——为短时流式语音任务提供了介于 CNN 与 SSM 之间的第三选择。

§05 · 局限与展望

单种子、单数据集、单硬件——外推需谨慎

方法本身的技术局限

  • 短记忆假设的适用边界：整个设计前提是 KWS 只需有限局部记忆（scan 学到 3–21 帧窗口佐证）；长关键词、上下文自适应、连续大词表识别下 W 有限的硬窗口是否够用未验证。
  • 硬窗口不连续：旧项退出窗口时表示跳变（论文自认）；块衰减是理论替代但主实验未采用，平滑遗忘收益缺数据。
  • 固定频率振荡器表达上限：无法像 Mamba 按输入内容选择记忆；表达力换实现简洁性的取舍在更难任务上是否划算未检验。
  • 大批次显存压力：cumsum 前端物化全分辨率复旋转张量；融合算子列为未完成的下一步。
  • 反向传播未分析：只论证了前向等价，长序列（完整 ASR）下 cumsum 反向的内存与稳定性没有分析。

实验设计的不足

  • 全部单种子，无方差报告；0.49 点的 cumsum 对 scan 优势缺乏显著性支撑。
  • 本地 36K 训练集，少于社区常用 85K 划分；97.3% 等绝对数字与外部文献不可直接横比。
  • 基线面窄：只与本地受控 MelCNNMaxPool 比；未对 DS-CNN、TC-ResNet、BC-ResNet、小 Conformer 等标准优化基线。
  • clip 级指标：缺误接受/误拒率、检测延迟等触发式指标——论文自己诚实标注的缺口。
  • 单 GPU 环境：scan 基线用本地研究实现而非优化官方内核，未必代表 scan 最优水平；自称 draft。
值得跟进的方向：① 三种子复跑 + 扩展到 CPU / Apple Silicon / 嵌入式目标的墙钟-显存-吞吐剖析；② 与标准优化基线（DS-CNN / TC-ResNet / BC-ResNet / 小 Conformer）对比；③ 事件触发式命令起始检测，在延迟和稀疏触发上检验；④ 扰动套件（音高偏移 / 混响 / 编解码 / 说话人留出）；⑤ 块衰减转正并量化平滑遗忘收益；⑥ 不同层不同 hop 的多分辨率记忆金字塔——比单纯加宽加深更符合该架构本性的扩容路径。
