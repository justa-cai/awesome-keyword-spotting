给权重矩阵立规矩：低位移秩结构化变换，10-50 倍压缩靠代数不靠砍

低位移秩 LDR 矩阵Toeplitz / Vandermonde / Cauchy 家族O(n²)→O(nr) 参数FFT 乘法 O(n log n)从头训练非压后处理
Structured Transforms for Small-Footprint Deep Learning · Vikas Sindhwani / Tara N. Sainath / Sanjiv Kumar（Google）· 2015 · arXiv 1507.02593
一句话：用低位移秩矩阵（∇_{F,G}(A)=FA−AG 的秩 r ≪ n → 只需 O(nr) 参数）替换密集权重——Toeplitz 等结构家族 + 直接参数化端到端训练：10-50× 参数压缩、FFT 乘法加速、精度保持，「压缩 = 引入结构先验」的代数流派代表作。

1问题：2015 年的压缩困境

TL;DR
  • 语音 DNN 数百万参数——移动/嵌入式内存装不下。
  • 剪枝/量化常需重训、压缩比不够、稀疏结构本身也要存储成本。
  • 目标：10-50× 压缩 · 精度保持 · 不牺牲表达能力——换一条路：从参数化本身动手。
图 1 · 机制全景：压缩困境 → LDR 的位移定义与结构矩阵家族 → 替换与训练四步 → 关键数字。

2机制：Toeplitz 的「常对角线」几何

位移结构

∇_{F,G}(A) = FA − AG 的秩 r 远小于 n——A 可从低秩分解 G·Hᵀ 恢复，O(nr) 参数表达 n×n 矩阵。

结构家族

Toeplitz（常对角线 · O(n)）· Vandermonde · Cauchy · Hankel——全是 LDR 特例；Toeplitz-like 是一般化。

双降收益

参数 O(n²)→O(nr)；Toeplitz 乘法走 FFT O(n log n)——存储与计算同时降。

RNN 收益最大

循环权重矩阵是网络里最大的——替换成 LDR 压缩比最高。
图 2 · 左：密集矩阵每格独立（n² 自由度）；右：Toeplitz 沿对角线共享参数（n 个自由度表达整张矩阵）——信息藏在结构里而非格子里。
∇_{F,G}(A) = FA − AG = GHᵀ（秩 r） A 用 O(nr) 参数表示 Toeplitz: y = A·x 经 FFT 在 O(n log n) 完成
人话：普通矩阵像一张每个格子都不同的表格，要存 n² 个数。Toeplitz 矩阵像「斜条纹壁纸」——沿对角线的格子全是同一个值，只要存 n 个数就能画出整张表。低位移秩是给「这张表有多规则」定一个可度量的指标，规则程度越高，要存的越少。

图 3 · 五维对比表——结构化路线 vs 剪枝/量化路线的哲学差异：「先给矩阵立规矩再训」 vs 「训完再删/再压」。

4边界：结构先验的天花板

结构即天花板

Toeplitz 先验假设权重有平移结构——学不到的结构硬套会限表达力（r 的选取是折衷）。

实现复杂度

FFT 乘法与位移参数化在通用框架里没有现成算子——工程落地成本高于量化。

r 的选择靠经验

位移秩逐层怎么定——没有自动搜索（后继工作接手）。

被后来者盖过

depthwise/低秩/量化的组合在工程上更顺手——结构化变换未能成为主流。
图 4 · 边界四条 + 谱系坐标：思想遗产——「权重的冗余可由代数结构描述」；SVD 低秩（others №3）是特例化、cFSMN 低维投影（01 期）是投影版、LR-RNN 一脉相承；工程上 depthwise 赢了落地，但结构化参数化思想活在一切高效架构里。

5判断：能带走的三句话

JUDGEMENT

压缩有两条哲学：「训完再压」（剪枝/量化）与「先立规矩再训」（结构化参数化）——后者把先验写进参数空间，训练全程在低维流形上进行；没有重训环节，但规矩错了天花板也低。

参数的「自由度」不等于「个数」：密集矩阵 n² 个参数但有效自由度可能远低——识别数据的内在维度并用紧凑参数化对齐它，是所有高效架构（卷积/循环/低秩/结构化）的共同本质。

工程可落地性往往决定学术路线的胜负：结构化变换数学上更优雅，但量化/depthwise 有现成算子与工具链——好思想的扩散速度受工程摩擦力制约，这是读「被埋没的好论文」时最该带的眼镜。
