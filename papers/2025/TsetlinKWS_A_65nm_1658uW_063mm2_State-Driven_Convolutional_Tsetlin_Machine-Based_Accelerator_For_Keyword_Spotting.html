TsetlinKWS
状态驱动架构：用确定性稀疏同时吃下数据复用与稀疏利用，907k 次与门跑完一次推理

TsetlinKWS: A 65nm 16.58µW 0.63mm² State-Driven Convolutional Tsetlin Machine-Based Accelerator for Keyword Spotting

作者：Baizhou Lin、Yuetong Fang（共同一作）等 —— 南安普顿大学 × 港科大（广州）× 纽卡斯尔 × UCL

发表：2025.10 · arXiv:2510.24282 · RTL 与流程开源

Tsetlin Machine算法-硬件协同设计状态驱动架构 OG-BCSR 压缩MFSC-SF 特征65nm 流片

一分钟版本

  • 范式定位：Tsetlin Machine 用命题逻辑 + 学习自动机替代神经网络——布尔文字输入、子句做模式匹配、推理只有与/求和/比较无乘法、训练无反向传播。但 TM 在语音上从未进过标准基准（原版 9 类就掉到 80.5%）。
  • 架构机会：CTM 训练后 include 的 TA 仅约 1%（确定性稀疏）——稀疏模式不随输入变化。数据驱动架构（脉动阵列）吃复用不吃稀疏、事件驱动（SNN）吃稀疏但不规则——状态驱动把稀疏在「状态」层面预先展开调度，两样同时拿。
  • 算法突破：MFSC-SF 特征（删 DCT——与谱卷积冲突；删 LOG；拼谱通量补充动态信息，+4 pp）+ 64×7 谱卷积核 → CTM 首次在 GSCD 12 类拿 87.35%（对 BWN 87.9% 基本持平）。
  • 硬件结果：65nm / 0.63mm² 核 / 0.7V 16.58µW（外推）——批量式内部推理核功耗比 22nm 双手（归一化后 57.6/65.2µW）至少降 4.8 倍；运算量 907k AND 全场最少（少于帧式的 980 万/930 万归一化）。
  • 代价的诚实清单：精度五款垫底（低 2.0~5.7 pp）；模型 SRAM 占总功耗 42%；训练只敢加 20–40dB 轻噪（单层逻辑模型处理不了高噪声）；0.7V 功耗是外推非实测。

四个缺口：算法 / 架构 / 压缩 / 特征

§02 · 方法论

特征侧救精度 + 存储侧吃稀疏 + 架构侧预展开

动态均值阈值：th' = th + x_new − x_old 批 64 用右移 6 位代替除法 · 两周期流式更新 SF（变化量·增益不敏感）→ 固定阈值 1024 分位数分箱在高度不均衡音频上引入量化误差 → 弃用 推理原理：confidence_k = Σ_j w_kj · C_kj(X)，ŷ = argmax_k —— 只有逻辑与 / 求和 / 比较，无浮点乘法 谱卷积核 64×7：64 维系数全覆盖 + 7 个时间片——单层模型小核注意力不够（64−7+1=58 滑窗，恰好对应 PE 阵列的 58）；滑动展开 = 58×1 PE 阵列，每 PE 一个与门

状态驱动的四步推导（图 12）：① 按 included TA 行索引读特征图整行；② 按列索引选出覆盖位（滑动文字数据，长度=窗口数）；③ 每个 included TA 的滑动数据按窗做与；④ 任一窗为 1 → 子句满足输出权重。excluded TA 是 don't care 直接跳过——存储访问全部确定性顺序访问，不需要稀疏 NN 的索引模块与交集策略。

SynOps ≠ 这里；这里的账是 AND：每次推理 907k 次 2 输入与门等效——表 I 脚注 c 把 16bit 加 / 8×8 乘 / 32bit 加统一折算，跨范式同尺
压缩侧的账：TA 动作矩阵 180KB → OG-BCSR（块索引跳空块 + Blossom 最大权匹配两两分组 + 直接行索引免指针）→ 19.9KB（9.84×）。分组把「多个子句的矩阵合并存储、子句索引区分归属」——直接针对「99% 稀疏反噬 CSR 效率」的观察；行计数 ≤7 → 表只需 3bit。调度侧的账：模拟退火两阶段（轮间交换 + 轮内 PE 间交换）离线负载均衡——确定性稀疏允许软件精确仿真硬件活动，PE 利用率提升 12.2%（到 63.1%）、省 1.2k 周期支撑 400kHz。

§03 · 实验结果

严格归一化的五芯片对比

设置与物理实现

GSCD 12 类（10 命令词 + Silence + Unknown），训练/验证/测试 74922/4490/4870 条；训练只加 20–40dB 轻度白噪（论文明说：单层逻辑 CTM 无法有效处理高背景噪声——能力边界声明）+ 随机音高增强。120 子句 CTM（T=300, s=8.0, 400 epoch）；软件预处理与硬件数值一致（software 精度直接映射芯片行为）。TSMC 65nm LP 流片：die 1.67mm² / 核 0.63mm²；实测 1.2V 下 40.8µW（25°C 无 IO pad），0.7V 16.58µW 是外推（动态按 V²、静态按 V 线性缩放，论文论证保守）。时钟门控 + 操作数隔离降功耗；400kHz 做特征提取与推理。

五款数字全景（表 I）：BWN 87.9% / TC-ResNet 93.09% / LSTM 90.87% / DeltaGRU 89.5% / 本文 87.35% clean；延迟 16 / 100 / 16 / 6.9 / 16 ms；模型 4.4 / 49.5 / 10.1 / 14.8 / 19.9 KB；片上存储 10.7 / 74.1 / 96 / 25.7 / 33.5 KB。类别缩放特性：CTM 各类不共享参数——裁到 2 个关键词时每帧逻辑运算降到 15 万次（批量式唤醒场景依然划算）。

四组消融式发现：① 特征消融（图 7）：MFSC-SF 在多档规模上一致有效（120 子句 +4 pp），三处简化合计 <1% 损失；② 压缩消融（图 10）：OG-BCSR 对 CSR 再砍 2.37×；③ 调度消融（图 15）：模拟退火两阶段 PE 利用率到 63.1%——确定性稀疏允许离线负载均衡，是状态驱动相对事件驱动的结构性优势的直接证据；④ 类别缩放：各类不共享参数 → 2 关键词时每帧逻辑运算降到 15 万。

§04 · 主要贡献

四条可转述的判断

1算法侧首次同台
MFSC-SF + 谱卷积让 CTM 首次在 GSCD 12 类拿 87.35%——CTM 对边缘部署 NN 在标准基准上的第一次有竞争力竞技。
2状态驱动加速器
同时解锁高数据复用与稀疏全利用——0.63mm² 核 / 16.58µW（0.7V）。
3边缘优化部署
OG-BCSR（9.84× 压缩）把极稀疏变成存储优势；两阶段离线调度（PE 利用率 +12.2%）把负载均衡从运行时搬到离线。
4可信证据 + 开源
严格归一化的 SoTA 芯片级对比取代 TM 文献「跟未优化 NN 比」的惯例；全部 RTL 与流程开源可复现。

§05 · 局限性与展望

单层结构是精度的根因，SRAM 是功耗的根因

方法的技术局限

  • 精度天花板来自单层：87.35% 五款垫底；论文自认超 90% 需更大 CTM——模型尺寸与存储访问成为必须正视的问题。
  • 噪声鲁棒性是硬边界：只敢加 20–40dB 轻噪（单层逻辑模型处理不了高噪声）；直说只适合近麦克风场景；对手都报了 10dB/20dB/5dB 档位，本文一个噪声精度都没报。
  • 模型存储是功耗瓶颈：27.25KB 模型 SRAM 占 42%；CTM 模型天然大于 NN 对手——单层特征能力不足的连带代价。
  • 特征前端未优化：FFT 方案对实值音频非最优，论文自认超范围。
  • 批量式固有代价：16ms / 191nJ 逊于帧式（6.9ms / 27nJ）——定位「可比」非「超越」。

实验设计的不足

  • 0.7V/16.58µW 是外推：实测只 1.2V 40.8µW——标题指标严谨性打折（论文论证了保守性）。
  • 口径小出入：总功耗 − 特征提取 − 特征库 = 10.6µW 与推理核 11.94µW 对不上，未解释。
  • 跨工艺归一化是线性外推：22nm ×8 假设——真实移植不严格服从，对比精度有限。
  • 细粒度结果缺失：无每类准确率 / 混淆矩阵 / 方差置信区间；图 7 只曲线示意 + 一句 4 pp；REDRESS 对比只说「更低」没给数。
  • 片上学习未验证：动机反复强调 TM 适合片上学习，交付物是推理-only——只停留在「确定性顺序访问利于存储优化」的架构潜力层面。

下一步方向（论文展望 + 笔者延伸）

论文自列：类别灵活缩放的进一步挖掘；存储优化（bank 划分 / 近端缓存 / 专用存储块）直攻 42% 功耗大头；生物声学特征（鲁棒性已被证明优于 MFCC）对抗噪声短板；超 90% 精度的更大模型 + 更激进压缩。
笔者延伸：多层 CTM 成熟后谱卷积 + MFSC-SF 组合需重验证（DCT 冲突论证建立在单层假设上）；FFT 前端的实值优化（实数 FFT / 滤波器组直接替代）；状态驱动架构与片上学习结合——确定性稀疏让训练时的 TA 状态翻转同样可离线分析（最值得期待的下一步）；动态均值阈值 + 固定 SF 阈值在极端环境（温度 / 老化导致麦克风漂移）下的长期稳定性验证。
