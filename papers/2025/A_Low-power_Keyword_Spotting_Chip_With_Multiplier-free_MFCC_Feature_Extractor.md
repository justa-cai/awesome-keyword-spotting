## 问题陈述

### 问题背景和领域痛点

这篇论文处理的是一个与主流 KWS 算法研究不太一样的问题：不是网络结构创新，而是**常开（always-on）KWS 芯片的功耗瓶颈出在特征提取（FEx）而不是分类器上**。论文开篇的逻辑链值得注意（Fig. 1）：在移动和物联网设备上，负责接收语音指令的 KWS 模块通常主导整个系统的功耗，因此需要低功耗方案。一个典型 KWS 系统由音频前端、MFCC 特征提取器和神经网络分类器三段组成，而 MFCC 是基于 FFT 的特征提取算法，在低功耗 KWS 芯片里是显著的耗电大户（摘要）。

为什么 MFCC 会成为耗电大户，这里有明确的电路层原因。MFCC 的完整管线是加窗 → FFT → 取功率谱 → 梅尔滤波 → 取对数 → DCT（Fig. 2 上半部分），每一步在理论实现里都离不开乘法：256 点海明窗加权要 256 次乘法、FFT 蝶形运算的复数乘法要 2048 次实数乘法、求模要开方和平方、三角梅尔滤波每拍加权也是乘法、DCT 的余弦旋转因子还是乘法（Table I 理论列合计 3168 次乘法、3808 次加法、932864 次位操作）。在 0.55 V 近阈值电压、125 kHz 低频工作的芯片里（Fig. 8 规格表），乘法器是面积和动态功耗都最贵的算术单元——一次两位操作数的乘法需要一整棵部分积压缩树加最终加法器，而移位只是连线重排、加法只需一级进位链。这就是"免乘法器（multiplier-free）"这个标题的立论基础：**把 MFCC 里所有乘法替换成移位和加法，FEx 的计算功耗就能数量级下降**。

痛点还有一个常被算法侧忽视的维度：存储。传统实现要把 256 点窗函数系数、FFT 旋转因子、梅尔滤波器系数全部存在片上存储器里，而片上存储器在近阈值下漏电和访问功耗都很可观。这篇论文最终的实测功耗分解（Fig. 9(c)）也印证了这一点——FEx 总功耗 1771 nW 里，计算部分只有 76 nW，存储部分高达 1695 nW（Table III），存储才是真正的第一大头。这个事实反过来解释了论文为什么在算法上同时做"免存储窗函数系数"这类优化。

### 现有方法的具体不足

论文用 Fig. 1 把近年降功耗路线归成三类，并逐一点出不足：

- **第一类：多级唤醒 + 占空比压缩运行时间**。用 VAD（语音活动检测）做多级唤醒，配合规律的睡眠和唤醒周期[13][14]。这类方法不改变单次计算的能耗，只是少算，代价是系统复杂度上升，且 VAD 漏检会直接漏唤醒词。
- **第二类：压缩分类器**。用量化、剪枝训练网络，或换更高效的网络架构[15][16][35]。这类方法把分类器功耗压得很低（如二值网络），但分类器一旦压到百纳瓦级，FEx 的功耗占比反而凸显出来——优化天花板出现在了另一侧。
- **第三类：用模拟信号处理器（ASP，如模拟带通滤波器组）替换 MFCC**[17-34]。模拟特征提取确实能做得很省电（如 JSSC'21 [34] 的 FEx 总功耗只有 35 nW，Table III），但论文指出两个代价：**增加芯片面积、降低算法精度**（Introduction）。而且模拟电路需要定制、工艺偏差敏感、无法复用数字设计流程；相比之下数字 MFCC 不需要定制模拟电路，更容易部署到物联网设备上——这是作者选择"把数字 MFCC 本身做省"而不是"换模拟前端"的根本立场。

具体到数字 MFCC 这条线，先例也不少：ISSCC'20 [15] 用流水线 FFT 做出 336 nW 的 FEx，JSSC'23 [14] 用基-2 实数 FFT 做到 180 nW，JSSC'24 [35] 做到 111.6 nW（Table III）。但它们的 FFT 蝶形运算里仍然是真乘法器（乘 8-10 bit 旋转因子），优化方向是流水线和位数控制，没有触碰"乘法本身能不能消掉"这个问题。本文正是瞄准这个空档：**把旋转因子量化到一组"移位友好"的离散值上，让乘法退化为移位加**。

### 该论文要解决的关键挑战

综合起来，论文要同时压住四个互相牵制的目标：（1）MFCC 全管线去乘法器，但不能让 KWS 精度崩掉——旋转因子量化太粗会直接污染频谱分辨率，论文需要找到"最粗但还能用"的量化档位；（2）去乘法器之后计算单元省下来的面积和功耗不能再被多套专用运算单元吃回去——Power、Mel、DCT 三种运算要共享同一个可配置处理元；（3）存储功耗要同步压——窗函数系数干脆不存；（4）整体要在 65 nm 老工艺、0.55 V 近阈值下做出有竞争力的 2 µW 级全芯片实测，而不只是仿真数字。最终结果是：E3bT-FFT 把 FFT 乘法功耗降 5.7 倍（Fig. 7(b)），MF-MFCC 把 MFCC 计算量降到 13.5%（7.3 倍，Table I），芯片 0.17 mm²、2.3 µW，1-Word KWS 在 Google Speech Commands 数据集上实测 94.9% 精度（摘要、Fig. 9(a)）。

## 方法论

### 整体架构设计和设计动机

整颗芯片（Fig. 6(a)）由两大块组成：**MF-MFCC 处理器**（特征提取加速器）和**深度学习加速器（DLA）**。语音信号进入芯片后先存入乒乓 FIFO（两个 128×16 bit 的 FIFO 交替读写，对应 8 kHz 采样、16 ms 帧移 = 128 个样本一帧，Table III），MF-MFCC 处理器按四步流水计算特征：加窗 → FFT → 功率/梅尔滤波 → 对数/DCT，其中功率、梅尔滤波和 DCT 三步共享同一组可配置免乘法处理元（MF-PE）。算出的特征交给 DLA 做 1-Word 关键词判决。顶层控制器加 SPI 接口负责权重加载（测试时初始存储内容由 PC 经 SPI 烧到 PCB，Section IV）。FFT 之外还有一条 FFT 共轭复用支路（16b），这是基-2 实数 FFT 的标准做法：实信号先当复数做 N/2 点 FFT，再用共轭对称性拆出 N 点实频谱，省一半 FFT 计算。

设计动机的层次很清楚。第一层，**攻击乘法器**：数字近阈值设计的功耗大体正比于开关活动的位数，乘法器是位数开关的重灾区，所以窗、FFT、功率、Mel、DCT 五级全部做"乘法 → 移位+加法"替换。第二层，**攻击存储**：量化窗函数后系数不再需要存储（Section II），旋转因子只需要 64×4 bit 的小存储体（Fig. 6(a)），片上存储改用锁存器实现以降功耗（Section IV）。第三层，**攻击面积**：Power/Mel/DCT 三种运算复用一个 MF-PE，DLA 用二值网络把 PE 里的乘法器换成 MUX 加反相器。整个设计是一条"算法近似换电路简化"的协同设计链，每一级近似都有精度实验背书（Table II）。

### 核心算法的数学原理

**量化窗函数（式 (1)）**：海明窗本来是连续函数 W(x) = 0.54 − 0.46cos(2πx/(N−1))，加窗时每帧要做 256 次浮点乘法。论文把它量化成以"样本索引到帧中心 N/2 的距离"为自变量的四级阶梯函数：距离最近取 1，向外依次取 0.5、0.25，最外取 0（式 (1)，阈值分档在提取文本中显示为 4/8/15 个 N/16 量级）。这样乘窗变成三种操作之一：直通（乘 1）、右移一位（乘 0.5）、右移两位（乘 0.25）、清零（乘 0）。副产品是窗函数系数完全不需要存储——硬件上窗口模块就是一个选择器加移位逻辑（Fig. 6(a)），由输入音频的索引决定窗值再执行对应移位（Section III），存储功耗和面积同步下降。

**E3bT 旋转因子与免乘法蝶形（式 (2)）**：这是全文最核心的一步。基-2 实数 FFT 的蝶形运算包含输入与旋转因子的复数乘法，等于 4 次实数乘法加 6 次加法（Section II）。论文把旋转因子量化并"扩展一位符号位"，得到 E3bT（expanded-3bit-twiddle）集合：{0, ±0.25, ±0.5, ±0.75, ±1.0}——普通 3 bit（1 符号 + 2 幅值）只能表示 0/0.25/0.5/0.75，表示不了 1.0，而扩展符号位后 +1.0 可编码（Fig. 4(a)）。+1.0 必须可表示，因为每个 FFT 级的第一组蝶形旋转因子恒为 W⁰=1，缺了它整个频谱都要缩放。乘法随之拆成两半（Section II）：先做数值计算，再做符号计算。数值计算即式 (2)：

- |twiddle| = 0 → 输出 0
- |twiddle| = 0.25 → x >> 2（右移两位）
- |twiddle| = 0.5 → x >> 1（右移一位）
- |twiddle| = 0.75 → (x >> 2) + (x >> 1)（两次移位一次加法，因为 0.75 = 0.5 + 0.25）
- |twiddle| = 1 → x 直通

符号计算单独处理：根据旋转因子与被乘数符号的乘积决定是否对数值结果取反。**这套替换的本质是把任意系数乘法逼近成 2 的幂次的多项式**——0.25 和 0.5 是纯移位（硬件上零成本），0.75 代价一次加法，1 和 0 是直通和清零。Fig. 7(a) 统计了 256 点 FFT 中各档旋转因子的出现频率，绝对值为 0.75 的占 24.4%——也就是说约四分之一的蝶形要付"两次移位加一次加法"的较贵档，但即便如此，与 8 bit 旋转因子真乘法相比仍把乘法功耗降了 5.7 倍（Fig. 7(b)）。

**加法功率（Add-Power，式 (3)）**：理论 MFCC 要算复频谱的模 P = √(x²_real + x²_imag)，包含平方（乘法）和开方。论文用 P(x) = |x_real| + |x_imag| 替代（式 (3)），把乘法和开方全部换成取绝对值加加法。这个近似的误差上界是明确的：当实部虚部等幅时，|x_r|+|x_i| 比 √(x_r²+x_i²) 高估 √2 ≈ 1.41 倍。它能工作的原因在于后面紧跟梅尔滤波的能量累加和对数压缩——对数会把乘性误差变成加性偏置，而分类器是拿着这套特征重新训练的，可以把系统性偏置学回去。Table II 显示单独换 Add-Power 只让 10-Word 精度从 94.04% 降到 92.51%（−1.53 个百分点），性价比极高。

**矩形梅尔滤波与 E3bT-DCT**：三角梅尔滤波器组每个频带内的权重是任意实数，累加即加权乘法；论文改用矩形带通滤波器组[12]，频带内权重全为 1，滤波退化为"频带内功率直接累加"，只剩加法（Section II）。DCT 里的余弦旋转因子同样量化成 E3bT 集合，复用式 (2) 的移位加逻辑。对数运算用查找表实现（Fig. 2 中 LOG 模块带 LUT；Fig. 6(a) 中 LOG 为 8b 输入 4b 输出）。

**计算量总账（Table I）**：理论 MFCC 与 MF-MFCC 逐级对比——窗：256 次乘 → 0；FFT：2048 乘 3072 加 → 0 乘 7168 加；功率：256 乘 128 加 → 0 乘 128 加；梅尔滤波：208 乘 208 加 → 0 乘 208 加；DCT：400 乘 400 加 → 0 乘 400 加。合计乘法从 3168 清零，加法从 3808 升到 7904（加法翻倍但每次加法远便宜于乘法），**位操作数从 932864 降到 126464，即 13.5%，等效 7.3 倍计算量削减**。用位操作数而不是运算次数做指标是有讲究的：位操作数近似门级开关活动，在近阈值电压下动态功耗基本正比于开关活动，这是比"乘法次数"更接近能耗真相的度量。

### 关键技术创新一：E3bT-FFT——旋转因子的"最粗可用"量化

E3bT 的选档不是拍脑袋，论文给了两级证据。第一级是**频谱分辨率分析**（Fig. 4）：对 100–2000 Hz 多频正弦组合输入做 FFT，8 bit 旋转因子的基准 FFT 分辨率良好（Fig. 4(b)）；E3bT 在 0–1000 Hz 范围内保持准确性能，只在 1000–2000 Hz 出现分辨率下降（Fig. 4(c)）；而 E2bT（2 bit）频率分辨率急剧衰减并向频谱引入显著噪声（Fig. 4(d)）。这说明 3 bit 是"从崩到可用"的临界档位——再省一位就不可用了。第二级是**端到端任务精度**（Table II）：单独用 E3bT-FFT，10-Word KWS 精度从 94.04% 降到 90.69%（−3.35 个百分点），是所有单项近似里掉分最多的，但换来 FFT 功耗 5.7 倍下降（Fig. 7(b)）。为什么 0–1000 Hz 保真就够了？论文的表述是 0–2000 Hz 覆盖了人耳听觉的主要频率范围（Section II），而说话人的基频和第一、二共振峰能量集中在 1 kHz 以下，1–2 kHz 段的分辨率损失对唤醒词判别的影响由分类器重训练吸收。另外值得注意 1000–2000 Hz 分辨率下降这件事是把双刃剑：对 20–4 kHz 采音带宽里上限频段的辅音摩擦音细节有潜在影响，论文用最终精度数字证明了这个代价可接受。

### 关键技术创新二：免乘法 MFCC（MF-MFCC）全管线近似

E3bT 只是 FFT 一级，论文的贡献是把同样的"移位友好系数"思想贯穿到整条 MFCC 管线：量化窗（四级阶梯）、Add-Power（绝对值和替代模）、矩形梅尔滤波、E3bT-DCT，再加上本就免乘法的 LUT 对数。五级近似各自独立可开可关，Table II 的消融就是逐级打开看精度。组合后 10-Word 精度 89.73%，比理论 MFCC 的 94.04% 低 4.31 个百分点——论文对这笔账的态度很坦率：窗、梅尔、功率、DCT 的近似对精度影响极小（都在 1.5 个百分点以内），主要代价来自 E3bT-FFT，但它显著降低功耗（Section II）。这是典型的"把精度预算花在刀刃上"：同样掉 3 个百分点，花在 FFT 上能换 5.7 倍功耗，花在别处只能换零头。

### 关键技术创新三：可配置免乘法处理元（MF-PE）与二值 DLA 的电路复用

算法近似省下的功耗如果被三套独立运算单元吃回去就白干了。论文的电路答案是 **MF-PE**（Fig. 6(c)）：一个加法器、一个 MUX、一个 E3bT 乘法器组成的最小处理元，靠配置切换三种角色——做功率时两路输入先取绝对值再经加法器求和；做梅尔滤波时输入经加法器和寄存器做累加；做 DCT 时输入先乘 E3bT 再经加法器与寄存器累加，且进 MF-PE 之前先过对数处理（Section III）。一个 PE 撑起三个流水级，功耗和面积双省。

E3bT 蝶形单元（Fig. 6(b)）由 4 个 E3bT 乘法器和 6 个加法器组成，正好对应复数乘法的 4 实乘 + 6 实加结构——乘法器被"E3bT 乘法器"（移位加网络）替换，加法器原样保留。

DLA 侧同样贯彻免乘法：8 个 PE 加 1 个批归一化 PE（BN-PE）。网络权重二值化到 1 bit（±1），激活量化到 8 bit，**二值 PE 用 MUX 加反相器替换传统乘法器**，结果送加法器树累加（Section III）——乘 ±1 本来就是"选原值或选反值"，这正是 MUX 的本职。每层 CNN/FC 算完后由 BN-PE 做批归一化，BN 权重是 8 bit 定点数，仍需要一个 8 bit 乘法器执行（Section III）——这是全芯片留下的最后一处乘法，因为 BN 的缩放系数是连续值、无法移位友好化。DLA 的配置极小（权重存储 78×8 bit、特征存储 82×8 bit，Fig. 6(a)），这也解释了为什么片上只跑 1-Word（3 层 CNN + 1 层 FC）分类器，10-Word（7 层 CNN + 1 层 FC）只能离片跑（Table III 分类器一栏标注 on-chip DS-CNN 与 off-chip DS-CNN）。

### 与现有方法的技术差异

与三条已有路线对比，这篇工作的差异点在于**用"系数离散化到 2 的幂次组合"替代"真乘法器的位数/流水线优化"**。同是数字 MFCC 的 ISSCC'20 [15]（流水线 FFT）、JSSC'24 [35]（流水线 FFT）优化的是 FFT 架构和位宽，蝶形里仍是乘法器；JSSC'23 [14] 用基-2 实数 FFT 降运算量，但旋转因子也是常规量化。本文是先把旋转因子约束到 {0, ±0.25, ±0.5, ±0.75, ±1}，让乘法在算术层面消失，再把同一套逻辑推广到窗、功率、Mel、DCT。与模拟特征提取路线（ISSCC'22 [26]、JSSC'23 [33] 等 ASP 方案）相比，本文保持全数字流程、不需要模拟前端（Table III 中 Analog Front-End 一栏为 No），换取可移植性和精度可控性，代价是 FEx 总功耗不敌最好的模拟方案（1771 nW 对 35 nW [34]、80 nW [33]）。与分类器侧路线（VLSI'19 [16] 的片上 RNN）相比，本文的分类器做到了二值 DS-CNN 加免乘法 PE，DLA 功耗 0.53 µW（Table III）。

## 实验结果

### 使用的数据集及其规模

训练与测试都用 **Google Speech Commands Dataset（GSCD）**[4]。两个任务：1-Word KWS 取 'happy'、'dog'、'up'、'down' 四个词分别训练，其余 GSCD 关键词充当填充词（filters）；10-Word KWS 取 'yes'、'no'、'up'、'down'、'left'、'right'、'on'、'off'、'stop'、'go' 十个词（Section II、Section IV）。芯片实测阶段的评测音频构造得比较讲究：所有关键词和填充词随机拼接，并按 **1:6 的比例混入静音**，拼成 **1 小时**的音频样本，由 FPGA 产生 8 kHz 数字音频流喂给芯片（Section IV）。选择拼接长音频而不是逐条孤立测试，是为了模拟常开设备连续监听的真实负载——静音占 6/7 对应语音稀疏出现的真实场景。数据集具体的训练/测试划分规模论文未报告（GSCD 常用的 v0.02 约 10.5 万条、约 30 词，本文未注明版本与划分）。

### 评估指标的定义和选择理由

- **KWS 精度（准确率）**：以分类正确率衡量，1-Word 报四词平均，10-Word 报十词平均（含混淆矩阵 Fig. 5(b)）。选它的理由很直接：本文的每一步近似都可能伤精度，精度是所有功耗收益的"支付货币"，必须逐级核算。
- **位操作数（Bit-Op）**：Table I 的核心列，把每种运算折算成门级位操作数。选择理由是它比乘法/加法次数更接近电路开关功耗，尤其当乘法被移位替代后，"运算次数"指标会失真（乘法清零、加法翻倍），位操作数能反映真实节省。
- **功耗分层报告**：Table III 把功耗拆成 FFT 计算功耗、FEx 计算功耗、FEx 存储功耗、FEx 总功耗、DLA 功耗、总功耗六档。这么拆的理由本文用 Fig. 9(c) 给了答案——只有分层才能看清"计算省了 7.3 倍之后瓶颈转移到了存储"这个事实。
- **工艺条件**：65 nm CMOS、0.55 V、125 kHz（Fig. 8）。在近阈值低频下测功耗，对应常开 IoT 的真实工作点。

| 项目 | VLSI'19 [16] | ISSCC'20 [15] | JSSC'21 [34] | ISSCC'22 [26] | JSSC'23 [14] | JSSC'23 [33] | JSSC'24 [35] | 本文 |
|---|---|---|---|---|---|---|---|---|
| 工艺 | 65 nm | 28 nm | 180 nm | 65 nm | 28 nm | 65 nm | 28 nm | 65 nm |
| FEx 技术 | MFCC | MFCC | IROC | ASP | MFCC | ASP | MFCC | MF-MFCC |
| FEx 总功耗 | 7137 nW | 336 nW | 35 nW | 11040 nW | 180 nW | 80 nW | 111.6 nW | 1771 nW |
| GSCD 精度 | 90.8%（10 词） | 97.3%（1 词） | 94.0%（1 词） | 86%（10 词） | 92.8%（5 词） | 91.5%（10 词） | 98.1%（1 词） | 94.9%（1 词）/ 89.6%（10 词） |
| 芯片面积 | 2.56 mm² | 0.23 mm² | 论文未报告 | 2.03 mm² | 0.8 mm² | 论文未报告 | 0.47 mm² | 0.17 mm² |
| 总功耗 | 16.1 µW | 0.51 µW | 0.148 µW | 32.3 µW | 1.48 µW | 论文未报告 | 0.61 µW | 2.3 µW |

对比结论需要分层读，不能只看单一列。**同工艺同路线的直接对手**是 VLSI'19 [16]（65 nm、数字 MFCC）：FEx 总功耗 7137 nW 对本文 1771 nW，**4 倍改善**（结论部分明确引用），同时面积从 2.56 mm² 缩到 0.17 mm²、精度从 90.8%（10 词）到 89.6%（10 词）基本持平、总功耗从 16.1 µW 到 2.3 µW。这是论文最扎实的对比。**FFT 计算功耗**横向看：本文 64 nW，优于 ISSCC'20 [15] 的 205 nW 和 JSSC'23 [14] 的 130 nW，略高于 JSSC'24 [35] 的 56.9 nW——但 [35] 是 28 nm 工艺，本文是 65 nm，老工艺做到接近甚至部分反超，归功于免乘法器本身。**绝对功耗的诚实读法**：本文总功耗 2.3 µW 并非 SOTA，ISSCC'20 [15] 的 0.51 µW、JSSC'21 [34] 的 0.148 µW、JSSC'24 [35] 的 0.61 µW 都更低，但其中 [34] 用模拟特征提取、[35] 在 28 nm 且 0.36 V、[15] 在 28 nm 且 0.41 V；本文的优势面是**面积最小（0.17 mm²，所有报告面积的工作中最小）加老工艺加免模拟前端**。音频位宽上本文反而用 16 bit 输入（Table III Audio Bit-width 行，多数对比工作 8-10 bit），用前端精度补偿后级近似。芯片版图整体 0.85×0.85 mm²、片上存储 1.6 KB（Fig. 8 规格表），核心面积 0.17 mm²（摘要、Table III）；1.6 KB 存储里 1188 字节给 MF-MFCC 加速器、493 字节给 DLA，且用锁存器实现以降功耗（Section IV）。

实测口径（Section IV、Fig. 9）：1 小时拼接音频、静音比 1:6 的条件下，1-Word 芯片实测精度 **94.9%**，高于仿真口径下 1-Word 配 MF-MFCC 特征的 93.4%（Section II）；0.55 V 供电下整芯片 **2.3 µW**（Fig. 9(b) 给出功耗随电压变化曲线）。功耗分解（Fig. 9(c)）：MFCC 计算功耗 76 nW 只占整芯片 3.3%；FEx 总功耗 1771 nW 占整芯片约 77%（其中存储 1695 nW、计算 76 nW，Table III）；扣除 FEx 后剩余约 0.53 µW 即 DLA 功耗（与 Table III 的 DLA Power 0.53 µW 一致）。这个分解是全文最重要的一张图：**免乘法优化把 FEx 计算功耗打到只剩 3.3%，但存储功耗成了新的第一瓶颈**。

### 消融实验的发现

Table II 是算法侧消融，以 10-Word KWS 精度为标尺，逐项替换理论 MFCC 的组件：

| 配置 | 10-Word 精度 | 相对理论 MFCC 的损失 |
|---|---|---|
| 理论 MFCC（基线） | 94.04% | — |
| 量化窗 | 93.04% | −1.00 |
| E3bT-FFT | 90.69% | −3.35 |
| 加法功率 | 92.51% | −1.53 |
| 矩形梅尔滤波 | 93.74% | −0.30 |
| E3bT-DCT | 93.74% | −0.30 |
| 完整 MF-MFCC | 89.73% | −4.31 |

三个发现值得展开。**第一，各近似不是等价的**：矩形梅尔滤波和 E3bT-DCT 几乎白拿（各只掉 0.30 个百分点），量化窗和加法功率便宜（约 1-1.5 个百分点），E3bT-FFT 是唯一的精度大头（3.35 个百分点）——与 Fig. 4 的频谱分析一致，损失集中在 1-2 kHz 分辨率下降，最终由分类器重训练部分吸收。**第二，组合误差近似可加**：完整 MF-MFCC 掉 4.31 个百分点，与各单项损失之和（约 6.5）相比略好，说明各近似的误差源相对独立、没有恶性耦合。**第三，精度换功耗的兑换率不对称**：E3bT-FFT 用 3.35 个百分点换 FFT 乘法功耗 5.7 倍（Fig. 7(b)），而其余四级近似合计只掉约 1 个百分点却贡献了 Table I 中窗/功率/Mel/DCT 四级的全部位操作削减（理论合计约 34 万位操作压到约 1.2 万）。论文自己对消融的总结是：窗、梅尔、功率、DCT 的近似对精度影响最小，E3bT-FFT 略降精度但显著省功耗（Section II）。

另外 Fig. 7(a) 的旋转因子使用统计构成了一种"硬件侧消融"：256 点 FFT 里 |T|=0.75 档出现频率 24.4%，说明最贵的移位加组合只占四分之一，其余档位（0、0.25、0.5、1）几乎免费——这解释了为什么整体乘法功耗能降 5.7 倍而不是只降一点。1-Word 与 10-Word 两个分类器规模的对比（Fig. 5(a)：3CNN+1FC 对 7CNN+1FC）则给出了任务复杂度对近似鲁棒性的影响：1-Word 在 MF-MFCC 特征下仍有 93.4%，10-Word 掉到 89.6%，说明类别越多、对特征损伤越敏感。

## 主要贡献

1. **E3bT-FFT**：提出扩展 3 bit 旋转因子量化算法，把 FFT 蝶形中的复数乘法分解为"数值移位加 + 符号判断"，配合频谱分辨率分析（Fig. 4）和任务精度验证（Table II），在 256 点 FFT 上实现乘法功耗 5.7 倍下降（Fig. 7(b)）。
2. **MF-MFCC 全管线免乘法**：把量化窗、加法功率、矩形梅尔滤波、E3bT-DCT 串成完整的无乘法器 MFCC，位操作量降到理论 MFCC 的 13.5%（7.3 倍，Table I），乘法从 3168 次清零，同时消除窗函数系数存储。
3. **可配置 MF-PE 与二值 DLA 的电路协同**：Power/Mel/DCT 三种运算共享单一免乘法处理元，DLA 用 1 bit 权重把 PE 乘法器换成 MUX 加反相器，从算法到版图贯彻"免乘法"设计准则。
4. **65 nm 硅验证**：流片实测 0.17 mm²、0.55 V 下 2.3 µW、FEx 计算功耗仅 76 nW（占整芯片 3.3%）、1-Word GSCD 精度 94.9%，相对同为 65 nm 数字 MFCC 的 VLSI'19 [16] FEx 功耗降 4 倍、面积缩 15 倍（2.56 mm² → 0.17 mm²）。

## 局限性与展望

### 方法的技术局限性

- **精度代价在多类别任务上放大**：MF-MFCC 让 10-Word 精度从 94.04% 掉到 89.73%（Table II），而对比工作里 28 nm 的 JSSC'24 [35] 做到 98.1%（1 词）、ISSCC'20 [15] 做到 97.3%（1 词）。近似特征的精度上限低于全精度特征加常规量化分类器的组合，类别数继续增加时差距可能进一步拉开。
- **频谱分辨率在 1-2 kHz 受损**：E3bT 在 1000-2000 Hz 分辨率下降是论文自己承认的（Fig. 4(c)）。对能量集中在低频的元音无碍，但依赖高频摩擦音细节的唤醒词（含 /s/、/f/ 等清擦音的词）可能更易混淆，论文没有按音素类别做分错误分析。
- **存储功耗成为新瓶颈而未被根治**：免乘法优化后 FEx 计算只有 76 nW，但存储 1695 nW 占了 FEx 的 96%（Table III、Fig. 9(c)）。锁存器存储器只是缓解，2.3 µW 总功耗中约 77% 花在 FEx 且大头是存储——算法侧的红利已经被吃干净，下一步必须动存储架构（比如更激进的逐帧流式计算省掉特征缓存）。
- **BN-PE 仍保留 8 bit 乘法器**：批归一化的 8 bit 定点缩放无法移位友好化（Section III），免乘法设计在 DLA 里不彻底；若网络加深，这处乘法器的功耗占比会上升。
- **近似对 SNR 的依赖未刻画**：Add-Power 的相对误差在实虚部等幅时最大（高估约 √2 倍），加性噪声会抬高这类边界情形的出现频率，论文全部测试基于 GSCD 的相对干净录音，未报告噪声鲁棒性曲线。

### 实验设计的不足

- **实测精度与仿真精度不一致且未解释**：1-Word 芯片实测 94.9%（Section IV）高于同配置仿真 93.4%（Section II），通常实测应低于仿真；两者评测口径不同（芯片用 1 小时随机拼接、静音 1:6 的长音频，仿真 presumably 用标准测试集），论文没有对齐口径或给出解释，读者无法判断 94.9% 与其他工作的精度是否可比。
- **缺少标准协议下的横向精度**：GSCD 社区通行 test set 划分和逐词报告，本文只有平均精度和仿真混淆矩阵（Fig. 5(b)），无每词准确率/误唤醒率/ROC 类指标；对唤醒应用最关键的误触发率（false accept）论文未报告。
- **数据集版本与规模未报告**：GSCD 的版本号、训练/验证/测试划分、词表裁剪规则均未给出，复现需要猜测。
- **10-Word 只在片外验证**：Table III 中 10-Word 的 89.6% 是 off-chip DS-CNN 结果，片上 DLA 只承载 1-Word；"片上免乘法全管线 + 多词精度"这一组合没有硅证明。
- **10-Word 消融基线未含 1-Word 口径**：Table II 只报 10-Word 的逐项消融，1-Word 任务下各近似档的敏感度未给出，而 1-Word 恰恰是芯片实际跑的任务。
- **工艺与电压条件不统一**：对比表里 28 nm/0.36-0.41 V 的工作与本文 65 nm/0.55 V 直接比绝对功耗，未做工艺归一化能效（如 pJ/operation）对比，公平性打折。

### 未来可能的改进方向

- **存储侧攻坚**：既然 Fig. 9(c) 显示存储占 FEx 功耗 96%，最直接的下一步是把 MFCC 管线改成全流式（逐样本进、逐特征出），削减 256×16 bit 特征存储体，或用近阈值存储单元 / 特征压缩降低访问功耗。
- **旋转因子档位与字长的联合搜索**：E3bT 是手工选档（3 bit 加扩展符号）；可以想象对 {0, 0.25, 0.5, 0.75, 1} 集合做频段自适应（低频段用更细档、高频段用粗档），或用训练感知量化在 0.75 档占比 24.4%（Fig. 7(a)）的基础上进一步压加法次数。
- **与 VAD 多级唤醒正交叠加**：本文只做了 Fig. 1 中第三类方法（降 FEx），与第一类（VAD 帧跳过[14]）完全正交，两者叠加有望把 2.3 µW 的常开功耗再往下压。
- **近似感知的训练**：目前是"先定近似、再训分类器"的两步法；把 E3bT-FFT 和 Add-Power 写进前向图做端到端联合训练（类似量化感知训练），有望收回部分 4.31 个百分点的损失（Table II），支撑 10-Word 以上词表上片。
- **误唤醒与噪声评测补全**：按流式 KWS 惯例补 false reject / false accept 曲线和带噪测试，验证移位友好近似在真实声学环境下的边界，这对落地智能音箱、耳机类产品是必需证据。
