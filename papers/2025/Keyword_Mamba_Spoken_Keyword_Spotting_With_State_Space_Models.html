Keyword Mamba
SSM 首次进 KWS：只在时间轴扫、必须双向、非线性靠 FFN 补

Keyword Mamba: Spoken Keyword Spotting with State Space Models

作者：Hanyu Ding、Wenlong Dong、Qirong Mao —— 江苏大学

发表：2025.08 · arXiv:2508.07363 · 代码开源（dhyzy123/KWM）

Mamba / SSM双向 BiMamba线性复杂度 时域单向轴扫描KWM / KWM-TGSC 四设定 SOTA

一分钟版本

  • 三类现有架构各占一头：CNN 感受野固定（要长程就堆深度）、RNN 无法并行、Transformer 复杂度 O(N²)（KWT-3 参数失控到 5.36M）。KWS 需要的是长程依赖 + 线性复杂度同时满足——Mamba 恰好两者都占，但在 KWS 上从未被研究过。
  • 三个设计问题的任务级答案：扫描轴——patch 取 [40,1] 只在时间轴扫（等价 kernel[40,1] 时域卷积；纯频率扫描掉 3.67 pp）；方向——必须双向（全单向从 98.01 崩到 78.29，掉近 20 pp）；非线性——KWM-T 保留 FFN 补语义表达。
  • 双变体：KWM（纯 BiMamba 堆叠，3.4M 拿 98.01/98.79）与 KWM-T（只把 MHSA 换成 BiMamba、保留 FFN，5.2M 拿 98.05/98.91）——KWM-T-192 与 KWT-3 参数量几乎持平（5.2 vs 5.361M）下四项全面占优，是「Mamba 可替代自注意力」最干净的受控证据。
  • GSC V1/V2 四设定全部刷新基准；缩到 6 层 64 维（0.2M）仍有 96.74–97.45%——压缩鲁棒性好于 Transformer/CNN 缩小时的掉点。
  • 诚实账单：零 FLOPs / 延迟 / 内存实测；对轻量 CNN（BC-ResNet-8 用 1/10 参数做到 98.7）优势很薄；双向架构与流式因果推理结构性冲突——离落地还差一步关键架构工作。

§01 · 问题陈述

三类架构各占一头，Mamba 两头都占但没人摆过

§02 · 方法论

管线与两个编码器变体

三个关键决策的消融背书：① patch [40,1]：Patching+线性投影 ≈ kernel[40,1] 时域卷积——把 CNN 时代验证过的时域优势无缝继承进 SSM；② class token 中置：与前后两半等距、双向聚合（但影响仅 ≤0.26 pp，KWS 里 token 位置远不如其他任务重要）；③ 双向：全单向 78.29% 的崩溃性结果直接证明双向信息流是性能前提。

h′(t) = Ah(t) + Bx(t)，y(t) = Ch(t)　→　离散化 Ā=exp(ΔA)　→　全局卷积 y = x ⊛ K　（式 1–4）
Mamba 的选择机制（式 5）：B̄=s_B(x)、C̄=s_C(x)、Δ=τ(Param)+s_A(x)——参数随输入变化，获得内容过滤能力。训练时并行（卷积模式）+ 推理时恒定状态递推 + 硬件感知扫描 = O(N) 复杂度的长程建模。

§03 · 实验结果

四设定刷新基准，但优势分布要看清

设置

GSC V1（30 词 64,727 条）/ V2（35 词 105,829 条）× 12/30/35 标签四设定，80:10:10 划分沿用 MHAtt-RNN/KWT 以便并排。增强：±100ms 平移、[0.85,1.15] 重采样、0.1 音量背景噪声、2 时间掩码 + 2 频率掩码。AdamW + 余弦退火 + 10 warmup，label smoothing 0.1，主结果统一 12 层对齐 KWT。三随机初始化取平均——但本文模型未报方差（KWT 基线都带 ±std 0.03–0.18，0.05–0.35 pp 的领先幅度部分对比显著性存疑）。

深度宽度扫描的两个发现（表 2）：① 压缩鲁棒性——6 层 64 维（0.2M）仍有 96.74–97.45%，Transformer/CNN 缩小时往往明显掉点；解释：Mamba 靠循环状态结构覆盖长时间跨度，不依赖注意力。② 深度不敏感——192 档 6 层在 V1-12 上（97.92）反高于 8 层（97.70），盲目加深性价比低。KWM-T 的边际收益：FFN 补非线性有效但参数 +53%（3.4→5.2M）只换 0.04–0.12 pp——端侧要掂量。

消融只在单一设定做（V1-12 + KWM-192），未跨数据集跨规模验证外推性。Conv1D 的方向化也有贡献但不大（Fo-Bi 97.69 vs Bi-Bi 98.01，差 0.32 pp）。

§04 · 主要贡献

五条可转述的判断

1SSM 首次进 KWS
补上 Mamba 语音版图缺失的一块——探路型工作，价值在把「该怎么摆」的三个问题一次性答清楚，不在单点精度。
2任务感知的双变体配方
KWM（纯 BiMamba，轻量档）与 KWM-T（器官移植式替换 MHSA、保留 FFN，精度档）——共用时域单向轴扫描 + 中置 class token + 双向 SSM。
3等预算替代自注意力的干净证据
KWM-T-192（5.2M）vs KWT-3（5.361M）四项全面占优；对 Transformer 系参数效率优势实打实（3.4M 对 5361K 仍全面反超）。
4两个大效应消融结论
频率轴扫描 −3.67 pp、全单向 −19.72 pp——对后续所有语音 SSM 工作有直接迁移价值。
5四设定刷新基准 + 开源
KWM-T-192：V1-12 98.05 / V1-30 97.80 / V2-12 98.91 / V2-35 97.89；压缩鲁棒性（6 层 64 维 0.2M 仍 96.74+）；代码开源。总体判断：值得追踪的是它的流式化与小型化两个方向——那才是 Mamba 路线在端侧 KWS 上能否站住的决定性变量。

§05 · 局限性与展望

效率主张全部停留在纸面

方法的技术局限

  • 零效率实测：反复强调线性复杂度但 FLOPs / 延迟 / 峰值内存 / 吞吐一项没报；参数量在端侧谱系里也偏大（3.4M/5.2M vs MatchboxNet 93K、BC-ResNet 321K）。
  • 双向 vs 流式结构冲突：全单向 78.29% 等于宣判「直接因果化」走不通；chunk 双向、有限回看、因果 SSM 变体全没碰——离落地差一步关键架构工作。
  • utterance 级分类与端侧范式不合：class token + 整句 MLP 依赖固定 98 帧补零；端侧惯用逐帧滑窗打分 + 后处理，接口不天然兼容。
  • 非线性靠加参数补：KWM-T 参数 +53% 只换 0.04–0.12 pp，边际收益偏低。
  • 长程优势发挥不出来：GSC 每条 1 秒 98 帧——O(N) 对 O(N²) 的优势在这么短的序列上无从体现，长时序场景未检验。

实验设计的不足

  • 数据集单一且偏简单：只有 GSC 封闭集分类；无自建唤醒词集、无远场强噪压测（0.1 音量背景噪声是唯一噪声设置）、无多语言口音。
  • 自身结果未报方差：三次初始化取平均但不报 std，而 KWT 带 ±std 0.03–0.18——0.05–0.35 pp 的领先部分不显著。
  • 消融只在单一设定：V1-12 + KWM-192，结论外推性未验证。
  • 轻量 CNN 对比叙事不对称：参数效率焦点放在 Transformer 系（3.4M 对 5361K 确实漂亮），回避与 BC-ResNet-8 / MatchboxNet 十倍参数差距的帕累托讨论——在 KWS 这个以小为美的领域，精度-参数权衡曲线才是公平呈现。

下一步方向（论文展望 + 笔者补充）

① 补系统级评测：FLOPs、真机延迟内存，与 MatchboxNet/BC-ResNet 同一块 MCU 实测——把效率从理论变成工程事实。
② 流式因果化改造：chunk 级双向或有限回看的因果 Mamba + 逐帧打分头替换 class token——走向产品的前置条件。
③ 极致小模型：0.2M 档 + 蒸馏 / 低比特量化 / 剪枝，冲击 100K 以内与 SincConv 系竞争。
④ 扩任务边界：自定义唤醒词、多语言、远场仿真、开集拒识；拉长到连续监听让线性复杂度真正兑现。
⑤ 与自监督结合：AuM 式掩码预训练或 wav2vec2.0/WavLM 特征。
⑥ 混合比例系统搜索：Mamba 层与 FFN/注意力层的最优配比用 NAS 探索，而非手工二选一。
