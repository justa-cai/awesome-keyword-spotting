# Lightweight Dynamic Filter for Keyword Spotting

- **Authors/Affiliations**: Minjae Lee, Hyungshin Kim - Korea University; Drexel University
- **Date**: 2021.09
- **Link**: https://arxiv.org/abs/2109.11165
- **Keywords**: Dynamic Filter, Lightweight Model, Conditional Network, Input-Adaptive, Keyword Spotting, Google Speech Commands

## Problem Statement

Keyword Spotting (KWS) models on edge devices need to maintain high accuracy under strict computational and memory constraints. Standard static convolutional filters (i.e., weights fixed after training) are efficient but have a fundamental limitation: the same set of filter weights must process all input samples and cannot adapt to the acoustic characteristics of the input (such as speaker characteristics, noise conditions, speaking rate, etc.).

This "one-size-fits-all" strategy may lack flexibility in diverse input scenarios:
- Speech characteristics vary significantly across different speakers (male/female, adult/child, different accents)
- Speech characteristics differ under various environmental conditions (quiet/noisy, near-field/far-field)
- Acoustic patterns of different keywords have different feature distributions

Dynamic Filters can address this issue by generating input-dependent convolutional weights based on the input. However, existing dynamic filter methods typically have a large number of parameters (the conditional network itself can be large), making them unsuitable for lightweight applications like KWS.

The core problem this paper addresses is: How to design an extremely lightweight dynamic filtering mechanism that provides input-adaptive feature extraction capabilities for KWS models with almost no increase in model parameters and computational cost.

## Methodology

### Overall Architecture
The proposed Lightweight Dynamic Filter (LDF) is a plug-and-play module that can be integrated into any existing lightweight KWS CNN architecture (such as DS-CNN, BC-ResNet, etc.).

### Dynamic Filter Module Design
The core design idea of the LDF module is to decompose the dynamic filter into two branches to reduce the number of parameters in the conditional network:

1. **Conditional Network**:
   - Input: Channel statistics of the current feature map (channel descriptors after Global Average Pooling)
   - Structure: Two-layer fully connected network (FC -> ReLU -> FC -> Sigmoid)
   - Output: Dynamic filter weights or weight modulation coefficients
   - Parameter count is extremely small: containing only the parameters of two small FC layers

2. **Dual-Branch Decomposition**:
   - **Main Branch**: Standard depthwise separable convolution that processes the input feature map
   - **Dynamic Branch**: The filter weights generated by the conditional network modulate the output of the main branch
   - This decomposition avoids directly generating complete convolutional kernels (which would have too many parameters) and instead adjusts feature responses through modulation coefficients

### Mathematical Representation of the Dynamic Filter
Let the input feature map be $X$, the conditional network be $g(\cdot)$, and the main branch convolution be $f(\cdot)$:

- Channel statistics: $s = \text{GAP}(X)$, where GAP is Global Average Pooling
- Dynamic weights: $w = \sigma(W_2 \cdot \delta(W_1 \cdot s))$, where $\delta$ is ReLU and $\sigma$ is Sigmoid
- Dynamic output: $Y = f(X) * w$, using the dynamic weights $w$ for element-wise modulation along the channel dimension of the convolution output

The parameter count of this design is only $2 \cdot (C/r) \cdot C$, where $C$ is the number of channels and $r$ is the compression ratio (typically $r=4$ or $r=8$), which is far smaller than the parameter count of directly generating complete convolutional kernels.

### Integration Method
The LDF module can be inserted at different positions in a standard CNN architecture:
- **Front-end**: After the earliest convolutional layer, to adaptively enhance raw acoustic features
- **Mid-level**: After intermediate convolutional layers, to adaptively modulate intermediate features
- **Multi-layer Integration**: Using LDF simultaneously in multiple layers, with each layer's conditional network running independently

### Input Features
40-dimensional MFCC (Mel-frequency cepstral coefficients) are used as input features, which is the mainstream choice in the KWS field.

## Main Contributions

1. **Introduction of an extremely lightweight dynamic filtering mechanism designed for KWS**: Through dual-branch decomposition and a channel-statistics-based conditional network, the LDF module provides input-adaptive capabilities for KWS models with only about a 2% increase in parameters. This parameter efficiency allows LDF to be used under the strictest edge deployment constraints.

2. **Plug-and-play design**: The LDF module does not require modifications to the structure of the base architecture and can be easily integrated into any existing CNN-based KWS model, reducing engineering implementation costs.

3. **Proof that input-adaptive filtering benefits KWS**: Experiments show that even a simple adaptive mechanism implemented via a very small conditional network can bring considerable accuracy improvements, validating the necessity of input-adaptive processing in KWS.

4. **Consistent improvements across architectures**: Consistent improvements were observed on various base architectures (DS-CNN, BC-ResNet, etc.), indicating that the benefits of LDF do not depend on a specific backbone network.

## Experimental Results

### Datasets
- **Google Speech Commands v2**: 12-class classification task
- **Features**: 40-dimensional MFCC, approximately 49 time steps

### Main Performance
- **Accuracy**: LDF-enhanced DS-CNN achieved 95.6% accuracy on GSC v2 (12 classes)
- **Parameter Increase**: Only about 2% more parameters compared to the base model
- **Accuracy Improvement**: LDF brought a 0.5-1.5% accuracy improvement across all tested base architectures
- **Inference Latency**: Maintained low latency suitable for real-time applications; the additional computation of the conditional network is negligible

### Ablation Studies
- **LDF Position**: Inserting LDF at the mid-level performed better than at the front-end and back-end
- **Multi-layer LDF**: Using LDF simultaneously in 2-3 layers yielded the best results; benefits diminished after more than 3 layers
- **Compression Ratio $r$**: $r=4$ achieved the best balance between parameter efficiency and accuracy improvement
- **Conditional Network Input**: Using global average pooling statistics performed better than using the raw feature map as input to the conditional network

### Comparison with Attention Mechanisms
- The effect of LDF is comparable to or slightly better than SE (Squeeze-and-Excitation) attention
- LDF and SE attention can be used complementarily, with additional gains observed when stacked
- The parameter overhead of LDF is similar to that of SE attention

## Limitations and Future Work

### Technical Limitations
- **Insufficient evaluation of noise and far-field conditions**: The paper did not sufficiently evaluate the performance of LDF under noisy and far-field conditions. Theoretically, input-adaptive mechanisms should have more advantages under diverse acoustic conditions, but this lacks experimental verification
- **Interpretability of dynamic filters**: The modulation patterns learned by the conditional network were not analyzed—did it learn modulation strategies related to speakers, noise types, or pronunciation features?
- **Evaluation based solely on GSC**: All experiments were limited to the Google Speech Commands dataset

### Experimental Design Shortcomings
- Incomplete comparison with other adaptive mechanisms (such as CBAM, ECA, and other attention modules)
- Not evaluated in streaming inference scenarios
- Lack of deployment performance data after quantization

### Future Improvement Directions
- Verify the input-adaptive advantages of LDF on noisy datasets
- Explore temporal dynamic filtering (currently only channel dimension)
- Further compress the model by combining knowledge distillation
- Insights for the KWS field: Even extremely lightweight input-adaptive mechanisms can bring considerable performance improvements; this finding encourages the adoption of conditional computation strategies more frequently in KWS model design
