## Problem Statement

### Problem Background and Domain Pain Points

The task of keyword spotting (KWS) is to detect instances of a small set of predefined keywords spoken within potentially long recordings, while ignoring all other audio content (Section 1). This definition dictates two essential attributes of KWS: First, it is inherently an open-set classification task—the model must not only recognize a dozen target words but also reliably say "no" to infinite, unenumerable non-target content; second, the negative sample space is unseen at deployment, meaning any closed-vocabulary softmax classifier will produce uncontrollable false alarms on out-of-distribution audio. The paper cites typical applications including wake-up voice assistants, speech content retrieval in large databases, and continuous monitoring of audio streams such as radio communications (Section 1).

These applications impose three simultaneous, mutually constraining engineering requirements. First, the cost of registering a new keyword must be extremely low: many scenarios (e.g., temporarily monitoring specific words) provide only a few examples per word, totaling tens of seconds of audio, which constitutes a strict few-shot setting. Second, the system must handle completely unconstrained open-set negative samples, where continuous full-sentence speech contains target words, near-homophones, and irrelevant chatter. Third, downstream usage often involves human analysis, so the system cannot merely report "a keyword is here"; it must also accurately report the detected start and end times (on-/offset) (Section 1). The third point is often overlooked, but it is precisely the starting point for the entire method design.

The paper’s target is the mainstream paradigm of "sliding window segmentation plus neural network discriminative embeddings" (Section 1): audio is cut into fixed-size sliding windows, and each window independently passes through the network to extract embeddings for discrimination. The abstract clearly articulates the structural contradiction of this paradigm—the window must be long enough to contain all information required to recognize a keyword; however, longer windows are likely to contain multiple words or noise/irrelevant information, making it difficult to reliably estimate the start and end times of keywords; moreover, different keywords vary greatly in length, and a single fixed window length cannot simultaneously accommodate words of vastly different magnitudes like "night" and "credit card." In other words, window length selection is an unsolvable compromise: choosing a long window blurs boundaries and increases false alarms, while choosing a short window lacks sufficient information and increases missed detections.

### Specific Deficiencies of Existing Methods

Section 1 of the paper reviews existing routes one by one, with each deficiency corresponding to a class of methods:

- **ASR approaches using sequence-to-sequence losses**. Automatic speech recognition solves variable-length alignment problems using sequence-to-sequence losses like CTC, but training such losses requires sufficient data volume, making them naturally unsuitable for few-shot classification tasks (Section 1). Why: The supervision signal of CTC is built on "full-sentence transcription," and tens of seconds of training audio are far from enough for it to learn stable alignment statistics.
- **Pre-trained ASR systems / Pre-trained ASR embeddings**. Large models can be borrowed, but this requires collecting hours of training data in similar acoustic environments and brings significant computational overhead (Section 1). Why: Both of these directly conflict with the first engineering requirement of "low registration cost."
- **Classic template matching with handcrafted features and DTW**. Handcrafted speech features like Harmonic Frequency Cepstral Coefficients (HFCC) can be fed directly into Dynamic Time Warping (DTW) as 2D templates, which is a classic approach for query-by-example KWS; however, these unsupervised methods degrade rapidly in performance for very short words or harsh acoustic conditions (Section 1). Why: Handcrafted features do not contain task-discriminative information; short words have few frames and thin time structures available for DTW, and noise pollution distorts the spectral frame-by-frame distances globally.
- **Few-shot KWS and few-shot sound event detection based on prototype losses** (References [10]–[15]): These generally use neural networks to learn embedding functions, but inference still relies on fixed-size sliding window segmentation, inheriting all the problems of sliding windows (Section 1).
- **Authors' previous work [24]** (2021 ITG Speech): This work already proposed using a neural network to extract 2D embeddings from windowed speech segments as features for DTW. However, the embeddings trained in that work are mostly constant over time, making the time-warping capability of DTW virtually useless with a template trajectory that is approximately constant, and "many problems caused by sliding windows still exist" (original text from Section 1).

There are two additional related works as background: Reference [21] proposes immediately triggering a spike upon keyword detection and stopping analysis of the remaining input to save compute; Reference [23] uses DTW with handcrafted features to filter training data before training a neural network KWS. Neither addresses the core question of "whether the embedding itself should carry temporal structure."

### Key Challenges to be Solved by This Paper

In summary, the paper aims to solve four interlocking challenges simultaneously: First, how to make the embedding network output truly time-varying 2D embeddings, so that DTW templates carry the dynamic process of speech, rather than being temporally constant as in [24]; second, how to learn discriminative representations under the extreme few-shot condition of only five examples per word and a total of 39 seconds of training audio; third, how to accurately output start and end times while detecting keywords, rather than guessing boundaries via window edges or post-processing; fourth, how to avoid the trouble of per-word threshold tuning in practical systems with multiple keywords (per-word thresholds are neither realistic nor robust in few-shot scenarios, described as "very unrealistic" in the original text of Section 3.3).

## Methodology

### Overall Architecture Design and Design Motivation

The entire system is divided into three stages: frontend (preprocessing, segmentation, log-Mel spectrogram), embedding network (modified ResNet), and backend (sub-sequence DTW plus post-processing), with the overall flow shown in Figure 1. Figure 1 also color-codes the lifecycle of modules: blue modules are used only during training (position information encoding other than keyword label acquisition, time-axis reversal, data augmentation), yellow modules are used only during inference (extracting embeddings, computing cost matrices, sub-sequence DTW, post-processing of candidate matches), and red modules are shared by training and inference (raw waveform acquisition, preprocessing). This division of labor itself embodies the paper's design philosophy: "teach the network to understand time" during the training phase, and "let DTW align time" during the inference phase, with the interface between the two being the temporally structured 2D embedding.

**Frontend** (Section 2.1): All waveforms are converted to mono, amplitude-normalized to 1, resampled to 16 kHz, and high-pass filtered at 50 Hz. Isolated keyword samples used for training are cut into segments of length $L_{seg} = 0.25$ s with an overlap of $L_{seg}/256$ (as stated in the original text of Section 2.1); during inference, the inter-segment overlap is changed to 16,000 Hz/256 to obtain denser embedding outputs in time, improving temporal resolution. Zero-padding is applied to both sides of the samples (the quantity is an expression involving $L_{seg} \cdot 16000$ as per the original text, i.e., on the order of half a segment length) to ensure that the center of the cut segment aligns with its time position in the audio; samples shorter than one segment length are zero-padded. Features are taken as 64-band log-amplitude Mel spectrograms, using a 1024-point Hanning window and 256-point frame shift for STFT. Why 0.25 s: This length is sufficient to cover the main body of common single keywords (English words are mostly 0.3–0.7 s, so the segment only contains local parts of the word, which are then stitched together by DTW), and short enough to avoid easily containing two words simultaneously.

**Embedding Network** (Section 2.1): Follows the modified ResNet from [24]—4 groups, 2 residual blocks per group (8 in total), with 3×3 convolutions, frequency-dimension max pooling, and 20% probability dropout within each residual block; followed by frequency-dimension global max pooling and a fully connected layer without activation. The most critical structural constraint is **keeping the time dimension unchanged throughout**: through appropriate padding and without any temporal pooling, a 0.25 s segment goes in, and a 2D sequence of size $T \times D_{emb}$ comes out ($T$ is the number of time frames in the segment, $T = L_{seg} \cdot 16000/256$, approximately 16 frames; $D_{emb} = 128$, Section 2.2). The model without the loss part has only 713,486 trainable parameters (Section 2.1). Why insist on not compressing the time dimension: Once temporal pooling and flattening are performed inside the network (as done in the sliding window baseline, Section 3.2), the output collapses into a single vector, time information is consumed, and boundary accuracy is henceforth locked by the window length; after retaining the time dimension, the embedding sequence itself becomes the template for DTW, and frame-level alignment naturally provides boundaries, with the resolution of start and end times equal to the embedding frame rate rather than the window length.

**Training Configuration** (Section 2.1): 1000 epochs, batch size 32, Adam optimizer. Different keywords have different lengths, resulting in different numbers of cut segments, causing class imbalance, which is handled by random oversampling. Data augmentation uses Mixup (mixing coefficient sampled from a uniform distribution) plus SpecAugment. Additionally, random segments of background noise from SpeechCommands are added as an additional "no speech" class for training. Why add the noise class: In open-set tasks, "nothing" must be an explicit class; otherwise, the network will only push all inputs toward the nearest keyword×position combination, and false alarms cannot be suppressed; background noise segments have no position attributes, making them natural negative samples for "unknown position" for the position loss (see the uniform encoding processing in Section 2.3).

**Backend** (Section 2.1): The core is sub-sequence DTW. Embeddings of segments from the same audio signal are averaged frame-by-frame for temporally overlapping frames, and stitched together to form a template sequence covering the entire sentence; the cost matrix between the test sentence template and each training sample's template is calculated using pair-wise cosine distance. The authors also experimented with using the DBA (DTW barycenter averaging) algorithm to compute the Fréchet mean of all templates for the same keyword, but performance was worse than directly using the individual templates of each training sample (Section 2.1). Why averaging performs worse: In the five-sample scenario, intra-class variability (trajectory shapes of different speakers, different speaking speeds) is itself a matching basis that needs to be preserved; forcibly averaging into a single "average trajectory" compresses the multi-modal intra-class distribution into a uni-modal one, reducing coverage capability for test variants. DTW step patterns take (2,1), (1,1), (1,2) three types, allowing paths to locally stretch and compress on the time axis; the accumulated cost matrix can be calculated in parallel by scanning along the diagonal, and the paper claims the entire system is "much faster than real-time" (specific real-time rate values are not reported in the paper). For each time position, a warping path is calculated, and the accumulated cost is normalized by path length (eliminating cost bias for long/short paths), and the negative value is taken as the match score, compared with a preset threshold; exceeding the threshold is considered a detection, and the start and end points of the path are returned directly as the start and end times of the detected keyword. When multiple detections overlap in time, they are uniformly shortened to ensure that only the detection with the highest score is retained at each moment; detections with a duration less than half the duration of the corresponding training sample are discarded (Section 2.1). Why add these two post-processing steps: The former solves the problem of the same keyword being repeatedly triggered by adjacent start points, and the latter filters out intra-word fragments and noise spikes—too short "detections" are almost never complete keywords.

### Mathematical Principles of Core Algorithms

The TACos loss consists of two terms (Section 2.2, structure shown in Figure 2): the supervised term $L_{kw}$ is responsible for predicting which keyword a speech segment belongs to (same as [24]), and the self-supervised term $L_{pos}$ is responsible for predicting the relative position of this segment within the keyword. Why the second term is needed: When only supervised loss is used, embeddings are basically constant over time (original text of Section 2.2), and constant embeddings are degenerate templates for DTW—if all frames are identical, any warping path has the same cost, and DTW collapses into a single global nearest-neighbor comparison. The position term forces the embedding trajectory to vary over time, truly matching the usage of DTW.

**Relative Position Encoding**. Let $K$ be the total number of training samples, $N_{seg}(k)$ be the number of segments cut from the $k$-th sample, and $N_{pos} = \max_k N_{seg}(k)$ be the total number of position classes. The relative position label for the $i_{seg}$-th segment of the $k$-th sample is a soft one-hot:

$$y_{pos}(e_{k,i_{seg}}, i_{pos}) = \frac{1_{I_{active}(k,i_{seg})}(i_{pos})}{\sum_{j_{pos}=1}^{N_{pos}} 1_{I_{active}(k,i_{seg})}(j_{pos})}$$

where the active interval $I_{active}(k, i_{seg}) = [1 + \lfloor (i_{seg}-1) \cdot N_{pos} / N_{seg}(k) \rfloor,\ \lceil i_{seg} \cdot N_{pos} / N_{seg}(k) \rceil]$. Intuition: The segment index is divided by the total number of segments for that sample, mapped to the [0,1] interval, and then multiplied by $N_{pos}$ to obtain the relative position. Samples shorter than the longest sample will activate multiple positions simultaneously with equal probability, forming soft labels (Section 2.2). Why designed this way: Keywords vary in length, so absolute positions cannot share a set of class heads across words; only relative positions normalized by their respective lengths can cover all words with a fixed number of $N_{pos}$ position classes. And a segment of a short word inherently does not correspond to a unique relative position, so soft labels explicitly write this uncertainty into the target, rather than letting hard labels introduce systematic annotation noise.

**Similarity and Probability**. Let $N_{kw}$ be the number of keyword classes (including "no speech"), $y_{kw} \in [0,1]$ be the class label, $e \in \mathbb{R}^{T \times D_{emb}}$ be the embedding of a segment, and trainable cluster centers $c \in \mathbb{R}^{N_{cluster} \times N_{kw} \times N_{pos} \times D_{emb}}$ (without time dimension). The cosine similarity between embedding $e$ and the combination of (keyword $i_{kw}$, position $i_{pos}$) is defined as "take the max over clusters frame-by-frame, then average over time":

$$\theta(e, i_{kw}, i_{pos}) = \frac{1}{T} \sum_{t=1}^{T} \max_{i_{cluster}} \frac{\langle e(t),\, c(i_{cluster}, i_{kw}, i_{pos}) \rangle}{\|e(t)\|_2 \, \|c(i_{cluster}, i_{kw}, i_{pos})\|_2}$$

The corresponding softmax probability is

$$s(e, i_{kw}, i_{pos}) = \frac{\exp(\hat{s} \cdot \theta(e, i_{kw}, i_{pos}))}{\sum_{j_{kw}=1}^{N_{kw}} \sum_{j_{pos}=1}^{N_{pos}} \exp(\hat{s} \cdot \theta(e, j_{kw}, j_{pos}))}$$

where $\hat{s} \in \mathbb{R}^+$ is the dynamic adaptive scale parameter defined in the sub-cluster AdaCos loss [34]. The probability that the embedding belongs to keyword $i_{kw}$ is obtained by marginalizing over all positions: $\sum_{i_{pos}} s(e, i_{kw}, i_{pos})$; the probability that it belongs to position $i_{pos}$ is obtained by marginalizing over all keywords: $\sum_{j_{kw}} s(e, j_{kw}, i_{pos})$. The two cross-entropy losses are

$$L_{kw}(e) = -\sum_{i_{kw}=1}^{N_{kw}} y_{kw}(e, i_{kw}) \log \Big( \sum_{i_{pos}=1}^{N_{pos}} s(e, i_{kw}, i_{pos}) \Big)$$

$$L_{pos}(e) = -\sum_{i_{pos}=1}^{N_{pos}} y_{pos}(e, i_{pos}) \log \Big( \sum_{j_{kw}=1}^{N_{kw}} s(e, j_{kw}, i_{pos}) \Big)$$

The complete TACos loss first averages over segments, then averages over samples, and finally divides by the number of samples (Section 2.2):

$$L_{TAC} = -\frac{1}{K} \sum_{k=1}^{K} \frac{1}{N_{seg}(k)} \sum_{i_{seg}=1}^{N_{seg}(k)} \big( L_{kw}(e_{k,i_{seg}}) + L_{pos}(e_{k,i_{seg}}) \big)$$

In the experiment, $D_{emb} = 128$, $N_{cluster} = 16$ (Section 2.2). The paper reminds: The cluster center tensor significantly increases the total number of trainable parameters in the model (original text of Section 2.2; the total number of parameters including centers is not reported in the paper).

**Why choose angular margin loss instead of standard softmax cross-entropy**: AdaCos family uses dynamic scales in the cosine angle domain to pull apart inter-class angular distances and compress intra-class angular distributions; the geometric quantity optimized during training (cosine angle) is completely isomorphic to the metric used in the backend cost matrix (cosine distance). Consistency between training objectives and inference metrics is the key to stitching together the "embedding network" and "DTW backend" from a metric learning perspective—if training uses Euclidean softmax while inference uses cosine DTW, the two geometries do not match, and embedding quality will be compromised. **Why take max over clusters then average over time**: The same (word, position) combination corresponds to multiple acoustic realizations (formant patterns of different speakers, energy distributions at different speaking speeds); 16 cluster centers prevent the intra-class multi-modality from being averaged out by a single center; the max operation ensures that each frame aligns only with the most matching cluster, avoiding gradient pulling from sub-correlated clusters; time averaging ensures that discriminative power falls on the entire trajectory rather than a single frame, which aligns with the scoring method of DTW accumulating costs frame-by-frame.

### Key Technical Innovation 1: TACos Loss (Angular Margin Loss with Temporal Structure)

The core insight is that "the time dimension of embeddings must be supervisedly activated." In traditional approaches, the time dimension is merely an附带 dimension of the network output, with no loss term directly constraining "embeddings at different moments should be different," so training converges to the easiest solution: all frame outputs converge (because each frame shares the same classification target and the network has infinite collapse paths). $L_{pos}$ gives each time position a clear identity (relative position class), and for the network to simultaneously satisfy the two constraints of "is this word" and "is at this position," it is forced to unfold the embedding trajectory over time. Position labels are automatically derived from the segment indexing, requiring no additional manual annotation—a zero-annotation-cost self-supervised signal, which is also why it can be used in the five-sample setting. In terms of effects (Table 1, test set, global threshold): without reversal 64.65% vs 54.25%, with reversal 70.47% vs 61.30%, both are about 9 to 10 percentage points higher than the [24] scheme using only $L_{kw}$.

### Key Technical Innovation 2: Time-Reversed Segments as Additional Training Samples

The second modification is surprisingly simple: reverse all keyword segments along the time axis and add them as additional training samples (Section 2.3). The idea is to force the network to recognize the correct time order—i.e., forcing "reversed keywords" and "forward keywords" to be treated as different classes. The task becomes harder: the network can no longer get away with the overall timbre of the word or bag-of-frames features, but must truly rely on temporal direction cues to predict keywords and positions, thereby learning more informative embeddings and reducing false detections (original text of Section 2.3). Specifically, an independent reversal label is introduced for each keyword class except "no speech," almost doubling the number of classes; the positions of reversed segments and no-speech segments are encoded with uniform posterior probabilities on the position classes (Section 2.3). Why uniform distribution: Reversed segments do not have a well-defined "forward position," and no-speech segments do not belong to any position at all; uniform distribution is equivalent to "position unknown," causing $L_{pos}$ to produce almost no gradient pressure on these samples, concentrating supervision pressure on $L_{kw}$'s "this is not any forward keyword," with the two signals not polluting each other. It is worth emphasizing (original text of Section 3.3): This gain is achieved on top of two strong augmentations, Mixup and SpecAugment—time reversal provides a signal that neither of these augmentations can provide (temporal directionality), and is orthogonal to the former two. In terms of effects (Table 1, test set, global threshold): sliding window 44.83% vs 38.35%, $L_{kw}$ embedding 61.30% vs 54.25%, TACos 70.47% vs 64.65%, each method consistently improves by about 6 to 7 percentage points.

### Key Technical Innovation 3: System Integration of Frame-by-Frame 2D Embeddings and Sub-sequence DTW

The third innovation is at the system level: assembling "network structure without temporal pooling, template stitching by averaging temporally overlapping frames, sub-sequence DTW with path-length normalization, post-processing of retaining the highest score for overlaps and filtering out detections shorter than half the duration" into a complete pipeline (Figure 1, Section 2.1), making start and end times a byproduct of detection rather than an additional estimation task—the start and end points of the DTW path are the boundaries, at zero extra cost. In contrast, the sliding window baseline (Section 3.2) needs a whole set of post-processing to provide boundaries: cosine distance of embeddings to keyword centers exceeds threshold to get boolean decision, then median filtering smoothing (filter window length equals the average number of segments of all training samples for that word, rounded to the nearest odd number), and the start and end points of positive regions are each extrapolated by half a segment length. Every hyperparameter in this rule chain relies on fragile priors like "keyword duration statistics," whereas TACos boundaries come directly from the alignment path itself. Furthermore, normalizing accumulated cost by path length makes scores comparable across different words, which is the mechanistic root of the conclusion in the following text that "a single global threshold is sufficient to work, without per-word tuning" (Section 3.3).

### Technical Differences with Existing Methods

- **Compared to prototype-loss-based few-shot KWS ([10]–[12], etc.)**: They learn single-point embeddings for the entire segment and rely on sliding windows for inference; TACos learns frame-by-frame 2D embeddings and relies on DTW alignment for inference, changing boundary resolution from window length to frame rate.
- **Compared to CTC / Pre-trained ASR routes ([17]–[20])**: Those methods exchange alignment capability for large amounts of data or large models; TACos exchanges temporal structure for 39 seconds of data plus a self-supervised position term, with registration costs of completely different orders of magnitude.
- **Compared to classic schemes of HFCC plus DTW ([22], [32])**: Templates are also 2D time series, and DTW is also used, but HFCC is unsupervised handcrafted features, with discriminative power unrelated to the task; TACos templates are discriminatively trained embeddings, and the training objective and inference metric are both cosine geometry. HFCC is extracted with a 40 ms window and 10 ms step (Section 3.2).
- **Compared to authors' previous work [24]**: Both belong to the "embedding fed to DTW" framework, but [24] only has $L_{kw}$ and temporally constant embeddings; TACos adds two orthogonal improvements, $L_{pos}$ and reversed segments, which are the source of all incremental contributions in this paper.
- **Compared to Reference [23]**: [23] uses DTW with handcrafted features to generate training data before training a discriminative network, with DTW used only in the data preparation stage; TACos keeps DTW in the inference link, directly enjoying boundary accuracy brought by frame-level alignment.

## Experimental Results

### Datasets Used and Their Scale

All experiments are conducted on KWS-DailyTalk, released synchronously with the paper (Section 3.1), built based on the ASR dataset DailyTalk [25] (conversational speech synthesis corpus), which is open-sourced (github.com/wilkinghoff/kws-dailytalk). This is a five-shot KWS dataset, detecting 15 keywords: afternoon, airport, cash, credit card, deposit, dollar, evening, expensive, house, information, money, morning, night, visa, yuan. The training set contains 5 isolated samples per keyword, with a total duration of only 39 seconds (15 words × 5 samples = 75 items). The validation and test sets each contain approximately 10 minutes, comprising 156 and 157 sentences taken from conversations, respectively; sentences may contain no keywords, one keyword, or multiple keywords, and also include other words that may cause false alarms; each keyword appears approximately 12 times in both the validation and test sets; start and end times for all keywords are manually annotated. Additionally, the dataset design includes an anti-leakage constraint: training samples for a keyword and sentences containing that word in the validation/test sets do not belong to the same conversation, making the task closer to real registration scenarios and slightly harder (Section 3.1). Why build a custom dataset: Existing KWS datasets (such as SpeechCommands [26]) do not satisfy the combination protocol of "isolated word training + full sentence testing + open-set + manual boundary annotation" (Section 1), and this protocol corresponds exactly to the challenges this paper aims to solve.

### Definition and Rationale for Evaluation Metrics

Event-level, micro-averaged F-score is used, implemented by the sed_eval toolbox (Section 3.1), with precision and recall also reported (Table 1). Rationale: Event-level metrics require the start and end times of detected events to align with manual annotations within a tolerance to count as a hit, while penalizing false alarms (suppressing precision) and missed detections (suppressing recall), strictly corresponding to the application requirement that "KWS must provide boundaries for human analysis"—frame-level metrics would overestimate the performance of systems with blurred boundaries, and pure detection rate metrics would completely ignore boundary quality. Micro-averaging ensures that the overall score is dominated by the total number of events, so words with few occurrences do not disproportionately influence the conclusion. All hyperparameters are tuned on the validation set (Section 3.1), and the test set is used only for final evaluation.

### Findings from Ablation Experiments

Table 1 itself is a 2×2×2 ablation matrix (loss: $L_{kw}$ vs $L_{kw}+L_{pos}$; reversed segments: No vs Yes; threshold: Global vs Per-word), from which four findings can be extracted:

1. **Net contribution of position loss $L_{pos}$ is about 9–10 percentage points** (controlling for reversed segments and threshold): Under global threshold on test set, without reversal 64.65% vs 54.25% (+10.40 percentage points), with reversal 70.47% vs 61.30% (+9.17 percentage points); under per-word threshold, there are also +10.27 and +8.63 percentage points respectively. This is the gain brought by "temporal structure" itself (rather than doubling training data), and is the core causal evidence of the paper.
2. **Net contribution of time-reversed segments is about 6–10 percentage points, and is method-independent**: Under global threshold on test set, sliding window +6.48 (44.83 vs 38.35), $L_{kw}$ +7.05 (61.30 vs 54.25), TACos +5.82 (70.47 vs 64.65); under per-word threshold, sliding window is as high as +9.98 (50.42 vs 40.44). The paper specifically emphasizes that this gain holds even on top of two strong augmentations, Mixup and SpecAugment (Section 3.3), indicating that temporal directionality is an orthogonal signal that conventional augmentations do not cover.
3. **Per-word thresholds only benefit sliding window, while the proposed methods slightly decrease**: On the test set, sliding window rises from 44.83% to 50.42%, while TACos slightly drops from 70.47% to 69.16%, and $L_{kw}$ drops from 61.30% to 60.53%. From this, the paper draws an engineering-valuable conclusion: this method works with a single global threshold, avoiding per-word tuning—per-word threshold tuning is "very unrealistic" in few-shot registration scenarios (original text of Section 3.3). Mechanistic explanation: The score distribution of sliding windows drifts with word length and center distance scale, requiring per-word calibration; path-length normalization of DTW makes scores comparable across words, so a global threshold is sufficient.
4. **Two secondary findings on template averaging and training data scale**: Using DBA to compute intra-class Fréchet mean templates is worse than per-sample templates (Section 2.1, specific numbers not reported in the paper); and under 39 seconds of training audio, discriminatively trained embeddings completely exceed handcrafted HFCC features (Table 1), indicating that "supervised discriminative representations" still outperform "unsupervised handcrafted representations" under small data conditions.

## Main Contributions

1. **TACos Loss Function**: A novel angular margin loss that trains 2D embeddings preserving speech temporal structure through a dual-head structure of "keyword supervision + relative position self-supervision"; position labels have zero annotation cost and are compatible with dynamic scales of sub-cluster AdaCos and multi-cluster center design (Section 2.2, Figure 2).
2. **Complete DTW Few-Shot KWS System**: Frame-by-frame 2D embeddings as DTW templates, sub-sequence DTW scoring with path-length normalization, post-processing of retaining the highest score for overlaps and filtering out detections shorter than half the duration, with start and end times directly provided by the alignment path, working with a single global threshold (Section 2.1, Section 3.3).
3. **KWS-DailyTalk Open Dataset and Open-Set Evaluation Protocol**: Isolated word training (5 samples per word, 39 seconds total) plus full conversation sentence testing (validation and test each about 10 minutes, 156/157 sentences, each word about 12 times), manual boundary annotation, cross-conversation anti-leakage design, filling the gap in this evaluation combination (Section 3.1).
4. **Transferable Empirical Conclusions**: Time-reversed segment training is consistently effective for sliding windows, previous embeddings, and TACos embeddings, and is orthogonal to Mixup and SpecAugment (Table 1, Section 3.3)—this conclusion does not depend on the system in this paper and can be directly borrowed by any temporal embedding learning.

## Limitations and Future Work

### Technical Limitations of the Method

- **Parameter overhead of cluster centers**: The dimension of the center tensor is $N_{cluster} \times N_{kw} \times N_{pos} \times D_{emb}$, growing linearly with the number of keywords and position classes; the paper itself admits it "significantly increases the total number of trainable parameters in the model" (Section 2.2); the total number of parameters including centers is not reported in the paper. This part will become considerable when the vocabulary expands to hundreds of words.
- **Noise in position labels**: Relative positions are calculated proportionally from segment indices, implicitly assuming "uniform speaking speed, no internal pauses"; real speaking speed variations and intra-word pauses will cause systematic shifts in labels, and soft labels for short words further dilute the supervision signal. The paper does not perform label noise sensitivity analysis.
- **Backend computation grows linearly with registered samples**: Cost matrices need to be calculated one by one for each training sample template (5 templates per word), and the reversal class almost doubles the number of classes (Section 2.3) which is also reflected in the training classification head scale; the paper only qualitatively claims the system is "much faster than real-time" (Section 2.1), without reporting specific real-time rates, single-sentence inference time, or template number scalability curves.
- **Threshold is still a preset quantity**: Although per-word tuning is avoided, the global threshold still needs to be calibrated on the validation set (Section 3.1 "all hyperparameters tuned on validation set"), and threshold drift issues in cross-domain deployment are not discussed.
- **Post-processing rules are manually designed**: Retaining the highest score for overlapping detections, discarding detections shorter than half the duration of the training sample (Section 2.1), the hyperparameters of these two rules ("half") lack ablation support.

### Deficiencies in Experimental Design

- **Single dataset, self-built self-evaluated**: Training, validation, and test all originate from DailyTalk conversational corpus, without cross-corpus (e.g., training on SpeechCommands, testing on KWS-DailyTalk) generalization evaluation, and the external validity of conclusions relies on the acoustic characteristics of a single corpus.
- **Only clean conditions**: All experiments are conducted on nearly clean conversational speech, without evaluation with noise, reverberation, far-field—the authors list this as future work in the conclusion (Section 4). This contrasts with the criticism of the HFCC route that it "degrades rapidly in harsh acoustic conditions" (Section 1): this paper does not prove that it outperforms HFCC under harsh conditions.
- **No statistical significance reported**: Each word appears only about 12 times in the validation/test sets (Section 3.1), and event-level metrics have considerable random fluctuations at this scale; the paper does not report variance or confidence intervals for multiple runs, and some gaps (e.g., direction inconsistency between test set 70.47% vs 69.16%, validation set 65.78% vs 69.44%) are difficult to judge as significant.
- **Lack of strong external baselines**: Only motivational citation comparisons are made with pre-trained ASR embedding methods (such as [20]), without actual measurement; no comparisons are seen with other neural network template methods in the query-by-example field, and comparison objects are limited to handcrafted features, own previous work, and sliding window variants.
- **Hyperparameter sensitivity not reported**: Key values such as $N_{cluster} = 16$, $D_{emb} = 128$, segment length 0.25 s, 64 Mel bands have no ablation (not reported in the paper).

### Possible Directions for Future Improvement

The paper's conclusion (Section 4) explicitly gives two directions: first, evaluate the proposed method under noisy conditions; second, extend to zero-shot KWS—pre-training embeddings on large-scale ASR datasets (as in [20]), and/or replacing Mel spectrograms with pre-trained ASR embeddings as network input, thereby摆脱ing dependence on training samples for registered words. Combining a full reading of the paper, the author believes there are several directions worth extending: systematic ablation on $N_{cluster}$, $D_{emb}$, and segment length to clarify the respective contributions of temporal structure and capacity; improving DBA-like template averaging to weighted or selective averaging (compressing template numbers while preserving multi-modality); introducing learnable score normalization or temperature calibration to make global thresholds more stable across domains; and upgrading relative position encoding from uniform calculation to soft targets based on forced alignment, reducing label noise under speaking speed variations. These are all extensions by the author based on the original text, and the paper itself does not elaborate on them.
